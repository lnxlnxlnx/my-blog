# 教学约定（汇编课程）

## 与用户确认的偏好（承接 course/linux 的访谈结论）

- 动手为主；先上手看结果，再查指南。
- 目标：把"看过没写过寄存器"补成"亲手写过"——汇编点是绕不开的第一站。
- 单板安全：汇编阶段**只烧 SD 卡**，不动 eMMC；先备份再烧。链接地址用 0X87800000（正点原子惯例，DDR 起始 0x80000000）。
- 工具链：`arm-linux-gnueabihf-*`（`source /opt/fsl-imx-x11/4.1.15-2.1.0/environment-setup-...` 后可用）。

## 课程设计原则

1. 紧扣 Linux 课需要：主流寄存器读写、点灯四步、按键轮询、start.S 套路。
2. 每课 = 一个能"编译 + objdump 反汇编"验证的小片段；能上板才上板。
3. 每课页面带「上一节 / 课程目录 / 下一节」导航（与 course/linux 一致）。
4. 编号：lessons/`NNNN-slug.html`（A01..A06）、learning-records/`NNNN-slug.md`。
5. 视觉：复用 assets/lesson.css + VSCode Light 高亮三件套。

## 与课程指南章节对应

- A01 工具链+第一个 led.s ↔ 第 4/7/8 章
- A02 寄存器与模式 ↔ 第 6 章
- A03 指令与寻址 ↔ 第 7 章
- A04 分支·循环·延时 ↔ 第 7 章（led.s 延时循环）
- A05 栈与汇编调 C（start.S + main.c）↔ 第 10 章
- A06 按键轮询综合 ↔ 第 15 章

## 待核实前置条件

- 板子当前启动拨码/是否能从 SD 启动；烧录用 imxdownload 是否就位（正点原子资料盘 5、开发工具）。
- 若暂时不想烧录：本课练习用 objdump 反汇编代替"上板看灯"，也能完成 80% 的学习目标——先编译先验。

汇编术语表

收录 A 系列课程会用到的术语；未用过的没列。和 Linux 课术语表是两套，但互通。

汇编器 / 链接器 / 格式转换: 分别把 .s 编译成 .o(gcc)、把 .o 按地址放好成 .elf(ld)、把 .elf 剥成纯二进制( objcopy .bin)。烧录只认 .bin。

链接地址: 代码运行时要被放置的内存地址。裸机链接到 0X87800000（DDR 起始 0X80000000 之上），u-boot 把内核放到 0X80800000，道理相同。

全局标号（.global _start）: 声明一个符号对链接器可见（别的文件能引用、链接器能找到入口）。裸机/内核入口都叫 _start。

立即数: 指令里直接嵌的常量，写法 #5、#(1<<3)。ARM 对立即数的编码有限制，但 ldr = 伪指令绕开它装任意 32 位常量。

伪指令: 汇编器替你"变魔法"的写法，如 ldr r0, =值 会被转成一条真正的取常量指令（常用"从字面池 ldr [pc,#…]"），不是真实 ARM 指令名。别和真 ldr 混淆。

寄存器寻址 / 内存寻址: 操作对象在寄存器里(add r3,r1,r2) 还是内存里(ldr r3,[r1])。外设寄存器操作 = 拿地址 → 读/写 [地址]。

条件执行 / 条件后缀: 指令可以带 eq/ne 等后缀，仅在 CPSR 对应标志满足时才执行。ARM 特色，让常见分支少跳几次。

标志位（N/Z/C/V）: CPSR 里由比较/算术指令设置的状态。Z=结果为零；C=进位/借位；N=结果负；V=溢出。beq 看 Z。

栈 / 栈指针 SP: 一段后进先出的内存区，SP 指向顶端，满递减（从高地址往下长）。函数局部变量/保存现场/返回地址都在这。

链接寄存器 LR: r14。bl 把返回地址存进 LR，子程序结束 mov pc,lr 或 bx lr 返回。深层嵌套要压栈保存 LR。

填栈/弹栈（push/pop、stmfd/ldmfd）: 把寄存器现场存进栈/恢复。函数调用前保存需要保护的寄存器（尤其 LR 和用到的 r*），返回前恢复。栈指针自动增减。

看门狗（WDOG）: 硬件"防死机狗"：必须周期性喂（写某些位），超时不喂自动复位系统。start.S 先关掉它，调试期才安定。

轮询 vs 中断: 轮询=CPU 反复读判断（吃 CPU 但简单）；中断=硬件主动通知（省 CPU 但需要异常处理）。裸机按键常用轮询，Linux 驱动用中断（见 Linux 课 L06）。

消抖: 机械按键按下瞬间的颤动噪声（几十 ms），软件上"检测后再延时确认一次"过滤掉。

## 三个最基础的概念

1. **App 由 C++ 启动 + QML 画界面**：`main.cpp` 创建 `QQmlApplicationEngine` 加载 `main.qml`，界面全部用 QML 写。
2. **C++ 给 QML 提供能力**：摄像头、GPIO、网络等底层能力用 C++ 实现，通过 `qmlRegisterType` 或 `contextProperty` 暴露给 QML 调用。
3. **App 嵌入 systemui 桌面**：每个 App 的 `AppMainBody.qml` 是入口界面，通过 `client/Client.qml` 与 systemui 协调显示（隐藏桌面、返回按钮、退出）。

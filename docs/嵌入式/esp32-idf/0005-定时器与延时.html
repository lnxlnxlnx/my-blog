定时器与延时

ESP-IDF 课程 · 课程 0005 · 预计 15 分钟

STM32 里你有 SysTick、TIM、HAL_Delay。ESP32 世界里有三层"时间":FreeRTOS ticks、esp_timer、硬件定时器(gptimer)。分清它们,才不会在看 xiaozhi 代码时晕。

知识点 1:三层时间体系

机制精度用途STM32 类比
vTaskDelay / pdMS_TO_TICKSms 级任务里"让位睡觉"HAL_Delay
esp_timer(软件定时器)µs 级回调定时任务,不占任务栈TIM + 回调
gptimer(硬件定时器)ns 级精确 PWM/测量TIM 高级定时器

知识点 2:esp_timer(最常用)

static void tick_cb(void *arg) {
    ESP_LOGI(TAG, "tick!");          // 在 esp_timer 任务上下文执行
}
esp_timer_create_args_t args = { .callback = tick_cb };
esp_timer_handle_t t;
esp_timer_create(&args, &t);
esp_timer_start_periodic(t, 1000 * 1000);  // 每 1 秒(µs 为单位)

注意:esp_timer 回调跑在系统任务里,不能做阻塞操作——和 STM32 中断回调一个脾气。

知识点 3:测量时间戳

int64_t now = esp_timer_get_time();  // µs 时间戳,常用于性能测量

动手

去 basic_routines/05_esp_timer(或 06_gp_timer)看例程:对照上面的三层体系,说出这个例程用了几种"时间"机制、各是什么。再看 02_key 例程,猜猜按键消抖为什么不用 HAL 式 delay。

小测验

Q1

esp_timer 回调里能做长时间阻塞吗?

不能,它跑在系统任务里,阻塞会卡住其他定时器。

Q2

esp_timer_get_time 返回的单位是?

微秒(µs),int64_t 类型。

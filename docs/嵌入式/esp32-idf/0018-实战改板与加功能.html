实战收尾：改自己的板子

ESP-IDF 课程 · 课程 0018 · 预计 30 分钟

收尾课。目标:把你的面包板组合板"再定义"一遍——完成一次真实的改动、编译、烧录,证明 17 课的知识能闭环。

任务 1:加一个"板载呼吸灯"功能

在 basic_routine_3/07_ledc(LEDC 硬件 PWM)基础上,把呼吸灯例程看懂:LEDC 定时器/通道/占空比是配置结构体的哪几个字段。看懂了,这个技能就能移植到任何板。

任务 2:给 xiaozhi 换一个屏(或加一个提示音)

选一:

  • 换屏:按 0015 课,改 boards/bread-compact-wifi/config.h 的 I2C 引脚(或 config.json 换 128x64 变体),重新 python scripts/release.py bread-compact-wifi 出固件
  • 加提示音:在 main/assets 里放一个 wav,找到资产打包脚本(scripts/build_default_assets.py)注册它,在状态机某事件里触发播放——顺路复习 0012/0016 的音频链路

任务 3:自问自答(考官模式)

不看资料,回答这 6 题(每题一句话):

  1. app_main 为什么不写 while(1)?
  2. 改引脚去哪个文件?sdkconfig 能进 git 吗?
  3. vTaskDelay 和 HAL_Delay 的区别?
  4. 唤醒词在哪检测?音频帧在 WebSocket 里怎么传?
  5. OTA 双分区+回滚保护解决了什么问题?
  6. 你的板子 PSRAM 多大?去哪查?

交作业

把改动的文件清单 + 串口日志(关键几行)+ 6 题答案发我,我给你打分并指出下一阶段的"补课点"。之后可以选:① 深入音频/AFE 源码;② 把 xiaozhi 协议文档逐条精读;③ 换非 IDF 路线(裸机/其他框架)。

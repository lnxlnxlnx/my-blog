# 嵌入式工程师工具箱 课程资源

## Knowledge

- [《STM32 启动文件浅析 V1.2》— 正点原子](参考文档/other/STM32 启动文件浅析_V1.2.pdf)
  启动文件（startup_xxx.s）逐段解析：栈堆、向量表、复位程序、_main、启动流程。**用**：第 3 课。

- [《STM32 MAP 文件浅析 V1.1》— 正点原子](参考文档/other/STM32 MAP文件浅析_V1.1.pdf)
  MDK 编译产物与 MAP 文件五大组成部分（交叉引用/未使用段/符号表/内存分布图/组件大小）。**用**：第 1、2 课。

- [《STLINK 调试补充教程》— 正点原子](参考文档/other/STLINK调试补充教程.pdf)
  ST-Link 驱动安装、MDK 配置（JTAG/SWD）、固件升级。**用**：第 4 课。

- [《嵌入式单片机 C 代码规范与风格 V1.1》— 正点原子](参考文档/other/嵌入式单片机 C代码规范与风格_V1.1.pdf)
  排版格式、注释、命名、函数、变量、宏的规范。**用**：第 5~7 课。

- [《BMP 图片文件详解》](参考文档/other/BMP图片文件详解.pdf)
  位图/调色板概念与 BMP 文件结构。**用**：第 8、9 课。

- [《WAV 文件格式分析与应用》](参考文档/other/WAV文件格式分析与应用.pdf)
  RIFF 概念、WAV 结构（fmt/data chunk）、实例分析。**用**：第 11 课。

- [《E文 JPEG 编解码介绍》（ISO/IEC 10918-1 英文原版）](参考文档/other/E文JPEG编解码介绍.pdf)
  JPEG 标准原文，含 DCT、量化、霍夫曼编码定义。**用**：第 13、14 课（挑核心章节中文讲解）。

- [《GIF Decoder》英文文章](参考文档/other/GIF Decoder.pdf)
  GIF 文件结构与 LZW 压缩解码器实现（C++ 示例）。**用**：第 15 课。

- [《can 入门教程》— 瑞萨电子](参考文档/other/can入门教程.pdf)
  CAN 协议官方入门：特点、报文格式、仲裁、位时序、错误处理。**用**：第 16~19 课。

- [《电脑游戏机硬件与编程特技》](参考文档/other/电脑游戏机硬件与编程特技.pdf)
  ⚠️ 扫描版无文字层，暂无法使用，课程未包含。

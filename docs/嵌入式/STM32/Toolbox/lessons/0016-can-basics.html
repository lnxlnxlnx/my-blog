第 16 课：CAN 入门：物理层与特点

两根线读懂差分信号：CAN 是怎么做到"多主 + 抗干扰"的（瑞萨《CAN 入门教程》第 3~6 章）

本课目标：把 CAN 当成一条"会自己排队的总线"来认识。学完你能说清 CAN 是什么、它比 UART/SPI 强在哪（多主、仲裁、差分信号、错误恢复），能画出带 120Ω 终端电阻的三节点总线拓扑，并解释"为什么 CAN 要用差分信号"——这是后面读懂报文、调 bxCAN 外设的地基。

1. CAN 是什么

CAN 是 Controller Area Network（控制器局域网）的缩写，是 ISO 国际标准化的串行通信协议（PDF p.2）。1986 年，德国博世公司为了解决汽车线束太多、又要高速可靠通信的问题，开发了它；之后通过 ISO11898 和 ISO11519 标准化，现在已经是欧洲汽车网络的标准协议，也广泛用在工业自动化、船舶、医疗设备等领域。

一句话记住它：两根差分线，挂很多节点，谁有数据谁就能广播——总线上没有"主从"，只有"先后"。

2. 应用示例

教材第 3 章给了两个图（PDF p.2~3）：

  • 车载网络构想（图 1）：一辆车被网关分成多个子网——动力/底盘用 500kbps 的高速 CAN，车身/信息部用 125kbps 的 CAN，再加上 LIN（19.2kbps）、MOST、FlexRay（5Mbps）各司其职。不同速率、不同用途的网络靠网关交换数据。
  • 应用示例（图 2）：发动机控制、仪表集群、空调、车门（后视镜/门锁/电动车窗）、座椅、车顶（天窗）…… 十几个 ECU 全挂在同一根 CAN 总线上共享信息。

到了工业领域，CAN 演变成你更熟悉的兄弟：DeviceNet、CANopen（工业设备）、SAE J1939（卡车/农用机械）、NMEA-2000（船舶）——协议栈不同，但底层都是这条 CAN 总线。

3. CAN 的八大特点

教材第 4 章总结了 CAN 协议的特点（PDF p.5），挑核心的说：

特点一句话
多主控制总线空闲时，任何单元都能开始发消息（CSMA/CA 方式），没有固定的主站
消息固定格式所有消息都按固定格式发送，优先级由 ID 决定，同时发送时逐位仲裁
系统柔软性节点没有"地址"，增减节点不影响其它节点的软硬件
通信速度可设按网络规模设定速度；但同一网络必须统一速度
远程数据请求能发"遥控帧"主动向别的节点要数据
错误检测/通知/恢复任何节点能检测错误、立即通知全总线、发错了自动重发
故障封闭能区分"暂时噪声"和"持续故障"，把坏节点从总线上隔离出去
连接理论上节点数不限，实际受时间延迟与电气负载限制（降速能挂更多）

4. 通信状态与数据：显性 / 隐性

CAN 控制器靠两根线（CAN_H、CAN_L）之间的电位差判断总线电平（PDF p.4, 15）。总线电平只有两种：

  • 显性电平（Dominant）：逻辑值 0，CAN_H 高、CAN_L 低，电位差约 2V——"显性"很霸道，只要有一个单元输出显性，总线上就是显性
  • 隐性电平（Recessive）：逻辑值 1，CAN_H 和 CAN_L 都在 2.5V 左右，电位差约 0V——"隐性"很随和，所有单元都输出隐性时总线才隐性

这就是"总线上的线-与（wired-AND）"：显性（0）覆盖隐性（1），0 比 1 更"强"。这个特性是后面讲仲裁的基础——记住它，第 17 课你会用到。

5. 总线拓扑与终端电阻

CAN 是多主广播式总线（PDF p.4, 14~15）：

  • 拓扑：双绞线 + 闭环总线，两端各接一个 120Ω 终端电阻（ISO11898 高速，阻值 85~130Ω 均可）
  • 终端电阻的作用：吸收信号到达线端的反射，不然波形振铃、误码率飙升
  • 速度与长度成反比：1Mbps 时最长 40m；降到 40kbps 能到 1km（PDF p.14 图 8）
  • 低速容错型 ISO11519-2 用开环总线 + 2.2kΩ 终端电阻，后面第 17 课再对比

你的 F407 探索者板上已经有 CAN 收发器（如 TJA1050）和 120Ω 匹配电路，接上外部 CAN 总线时只要两端各有一个 120Ω 就行——板上一般都帮你放好了。

代码示例

下面两段小 C 代码，把"线-与"和"差分判断"这两个概念翻译成代码，帮你内化。

/* 模拟总线"线-与"：显性(0)覆盖隐性(1) */
typedef enum { RECESSIVE = 1, DOMINANT = 0 } CAN_Level;

CAN_Level bus_wire_and(CAN_Level a, CAN_Level b)
{
    /* 只要有一个是显性(0)，总线就是显性(0) */
    return (CAN_Level)(a & b);
}

/* 两个节点同时输出时，总线电平 = 二者电平的"与" */
CAN_Level level = bus_wire_and(DOMINANT, RECESSIVE);   /* 结果是 DOMINANT */

/* 用 CAN_H 与 CAN_L 的电位差判断总线电平（ISO11898 高速，单位 V） */
typedef enum { BUS_RECESSIVE, BUS_DOMINANT } BusLevel;

BusLevel decode_can_level(float vh, float vl)
{
    float diff = vh - vl;
    if (diff > 1.5f) return BUS_DOMINANT;   /* 差压明显 → 显性 */
    if (diff < 0.05f) return BUS_RECESSIVE; /* 差压≈0 → 隐性 */
    return BUS_RECESSIVE;                    /* 不确定时按隐性处理（fail-safe） */
}

💡 记忆锚点：显性 = 0 = 霸道 = 优先；隐性 = 1 = 随和 = 包容。谁嗓门大（显性）总线就听谁的；大家都不说话（都隐性）总线才安静。

⚠️ 同一网络的所有节点必须统一波特率。哪怕只有一个节点速度不对，它也会不断输出错误信号，把整个网络的通信拖垮（教材 p.5"通信速度"一条）。不同网段之间倒可以用不同速度——这正好解释了图 1 里为什么一辆车要分 500k/125k 好几张网。

3️⃣ 对照教材 p.4 图 3，检查：终端电阻是不是只在两端？节点是不是挂在中间而不是一端？

练习 16.2：为什么用差分信号？

1️⃣ 假设电机启动瞬间给总线叠加上 1V 共模噪声（两根线上同时 +1V）。

2️⃣ 推导：接收端读的是 CAN_H − CAN_L 的差。两根线同时加 1V，差变了吗？

3️⃣ 对比单端信号（如 TTL 3.3V，0/1 靠绝对电压判断），说说为什么汽车环境里 CAN 更抗干扰。

随堂小测

Q1. CAN 是哪个英文词的缩写？

A. Controller Area Network

B. Control Access Network

C. Common Area Network

查看答案
A。Controller Area Network，控制器局域网（PDF p.2）。

Q2. 显性电平对应的逻辑值是多少？

A. 逻辑 1，随和包容

B. 逻辑 0，霸道优先

C. 逻辑 0，表示空闲

查看答案
B。显性电平逻辑值为 0，谁输出显性总线就是显性（PDF p.15）。

Q3. 关于总线"线-与"，正确的说法是？

A. 全部显性时总线才显性

B. 一个显性就能让总线显性

C. 显性需超过半数的节点

查看答案
B。显性（0）覆盖隐性（1），只要有一个节点输出显性，总线电平就是显性（PDF p.15, 22）。

Q4. 高速 CAN（ISO11898）终端电阻两端各是多少？

A. 两端各 120Ω，吸收信号反射

B. 两端各 2.2kΩ，限流保护

C. 只在中间接一个 120Ω

查看答案
A。ISO11898 高速 CAN 用闭环总线，两端各 120Ω 终端电阻抑制反射（PDF p.14）。

第 18 课：CAN 位时序与错误处理

采样点定在哪？错误计数怎么涨？——让总线稳定可靠的底层机制（瑞萨《CAN 入门教程》第 5、8.8~8.9 章）

本课目标：上一课看清了"帧"，这一课拆开"位"。学完你能说出一个位的四段结构（SS/PTS/PBS1/PBS2）和采样点位置，手算波特率与采样点，列出 CAN 的五种错误，并说清"主动错误 → 被动错误 → 总线关闭"三级状态机是怎么用计数管起来的——这正好是你调 bxCAN 波特率、排查总线异常的理论弹药。

1. 位时序：一个位拆成四段

CAN 的通信方法是 NRZ（Non-Return to Zero）——位与位之间没有独立的同步信号（PDF p.42）。发送单元按自己的位时序发，接收单元靠总线上的电平边沿来同步。一个位被分成 4 段（PDF p.40）：

段作用Tq 数
SS 同步段大家用它对齐时序，电平边沿最好出现在此段1 Tq
PTS 传播时间段吸收发送/总线/接收的物理延迟（取两倍传播延迟）1~8 Tq
PBS1 相位缓冲段 1补偿边沿没落在 SS 里时的偏差1~8 Tq
PBS2 相位缓冲段 2吸收各单元时钟误差，配合 SJW 加减2~8 Tq

这些段由最小时间单位 Tq（Time Quantum，时间量子）构成，1 个位共 8~25 Tq。采样点就是读总线电平的位置，落在 PBS1 结束处（PDF p.41）。

# 1 bit = 16 Tq 的示例（PTS+PBS1 加大 → 采样点后移）
┌─────────┬───────────┬────────────┬──────────┐
│ SS  1Tq │ PTS  4Tq  │ PBS1  9Tq  │ PBS2  2Tq │
└─────────┴───────────┴─────┬──────┴──────────┘
                            │
                         采样点
       采样点位置 = (SS+PTS+PBS1) / 总Tq = 14/16 ≈ 87.5%

2. 同步：硬件同步与再同步

因为每个节点各用自己的时钟，晶振偏差和电缆相位延迟会让边沿漂移，所以接收单元要不断调整（PDF p.42~45）：

  • 硬件同步：总线空闲时检测到 SOF（隐性→显性边沿）做的一次同步——不管 SJW 是多少，直接把边沿当 SS 段起点
  • 再同步：帧接收过程中检测到电平边沿时，按 SJW（再同步补偿宽度，1~4 Tq）加长 PBS1 或缩短 PBS2 来对齐。误差超过 SJW 时最多也只能补 SJW 那么宽
  • 位填充：NRZ 信号连续同电平太久就没了边沿，所以 SOF~CRC 段内连续 5 个相同位后，第 6 位强制插入 1 位反型电平（PDF p.36）。接收端把第 6 位删掉还原数据；如果第 6 位没反型，就判为填充错误

3. 波特率计算

波特率由三个量决定：CAN 时钟、预分频 Prescaler、每位的 Tq 总数。STM32F407 的 CAN 时钟来自 APB1（默认 42MHz）：

  • Tq = 1 / (CAN_时钟 / Prescaler)
  • 1 位 = SS(1) + BS1 + BS2 个 Tq（PTS 通常并入 BS1 的 TimeSeg1）
  • 波特率 = CAN_时钟 / (Prescaler × (1 + BS1 + BS2))

💡 经验值：汽车行业采样点一般取 75%~87.5%（长总线、高波特率用大值，防止边沿抖动吃到下一位）。CubeMX 里调 TimeSeg1/TimeSeg2 时，让 (1+BS1)/(1+BS1+BS2) 落在这个区间附近。

4. 错误种类：五大金刚

CAN 一共能检测 5 种错误（PDF p.37~38）：

错误内容检测单元
位错误比较输出电平和总线电平（不含填充位），两电平不一致发送/接收单元
填充错误需要位填充的段内，连续检测到 6 位相同电平发送/接收单元
CRC 错误本地算出的 CRC 与收到的 CRC 序列不一致接收单元
格式错误固定格式的位段（CRC 界定符/ACK 界定符/EOF）出现反电平接收单元
ACK 错误发送单元在 ACK 槽没等到显性位（没人应答）发送单元

检测到错误的单元输出错误帧通知全网：主动错误状态输出 6 个显性位 + 8 个隐性界定符；被动错误状态只输出 6 个隐性位。发送方发完错误帧后自动重发刚才失败的帧。

5. 错误状态机：主动 / 被动 / 总线关闭

每个单元始终处于三种状态之一，由发送错误计数（TEC）和接收错误计数（REC）管理（PDF p.5~9）：

状态TEC / REC行为
主动错误0~127 / 0~127正常通信；检测错误输出主动错误标志（6 显性）
被动错误128~255 / 128~255（任一超限）能收发，但只能输出被动错误标志（6 隐性），发完一帧后要插 8 位"延迟传送"
总线关闭TEC ≥ 256收发全禁止，从总线上"消失"

计数规则（PDF p.6~7 表 2）几条关键的：

  • 接收单元检测出错误时 REC +1
  • 发送单元输出错误标志时检测出位错误等 TEC +8
  • 发送单元正常发送结束（收到 ACK 且到帧结束）时 TEC −1
  • 接收单元正常接收结束（无错误且 REC 在 1~127）时 REC −1
  • 总线关闭的单元，检测到 128 次连续 11 个隐性位后回到主动错误状态（推荐计数清零）

⚠️ 总线关闭不是软件能随便"恢复"的——硬件要求收到 128 次连续 11 个隐性位才回到主动错误状态（教材 p.7 第 10 条）。在这期间这个节点彻底沉默。所以排查"某节点突然不上线"时，先怀疑它进了总线关闭态。

代码示例

下面两段代码：第一段把波特率和采样点公式变成可运行的函数（第 19 课你要用它核对 CubeMX 的数值），第二段模拟错误计数状态机。

#include <stdint.h>

/* 波特率：bps = CAN_Clock / (Prescaler × (1 + BS1 + BS2)) */
uint32_t can_calc_bps(uint32_t can_clock, uint32_t prescaler,
                      uint32_t bs1, uint32_t bs2)
{
    return can_clock / (prescaler * (1u + bs1 + bs2));
}

/* 采样点比例（%）：SS+PBS1 在整个位里的位置 */
uint32_t can_sample_point(uint32_t bs1, uint32_t bs2)
{
    return (100u * (1u + bs1)) / (1u + bs1 + bs2);
}

/* F407：APB1 = 42MHz，Prescaler=6，BS1=10，BS2=3 → 500kbps，采样点 ≈ 78% */
uint32_t bps = can_calc_bps(42000000u, 6u, 10u, 3u);  /* 500000 */
uint32_t sp  = can_sample_point(10u, 3u);             /* 78 */

/* CAN 错误状态机（简化）：由 TEC/REC 决定所处状态 */
typedef enum { ERR_ACTIVE, ERR_PASSIVE, ERR_BUS_OFF } CanErrState;

CanErrState can_err_update(uint32_t tec, uint32_t rec)
{
    if (tec >= 256u) return ERR_BUS_OFF;        /* TEC 到 256 → 总线关闭 */
    if ((tec >= 128u) || (rec >= 128u)) return ERR_PASSIVE;
    return ERR_ACTIVE;
}

/* 典型计分规则（教材 5.2 节）：
 *   接收出错 REC+1；发送出错 TEC+8；
 *   发送成功（收到 ACK）TEC-1；正常接收 REC-1；
 *   总线关闭后：128 次连续 11 个隐性位 → 回到主动错误 */

动手练习（约 20 分钟）

练习 18.1：算波特率与采样点

1️⃣ 已知 APB1 = 42MHz，Prescaler = 7，TimeSeg1(BS1) = 9，TimeSeg2(BS2) = 2。

2️⃣ 用公式算：Tq 数 = 1+9+2 = 12，波特率 = 42M / (7 × 12) = 500kbps。

3️⃣ 采样点 = (1+9)/12 ≈ 83.3%，判断是否落在推荐的 75%~87.5% 区间，并说说如果总线加长到 100m 该往哪个方向调。

练习 18.2：推导"总线关闭"的完整恢复流程

1️⃣ 场景：节点上的 CAN 收发器 TX 引脚被干扰，持续输出错误——推演 TEC 如何从 0 涨到 ≥256 并进入总线关闭。

2️⃣ 写出恢复条件：检测到 128 次连续 11 个隐性位后回到主动错误（计数清零）。

3️⃣ 思考：为什么用"128 次连续 11 个隐性位"这么苛刻的条件？它保证了什么？（提示：避免刚恢复就再次被冲下去，保证总线上确实恢复了安静）

随堂小测

Q1. CAN 的采样点一般设在哪个位置？

A. PBS2 结束处，越晚越准

B. PBS1 结束处，读边沿稳定的电平

C. SS 段正中间，紧贴边沿

查看答案
B。采样点落在 PBS1 结束处（PDF p.41 图 32 注）。

Q2. 位填充的规则是什么？

A. 连续 5 位相同后，第 6 位插 1 位反型

B. 每发完 8 位就插 1 个停止位

C. 连续 5 位不同后，插入 1 个显性位

查看答案
A。SOF~CRC 段连续 5 位相同电平，第 6 位插入反型电平，保证有边沿可同步（PDF p.36）。

Q3. 发送错误计数 TEC 达到多少进入总线关闭？

A. 128，同时 REC 也要 ≥128

B. 256，收发全被禁止

C. 512，需要硬件复位

查看答案
B。TEC ≥ 256 进入总线关闭态，禁止收发（PDF p.5 表 1）。

Q4. 发送方在 ACK 槽等不到显性位，报的是什么错误？

A. ACK 错误，说明没人应答

B. 格式错误，EOF 电平异常

C. 位错误，总线电平不符

查看答案
A。发送单元在 ACK 槽检测到隐性（没人回显性位）即 ACK 错误（PDF p.37 表 9）。

LVGL 产品界面开发

基于 STM32F407 + 320×240 触摸屏 + LVGL v8.3.11 · 主线教材：正点原子《LVGL 开发指南 V1.5》

课程使命：做出一套完整、可交付的产品界面——多页面导航、设置项、数据展示、交互动画。教材在 MISSION.md，配套资源在 RESOURCES.md。

课程地图（12 课，三个阶段）

每课一个独立页面，约 30~60 分钟，含知识讲解 + 自测 + 真机练习。🟡 进行中 · ⬜ 未开始

    样式属性、部件组成/状态、样式叠加优先级 —— 给你的控件"化妆"（PDF 6.4） → 上课

    事件类型、回调、事件字段；触摸输入链路 —— 让界面"会响应"（PDF 6.8） → 上课

    动画路径/速度/时间线、LVGL 定时器 —— 让界面"活起来"（PDF 6.6~6.7） → 上课

  • 11 图片与字库 · 组件篇

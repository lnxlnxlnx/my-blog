# Mission: LVGL 产品界面开发

## Why

在 STM32F407 探索者开发板（320×240 触摸屏）上，用 LVGL v8.3.11 做出一个**完整、可交付的产品界面**——多页面导航、设置项、实时数据展示、交互动画，而不只是单个部件的堆砌。学完这套课程，我能独立把"一块屏幕 + 一个 MCU"做成像样的用户界面。

## Success looks like

- 独立完成一个 3+ 页面的产品 UI（如：主页仪表 + 设置页 + 数据页），页面间可流畅切换
- 能用 Flex / Grid 布局搭出规整、自适应屏幕的页面骨架，而非手工算坐标
- 熟练使用样式、事件、动画、定时器四大机制，实现带反馈的交互（点击、滑动、状态切换）
- 能把图片（BMP/PNG/JPEG/GIF）和外部字库接进界面，UI 不再只是"裸控件"
- 掌握 lv_conf.h 的裁剪思路，知道每个部件/功能的内存代价，能控制 Flash/RAM 占用
- 输出的课程笔记体系（HTML 课程 + 速查表）可以随时回看，成为自己的 LVGL 知识库

## Constraints

- 硬件：STM32F407 探索者，320×240 TFTLCD，触摸输入，FSMC 接口
- 软件：LVGL v8.3.11 已移植完毕（显示/触摸/文件系统），裸机运行（FreeRTOS 留到 FreeRTOS 课程）
- 教材主线：正点原子《LVGL 开发指南 V1.5》（`参考文档/LVGL开发指南_V1.5.pdf`，对应 v8.2，与 v8.3 兼容）
- 课程形式：每课一个独立 HTML 页面，含知识讲解、自测题、动手练习；配套术语表与 API 速查表
- 语言：中文教学

## Out of scope

- FreeRTOS 与 LVGL 的集成（属于 FreeRTOS 课程）
- SquareLine Studio 可视拖拽设计器（课程后期可选加）
- DMA2D / 渲染性能深度优化
- LVGL v9 新版本迁移

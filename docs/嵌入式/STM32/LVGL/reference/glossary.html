LVGL 术语表

全课程统一使用的术语定义。速查用，不用背，遇到生词回来翻。

核心概念

术语定义备注
LVGLLight and Versatile Graphics Library，纯 C 开源图形库工程版本 v8.3.11
对象（Object / lv_obj）屏幕上一切元素的基类：按钮、标签、屏幕本身都是对象部件是"加工过的对象"
部件（Widget）基于 lv_obj 扩展出的具体控件，如 lv_btn、lv_label33 种核心部件（v8）
屏幕（Screen / scr）对象树的根，一屏一个。默认屏幕 lv_scr_act()可建多屏切换
图层（Layer）屏幕之上的独立层：顶层（top）/系统层（sys）加载动画、光标等用
父/子对象对象树结构，子对象随父对象移动/隐藏/删除GUI 组织的核心思维
样式（Style）对象的"皮肤"：背景、边框、文字、圆角、阴影等属性集合CSS 风格，可叠加
状态（State）对象的交互状态：默认/按下/聚焦/禁用/选中/勾选/编辑样式可按状态区分
部件组成（Part）复杂部件的可独立设置样式的部分（如滑块的轨道/旋钮）详见各部件文档
事件（Event）用户交互或对象变化的通知，如点击、值改变、滚动回调函数处理
动画（Animation）对象属性随时间的平滑变化（位置、透明度、角度…）依赖时基推进
定时器（Timer）LVGL 内部周期性回调，替代裸机"软件定时器"由 lv_timer_handler 调度
时基（Tick）LVGL 的时间基准，由 lv_tick_inc() 周期性喂入SysTick 1ms
刷新（Refresh）检测"脏区域"并重绘到缓冲区，再经 flush 推给屏幕不是每帧全屏重绘
绘制缓冲区（Draw Buffer）LVGL 渲染用的内存区，可单缓冲/双缓冲/全屏缓冲你的工程：320×10 单缓冲
flush把缓冲区内容拷贝到 LCD 的回调（flush_cb）接 LCD 驱动
输入设备（Indev）触摸屏、鼠标、键盘、编码器、按键的统称注册为 indev
组（Group）用键盘/编码器导航时，把对象归组实现焦点移动v8 的 keypad 导航
主题（Theme）一套默认样式，决定新部件"长什么样"default/basic/mono
布局（Layout）子对象自动排列的机制：Flex（一维）与 Grid（二维）产品界面的骨架
字库（Font）字形数据集合，LVGL 内建 ASCII 字库 + 自定义字库C 数组或文件加载
lv_conf.h用户级配置文件：色彩深度、内存池、功能裁剪不属于内核
内存池（Mem Pool）LVGL 自管堆，所有对象/样式/动画从这里分配LV_MEM_SIZE 配置
滚动（Scroll）内容超出对象区域时的滚动手势与滚动条触摸滑动天然支持
对齐（Align）对象相对父对象的摆放方式（居中、左上、右中…）lv_obj_align()

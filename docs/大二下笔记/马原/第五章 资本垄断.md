# 马原政治经济学垄断、当代资本主义专题完整讲解
## 一、垄断的产生
### 1. 垄断形成的根本动因：自由竞争引起生产集中，生产集中发展到一定阶段必然走向垄断
1. **自由竞争推动生产集中**
自由资本主义阶段，资本家为追逐剩余价值相互竞争；大企业凭借技术、资本优势不断吞并、排挤中小企业，生产资料、劳动力、产品日益集中到少数大企业手中，即**生产集中**。
2. **生产集中达到临界点，垄断产生（两重客观条件）**
- 少数大企业势均力敌，激烈竞争会两败俱伤，为瓜分市场、稳定利润，达成联合协议；
- 企业规模巨大，新企业难以进入行业，形成行业壁垒，少数大企业掌控整个行业供给。
3. **垄断的含义**
少数资本主义大企业，为获取高额垄断利润，通过协议、联合、参股等方式，控制一个或多个部门的生产与流通。
4. **垄断组织形式**
短期价格协定、卡特尔、辛迪加、托拉斯、康采恩，现代以混合联合企业为主。
5. 重要结论：**垄断没有消除竞争**
垄断与竞争并存：垄断组织内部、垄断组织之间、垄断企业与非垄断中小企业之间始终存在竞争，只是竞争形式、激烈程度发生改变。

## 二、国家垄断资本主义的本质
### 1. 定义
国家政权与私人垄断资本融合在一起的垄断资本主义。
### 2. 形成原因
私人垄断资本无法解决资本主义固有矛盾（生产过剩、经济危机、基建投入巨大、贫富分化、国际竞争等），必须借助国家力量调节经济。
### 3. 主要形式
1. 国家所有并直接经营企业（国有垄断企业）；
2. 国家与私人共有、合营企业；
3. 国家通过多种形式参与私人垄断资本再生产（补贴、信贷、订货）；
4. 宏观经济调节（财政、货币政策）；
5. 微观规制（反垄断、行业监管、社会保障法规）。
### 4. 核心本质
**国家垄断资本主义是垄断资本利用国家政权，维护自身统治、攫取高额垄断利润的工具，本质依旧是资本主义私有制。**
- 国家代表垄断资产阶级整体、长远利益，而非全体民众利益；
- 国家干预、国有经济、福利政策，只是调整分配、缓和阶级矛盾，不会改变生产资料私人占有根基；
- 一切宏观调控、基建投资、危机救助，最终收益流向大垄断资本。

## 三、经济全球化的主要表现
1. **生产全球化**
跨国公司主导，产品研发、零部件生产、组装分散在全球各国，利用各国劳动力、资源、成本优势，形成全球产业链分工。
2. **贸易全球化**
国际贸易规模持续扩张，商品、服务贸易自由流动，各国市场相互依存，关税降低、全球贸易体系成型。
3. **金融全球化**
国际资本跨国高速流动，跨国银行、国际金融市场、外汇、证券全球联通；跨国投融资、国际信贷规模大幅提升。
4. **企业经营全球化**
跨国公司成为经济全球化主要载体，跨国并购、海外分支机构遍布全球，资本突破国界限制。

## 四、当代资本主义的新变化（二战后至今）
### 1. 生产资料所有制变化
私人垄断资本比重下降，**国家资本所有制、法人资本所有制**崛起；企业股权分散化，普通工人持有少量股票，但控股权仍掌握在少数大股东手中。
### 2. 劳资关系与分配制度调整
- 推行职工持股、职工参与决策、终身雇佣、工会协商制度；
- 建立覆盖全民的社会福利制度（社保、医疗、失业救济），缓和贫富对立。
### 3. 社会阶层、阶级结构变化
- 资本家不再直接经营企业，高级职业经理人、专业技术阶层壮大；
- 传统产业工人占比下降，服务业、脑力劳动者成为劳动者主体；
- 中间阶层规模扩大。
### 4. 经济运行机制变化
放弃完全自由放任，普遍实行国家宏观调控，依靠财政、货币、产业政策平抑经济波动，建立危机缓冲机制。
### 5. 国际垄断格局深化
跨国公司、国际垄断同盟主导全球经济；依靠国际货币基金组织、世界银行等国际经济机构操控全球规则，垄断资本向全球扩张。

## 五、2008年金融危机以来资本主义凸显的新矛盾
2008年全球金融次贷危机是当代资本主义内在矛盾的集中总爆发，暴露多重深层矛盾：
1. **金融资本过度虚拟化，实体经济空心化**
资本大量脱离生产领域涌入股市、房地产、衍生品投机，金融投机成为主要获利手段，制造业萎缩，经济泡沫化严重。
2. **贫富两极分化空前加剧**
危机后各国政府用财政资金救助金融巨头，负担转嫁普通民众；财富快速向顶层垄断资本集中，中产阶层萎缩，阶级对立重新激化。
3. **国家宏观调节存在根本局限**
财政刺激、量化宽松只能短期延缓危机，无法根治生产社会化与私人占有基本矛盾；超发货币带来通胀、债务危机后遗症。
4. **发达资本主义国家内部社会矛盾激化**
失业、物价上涨、福利削减催生民粹主义、反全球化运动，政党对立、社会撕裂加剧。
5. **全球范围内垄断资本矛盾加剧**
经济全球化红利分配不均，发达国家与发展中国家发展差距拉大；大国之间贸易摩擦、科技封锁、地缘经济对抗常态化。
6. **资本主义周期性经济危机常态化**
金融泡沫、债务危机、通胀衰退交替出现，证明国家垄断资本主义无法根除经济危机。

## 六、当代资本主义新变化的实质
1. **根本制度没有改变：资本主义私有制根基不变**
股权分散、国有经济、福利政策只是生产关系局部调整，生产资料依旧由垄断资产阶级掌控，资本剥削雇佣劳动的核心关系没有消失。
2. **新变化是生产力发展倒逼下，资本主义生产关系的自我改良、自我调节**
科技革命、全球化、工人长期斗争迫使资本主义调整制度，目的是缓和阶级矛盾，延长资本主义制度寿命。
3. **剥削形式更加隐蔽，但剩余价值榨取逻辑不变**
福利、员工持股只是改变分配表象；脑力劳动、服务业劳动同样创造剩余价值，跨国资本在全球范围内掠夺超额垄断利润。
4. **无法消除资本主义基本矛盾**
生产社会化与生产资料资本主义私人占有之间的内在矛盾依然存在，经济危机、贫富分化、社会冲突周期性爆发，新变化只是缓解矛盾，不能根除矛盾。
5. **历史趋势不变**
当代资本主义的调整改良，只是延缓衰落，没有改变资本主义必然被更高级社会形态取代的客观历史规律。

# 整体逻辑串联
自由竞争→生产集中→垄断→私人垄断发展为国家垄断；生产力发展推动经济全球化，带来当代资本主义一系列表层新变化；2008金融危机暴露改良手段的内在局限；所有新变化只是资本主义生产关系的局部调整，不改变资本主义剥削本质与内在基本矛盾。

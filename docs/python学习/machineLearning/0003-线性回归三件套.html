线性回归：三件套完整走一遍

课程 0003 · 预计 25 分钟 · 前置：课程 0002

上一课你学会了「模型 / 策略 / 算法」三要素的辨析。这一课就用最简单的算法——线性回归——把三件套从头到尾亲手装一遍。这是全书最简单的一课，但也是最值得练熟的一课：你会第一次看到「过拟合」和「正则化」在真实数字里长什么样。

三要素之「模型」：假设空间

线性回归假设：输出是输入的线性组合加一个常数。写成向量形式：

ŷ = w₁x₁ + w₂x₂ + … + w_d x_d + b  =  wᵀx + b

模型 = 所有形如 wᵀx + b 的函数（w、b 取任何实数）。假设空间是「所有直线/超平面」的集合，学习就是在这个集合里挑一条。

我们把 b 收进 w：记增广输入 x' = (x₁,…,x_d,1)，则 ŷ = wᵀx'。代码里一行 `np.hstack([x, ones])` 就干这个。

三要素之「策略」：均方误差 + 经验风险最小化

怎么判断一条线好不好？用均方误差（MSE）：

L(w) = (1/N) Σ (yᵢ − ŷᵢ)² = (1/N) ||Xw − y||²

含义：预测和真实值平均差多少（平方）。MSE 是二次函数、处处可导、对大误差惩罚重——所以既好算又「对离群点敏感」。

策略 = 经验风险最小化（ERM）：w* = argmin L(w)。「经验」指我们用的是训练集上的平均损失（样本均值），而不是真实分布的期望。

三要素之「算法」：两条路到终点

同一个「模型 + 策略」，有两条搜索路径：

正规方程（解析解）

令梯度为 0，直接解出 w* = (XᵀX)⁻¹Xᵀy。一步到位。

梯度下降（迭代）

w ← w − η·∇L(w)，沿损失下降最快的方向一步步走。可扩展到神经网络。

你跑脚本时两条路得到几乎一样的 w——这正好证明：换「算法」只是换搜索方法，终点相同。什么时候不同？当 (XᵀX) 不可逆（特征太多/有共线性）或特征维度极大时，正规方程就不可行或太慢，只能梯度下降。

泛化：过拟合与正则化

线性回归不够用时，人们会把特征变「花哨」——比如多项式特征 1, x, x², …, xᵈ。于是「模型」变大了（候选函数更多、更弯）。这时出现经典一幕：

  • 欠拟合：degree 太小（d=1 一条直线），训练和测试误差都高。
  • 过拟合：degree 太大（d=20），训练误差很低，但测试误差暴涨——模型把噪声也背下来了。

对策是正则化：在损失里加惩罚项，主动收紧模型。李航把它叫做结构风险最小化（SRM）：

损失 = MSE + λ·||w||²            ← 岭回归（L2）
损失 = MSE + λ·Σ|wⱼ|             ← Lasso（L1，会让系数变成 0）

λ 是「惩罚力度」：太大则模型被压得太扁（欠拟合），太小则压不住（过拟合）。偏差-方差权衡说的就是这个换挡过程。

测一测

测验 1

线性回归的「模型」指的是什么？

模型 = 候选函数的集合。线性回归的候选空间是所有 wᵀx+b 组成的集合。

测验 2

均方误差在「三要素」里属于？

损失函数 = 判断好坏的标准 = 策略。

测验 3

训练误差很低、测试误差很高，首先怀疑？

典型的过拟合：模型记住了训练集的噪声。应对：加正则化或减小模型复杂度。

测验 4

岭回归与 Lasso 的主要区别？

L1（Lasso）会把部分系数压到恰好 0，等于自动做特征选择；L2（岭）只把系数整体缩小。

决策树：分而治之的规则树

课程 0007 · 预计 40 分钟 · 前置：课程 0005（偏差-方差）

前几课的「模型」都是数学函数（直线、超平面、概率分布）。决策树是完全不同的东西：它是一棵 if-then 规则树——「今天天气如何？下雨 → 要不要带伞」这样一串判断。它天然可解释、能处理混合类型特征，更重要的是它是随机森林和梯度提升的地基。

三要素

模型

if-then 规则的集合；从根到叶的每条路径都是一条规则，规则之间互斥且完备。

策略

每个结点挑「最能使子结点变纯」的特征分裂——用信息增益 / 基尼不纯度来度量。

算法

贪心递归：选特征 → 分裂 → 递归；配以剪枝（预剪枝/后剪枝）防过拟合。

核心问题：怎么选分裂特征

树的每层都要问「按哪个特征、在什么阈值处切，能让两边的类别更纯」。衡量「纯度」有两种常用度量：

信息增益（ID3/C4.5 用）

先算结点的熵：

H(S) = −Σ pᵢ log₂ pᵢ        # 越纯熵越低；全同类的叶熵 = 0

再算按特征 A 分裂后子结点熵的加权平均，两者的差就是信息增益：

Gain(S, A) = H(S) − Σ_v (|S_v|/|S|)·H(S_v)     # 选增益最大的特征

基尼不纯度（CART 用）

Gini(S) = 1 − Σ pᵢ²        # 越纯越小；全同类 = 0

scikit-learn 的 DecisionTreeClassifier 默认用基尼。两者选出的分裂往往很接近，实现上基尼更省算（不用 log）。

三个必懂点

1. 树越深越容易过拟合

只要数据没有冲突，深度无限的增长可以把训练集「背下来」——但边界碎成锯齿，泛化差。控制方式：

  • 预剪枝：设 max_depth、min_samples_leaf，提前停。
  • 后剪枝：先长满再自底向上剪掉不带来验证集提升的子树。
  • 这正是 0005 学过的偏差-方差权衡：浅 → 高偏差，深 → 高方差。

2. 边界是「轴对齐」的矩形

每个结点只按一个特征切，所以决策边界永远是平行于坐标轴的阶梯形，而不是斜线。真实数据里的斜边界要用很多层来逼近——这就是为什么集成学习能大幅提升它。

3. 它很好解释，但要小心过拟合与不稳定

「叶子里样本最多的类」就是预测；一条从根到叶的路径可以讲给人听（可解释性）。但贪心分裂意味着训练数据的小扰动可能换一棵完全不同的树——高方差，这也是它需要集成的主要原因。

测一测

测验 1

决策树的「模型」本质是什么？

每条根到叶的路径是一条规则，规则互斥且完备。

测验 2

分裂时选特征的标准是？

信息增益/基尼度量的是分裂后子结点「变纯」的程度。

测验 3

纯结点的熵是多少？

熵 H = −Σ p log₂ p；p=1 时 = 0，全同类结点最纯。

测验 4

决策树的决策边界是什么形状？

每次只切一个特征 → 边界是平行于坐标轴的阶梯形。

结构化数组与进阶

Numpy 专题 · 课程 0005 · 预计 30 分钟 · 配套 100 题 57、59、61、62、64~74

有时数组元素是"复合记录"(如 坐标+颜色),或想按某列重排、算窗口均值。本课覆盖结构化数组(自定义 dtype)、按列排序、滑动窗口 与 groupby 式技巧,对应题 57、59、61、62、64~74。

知识点 1:结构化数组——元素是一"条记录"(题 46、48、51、57)

自定义 dtype 让数组的每个元素是一组命名字段(像 C 的 struct):

import numpy as np
dt = np.dtype([("x", "f8"), ("y", "f8"), ("color", "u1")])
Z = np.zeros(3, dtype=dt)
Z["x"] = [1.0, 2.0, 3.0]       # 按字段名批量赋值
Z["color"] = [255, 0, 128]
(n, m) = Z.shape               # 每个元素有 3 个字段
print(Z["x"])                  # [1. 2. 3.]

题51:造一个"位置(x,y)+颜色(r,g,b)"的结构化数组——就是上例扩展成 struct。题46:坐标覆盖[0,1)的网格,用 np.mgrid / np.meshgrid。

知识点 2:按列重排(题 59)+ 距离/欧氏(题 52、61)

题59按第 n 列升序重排,用 argsort(前面讲了)。题61找最接近给定值的元素:

Z = np.random.random(10)
z = 0.5
Z[np.argmin(np.abs(Z - z))]        # 最接近 z 的元素

题52:两个向量集合求两两距离:

A = np.random.random((5, 3))
B = np.random.random((5, 3))
# 逐个距离(5 个)
np.linalg.norm(A - B, axis=1)      # 每个 (A[i]-B[i]) 的模

np.linalg.norm(x, axis=n) 是"沿轴的模"(欧氏距离)。这是向量距离的通用求法。

知识点 3:多维聚合 & 梯度(题 67、73)

题67:对 (w,h,3) 图像按最后两维求和:

img = np.random.random((10, 10, 3))
# 期望:把最后两维(空间)求和,保留通道
img.sum(axis=(-2, -1))             # 一维长度为 3
# 或 reshape:img.reshape(10, -1).sum(axis=1)

axis 可以是负的(从尾部数)。题73 涉及三角网格,用 np.unique 去重边(unique 前文讲过)。

知识点 4:groupby 式思路——bincount / segsum(题 64、65、68)

要点:别写 for 循环遍历下标,用向量化"按标签累加":

# 题64:给向量,把"用另一下标索引的元素"各加 1
Z = np.zeros(5)
I = np.array([0, 2, 2, 3])
Z += np.bincount(I, minlength=len(Z))   # I里0出现1次,2两次,3一次
# → Z = [1,0,2,1,0]

# np.add.at 也是"打散添加"的工具
np.add.at(Z, I, 1)                      # 等价做法,可加任意权重

题65(accumulate X to F based on index)就是 np.add.at(F, I, X) 的直译。题68(分组均值):用 np.bincount(索引, weights=值)/np.bincount(索引)。

知识点 5:滑动窗口——sliding_window_view(题 70、75)

近年官方推荐 np.lib.stride_tricks.sliding_window_view 做"每 N 个连续"的处理:

x = np.arange(10)
from numpy.lib.stride_tricks import sliding_window_view
W = sliding_window_view(x, 3)         # shape (8,3):每行是连续3个
avg = W.mean(axis=1)                  # 滑动窗口均值(题75)

题70:从 [1..5] 构造"3个连续"的新向量——用 sliding_window_view(then 也许 reshape)。它把"相邻 N 个"变成"矩阵每行",后续按行操作即可,是滑窗类题的最佳工具。

排序、统计与随机

Numpy 专题 · 课程 0004 · 预计 25 分钟 · 配套 100 题 43~56、58、60

处理数据时你要:排序、找最值位置、统计分布、生成随机样本。numpy 都内置了。本课讲 sort/argsort、min/max/argmin/mean、unique、bbox 与随机抽样,覆盖题 43~56、58、60。

知识点 1:排序与"排序后下标"——sort / argsort

Z.sort() 原地排;np.sort(Z) 返回新数组;np.argsort(键:排序后每个位置原来的下标)——按某列排整个矩阵就用它:

import numpy as np
Z = np.array([3,1,2])
np.sort(Z)            # [1,2,3](新数组)
Z.sort()              # 原地排序
np.argsort([3,1,2])   # [1,2,0]:排序后第0个来自原1号...

# 按第n列把矩阵整行排序(题59)
M = np.random.randint(0,10,(5,3))
M[M[:, 1].argsort()]        # 按第1列升序重排所有行

题59 正是 M[M[:, n].argsort()] 的用法。

知识点 2:min/max 与它们的位置——arg/min

不只是取值,还要位置用 argmin/argmax:

Z = np.random.random(10)
Z.min()            # 最小值
Z.max()            # 最大值
Z.mean()           # 均值
Z.argmin()         # 最小值所在下标(题45:把最大值变0)
Z.argmax()
# 题45: 
Z[Z.argmax()] = 0          # 把最大那个元素换为 0

题45 就是 Z[Z.argmax()] = 0。find maximum element index + set 0。

知识点 3:去重与计数——unique / bincount(题 60)

np.unique 去重(还能返回每个值首次出现位置/计数);np.bincount 数每个非负整数出现次数:

Z = np.array([1,1,2,3,3,3])
np.unique(Z)                      # [1,2,3]
vals, counts = np.unique(Z, return_counts=True)
# 出现最多的值:vals[counts.argmax()](题83)
np.bincount(Z)                    # [0,2,1,3] 0出现0次,1出现2次...

题60(2D 有没有空列)思路:每列是否全 0 → (Z == 0).all(axis=0)。

知识点 4:可控随机——default_rng 全套(题 52、53、55 涉及随机)

新版 np.random.default_rng() 提供:

rng = np.random.default_rng(seed=42)   # seed 固定可复现
rng.integers(0, 10, size=5)            # 随机整数(含0不含10)
rng.random((3,3))                      # 0~1 浮点
rng.normal(0, 1, size=5)               # 标准正态
rng.choice([1,2,3], size=5, replace=True)   # 抽样
rng.permutation(10)                    # 洗牌

题52/53 随机坐标/距离:先生成 (100,2) 坐标再算两两欧氏距离。rng.choice 带 replace=True/False,可抽样。

知识点 5:深入聚合——axis 与 keepdims(题 58)

要让"每行减掉行均值":

X = np.random.random((5, 10))
X - X.mean(axis=1)                  # 错:shape 不匹配 → 广播崩
X - X.mean(axis=1, keepdims=True)   # 对:keepdims 保留维度(5,1)才能广播
# keepdims=True 保证减数和被减数形状兼容

题58 的标准答案就是 X - X.mean(axis=1, keepdims=True)。记住:按行/列做聚合后想安全广播,加 keepdims=True。

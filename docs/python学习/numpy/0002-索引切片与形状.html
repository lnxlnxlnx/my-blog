索引、切片与形状

Numpy 专题 · 课程 0002 · 预计 25 分钟 · 配套 100 题 15、16、19~22、24、25、35

上一课会创建数组了。这一课是 numpy 的"手指":索引(取某个元素/一块)、切片(取一段)、形状操作(reshape/转置/拼接),以及in-place 修改。习题 15/16/19/21/35/25 都在这。

知识点 1:基本索引与切片——含省略号和负号

和 list 切片很像,但维度更多(下标用 [a, b] 而不是 [a][b]):

import numpy as np
A = np.arange(10)            # [0..9]
A[4] = 1                     # 题6:第5个元素变1
A[::-1]                      # 题8:反转 → [9..0]
A[3:8]                       # [3,4,5,6,7] (半开)

B = np.arange(16).reshape(4, 4)
B[0, 0]        # 第0行第0列
B[1:3, 1:3]    # 第1、2行的第1、2列 → 2x2 子块
B[:, -1]       # 所有行的最后一列

关键:arr[i, j] 是二维下标;arr[i][j] 也能用但慢。题8反转用 Z[::-1]。

知识点 2:边界与填充——题 15、16(pad)

题15:造一个 10x10,四周是 1、中间是 0。先 all 1,再挖空中间:

Z = np.ones((10, 10))          # 全 1
Z[1:-1, 1:-1] = 0              # 中间挖空为 0
# 结果:边框=1, 内部=0

题16:给已有数组"加一圈 0 边框",用 np.pad:

Z = np.ones((5, 5))
Z = np.pad(Z, pad_width=1, mode="constant", constant_values=0)
# 变成 7x7,外圈是 0(可控制每边宽度/填充值)

pad_width=1 四边各加一圈; constant_values=0 填 0。这是题16的标准解。

知识点 3:形状操作——reshape / transpose / flatten

形状不代表数据变,只是"怎么看"。

np.arange(9).reshape(3, 3)     # 题9:0~8 排成 3x3
A = np.arange(16).reshape(4, 4)
A.T                       # 转置(4x4→4x4)
A.reshape(2, 8)           # 变形(不复制,同内存)
A.flatten()               # 展平成 1 维(复制)
A.ravel()                 # 展平(尽量不复制,推荐)

题21 用 np.tile 拼棋盘:np.tile(np.array([[0,1],[1,0]]), (4,4))(tile=重复铺瓷砖)。题19 是手工切片 1::2 / ::1 交替填。

知识点 4:矩乘与矩阵运算——题 24

矩阵乘法用 @ 或 np.dot:

A = np.arange(15).reshape(5, 3)      # 5x3
B = np.arange(6).reshape(3, 2)       # 3x2
C = A @ B                            # 5x2:真正矩阵乘
# 或 np.dot(A, B)
# 千万别用 A * B(那是逐元素乘,要求形状一致)

@ 是矩阵乘; * 是逐元素乘。题24 用 np.dot(A, B) 或 A @ B。

知识点 5:in-place 修改——切片赋值 & 布尔掩码(题 25、35)

想"就地改数组的满足条件的元素",用布尔掩码:

Z = np.arange(11)
Z[(Z > 3) & (Z <= 8)] *= -1       # 题25:3<x<=8 的取负(就地)
# & 是逻辑与;别写 and(会报错)

题35 要求"不复制地算 ((A+B)*(-A/2))",用 ufunc 的 out= 参数原地算:

A = np.arange(10, dtype=float)
B = np.arange(10, dtype=float)
np.add(A, B, out=B)      # B = A+B (原地)
np.divide(A, 2, out=A)   # A = A/2 (原地)
np.multiply(A, B, out=A) # A = (A/2)*(A+B) 原地
np.negative(A, out=A)    # A = -(...) 原地

ufunc(x, out=target) 把结果写进 target 而不新造数组,就是"in place、无复制"的关键(下一课正式讲 ufunc)。

测验 1

取 4x4 数组所有行的最后一列?

arr[:, -1]:所有行的最后一列(得到1维)。arr[:,-1:] 是保留维度的列。

测验 2

给数组四周加0 border 用什么?

np.pad 四边加边框(mode/constant_values 控制)。题16。

测验 3

两个矩阵真正相乘用?

@ 或 np.dot 是矩阵乘;* 和 np.multiply 是逐元素乘。

测验 4

就地改 3<x≤8 的元素为负?

布尔掩码 + & 组合条件,整体赋值。题25。

测试与日志 pytest / logging

Pythonic 代码 · 课程 0015 · 预计 30 分钟

C 程序员写测试常没有好工具,调试靠 printf + 断点。Python 有两大神器:pytest 写自动化测试(几行断言就能验证函数);logging 替代 print 输出分级日志(debug/info/warning/error,能关能调)。本课是收尾,让你写的每个函数都能被验证、出错能追踪。

知识点 1:pytest——最小测试框架

先 pip install pytest。写测试极简单:建一个 test_xxx.py 文件,函数名以 test_ 开头,里面用 assert 断言。然后运行 pytest 就自动发现并跑所有测试:

# 文件 test_math_utils.py
import pytest

def add(a, b):
    return a + b

def test_add_positive():     # 以 test_ 开头才会被 pytest 发现
    assert add(1, 2) == 3

def test_add_negative():
    assert add(-1, 1) == 0

# 期望抛异常:用 pytest.raises
def test_add_type_error():
    with pytest.raises(TypeError):
        add("a", 3)

运行:uv run pytest 或 pytest test_math_utils.py。通过就显示绿点,失败会告诉你哪一行断言错了。命名规则:pytest 找 test_*.py 文件里的 test_* 函数——这是和「C 里没有」最大的不写框架。

知识点 2:fixture——给测试准备数据/环境

多个测试要共用「准备数据、建对象、开连接」,用 @pytest.fixture,它是自动注入的依赖(呼应你学过的依赖注入——这是 pytest 的标志):

import pytest

@pytest.fixture
def numbers():
    return [3, 1, 4, 1, 5]

def test_sum(numbers):        # 参数名= 函数名,自动注入
    assert sum(numbers) == 14

def test_max(numbers):
    assert max(numbers) == 5

fixture 函数返回值会被「按参数名自动传给」测试函数;fixture 还能做 yield 形式的「前后清理」(setup/teardown),像上下文管理器。

知识点 3:parametrize——同一个测试跑多组数据

同一逻辑测很多组输入,用 @pytest.mark.parametrize 展开成多个用例:

import pytest

def classify(n):
    return "even" if n % 2 == 0 else "odd"

@pytest.mark.parametrize("n, expected", [
    (2, "even"), (3, "odd"), (0, "even"), (-4, "even"),
])
def test_classify(n, expected):
    assert classify(n) == expected

一组参数一个用例,失败会单独标出来,定位精准。parametrize = 「一张表喂给同一个测试」。

知识点 4:logging——分层级、可开关的日志

代替散落的 print 调试,logging 提供分级:debug < info < warning < error < critical,设一个「门槛」就能批量过滤:

import logging
logging.basicConfig(level=logging.INFO)   # 门槛:INFO 及以上的才打印

logging.debug("细节调试")      # 不打印(低于 INFO)
logging.info("开始处理")       # 打印
logging.warning("磁盘快满了")  # 打印,样式显眼
logging.error("失败了")        # 打印

对应 C 的「printf 级别之分」:debug 细节、info 进度、warning 警告、error 错误。level= 设门槛,生产环境设 INFO/WARNING 少刷屏,调试改 DEBUG 全看。

知识点 5:logger 实例与格式

更好的习惯:每个模块建自己的 logger(带上模块名),并自定义格式(含时间、级别):

import logging

logger = logging.getLogger(__name__)     # logger 名字是模块名
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s %(levelname)s %(name)s: %(message)s",
)
logger.info("模块里的日志")   # 2026-08-24 ... INFO ...: 模块里的日志

加 logger.exception("...") 在 except 里还能自动带上堆栈。logging 的异步/生产用法比 print 强得多:能写文件、按级别过滤、人人都能搜。

时间与日期 datetime / time

Pythonic 代码 · 课程 0009 · 预计 20 分钟

C 里取时间要 time()、要自己转结构体、格式化要 strftime 还很绕。Python 有两个模块干活:time 管「计时、停顿、当前时间戳」;datetime 管「日历上的日期和时间(时区、加减、格式化)」。本课讲透日常 80% 会用到的部分。

知识点 1:计时与停顿——用 time,别用 time() 猜

C 思维(用 time_t 整数秒来测耗时,精度太粗):

import time
t0 = time.time()
# ... 干活 ...
dt = time.time() - t0      # 秒,但 time.time() 是墙钟,可能跳变

Pythonic——测代码耗时用 time.perf_counter()(高精度单调时钟,不受系统改时影响);想让程序睡一会用 time.sleep:

import time
t0 = time.perf_counter()
time.sleep(0.5)            # 停 0.5 秒
dt = time.perf_counter() - t0   # ≈ 0.5 秒

要点:perf_counter 只用来测相对耗时;要「当前日历时间」才用 time.time()。想手动 sleep 请用 decorator 封装,别散落各处。

知识点 2:当前日期时间——datetime.now()

datetime 是核心:拿到「此刻」用 datetime.now(),得到的是一个 datetime 对象,自带 year/month/day/hour/minute/second:

from datetime import datetime
now = datetime.now()
print(now.year, now.month, now.day)      # 2026 8 24
print(now.hour, now.minute, now.second)  # 当前时分秒
print(now.date())    # 只要日期部分 → datetime.date(2026,8,24)
print(now.time())    # 只要时间部分

注意 datetime 是从 datetime 模块里 import 的一个类——名字撞了,这是历史包袱,记住 from datetime import datetime 就好。

知识点 3:日期加减与间隔——timedelta

要「明天」「三天后」「两个时刻差多久」,用 timedelta:

from datetime import datetime, timedelta
now = datetime.now()
tomorrow = now + timedelta(days=1)            # +1 天
three_hours_later = now + timedelta(hours=3)
last_week = now - timedelta(weeks=1)

# 两个时刻之间的间隔
d1 = datetime(2026, 8, 1, 12, 0, 0)
d2 = datetime(2026, 8, 24, 9, 0, 0)
diff = d2 - d1
print(diff.days)        # 22
print(diff.total_seconds())  # 秒(含小数)

timedelta 的字段:days / hours / minutes / seconds / weeks 等,可加减。

知识点 4:格式化与解析——strftime / strptime

把 datetime 变成字符串给用户看:strftime(格式);把字符串读成 datetime:strptime。格式符和 C 的 strftime 同源:

from datetime import datetime
now = datetime.now()
s = now.strftime("%Y-%m-%d %H:%M:%S")    # '2026-08-24 09:15:30'
print(s)
s2 = now.strftime("%A, %B %d")           # 'Monday, August 24'

# 解析回来(格式必须和字符串完全对应)
parsed = datetime.strptime("2026-08-24 09:15:30", "%Y-%m-%d %H:%M:%S")
print(parsed)

常用格式符:%Y年 %m月 %d日 %H时 %M分 %S秒 %A星期名 %B月名。strftime 是把对象→字符串,strptime 是字符串→对象,别记反(p 是 parse 解析,f 是 format 格式化)。

知识点 5:time 模块的当前时间戳与 UTC

需要 Unix 时间戳(秒数)用 time.time();UTC 时间用 datetime.utcnow()(3.11 起推荐 datetime.now(timezone.utc)):

import time
ts = time.time()                 # 1774... (Unix 秒)
print(ts)

from datetime import datetime, timezone
utc_now = datetime.now(timezone.utc)   # 带时区的 UTC 时间
print(utc_now)

跨时区、存数据库要 UTC;给用户显示再转本地。时区处理进阶用 zoneinfo(3.9+)。

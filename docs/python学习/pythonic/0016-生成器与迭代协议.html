生成器与迭代协议

Pythonic 代码 · 课程 0016 · 预计 25 分钟

C 里你要写「惰性序列」成本很高(手写迭代器结构体、状态机)。Python 里 yield 一个关键字就造出生成器——一个能「暂停/继续」、按需产出元素、不一次性占内存的函数。本课讲透 yield 与 Python 的迭代协议(iter/next),这是协程(asyncio)的地基。

知识点 1:生成器函数——用 yield 而不是 return

任何函数里只要出现 yield,它就变成生成器函数:调用它不会执行函数体,而是返回一个生成器对象;只有迭代它时函数体才跑,而且每次到 yield 就暂停、把值吐出来,下次从这继续:

def countdown(n):
    while n > 0:
        yield n           # 产出 n,暂停
        n -= 1            # 下次回来从这一行继续

g = countdown(3)          # 现在还没开始跑!
list(g)                   # 迭代才开始 → [3, 2, 1]

对比 return:return 一次性结束;yield 能多次产出、函数变「可暂停的序列」。这就是「生成器」。

知识点 2:惰性求值——省内存,处理大/无限序列

之前的生成器表达式是「惰性」的;生成器函数同样惰性。好处:不用把整个序列塞进内存。你甚至能表示「无限序列」而不炸内存:

def naturals():
    n = 0
    while True:
        yield n          # 无限产出 0,1,2,3,...
        n += 1

from itertools import islice
first5 = list(islice(naturals(), 5))   # [0,1,2,3,4] 只取前 5 个

要点:while True + yield = 无限流。islice(上一课 itertools 学过)截取前 N 个,永远不会真正跑完。yield from heapq.merge(...) 这类还能做流式合并。

知识点 3:迭代协议——for 到底怎么工作(iter/next)

for x in obj 背后是协议:iter(obj) 拿到迭代器,再不断 next(it) 直到 StopIteration。任何对象实现 __iter__(返回迭代器)就能被 for 用:

nums = [1, 2, 3]
it = iter(nums)          # 迭代器
next(it)                 # 1
next(it)                 # 2
# 手动 next 到底会抛 StopIteration

# 自定义可迭代对象:实现 __iter__ + __next__
class Evens:
    def __init__(self, n): self.n = n; self.i = 0
    def __iter__(self):
        return self
    def __next__(self):
        if self.i >= self.n: raise StopIteration
        r = self.i * 2; self.i += 1; return r

list(Evens(4))           # [0, 2, 4, 6]

`for` 会自动调 next 并捕获 StopIteration 结束,所以你平时不用碰这些;但写自定义可迭代类就要实现 __iter__(懒人做法:内部用 generator 即 yield 即可,见下一条)。

知识点 4:最省事——类里用 yield 变可迭代

自定义类想被 for 迭代,最省事是实现 __iter__ 为生成器函数:yield 会自动处理暂停和 StopIteration,不用手写 __next__:

class Squares:
    def __init__(self, n): self.n = n
    def __iter__(self):
        for i in range(1, self.n + 1):
            yield i * i        # 自动实现迭代协议

list(Squares(4))           # [1, 4, 9, 16]

能 yield 就别手写 __next__/StopIteration,更少出错。yield 帮你自动实现迭代器。

知识点 5:yield 还能「省内存地生产」再「分批消费」

生成器的经典场景:一次读一个大文件/大结果集,逐行(分片)不息整块进内存:

def read_big(path):
    with open(path, encoding="utf-8") as f:
        for line in f:
            yield line.strip()    # 逐行产出,不一次全读

for line in read_big("big.txt"):   # 边读边处理
    pass                            # 内存占用恒定

对「处理大文件 / 流式管道」,生成器能让你把多个步骤串成交互式管道,每段只占一个元素的内存。

测验 1

调用生成器函数会立刻执行函数体吗?

调用生成器函数返回生成器对象,函数体要等迭代时才跑。

测验 2

生成器用哪个关键字产元素?

yield 让函数暂停并产出值,可多次产出,不像 return 一次结束。

测验 3

for 循环背后每个元素取用靠?

iter() 拿迭代器,next() 逐个取,直到 StopIteration 异常结束。

测验 4

自定义类被 for 用,最省事是实现?

__iter__ 写成生成器(yield)自动处理协议,比手写 __next__ 省事。

合并与重塑

Pandas 专题 · 课程 0005 · 预计 30 分钟 · 补书第8章(用 hangsz 3/4/5)

真实场景要把多张表拼起来:关系型合并 merge(像 SQL JOIN)、上下/左右拼接 concat、行列索引重塑 set_index/reset_index/stack/pivot。这是 [pydata-notebook](https://github.com/BrambleXu/pydata-notebook) 缺、但你必须会的内容,用 [hangsz 3/4/5](https://github.com/hangsz/pandas-tutorial) 和官方 Merging 补齐。

知识点 1:merge——像 SQL JOIN(hangsz 3)

两表按"共同键"配对,on 指定公共列,how 选内/左/右/外:

import pandas as pd
staff = pd.DataFrame({"id": [1, 2, 3], "name": ["Ann", "Bob", "Cara"]})
dept  = pd.DataFrame({"id": [2, 3, 4], "dept": ["tech", "fin", "hr"]})

pd.merge(staff, dept, on="id")            # 内连接(两边都有)
pd.merge(staff, dept, how="left")         # 左连接(保留staff全部)
pd.merge(staff, dept, how="outer")        # 外连接(并集,NaN补)
# 键名不同:
pd.merge(staff, dept, left_on="id", right_on="dept_id")
# 键是行索引:
pd.merge(s1, s2, left_index=True, right_index=True)

merge 类比:inner=∩, outer=∪, left/right=保一边。用错配对记得还口 on+how 四个参数。

知识点 2:concat——上下/左右拼接(hangsz 3)

把多个 DataFrame"叠"起来(不是按值配对,而是按位置/索引堆叠),用 concat:

df1 = pd.DataFrame({"a": [1, 2], "b": [3, 4]})
df2 = pd.DataFrame({"a": [5, 6], "b": [7, 8]})
pd.concat([df1, df2])                    # 竖向拼接(行变多),默认 axis=0
pd.concat([df1, df2], axis=1)            # 横向拼接(列变多)
pd.concat([df1, df2], ignore_index=True) # 重置索引连续编号
# 不同列的 DataFrame 拼接:缺列变 NaN

merge=按值配对(行对齐);concat=按轴堆叠。concat([...], axis=1) 是"左右加列"的标准方式。

知识点 3:set_index / reset_index——列和索引互转(hangsz 5)

把某列提为行索引 set_index;把索引降回列 reset_index:

df = pd.DataFrame({"name": ["Ann", "Bob"], "score": [92, 85]})
df.set_index("name")         # name 变成行索引
df.set_index(["name", "score"]).index   # 多列 → MultiIndex
df.set_index("name", append=True)       # 追加到现有索引

df2 = df.set_index("name")
df2.reset_index()            # 索引降回普通列
df2.reset_index(drop=True)   # 丢掉索引(不保留列)

这是"表格 → 统计/分组"反复用到的基本动作。理解 set/reset 这对互为逆的变换,后面 groupby 和 pivot 就顺了。

知识点 4:重塑——stack / pivot(hangsz 4、5 + 官方)

行↔列互换的两种视图:stack 把列堆成行(变"长"),unstack 反向;数据透视用 pivot/pivot_table:

data = {
    "day": ["Mon", "Mon", "Tue", "Tue"],
    "city": ["A", "B", "A", "B"],
    "temp": [20, 22, 19, 24],
}
df = pd.DataFrame(data)
piv = df.pivot(index="day", columns="city", values="temp")
#       A    B
# Mon  20  22
# Tue  19  24
# 等价于 set_index(["day","city"]).unstack("city")

pivot 把"长表"转"宽表";逆操作 melt/stack。书第9章(作图)常用宽表,groupby 常用长表——pivot/stack 是切换器。

知识点 5:Index 与 MultiIndex 进阶(hangsz 4)

多级索引(MultiIndex)让你能按"外层/内层"取数,xs 取某层:

idx = pd.MultiIndex.from_product([["A", "B"], ["x", "y"]])
s = pd.Series(range(4), index=idx)
print(s["A"])            # 外层取
print(s.xs("y", level=1))  # 按内层取(s.loc[:, "y"] 也行)
df.index.get_level_values(0)   # 取某一层标签
# Index 集合运算
idxA, idxB = pd.Index([1,2,3]), pd.Index([2,3,4])
idxA.union(idxB); idxA.intersection(idxB)

MultiIndex 是"分组/按两层取数"的高级能力;先会用 xs 和 get_level_values 就够了。

测验 1

像 SQL JOIN 按键配对用?

merge=按共同键配对(JOIN);concat=按轴堆叠。

测验 2

横向加列(列变多)用?

pd.concat([df1,df2], axis=1) 左右并排加列;axis=0 是竖向堆行。

测验 3

把某列提为行索引用?

set_index 提升;reset_index 是把索引降回列,两者互为逆过程。

测验 4

长表转宽表(透视)用?

pivot 把"某列的值变列标题"成宽表;逆操作 melt/stack。

数据清洗与变换

Pandas 专题 · 课程 0004 · 预计 30 分钟 · 书第7章(7.1/7.2/7.3)

现实中数据乱糟糟:缺失值、重复行、噪声符号、离散分箱、字符串清洗。这课覆盖书 第7章:缺失值处理、数据变换、字符串处理。

知识点 1:缺失值——isnull / dropna / fillna(书 7.1)

三步:找缺失 → 删/填:

import pandas as pd, numpy as np
df = pd.DataFrame(np.random.randn(5, 3), columns=list("abc"))
df.loc[:2, "a"] = np.nan      # 造缺失

df.isnull()                # 布尔矩阵,True=缺失
df.isnull().sum()          # 每列缺失个数
df.dropna()                # 删含缺失的行(默认 any)
df.dropna(how="all")       # 只删全缺失行
df.dropna(thresh=2)        # 至少2个非缺失才保留
df.dropna(axis=1)          # 删含缺失的列

df.fillna(0)               # 全填0
df.fillna({"a": 0, "b": 1})  # 按列填不同值
df.fillna(method="ffill")  # 向前填充(用上一个值)
df.fillna(method="ffill", limit=2)   # 只连续填2个

dropna 删带缺失的行/列;fillna 用常量/字典/前向填充补缺失。这是数据清洗第一件事。

知识点 2:去重——duplicated / drop_duplicates(书 7.2)

df = pd.DataFrame({"k": [1,1,2,2,3], "v": [10,10,20,30,40]})
df.drop_duplicates()        # 删完全重复行
df.drop_duplicates("k")     # 只按某列去重(保留第一次)
df.duplicated()             # 布尔:哪些是重复

drop_duplicates 默认保留重复中的第一行(keep="first");想留最后一行 keep="last"。

知识点 3:替换与重命名——replace / rename / map(书 7.2)

data = pd.Series([1, -999, 2, -999])
data.replace(-999, np.nan)          # 把哨兵值换成缺失
data.replace([-999, -999], np.nan)  # 多个
data.replace({1: "one", 2: "two"})  # 用 dict

df = dfs = pd.DataFrame({"a": [1, 2], "b": [3, 4]})  # 改名
df.rename(columns={"a": "A", "b": "B"})
df.rename(index={0: "first"})
# map:把一个值映射成另一个值(洗值)
s = pd.Series(["cat", "dog", "cat"])
s.map({"cat": "猫", "dog": "狗"})     # 值→值 映射
s.map(lambda x: x.upper())           # 或任意函数

replace=改坏值;rename=改行列名字;map/map=用映射/函数变换一列值。

知识点 4:离散化——cut / qcut(书 7.2)

把连续年龄分成年龄段:用固定边界 cut 或等频 qcut:

ages = [20, 22, 25, 27, 30, 45, 50, 60]
bins = [18, 25, 35, 60, 100]
labels = ["青", "中", "中老", "老"]
cats = pd.cut(ages, bins=bins, labels=labels)   # 固定区间
print(pd.value_counts(cats))

# qcut:按数据量等分(每箱个数相近)
q = pd.qcut(ages, 4)     # 四分位
print(q.categories)

cut 用固定边界;qcut 按分位使每箱样本数接近;labels 给名字。

知识点 5:字符串处理——str 访问器 + re(书 7.3)

Series 的字符串列用 .str 像字符串一样整体操作;复杂匹配用正则 re:

s = pd.Series(["Alice Alice", "   Bob   ", "carol"])
s.str.strip()            # 去两端空白
s.str.upper()            # 大写
s.str.contains("a")      # 是否包含
s.str.split()            # 按空格拆(返回 list)
s.str.split(expand=True) # 拆成多列 DataFrame
# 正则提取
s.str.extract(r"(\w+)")  # 取第一个单词
s.str.findall(r"[A-Z]")  # 找所有大写字母
import re
re.split(r"\s+", "a  b c")    # 标准 re(多空白拆分)

字符串清洗三步曲:strip(去空格)→ replace/contains(替换/筛选)→ extract/split(抽取)。这是"脏文本"最常见套路。

# 配置指南

主题采用模块化配置，**所有配置文件都在 `src/config/` 目录**，每个文件负责一个功能模块。修改后保存即可，`pnpm dev` 会自动热更新；若改动的是类型定义，建议跑一次 `pnpm check`。

> [!TIP]
> `src/config/index.ts` 统一导出所有配置。组件内部通过它引用，一般不需要直接改它。
> 所有路径若以 `/` 开头，指的是 `public/` 目录下的静态资源。

## 配置索引

| 文件 | 负责模块 |
| --- | --- |
| `siteConfig.ts` | 站点基础：标题、语言、主题色、壁纸、页面开关、分页 |
| `profileConfig.ts` | 侧边栏用户资料：头像、名字、简介、社交链接 |
| `navBarConfig.ts` | 导航栏链接（含多级菜单）与搜索方式 |
| `sidebarConfig.ts` | 侧边栏布局：左右组件、顺序、动画、响应式 |
| `commentConfig.ts` | 评论系统（Twikoo / Waline / Giscus / Disqus / Artalk） |
| `announcementConfig.ts` | 侧边栏公告栏 |
| `musicConfig.ts` | 音乐播放器（Meting 在线 / 本地音乐） |
| `pioConfig.ts` | 看板娘（Spine / Live2D） |
| `sakuraConfig.ts` | 樱花飘落特效 |
| `friendsConfig.ts` | 友情链接数据 |
| `sponsorConfig.ts` | 赞助页面与收款码 |
| `adConfig.ts` | 侧边栏广告位内容 |
| `fontConfig.ts` | 字体管理 |
| `footerConfig.ts` + `FooterConfig.html` | 页脚 HTML 注入（如 ICP 备案号） |
| `expressiveCodeConfig.ts` | 代码高亮主题 |
| `coverImageConfig.ts` | 文章随机封面图 |
| `licenseConfig.ts` | 文章版权协议（如 CC BY-NC-SA 4.0） |

## 1. 站点基础 `siteConfig.ts`

这是最重要的配置文件，包含：

| 配置项 | 说明 |
| --- | --- |
| `title` / `subtitle` | 站点标题 / 副标题 |
| `site_url` | 站点 URL（用于 SEO） |
| `description` / `keywords` | 站点描述与关键词（SEO meta） |
| `lang` | 站点默认语言：`zh_CN` / `zh_TW` / `en` / `ja` / `ru` |
| `themeColor.hue` | 主题色色相（0-360，红色 0、青色 200 等），`fixed: true` 时访问者不能改色 |
| `themeColor.defaultMode` | `light` / `dark` / `system` 默认主题模式 |
| `favicon` | 站点图标路径 |
| `navbarLogo` / `navbarTitle` | 导航栏 Logo（图标 / 本地图 / 网络图）与标题 |
| `siteStartDate` | 站点开始日期，用于统计"运行天数" |
| `showLastModified` | 文章页是否显示"上次编辑"卡片 |
| `generateOgImages` | OpenGraph 图片生成（**很慢，本地调试关掉**） |
| `postListLayout` | 文章列表布局：`list` 列表 / `grid` 网格，是否允许前台切换 |
| `pagination.postsPerPage` | 每页文章数 |
| `backgroundWallpaper` | 壁纸模式（`banner` / `overlay` / `none`）、图片、位置、波浪动画 |
| `pages` | 页面开关：`sponsor`（赞助）、`guestbook`（留言板）、`bangumi`（番组计划），设 `false` 则 404 |
| `bangumi.userId` | Bangumi 用户 ID（番组计划页面数据源） |

**本博客的个性化建议**：改 `title`、`description`、`navbarTitle`、`themeColor.hue`、`siteStartDate`，把示例内容换成自己的。

## 2. 用户资料 `profileConfig.ts`

```typescript
export const profileConfig = {
  avatar: "/assets/images/avatar.webp", // 头像（放 public/assets/images/）
  name: "你的名字",
  bio: "一句简介",
  links: [
    { name: "GitHub", icon: "fa6-brands:github", url: "https://github.com/lnxlnxlnx" },
    { name: "Bilibili", icon: "fa6-brands:bilibili", url: "https://..." },
  ],
};
```

- 头像替换：把新图片放进 `public/assets/images/` 并更新 `avatar` 路径
- 图标用 [Iconify](https://iconify.design/) 名称，格式 `集合:图标名`

---

## 3. 导航栏 `navBarConfig.ts`

- `links` 数组：支持 `LinkPreset.Home`、`LinkPreset.Archive` 等预设，也支持自定义项（`name` + `url` + `icon`）
- 支持**多级菜单**：给链接加 `children` 数组即可
- 外部链接加 `external: true`
- `navBarSearchConfig`：搜索方式 `PageFind`（默认，客户端本地索引）或 `MeiliSearch`（需自建服务）
- 留言板、赞助、番组链接会根据 `siteConfig.pages` 开关自动显隐

---

## 4. 侧边栏 `sidebarConfig.ts`

控制侧边栏的显示：

- `enable`：总开关
- `position`：`left` 左侧 / `both` 双侧边栏（双侧时**不能**用网格文章布局）
- `leftComponents` / `rightComponents`：组件数组，每个组件含：
  - `type`：组件类型（`profile` 资料、`announcement` 公告、`categories` 分类、`tags` 标签、`stats` 统计、`calendar` 日历、`sidebarToc` 目录、`advertisement` 广告）
  - `enable`：该组件开关
  - `order`：显示顺序（数字小靠前）
  - `position`：`top` 顶部 / `sticky` 粘性跟随
  - `showOnPostPage`：是否在文章页显示（日历通常设为 `false`）
  - `responsive.collapseThreshold`：分类/标签超过多少项自动折叠
- `responsive.layout`：移动端 / 平板 / 桌面端的显示模式（`hidden` / `drawer` / `sidebar`）

---

## 5. 评论系统 `commentConfig.ts`

`type` 支持：`none`（关闭）、`twikoo`、`waline`、`giscus`、`disqus`、`artalk`。

**当前博客使用 Waline**，关键配置：

```typescript
waline: {
  serverURL: "https://waline.vercel.app", // 你的 Waline 后端地址
  lang: "zh-CN",
  login: "enable", // enable 允许匿名+OAuth；force 强制登录；disable 仅匿名
  visitorCount: true, // 文章访问量统计
}
```

切换评论系统：改 `type`，并填写对应系统的配置块（如 Twikoo 填 `envId`）。

---

## 6. 音乐播放器 `musicConfig.ts`

- `enable`：总开关
- `mode`：`meting`（在线，从网易云/QQ 音乐等拉歌单）或 `local`（本地音频）
- `meting`：`server`（netease/tencent/kugou…）、`type`（playlist/song/album/search）、`id`（歌单/单曲 ID）
- `local.playlist`：本地歌曲数组（`name`、`artist`、`url`、`cover`、`lrc`），音频放 `public/assets/music/`
- `player`：APlayer 参数（autoplay、loop、order、volume 等）

---

## 7. 看板娘 `pioConfig.ts`

- `spineModelConfig` / `live2dModelConfig`：Spine 与 Live2D 两套模型配置
- `enable`：对应模型的开关
- `model.path`：模型文件路径（放在 `public/pio/`）
- `position.corner`：`bottom-left` / `bottom-right` / `top-left` / `top-right`
- `interactive`：点击动画列表、点击弹窗文字、待机动画
- `responsive.hideOnMobile`：移动端隐藏

> [!NOTE]
> 注意 `pioConfig.ts` 中注释有 `interactive.enabled` 字样，实际点击交互由 `clickMessages` / `clickAnimations` 等控制；模型 JSON 中的 motions/expressions 会自动读取。

---

## 8. 樱花特效 `sakuraConfig.ts`

- `enable`：开关（当前默认开）
- `sakuraNum`：樱花数量
- `size` / `opacity` / `speed`：尺寸、透明度、速度的范围
- 花瓣图片：`public/assets/images/sakura.png`

---

## 9. 友情链接 `friendsConfig.ts`

```typescript
export const friendsConfig: FriendLink[] = [
  {
    title: "站点名",
    imgurl: "头像链接",
    desc: "一句话描述",
    siteurl: "https://example.com",
    tags: ["Blog"],
    weight: 10, // 权重，数字越大越靠前
    enabled: true,
  },
];
```

页面的自定义文案（申请规则等）在 `src/content/spec/friends.md` 中编辑。

## 10. 赞助 `sponsorConfig.ts`

- `title` / `description`：留空则用 i18n 默认翻译
- `usage`：赞助用途说明
- `showSponsorsList`：是否显示赞助者列表
- `showButtonInPost`：文章底部是否显示赞助按钮
- `methods`：赞助方式数组（`name`、`icon`、`qrCode` 收款码图片、`link`、`enabled`）
- `sponsors`：赞助者列表

> [!NOTE]
> `sponsorConfig.ts` 中微信收款码路径为 `/assets/images/sponsor/my_wechat.png`，但 `public/assets/images/sponsor/` 下目前只有 `afdian.png`、`alipay.png`、`wechat.png`。若启用微信赞助，请把收款码放到该目录并确保文件名对应。

---

## 11. 广告 `adConfig.ts`

- `adConfig1`：纯图片广告
- `adConfig2`：图文广告（标题 + 内容 + 图片 + 链接）
- 每个广告含 `image`（图片/链接）、`link`（文字链接）、`closable`、`padding`
- **开关在 `sidebarConfig.ts`**：`leftComponents` / `rightComponents` 中的 `advertisement` 组件的 `enable`，并用 `configId: "ad1"` / `"ad2"` 指定用哪个广告配置

---

## 12. 字体 `fontConfig.ts`

- `enable` / `preload`：开关与预加载
- `selected`：当前选用的字体（支持多个组合），默认 `["system"]`
- `fonts`：字体库（系统字体 / Google Fonts / MiSans），每个含 `id`、`name`、`src`、`family`
- `fallback`：全局回退字体

---

## 13. 页脚注入 `footerConfig.ts` + `FooterConfig.html`

- `footerConfig.ts`：`enable: true` 后启用页脚注入
- `FooterConfig.html`：写入要注入的 HTML（如 **ICP 备案号**、版权声明、统计代码）

---

## 14. 代码高亮 `expressiveCodeConfig.ts`

- `darkTheme` / `lightTheme`：暗色 / 亮色主题名（如 `one-dark-pro`、`one-light`）
- 更多主题见 [Expressive Code 官方文档](https://expressive-code.com/guides/themes/)

---

## 15. 随机封面图 `coverImageConfig.ts`

- `enable`：总开关（默认 `false`）
- `apis`：随机图 API 列表（依次尝试）
- `fallback`：全部失败时的备用图
- `watermark`：水印（文字、位置、透明度）
- 使用：文章 Frontmatter 中 `image: "api"` 即启用随机封面

---

## 16. 版权协议 `licenseConfig.ts`

```typescript
export const licenseConfig = {
  enable: true,
  name: "CC BY-NC-SA 4.0",
  url: "https://creativecommons.org/licenses/by-nc-sa/4.0/",
};
```

文章底部会显示版权卡片（仅当 `enable: true`）。

## 17. 多语言 `src/i18n/`

- 站点语言在 `siteConfig.ts` 的 `lang` 设置
- 界面文案的翻译在 `src/i18n/languages/`（`en.ts`、`zh_CN.ts`、`zh_TW.ts`、`ja.ts`、`ru.ts`）
- 想改界面上某个按钮/标签的文字，改对应语言的 `.ts` 文件

## 19. SEO 与索引

- **RSS**：`src/pages/rss.xml.ts` 自动生成，订阅地址 `/rss.xml`
- **Sitemap**：`@astrojs/sitemap` 自动生成，`robots.txt.ts` 指向它
- **搜索**：Pagefind（默认）在 `pnpm build` 时自动为 `dist/` 建立索引；`pagefind.yml` 可配置排除选择器
- **OpenGraph 图片**：`siteConfig.generateOgImages` 开启后生成（构建慢）

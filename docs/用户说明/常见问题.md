# 常见问题

## 开发与构建

### Q1. `pnpm install` 报错或提示只能使用 pnpm

`.npmrc` 里有 `preinstall: only-allow pnpm`。请用 pnpm 而不是 npm：

```powershell
npm install -g pnpm
pnpm install
```

### Q2. 本地打开地址是 404？

`astro.config.mjs` 设置了 `base: "/my-blog/"`，本地开发访问的是：

```
http://localhost:4321/my-blog/
```

### Q3. 页面没变化 / 样式没生效？

- 确认保存的文件在 `src/` 下
- 修改 `src/config/` 后一般会热更新；若改的是 `astro.config.mjs`，**需要重启 `pnpm dev`**
- 浏览器缓存：硬刷新（Ctrl+Shift+R）

### Q4. `pnpm check` 报类型错误？

通常原因：
- Frontmatter 字段类型不对（如 `published` 写了非日期格式、`tags` 写了字符串而非数组）
- 配置文件引用了不存在的图标名或路径
- 按报错提示修正即可。类型定义在 `src/types/config.ts` 与 `src/content.config.ts`

### Q5. 构建很慢 / 卡在 OG 图片？

`siteConfig.generateOgImages` 为 `true` 时会生成 OpenGraph 图片，非常耗时。**本地调试建议设为 `false`**，发布前再决定是否开启。

## 文章相关

### Q6. 我写的文章在线上看不到？

检查 Frontmatter 的 `draft`：
- `draft: true` → 正式构建会被过滤，本地 dev 可见
- 确认已经 `git push` 且 GitHub Actions 部署成功

### Q7. 文章排序不对 / 想置顶？

- 排序先按 `pinned: true` 置顶，再按 `published` 倒序（逻辑在 `src/utils/content-utils.ts`）
- 置顶：`pinned: true`；调日期：改 `published`

### Q8. 封面图怎么用？

- 指定图片：`image: ./cover.png`（相对文章所在目录）
- 随机图：`image: "api"`，需在 `src/config/coverImageConfig.ts` 开启 `enable`

### Q9. 文章里写代码/公式/流程图不渲染？

- 数学公式用 KaTeX：行内 `$...$`，块级 `$$...$$`
- 流程图用 Mermaid：代码块指定 `mermaid` 语言
- 检查是否有语法错误（可对比 `src/content/posts/` 里的示例文章）

## 部署

### Q10. 推送后 Actions 没跑 / 部署失败？

1. 仓库 **Settings → Pages**：Source 必须选 **GitHub Actions**
2. Actions 页面看 `Deploy to GitHub Pages` 日志的具体报错
3. 常见失败：依赖安装失败（网络/版本）、`pnpm check` 类型错误（如果该 workflow 有 check）
4. 确认当前分支是 `main`（`deploy.yml` 只在 main 触发）

### Q11. 域名 / 路径不对？

`astro.config.mjs`：
```js
site: "https://lnxlnxlnx.github.io",  // 你的站点域名
base: "/my-blog/",                    // 子路径；若用裸域名可设为 "/"
```
改了 `base` 后**必须重新构建**，否则静态资源 404。

### Q12. 换电脑 / 换系统后环境？

只需安装 Node ≥ 20 与 pnpm ≥ 9，然后在项目根执行 `pnpm install`。依赖由 `pnpm-lock.yaml` 锁定。

## 功能配置

### Q13. 评论不显示 / 报错？

- 当前使用 Waline，检查 `commentConfig.ts` 的 `serverURL` 是否指向真实可用的 Waline 服务
- 切换评论系统后要确保该系统的配置块完整（Twikoo 需 `envId`，Giscus 需 `repo` 等）
- 留言板页面依赖评论系统，`siteConfig.pages.guestbook` 与评论系统都要开启

### Q14. 看板娘 / 樱花 / 音乐播放器不显示？

- 看板娘：`pioConfig.ts` 对应模型的 `enable`，且 `public/pio/` 下有模型文件
- 樱花：`sakuraConfig.ts` 的 `enable`
- 音乐：`musicConfig.ts` 的 `enable`；`mode: "meting"` 时检查歌单 ID 与 API 可用性，`local` 时检查音频路径

### Q15. 访问量 / 统计不显示？

- 访问量统计依赖评论系统配置中的 `visitorCount: true`（如 Waline 的 `visitorCount`）
- 侧边栏"站点统计"组件在 `sidebarConfig.ts` 的 `rightComponents` 中，检查 `enable`

### Q16. 想加/删导航栏菜单？

编辑 `src/config/navBarConfig.ts` 的 `links` 数组，支持多级 `children` 菜单。

### Q17. 想改侧边栏组件顺序或开关？

`src/config/sidebarConfig.ts` 中对应组件的 `enable` 与 `order`。

### Q18. 需要 ICP 备案号？

1. `src/config/footerConfig.ts` 把 `enable` 设为 `true`
2. 在 `src/config/FooterConfig.html` 中写备案号 HTML

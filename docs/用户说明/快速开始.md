# 快速开始

本博客基于 **Astro 5.16** + **Tailwind CSS**，使用 **pnpm** 作为包管理器，部署在 **GitHub Pages**。

## 1. 环境要求

- **Node.js ≥ 20**（README 建议 ≤ 22）
- **pnpm ≥ 9**（项目锁定 `pnpm@9.14.4`）
- **Git**（用于提交和推送）

检查本机环境：

```powershell
node -v     # 应 ≥ v20
pnpm -v     # 应 ≥ 9，若无则先安装：npm install -g pnpm
git --version
```

> [!CAUTION]
> 项目 `.npmrc` 使用 `only-allow pnpm`，会强制只能用 pnpm 安装依赖，`npm install` 会报错。

## 2. 安装依赖

在项目根目录（含 `package.json` 的目录）执行：

```powershell
pnpm install
```

如提示缺少 `sharp`（图片处理库），按 README 说明执行 `pnpm add sharp`。

## 3. 本地开发预览

```powershell
pnpm dev
```

启动后访问 **http://localhost:4321**。`astro.config.mjs` 中设置了 `base: "/my-blog/"`，本地开发同样通过 `/my-blog/` 路径访问（打开 `http://localhost:4321/my-blog/`）。

支持热更新：修改 `src/` 下任意文件保存后，页面自动刷新。

## 4. 类型检查与构建

```powershell
pnpm check        # Astro 类型检查
pnpm build        # 构建到 dist/ 目录
pnpm preview      # 本地预览构建产物（模拟生产环境）
pnpm lint         # Biome 格式化与 lint（--write 自动修复）
```

## 5. 部署到 GitHub Pages

本项目已经配置好自动部署（`.github/workflows/deploy.yml`），**无需手动上传构建产物**。

### 部署流程

1. 修改代码 / 新增文章
2. 提交并推送：

```powershell
git add .
git commit -m "你的提交说明"
git push origin main
```

3. 推送后，GitHub Actions 会自动：
   - 检出代码 → 安装依赖 → `pnpm build`
   - 将 `dist/` 部署到 GitHub Pages（`https://lnxlnxlnx.github.io/my-blog/`）

### 查看部署状态

打开仓库的 **Actions** 标签页，找到 `Deploy to GitHub Pages` 工作流。绿色对勾表示部署成功，几分钟内线上生效。

> [!WARNING]
> GitHub Pages 需要在仓库 **Settings → Pages** 中把 Source 设为 **GitHub Actions**（而不是分支），否则 Actions 部署不会生效。只有第一次需要检查此项。
>
> 构建使用仓库内 `vercel.json` 无关——该文件仅当在 Vercel 部署时才生效。

### 关联文件速览

| 文件 | 作用 |
| --- | --- |
| `.github/workflows/deploy.yml` | 推送到 main 时构建并部署到 GitHub Pages |
| `.github/workflows/build.yml` | 针对 master 分支的构建检查（本仓库用 main，实际不触发） |
| `.github/workflows/biome.yml` | 代码格式检查 |
| `astro.config.mjs` | `site`（`https://lnxlnxlnx.github.io`）与 `base`（`/my-blog/`） |

> [!NOTE]
> 如果你改用 Vercel 部署，部署配置在 `vercel.json`（`pnpm build` → `dist/`），并在 Vercel 控制台配置。GitHub Pages 与 Vercel 二选一即可。

## 6. 常见命令汇总

| 命令 | 作用 |
| --- | --- |
| `pnpm dev` | 本地开发服务器（localhost:4321） |
| `pnpm build` | 生产构建到 `./dist/` |
| `pnpm preview` | 本地预览构建产物 |
| `pnpm check` | Astro 类型检查 |
| `pnpm lint` / `pnpm format` | Biome 检查 / 格式化 |
| `pnpm new-post <文件名>` | 创建新文章 |
| `pnpm astro ...` | 执行 Astro CLI（如 `pnpm astro add`） |
| `pnpm index:meili` | 手动同步 MeiliSearch 索引 |

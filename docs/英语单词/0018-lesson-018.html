单词释义记忆钩子
uncovervt. 揭露,发现;揭开...的盖子un + cover 盖子 → 揭开盖子 = 揭露真相。
elbown. 肘;(衣服的) 肘部 vt. 用肘推记忆法:elbow 里有 bow(弓),手臂弯成弓形处就是肘。
hijackvt. 劫持 (⻜机、⻋辆等);控制,操纵 n. (⻜机、⻋辆等的) 劫持事件经典联想:歹徒喊 “Hi, Jack!” 趁机劫持飞机。
tempern. 脾气;怒气;心情 vt. 使缓和;使 (金属) 回火与 temperature 同源“适度”→ 调适缓和;lose temper 发脾气。
justicen. 公平,正义;法官;司法制度just 公正 + ice → 公平正义;法庭上主持的就是法官。
loann. 贷款;暂借 vt. 借出语境:向银行贷款 loan 买房,贷款要还本付息。
timbern. 树林;木材,木料;大梁画面:森林伐倒的 timber 原木,盖房的大梁木材。
crown. 乌鸦 vi. 啼叫,打鸣;(婴儿) 欢叫 vi. vt. 自鸣得意拟声词:乌鸦 crow 啼叫,公鸡打鸣也叫 crow。
inferioradj. 较差的,较次的;级别低的 n. 下级,下属反义 superior 优越 → inferior 较差的、级别低的下级。
gesturen. 手势,姿势;姿态,表示 vi. vt. 打手势,用手势表示语境:说话时打手势 gesture,姿态表示友好。
Thanksgivingn. 感恩节thanks 感谢 + giving 给予 → 感谢上天给予 = 感恩节。
cottonn. 棉花;棉布;棉线;药棉画面:棉花糖 cotton candy,软绵绵的棉花。
discouragevt. 打消...的念头,阻止;使灰心courage 勇气,dis 去掉 → 卸掉勇气 = 使灰心、劝阻。
threatn. 威胁;坏事发生的可能语境:收到 threat 威胁信,扬言坏事会发生。
portrayvt. 将...表现成;描绘,描写;扮演同源 portrait 肖像画 → portray 描绘、刻画、扮演。
statuen. 雕像,雕塑联想:status 地位,statue 立在广场的雕像,都源自“站立”。
pesticiden. 杀虫剂,农药pest 害虫 + cide 杀(suicide 自杀)→ 杀害虫的药 = 农药。
inhabitvt. 居住于,栖居在in 内 + habit 习惯 → 住习惯了 = 居住(habitat 栖息地)。
dispositionn. 性情;倾向;布置,安排;处置position 位置,dis 分开摆放 → 布置;天生摆好的性情。
tailorn. 裁缝 vt. 定做语境:裁缝 tailor 量体裁衣,为你定做衣服。
dormitoryn. 宿舍,宿舍楼dorm 睡(dormant 休眠)→ 睡觉的地方 = 宿舍。
sheltern. 住处;庇护;避难处,收容所 vt. 保护,掩蔽 vi. 躲避画面:暴风雨中 shelter 是避雨避难处,保护你。
starevi. 盯着看,凝视 n. 盯着看,凝视谐音联想:stare 像“死盯”,死死地盯着看。
affluentadj. 富裕的,富足的flu 流(fluid)→ 财富向里流 = 富裕的。
imitatevt. (为逗乐) 模仿;仿效,模拟同源 image 形象 → 照样子做出 = 模仿、仿效。
illiterateadj. 文盲的;外行的 n. 文盲literate 识字(literature 文学),il 否定 → 不识字 = 文盲。
frontiern. 国界,边界;(知识的) 前沿front 前面 → 最前线 = 边疆;(知识)前沿。
brokeadj. 身无分文的,破产的联想:账本被 break 破了 → 身无分文 = broke 破产。
informvt. 通知,告知;了解;影响同源 information 信息 → 把信息告诉人 = 通知。
wedvi. vt. (与...) 结婚同源 wedding 婚礼 → wed = 结婚。
eyesightn. 视力eye 眼 + sight 看 → 眼睛看东西的能力 = 视力。
feasibleadj. 可行的,行得通的同源 fact 做 → 做得成的 = 可行、行得通。
acquaintvt. 使熟悉,使了解同源 acquaintance 熟人 → 使熟悉、使了解。
indignantadj. 愤慨的,愤怒的dignity 尊严,in 否定 → 伤了尊严 = 愤慨的。
havocn. 灾害,祸患,浩劫语境:wreak havoc 造成浩劫,天灾人祸横行 = 大破坏。
collarn. 衣领,领子;(动物的) 项圈 vt. 抓住,逮住画面:抓猫抓 collar 项圈;抓人衣领 collar 就是逮住。
primitiveadj. 原始的;落后的;原始本能的 n. 原始派艺术家prim 第一(primary)→ 最早的阶段 = 原始的、落后的。
underlievt. 构成...的基础,作为...的原因under 下 + lie 躺 → 躺在下面支撑 = 构成基础。
joyn. 喜悦;令人高兴的事 (或人)画面:《头脑特工队》的主角 Joy 就是快乐本尊 = 喜悦。
optimismn. 乐观,乐观主义optim 最好(optimum 最优)→ 总往最好处想 = 乐观。

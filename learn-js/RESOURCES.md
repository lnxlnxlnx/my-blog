# JavaScript Resources

针对"读懂 Firefly 博客"这个目标的精选资源。知识主要来源于下面这些高可信来源，而不是我的参数记忆。

## Knowledge

- [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)
  Mozilla 官方 JS 教程，权威、免费。Use for: 任何 JS 语法/概念的权威定义。
- [MDN: JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)
  语法速查。Use for: 查具体语法（模板字符串、箭头函数、`switch` 等）。
- [MDN: Web APIs](https://developer.mozilla.org/en-US/docs/Web/API)
  浏览器 API 大全。Use for: `document`、`window`、`localStorage`、`matchMedia` 等浏览器环境知识。
- [JavaScript.info](https://javascript.info/)
  结构清晰、按主题组织的免费教材，中文版在 zh.javascript.info。Use for: 系统学习 DOM 与浏览器事件。
- [Astro Docs](https://docs.astro.build/en/concepts/why-astro/)
  本博客的核心框架官方文档。Use for: 理解 `.astro` 文件、构建流程、frontmatter。
- [Svelte Docs](https://svelte.dev/docs)
  本博客的组件框架官方文档。Use for: 理解 `.svelte` 组件语法。
- [Firefly 主题文档](https://docs-firefly.cuteleaf.cn/)
  本博客所基于的主题文档。Use for: 主题本身的配置与结构。

## Wisdom (Communities)

- [MDN Discussions](https://github.com/mdn/content/discussions) / [JavaScript 中文社区](https://zh.javascript.info/forum)
  Use for: JS 学习问题提问。
- [Astro Discord](https://astro.build/chat)
  Use for: Astro 框架问题。
- 本地: 你自己就有这个博客的源代码和 `node_modules` —— 它本身就是最好的"活教材"。

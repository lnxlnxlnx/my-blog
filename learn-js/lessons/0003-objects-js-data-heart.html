Lesson 0003 · 对象 (Object)：JS 的数据心脏

前两课里，你见到的 localStorage、document、window、mediaQuery——它们全都是对象。对象是 JS 里最核心的数据结构，不搞懂它，后面全是雾里看花。

今天这节课的收获：能看懂博客里到处出现的 { 名字: 值 } 这种代码，并读懂 src/utils/date-utils.ts 里的真实对象。

1. 什么是对象

对象就是一个"名字 → 值"的映射表。用花括号 {} 包起来，里面每一项叫一个属性 (property)：

const site = {
    name: "Firefly",       // 属性名 name → 值 "Firefly"
    year: 2026,            // 属性名 year → 值 2026
    isBlog: true,
};

// 读取：点号语法
console.log(site.name);   // Firefly
console.log(site.year);   // 2026

// 修改 / 新增
site.year = 2027;
site.author = "me";    // 没有的键，直接加
console.log(site.author); // me

两个读取方式：点号 vs 方括号

写法用途
site.name属性名是固定的、合法标识符时用（最常见）
site["name"]属性名是变量 / 字符串拼出来的时用
const key = "year";
console.log(site[key]);  // 2026 —— 方括号里可以是变量！点号不行
console.log(site.key);   // undefined —— 没有叫 "key" 的属性

高频坑：site[key] 和 site.key 是两码事。前者用变量 key 的值去找属性，后者直接找名为 "key" 的属性。写错过的人，十个里有八个。

2. 值可以是任何东西——包括函数

对象的属性值可以是字符串、数字、布尔、数组、对象，甚至函数。属性值是函数的，叫方法 (method)。你之前见的 localStorage.getItem(...)、document.documentElement.classList.add(...) 全都是在调用方法：

const calculator = {
    value: 10,
    add(n) {
        this.value = this.value + n;
    },
};

calculator.add(5);
console.log(calculator.value); // 15

关于 this：方法里 this 指"调用它的那个对象"。现在只需要记住一句话：this.value 就是"我这个对象自己的 value"。箭头函数里的 this 行为不同——那是 Lesson 0002 里 (e) => 的一个细节，我们以后单独讲，现在不碰。

3. 数组里装对象、对象里装数组（嵌套）

真实代码里对象基本不会"孤零零"出现，而是嵌套组合。博客里到处都是这种结构：

const posts = [
    { title: "第一课", date: "2026-08-16" },
    { title: "第二课", date: "2026-08-17" },
];

// 下标访问数组 → 得到对象 → 点号读属性，一步到位
console.log(posts[0].title); // 第一课
console.log(posts[1].date);  // 2026-08-17

// 遍历数组：forEach 里传入回调，数组把每个元素递给你
posts.forEach((post) => {
    console.log(post.title, "-", post.date);
});

拆解 posts[0].title：从左往右读——posts 是数组 → [0] 取第 0 个元素（一个对象）→ .title 读它的 title 属性。一层层剥下去，就是读嵌套数据的全部秘诀。

4. 读真实代码：date-utils.ts

现在你有能力读博客里第二个真实文件了。打开 src/utils/date-utils.ts，看第 20-35 行：

    const localeMap: Record<string, string> = {
        zh_CN: "zh-CN",
        zh_TW: "zh-TW",
        en: "en-US",
        ja: "ja-JP",
        ko: "ko-KR",
        // ... 后面还有更多语言
    };

    const locale = localeMap[lang] || "en-US";
    return date.toLocaleDateString(locale, options);
}

这里 localeMap 就是一个映射表对象：把博客内部的语言代码（zh_CN）翻译成浏览器标准代码（zh-CN）。第 9 行又用到了第一课的 ||：找不到就用 "en-US" 兜底。

再看上面第 13-17 行（我没放全），有个 options 对象：

    const options: Intl.DateTimeFormatOptions = {
        year: "numeric",
        month: "long",
        day: "numeric",
    };
    // 就是让日期显示成：2026 年 8 月 16 日
    return date.toLocaleDateString(locale, options);
}

发现了吗？你已经在读真实博客代码了——localeMap、options 都是对象，date.toLocaleDateString(...) 是方法调用，`localeMap[lang] || "en-US" 是第一课的 ||。这些你都认识了。

5. 更多例子：复制到控制台试

// 例子 1：一个"博客文章"对象，套娃读取
const post = {
    title: "学习 JS 第 3 课",
    meta: { tags: ["js", "object"], views: 99 },
};
console.log(post.meta.tags[0]);  // js
console.log(post.meta.views);      // 99

// 例子 2：方法 + 模板字符串
const user = {
    name: "Luna",
    sayHi() {
        console.log(`你好，我是${this.name}`);
    },
};
user.sayHi();  // 你好，我是 Luna

// 例子 3：方括号读取 + 数据驱动
const theme = { light: "#fff", dark: "#111" };
const mode = "dark";
console.log(theme[mode]);  // #111 —— 用变量选属性

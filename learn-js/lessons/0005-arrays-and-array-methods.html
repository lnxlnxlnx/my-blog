Lesson 0005 · 数组与数组方法

数组你应该认识（Python 的 list、Java 的 array）。但 JS 数组有一整套链式方法——map、filter、find、sort、forEach——它们是博客代码里最最常见的处理手段。这课我们把 content-utils.ts 里真实的数组代码全讲一遍。

今天这节课的收获：能看懂"遍历文章列表、统计标签、排序"这类代码。

1. 五个必会方法

方法干什么返回回调
arr.map(fn)每个元素变一个"新值"等长新数组return 新值
arr.filter(fn)留下满足条件的元素变短的新数组return 布尔
arr.find(fn)找到第一个满足的单个元素 / undefinedreturn 布尔
arr.sort(fn)排序（会改原数组）原数组return 比较数
arr.forEach(fn)逐个"看一眼"不返回值undefined做副作用
const posts = [
    { title: "A", pinned: true, views: 10 },
    { title: "B", pinned: false, views: 5 },
    { title: "C", pinned: false, views: 20 },
];

// map：每个元素 → 新值（只留 title）
const titles = posts.map((p) => p.title);
console.log(titles); // ['A', 'B', 'C']

// filter：留下 views > 8 的
const hot = posts.filter((p) => p.views > 8);
console.log(hot.length); // 2

// find：找第一个 pinned 的
const first = posts.find((p) => p.pinned);
console.log(first?.title); // A

记忆口诀：map = 变形，filter = 筛选，find = 找第一个，sort = 排序，forEach = 走一遍。五个回调都是箭头函数，参数就是"当前元素"。

2. sort 的特殊性

content-utils.ts 里 getRawSortedPosts 用的就是 sort：

    const sorted = allBlogPosts.sort((a, b) => {
        // 置顶文章在前
        if (a.data.pinned && !b.data.pinned) return -1;
        if (!a.data.pinned && b.data.pinned) return 1;

        // 再按日期排（新的在前）
        const dateA = new Date(a.data.published);
        const dateB = new Date(b.data.published);
        return dateA > dateB ? -1 : 1;
    });

sort 的回调拿两个元素 a、b：返回负数表示 a 排在 b 前，正数表示 a 排在 b 后，0 表示相等。这段代码：先比置顶，置顶相同再比日期。

3. 真实案例：统计标签

这是 getTagList 的核心，把三种技术组合起来：

    const countMap: { [key: string]: number } = {};
    // 1. forEach：遍历所有文章
    allBlogPosts.forEach((post) => {
        // 2. 再遍历这篇文章的所有标签
        post.data.tags.forEach((tag) => {
            // 3. 统计：没见过的标签初始化为 0，然后 +1
            if (!countMap[tag]) countMap[tag] = 0;
            countMap[tag]++;
        });
    });

    // 4. Object.keys 取出所有标签名，再 sort 排序
    const keys = Object.keys(countMap).sort((a, b) =>
        a.toLowerCase().localeCompare(b.toLowerCase()),
    );

    // 5. map：把 { 标签名: 次数 } 变成 [{ name, count }] 数组
    return keys.map((key) => ({ name: key, count: countMap[key] }));
}

读法：这段就是"把所有文章的标签全数一遍"。countMap 是一个对象，属性名 = 标签名，属性值 = 出现次数。最后 map 成规范数组返回。map/filter 常和对象"形状转换"搭配：数据进来是一种样子，map 成另一种样子出去。

4. 更多例子：复制到控制台试

const nums = [1, 2, 3, 4, 5];

// map：平方
console.log(nums.map((n) => n * n));        // [1,4,9,16,25]

// filter：偶数
console.log(nums.filter((n) => n % 2 === 0)); // [2,4]

// 链式：先 filter 再 map
console.log(
    nums.filter((n) => n % 2 === 0).map((n) => n * 10), // [20,40]
);

// sort：注意要传比较函数，否则按字符串排
console.log([10, 2, 33].sort());          // [10,2,33]（错了！）
console.log([10, 2, 33].sort((a,b)=>a-b)); // [2,10,33]

经典坑：sort() 不传参数时按字符串排，[10,2,33] 会排成 [10,2,33]。数字排序永远要传 (a,b) => a - b。

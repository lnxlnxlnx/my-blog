Lesson 0007 · 异步编程：async/await 与 Promise

这是 JS 新手最容易卡住的一关，但它本质就一句话："等数据回来的这段时间，程序别傻等，先去干别的；数据到了再接着往下走。"

今天这节课的收获：读懂博客里所有 async / await / fetch 代码，包括 RSS 生成和天气查询。

1. 为什么要"异步"

有些操作很慢：读文件、请求网络、等 2 秒。如果程序干等，整个页面就卡死。所以 JS 用回调（第二课学过）处理这类操作：先注册"做完了要做什么"，不等。

但回调嵌套多了很难读。于是有了 Promise 和 async/await——把"异步代码写得像同步一样"，可读性大幅提升。

2. async 函数：把函数变成"承诺返回结果"

// async 函数永远返回一个 Promise
async function getData() {
    return "数据";  // 直接返回，内部会自动包成 Promise
}

const result = await getData();  // await 等它完成，取出里面的值
console.log(result); // 数据

3. await：暂停，等结果

await 只能用在 async 函数里。它让代码"在这一行暂停"，直到 Promise 完成，然后取出结果继续往下。看一下博客 rss.xml.ts 的真实片段：

export async function GET(context: APIContext) {
    const posts = await getSortedPosts();  // 等文章数据回来
    // ... 数据到手后继续处理
    return new Response(xml);
}

content-utils.ts 里也到处是 await getCollection(...)。这些都是"先等数据，再往下算"。

类比：你去餐厅点餐。await = "点完餐坐好等上菜"——服务员去后厨了，你坐着等，但没占着整条街。等菜到了，你的"代码"继续执行。

4. fetch：请求网络的标准方式

about.astro 里查天气的真实代码（我们会在第 9 课细读）：

    async function fetchWeather() {
        try {
            // 1. 发请求，await 等响应回来
            const res = await fetch(`https://api.open-meteo.com/v1/forecast?latitude=...`);
            // 2. 把响应体解析成 JSON 对象
            const data = await res.json();
            // 3. 取里面的数据
            const temp = data.current.temperature_2m;
            console.log(`当前温度：${temp}°C`);
        } catch (err) {
            // 出错时处理（网络挂了、地址错了等）
            console.error("请求失败", err);
        }
    }

模式非常固定，记住就行：await fetch(网址) → await res.json() → 用数据。用 try/catch 包住，出错不崩。

5. Promise.all：并行等

有时多个请求互不依赖，可以同时发。rss.xml.ts 真实代码：

    const [rResp, bResp] = await Promise.all([
        fetch(regularUrl),   // 同时发两个请求
        fetch(boldUrl),
    ]);

Promise.all([...]) 接收一个 Promise 数组，等全部完成，结果按顺序放回数组。比一个个 await（串行）快得多。

6. 更多例子：复制到控制台试

// 例子 1：模拟慢操作，体会 await
async function demo() {
    console.log("开始");
    await new Promise((resolve) => setTimeout(resolve, 2000));
    console.log("2 秒后继续");
}
demo();

// 例子 2：真的 fetch 一次公共 API（天气）
const url = `https://api.open-meteo.com/v1/forecast?latitude=31.23&longitude=121.47&current=temperature_2m`;
const res = await fetch(url);
const data = await res.json();
console.log(`上海现在：${data.current.temperature_2m}°C`);

在浏览器控制台：顶级代码也支持 await（这叫 Top-level await），直接粘就行。成功后你能看到上海温度——这就是 about.astro 里天气面板的原理。

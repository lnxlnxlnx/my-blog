1. 新代码（真实文件 44-79 行）

这段在管"用户选了『跟随系统』时，系统切换暗/亮，博客要跟着变"。

    // Setup system theme change listener if using system mode
    if (theme === SYSTEM_MODE) {
        const mediaQuery = window.matchMedia("(prefers-color-scheme: dark)");
        const handleSystemThemeChange = (e) => {
            const currentStoredTheme = localStorage.getItem("theme");
            if (currentStoredTheme === SYSTEM_MODE) {
                const newTheme = e.matches ? DARK_MODE : LIGHT_MODE;
                const newIsDark = newTheme === DARK_MODE;

                if (newIsDark) {
                    document.documentElement.classList.add("dark");
                } else {
                    document.documentElement.classList.remove("dark");
                }

                const expressiveTheme = newIsDark ? "github-dark" : "github-light";
                document.documentElement.setAttribute("data-theme", expressiveTheme);
            }
        };

        // Add listener for system theme changes
        mediaQuery.addListener(handleSystemThemeChange);
    }

    const expressiveTheme = isDark ? "github-dark" : "github-light";
    document.documentElement.setAttribute("data-theme", expressiveTheme);

    // 确保主题正确应用 - 解决代码块渲染问题
    const currentTheme = document.documentElement.getAttribute("data-theme");
    if (currentTheme !== expressiveTheme) {
        document.documentElement.setAttribute("data-theme", expressiveTheme);
    }
}

第 1 个新概念：箭头函数 (e) => {...}

第 47 行 const handleSystemThemeChange = (e) => { ... } —— 这是在用箭头语法定义函数。它就是普通函数的简写：

写法含义
function getSystemPreference() { ... }普通函数（第一课见过）
const f = (x) => { ... }箭头函数：把函数值存进变量 f
const f = x => x * 2极简箭头：单参数省略括号、单行省略大括号和 return

关键点：箭头函数是一个"值"，可以被存进变量、被当作参数传递。这在 JS 里极其常见。

第 2 个新概念：回调函数（callback）

第 65 行 mediaQuery.addListener(handleSystemThemeChange) —— 注意这里传的是函数本身，不是调用它（没有 ()）。

意思是：告诉浏览器"当系统主题变化时，你替我调用这个函数"。被传进去、等事件发生时才执行的函数，叫回调函数。

事件驱动是这个博客前端大量 JS 的工作方式：注册一个"钩子"，事件来了浏览器叫你。

类比：你订了外卖，把手机号留给前台（addListener）。外卖到了前台打电话给你（回调）。你没在打电话，是前台在"等着"替你打。

第 3 个新概念：模板字符串 `${offset}px`

翻到真实文件 85-91 行，你会看到：

    let offset = Math.floor(window.innerHeight * (BANNER_HEIGHT_EXTEND / 100));
    offset = offset - (offset % 4);
    document.documentElement.style.setProperty(
        "--banner-height-extend",
        `${offset}px`,
    );
}

注意第 5 行用的是反引号 `（键盘左上角那个键，不是单引号）。它叫模板字符串：

  • `${offset}px` 会把变量 offset 的值拼进字符串
  • 比如 offset = 300 时，结果就是 "300px"
  • 等价于老写法 "300" + offset + "px"，但清晰得多

记忆点：字符串里有 ${...} 就往里插变量 → 用的是反引号 `，不是引号。

2. 更多例子：复制到浏览器控制台试

打开 DevTools 控制台（F12 → Console），把下面每一段整块复制进去回车，看输出，再改改数字、变量名试试。

例子 1：普通函数 vs 箭头函数

// 普通函数
function square1(n) { return n * n; }
// 箭头函数（等价的简写）
const square2 = (n) => n * n;

console.log(square1(4)); // 16
console.log(square2(4)); // 16

// 箭头函数没有参数、多行函数体的写法
const greet = () => {
    return "hello";
};
console.log(greet()); // hello

例子 2：回调函数（核心中的核心）

// 自定义一个"会在 2 秒后调用你给的函数"的函数
function waitTwoSeconds(callback) {
    setTimeout(callback, 2000);
}

// 传入箭头函数作为回调：2 秒后它会被调用
waitTwoSeconds(() => console.log("2 秒到了！"));

// 回调还能带参数：这里 2 秒后打印 "番茄"
setTimeout((fruit) => console.log(fruit), 2000);
console.log("这句话会先打印（因为上面在等 2 秒）");

例子 3：模板字符串

const name = "Firefly";
const year = 2026;

// 拼接：直接写在 ${} 里，还能放表达式
console.log(`${name} 建于 ${year} 年，距今 ${year - 2016} 年`);

// 多行字符串（不用 \n 也不用 +）
const multi = `第一行
第二行
第三行`;
console.log(multi);

小结：这三个东西你会在博客里到处看到。尤其是回调——先记住"传函数进去，等着被调用"这句就够了。

3. 练习

打开真实文件 src/scripts/theme-manager.js 的 74-79 行，那其实是简化过的。真实代码把这段包在 requestAnimationFrame(() => { ... }) 里。requestAnimationFrame 接收一个箭头函数作为回调——它会在浏览器下一次重绘前调用它。你能否认出：

  1. 哪个是回调函数？
  2. 谁在"等"它？
点击看答案

① () => { ... } 这整段是回调。② requestAnimationFrame 在等——它保证这个函数在屏幕刷新前执行，避免主题切换闪烁。

Lesson 0009 · Astro 文件结构

现在你把 JS 基础打牢了，可以正式进入博客的核心了。Astro 是一个静态站点生成器：写页面时用 JS 生成数据，构建时把它"烤"成纯 HTML 文件（所以加载飞快）。.astro 文件就是把"JS 逻辑 + HTML 模板"写在同一个文件里。

今天这节课的收获：能读懂任意一个 .astro 页面，知道它的"三段式"结构。

1. .astro 文件的三段式

---
// 第 1 段：frontmatter（脚本区）
// 放 import、从数据源取数据、做计算
import { getEntry } from "astro:content";
import MainGridLayout from "@/layouts/MainGridLayout.astro";

const aboutPost = await getEntry("spec", "about");
---

<!-- 第 2 段：HTML 模板（可以用 JS 变量） -->
<MainGridLayout title={aboutPost.data.title}>
    <h1>{aboutPost.data.title}</h1>
    <p>这篇文章写于 {aboutPost.data.date}</p>
</MainGridLayout>

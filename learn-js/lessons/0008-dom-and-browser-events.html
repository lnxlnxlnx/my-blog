Lesson 0008 · DOM 与浏览器事件

第一课我们见过 document.documentElement.classList。这课系统讲清楚 DOM（Document Object Model）：浏览器把整个网页 HTML 变成一棵"对象树"，JS 通过 document 找到任意元素、改它、听它的事件。这是所有"页面交互"的地基。

今天这节课的收获：读懂 code-copy-utils.ts（复制按钮）和 about.astro 里的事件代码。

1. DOM：网页 = 一棵对象树

浏览器的内存里，你的 HTML 长这样（示意）：

document
└── html (documentElement)
    ├── head
    └── body
        ├── div#app
        │   ├── button "读取状态"
        │   └── span#weather-temp "--"
        └── script

每个标签是一个"元素对象"。JS 能用 document 提供的各种方法把它们找出来。

2. 找元素：四种方法

方法返回例
document.getElementById("x")单个元素（按 id）博客里最常见
document.querySelector(".class")单个（CSS 选择器）取第一个匹配
document.querySelectorAll("...")所有匹配的列表循环处理
el.querySelector(...)在 el 内部找code-copy 里用过
// about.astro 真实代码：用 id 找到元素并操作
const msg = document.getElementById("esp32-msg")!;
msg.textContent = "请求中...";  // 改文本

// code-copy-utils.ts 真实代码：内部查找
const preEle = target.closest("pre");      // 往上找最近的 <pre>
const codeEle = preEle?.querySelector("code"); // 在里面找 <code>

元素常用的属性 / 方法

  • el.textContent / el.value：读改文本 / 表单值
  • el.className / el.classList.add()、.remove()：改 CSS 类
  • el.style.setProperty("--hue", "200")：改内联样式
  • el.setAttribute() / el.getAttribute()：设置/读 HTML 属性

3. 事件：addEventListener

事件 = "浏览器里发生了什么"（点击、键盘、滚动、窗口变化）。用 addEventListener(事件名, 回调) 注册监听，事件发生时浏览器调用你的回调：

// about.astro 真实代码：给按钮挂点击事件
document.getElementById("esp32-status")!.addEventListener("click", () => {
    request("/status");  // 点击时发起请求
});

// 窗口尺寸变化
window.addEventListener("resize", resizeCanvas);

// 定时器事件
const timer = setInterval(() => request("/status"), 2000); // 每2秒
clearInterval(timer); // 停止

和"回调"接上了：addEventListener("click", fn) 就是第二课学的回调——传函数进去，事件发生时浏览器替你调用。事件的回调常收到一个 event 参数（比如 (e) => e.target 拿到被点的元素）。

4. 完整真实案例：复制按钮

code-copy-utils.ts 把这一课的知识全串起来了（简化）：

export async function handleCodeCopy(target: Element): Promise<void> {
    // 1. 从被点的按钮往上找到 <pre>，再在里面找 <code>
    const preEle = target.closest("pre");
    const codeEle = preEle?.querySelector("code");
    if (!codeEle) return;

    // 2. 提取代码文本（用数组拼起来）
    const lines: string[] = [];
    const lineEls = codeEle.querySelectorAll("span.line");
    lineEls.forEach((line) => lines.push(line.textContent || ""));
    const code = lines.join("\n");

    // 3. 异步复制到剪贴板
    await copyToClipboard(code);

    // 4. 按钮加 success 类（变绿），1 秒后移除
    target.classList.add("success");
    setTimeout(() => target.classList.remove("success"), 1000);
}

注意每一行用到的知识：找元素（querySelector/closest）、数组 join、async/await（第七课）、classList、setTimeout 事件。你全都学过了。

5. 更多例子：复制到控制台试

// 例子 1：改当前页面的标题
document.title = "被我改了！";

// 例子 2：找到页面上所有 <a> 链接并数一数
const links = document.querySelectorAll("a");
console.log(`页面上有 ${links.length} 个链接`);

// 例子 3：给第一个链接加红边框
links[0].style.border = "2px solid red";

// 例子 4：点击任意处弹出坐标
document.addEventListener("click", (e) => console.log(e.clientX, e.clientY));

温馨提示：例子 4 会一直监听，刷新页面才会停。例子 1 会改掉博客页面标题，刷新即恢复。放心玩。

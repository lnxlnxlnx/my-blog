Lesson 0004 · TypeScript 类型标注

从这课开始，我们进入 .ts 文件。TypeScript（TS）就是 JS + 类型标注：在变量的名字旁边写清楚"这个东西是什么类型"。编译器会检查你的代码，写错了提前报错。博客里大多数逻辑代码都是 .ts。

今天这节课的收获：读懂 date-utils.ts 里全部的 : 冒号标注。

1. 最基本的类型标注

三种最常碰到的写法，都在 src/utils/date-utils.ts 里出现过：

function formatDateI18n(dateString: string): string {
    const date = new Date(dateString);
    return date.toLocaleDateString(locale, options);
}

const dateA = new Date(a.data.published); // Date 类型对象
const theme = localStorage.getItem("theme") || defaultMode;
const isDark = false; // boolean 布尔
标注意思举例
: string这是个字符串dateString: string
: number这是个数字count: number
: boolean这是 true/falseisDark: boolean
: Date这是个 Date 日期对象date: Date
: string[]这是字符串数组tags: string[]
: object / 对象字面量这是对象site: SiteConfig

函数参数的标注写在括号里（dateString: string），函数返回值的标注写在箭头之后（): string）。

关键心态：标注只是说明，不影响运行逻辑。TS 编译成 JS 时，这些 : string 全部被擦掉。你可以先忽略它们读懂逻辑，再回来看类型。

2. 对象的类型：Record 和自定义类型

date-utils.ts 里这两行是重点：

    const localeMap: Record<string, string> = {
        zh_CN: "zh-CN",
        en: "en-US",
    };

    const options: Intl.DateTimeFormatOptions = {
        year: "numeric",
        month: "long",
        day: "numeric",
    };
  • Record<string, string>：一个"键是 string、值是 string"的映射表。回想第三课——localeMap 恰好就是这种结构。
  • Intl.DateTimeFormatOptions：一个现成的类型名，它描述了"日期格式化选项这个对象允许有哪些属性"。你把 day 写成 "x"（非法值）编辑器就会红。

自定义类型：type 和 interface

博客里大量用 type / interface 给对象"起名字"。content-utils.ts 里就有：

export type Tag = {
    name: string;
    count: number;
};

export async function getTagList(): Promise<Tag[]> {
    // ... 返回一个 Tag 对象数组
    return keys.map((key) => ({ name: key, count: countMap[key] }));
}

type Tag = { name: string; count: number } 定义了一个"形状"：任何有 name(字符串) 和 count(数字) 的对象，都可以当 Tag 用。函数返回类型 Promise<Tag[]> 意思是"返回一个 Tag 数组"（Promise 下一课讲）。

3. 常见操作符：? 和 !

about.astro 里能看到这两个符号（我们在第 9 课会细读）：

const msg = document.getElementById("esp32-msg")!;
const data = weatherMsgEl?.value;
  • ! （非空断言）："我向你保证这个不是 null/undefined"。后面继续用。
  • ?.（可选链）："如果左边是 null/undefined，就返回 undefined，别再往下取"。防止"取一个不存在的东西"报错。

区分：a?.b 是"安全地访问"；a! 是"向编译器打包票"。一个是防御，一个是声明。

4. 更多例子：复制到控制台试（Node 或浏览器）

// 例子 1：给变量加类型标注（纯 JS 也能跑，标注被忽略）
const name: string = "Firefly";
const posts: string[] = ["第1课", "第2课"];
console.log(name, posts.length);

// 例子 2：可选链 vs 非空断言
const obj: { a?: { b?: number } } = {};
console.log(obj.a?.b);        // undefined，不报错
console.log(obj.a?.b ?? 0); // 0 —— ?? 是"兜底"，和 || 类似

?? vs ||：a ?? b 只在 a 是 null/undefined 时用 b；a || b 在 a 是任何"假值"（0、空字符串、false）时都用 b。大多数"兜底"场景用 ?? 更准确。

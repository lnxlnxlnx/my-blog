2. 先看真实的代码（前 22 行）

这就是 src/scripts/theme-manager.js 的开头（我加了行号）：

// 主题管理脚本
export function initThemeManager() {
    const _DEFAULT_THEME = "LIGHT_MODE";
    const LIGHT_MODE = "LIGHT_MODE";
    const DARK_MODE = "DARK_MODE";
    const SYSTEM_MODE = "SYSTEM_MODE";
    const BANNER_HEIGHT_EXTEND = 30;
    const configHue = 200; // 从配置中获取
    const defaultMode = "system"; // 从配置中获取

    // Load the theme from local storage, use defaultMode from config if not set
    const theme = localStorage.getItem("theme") || defaultMode;

    // Helper function to get system preference
    function getSystemPreference() {
        return window.matchMedia("(prefers-color-scheme: dark)").matches
            ? DARK_MODE
            : LIGHT_MODE;
    }
}

第 1 个新概念：const

在 JS 里声明"值不会变的变量"用 const。它和很多语言里的 final/readonly 类似——一旦赋值就不能再改。

注意这里字符串用 双引号，也可以写成 单引号，两者等价（跟 Java/C 一样）。数字就直接写数字，不用引号。

第 2 个新概念：一个函数里有多个"子函数"

第 15 行 getSystemPreference 是定义在 initThemeManager 里面的嵌套函数。外面函数没跑完之前，这个内部函数是可以随时被调用的——别慌，你只需要记住：函数里还能再定义函数。

第 3 个新概念：|| 和 ? :（可能是你最陌生的）

第 13 行和 16-18 行是 JS 特有的简洁写法：

  • localStorage.getItem("theme") || defaultMode
    意思是：如果左边取不到（是 null 或空），就用右边的 defaultMode。这就是"取不到就用默认值"的惯用法。
  • cond ? A : B（三目运算符）
    第 16-18 行：如果系统偏好是暗色，就返回 DARK_MODE，否则返回 LIGHT_MODE。等价于一段 if/else。

第 4 个新概念：localStorage 和 window（浏览器专属）

localStorage 是浏览器提供的"小仓库"，刷新页面数据还在。window 代表浏览器窗口。这两个东西在 Python/Java 里没有——它们是浏览器环境的 API，后面专门有课。

3. 看剩下的代码（23-43 行）

    const resolvedTheme = resolveTheme(theme);
    let isDark = false;

    switch (resolvedTheme) {
        case LIGHT_MODE:
            document.documentElement.classList.remove("dark");
            isDark = false;
            break;
        case DARK_MODE:
            document.documentElement.classList.add("dark");
            isDark = true;
            break;
    }

    const expressiveTheme = isDark ? "github-dark" : "github-light";
    document.documentElement.setAttribute("data-theme", expressiveTheme);
    document.documentElement.style.setProperty("--hue", "200");
}

let 和 const 的区别

let isDark = false 声明一个后面会被重新赋值的变量（后面 isDark = true 了）。规则很简单：

  • 值会变 → 用 let
  • 值不会变 → 用 const（更常用）
  • 注意：没有 var，不要用 var

switch 和 DOM 的第一次接触

switch 你应该认识（很多语言都有）。新的东西是里面的操作对象——document.documentElement.classList：

  • document = 整个网页的"文档"对象
  • document.documentElement = 网页的 <html> 标签
  • classList.add("dark") = 给 <html> 加一个 CSS 类名 dark
  • 于是 Tailwind 的暗色模式样式就生效了——就是这么简单！

看懂了吗？整段代码在做的其实是：
① 从 localStorage 取出用户上次选的模式 → ② 如果系统模式就换算成实际模式 → ③ 在 <html> 标签上加上/去掉 dark 这个类，让整个站点切换暗色/亮色。就这样。

4. 练习：现在你来判断

假设 localStorage 里没有 "theme" 这个值，theme 变量会是什么？

点击看答案

是 defaultMode，也就是 "system"。因为 localStorage.getItem("theme") 返回 null，null || "system" 会取右边的值。

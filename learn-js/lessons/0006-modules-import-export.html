Lesson 0006 · 模块与 import/export

博客有几百个文件。它们靠 import / export 连接成一张网。这一课帮你彻底搞懂这个"文件连接"机制——它是读懂任何大型项目的钥匙。

今天这节课的收获：能看懂任何文件的顶部 import 区，并知道"我要找的功能在哪个文件里"。

1. export：文件向外"开门"

一个文件想把自己的一部分（变量/函数/类型）给别人用，就 export 出去：

// ===== utils/date-utils.ts 文件内部 =====
export function formatDateI18n(dateString: string): string { ... }
export function formatDateToYYYYMMDD(date: Date): string { ... }

// 也可以 export 一个常量、一个类型、一个对象
export const SITE_NAME = "Firefly";
export type Tag = { name: string; count: number };
export const siteConfig = { title: "Firefly" };

2. import：别的文件进来"拿"

另一个文件想用它们，就 import：

// ===== 某个页面/组件里 =====
import { formatDateI18n, formatDateToYYYYMMDD } from "@/utils/date-utils";
import { siteConfig } from "@/config";
import type { Tag } from "@/utils/content-utils";

// 用起来——跟本文件定义的没区别
const date = formatDateI18n("2026-08-16");
console.log(siteConfig.title);

理解 import 的关键：它不只是"复制代码"，而是建立引用。import 一个函数，你就拿到了它在原文件里那个"本体"的入口。整个项目运行时，这些 import 连成一张依赖图——一个文件改了，所有 import 它的地方都受影响。

3. 三种 import 形式

写法什么时候用举例
import { a, b } from "..."导入具名导出（最常用）date-utils 的函数
import X from "..."导入默认导出（一个文件只有一个 default）Icon、组件等
import type { T } from "..."只导入类型标注（编译后被擦掉）Tag、SiteConfig
import * as X from "..."导入该文件所有导出偶尔用

默认导出 vs 具名导出

// 文件 A：默认导出 + 具名导出
export default function Layout() { ... }   // default：一个文件一个
export const theme = "dark";          // 具名导出

// 文件 B：引入
import Layout from "@/layouts/Layout";  // default 导入，名字随意起
import { theme } from "@/layouts/Layout"; // 具名导入，名字必须一致

记忆：default 像一个文件的"主打款"，import 时可以重命名；具名导出像"货架上标好名字的商品"，import 时名字必须对得上。

4. 别名 @/ 是什么

你会在 import 里看到 @/config、@i18n/...`、@components/...`。这是项目配置的路径别名：

  • @/ 通常指向 src/ 目录——@/utils/date-utils = src/utils/date-utils.ts
  • 好处：不用写一长串 ../../../ 相对路径，也不怕移动文件时路径断掉
  • 配置在 tsconfig.json / astro.config.mjs 里，你只需要知道它是个"快捷方式"

5. 真实例子：看 date-utils.ts 顶部

import { siteConfig } from "../config";

export function formatDateI18n(dateString: string): string {

6. 更多例子：复制到控制台试

浏览器控制台也支持模块（注意要写成 import(...) 动态导入）：

// 动态导入一个已有的库（比如 dayjs，博客里用到）
const dayjs = await import("dayjs");
console.log(dayjs.default().format("YYYY-MM-DD")); // 今天的日期

// 或者自己造一个小模块体验一下 export/import
const utilModule = await import("data:text/javascript;base64," + btoa("export const double = (n) => n * 2;"));
console.log(utilModule.double(21)); // 42

# 常用标准库

这是 Pythonic 系列课程笔记的第 7 课，预计 25 分钟。C 里你得自己写很多东西:链表、迭代器技巧、路径拼接、双向队列。Python 的**标准库**("batteries included")把这些都做好了。`itertools` 管迭代的花活,`pathlib` 管文件路径,`collections` 管特殊容器。本课挑三个最该记住的。

## 知识点 1:pathlib——别再用 os.path 拼路径

C 程序员(或老 Python)习惯用字符串拼路径、分平台处理分隔符:

```python
import os
base = "/home/user/data"
full = os.path.join(base, "train", "x.csv")   # C 思维:字符串拼 + join
exists = os.path.exists(full)
ext = os.path.splitext(full)[1]
```

Pythonic——`pathlib.Path` 把路径当对象,`/` 直接拼接,跨平台不用管:

```python
from pathlib import Path
base = Path("/home/user/data")
full = base / "train" / "x.csv"     # 用 / 分行,自动处理分隔符
full.exists()                       # 判断存在
full.suffix                         # '.csv'
full.parent                         # PosixPath('/home/user/data/train')
full.name                           # 'x.csv'
```

要点:读写文件也能 `Path.read_text() / Path.write_text()`,不用再 open+f.close(下一课讲 with)。路径操作优先用 pathlib。

## 知识点 2:itertools——循环花活一网打尽

很多「手写循环技巧」itertools 已经给好了,常用四个:

```python
from itertools import chain, product, groupby, islice

# 把多个序列连起来遍历(比嵌套循环扁平)
for x in chain([1, 2], [3, 4]):        # 1 2 3 4
    pass

# 笛卡尔积(两层嵌套循环的扁平替代)
for a, b in product("AB", [1, 2]):     # A1 A2 B1 B2
    pass

# 切片迭代器(对大迭代器切不用先转 list)
first3 = list(islice(range(100), 3))   # [0, 1, 2]
```

还有 `repeat / takewhile / permutations / combinations` 等。规则:想要「几种排列组合 / 扁平化嵌套 / 循环拼接」,先到 itertools 找现成的,别手写索引。

## 知识点 3:groupby——按键分组,替代「先排序再找断点」

C 程序员想给数据分组,常先排序再找边界。itertools.`groupby` 按「相邻相同键」分组(注意:要先排序才把相同键聚一起):

```python
from itertools import groupby

words = ["aa", "aa", "bb", "aa"]            # 需先排序
words_sorted = sorted(words)
for key, group in groupby(words_sorted):
    print(key, list(group))                 # aa [aa,aa] / bb [bb]
```

分组计数、分组汇总这类活,groupby + 推导式一条链即可;比手写断点检测舒服。

## 知识点 4:collections——deque / namedtuple

`deque` 是从两端都能高效增删的队列(C 里你会自己写链表循环);`namedtuple` 是「带名字的轻量记录」(介于 tuple 和 dataclass 之间):

```python
from collections import deque, namedtuple

dq = deque([1, 2, 3])
dq.appendleft(0)             # O(1),列表 insert(0) 是 O(n)
dq.append(4)
print(dq)                    # deque([0,1,2,3,4])

Point = namedtuple("Point", ["x", "y"])   # 有名字的 tuple
p = Point(3, 4)
print(p.x, p.y)              # 3 4;也能 p[0]
```

什么时候用什么:

- `deque`:频繁在两端插入/删除、做队列/栈 → 别用 list
- `namedtuple`:既想当 tuple 又想字段有名 → 但多数情况 `@dataclass` 更够用
- `defaultdict / Counter`:上一课(0005)讲过的计数与分组

<summary>答案与解析</summary>

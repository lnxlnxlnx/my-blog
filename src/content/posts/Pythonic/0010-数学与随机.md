# 数学与随机 math / random

C 里有 `math.h` 的 sqrt/sin/pow,Python 的 `math` 模块功能更全(还能拿 π、e、无穷);`random` 模块做随机数、抽样、洗牌、seed 复现。本课把数值计算和模拟抽样讲透。

## 知识点 1:math 常用函数与常量

数值计算:开方、幂、取整、绝对值、对数、三角:

```python
import math
math.sqrt(9)          # 3.0 开方
math.pow(2, 10)       # 1024.0 幂(等价 2**10)
math.floor(3.7)       # 3 向下取整
math.ceil(3.2)        # 4 向上取整
math.fabs(-5)         # 5.0 绝对值
math.log(100, 10)     # 2.0 以 10 为底;math.log(e) 自然对数
math.pi               # 3.14159...
math.e                # 2.718...
math.inf              # 无穷大
math.nan              # 非数字(NaN)
```

要高斯分布误差函数 `math.erf`、伽马 `math.gamma` 也都有。记一个:`math.floor / ceil` 从「截断/进位」取整,别用 int()(int 是朝 0 截断)。

## 知识点 2:幂和取整的 Python 原生写法对比

很多 math 函数有更 Pythonic 的写法,先想运算符和内置函数:

```python
2 ** 10            # 1024 幂(比 math.pow 更常用)

# abs() 绝对值 → math.fabs() 只返回 float
abs(-5)            # 5

# // 整除, % 取余(比 floor 更常用)
7 // 2             # 3 整除(向下)
7 % 2              # 1 取余
```

规则:能用 `** / // / % / abs()` 就别绕 math;`math` 主要用于:三角函数、对数、指数、取整、无穷、以及科学函数。

## 知识点 3:random 基础——随机数、整数、浮点

生成随机数:整数用 `randint(a,b)`(含两端),浮点用 `random()`(0~1):

```python
import random
random.randint(1, 6)     # 1~6 之间的整数(像掷骰子,含 6)
random.random()          # 0.0 ~ 1.0 之间的浮点
random.uniform(0, 10)    # 0~10 之间浮点(均匀)
random.choice(["A","B","C"])  # 随机挑一个
random.randrange(0, 10, 2)    # 0~10 步长 2 里挑(0,2,4,...)
```

`randint(1,6)` 是**含两端**(能掷到 6);`randrange` 是半开(不含上界)。

## 知识点 4:洗牌与抽样——shuffle / sample

整列洗牌用 `shuffle`(就地改);不放回/放回抽样用 `sample` / `choices`:

```python
import random
deck = [1, 2, 3, 4, 5]
random.shuffle(deck)          # 就地洗牌,deck 顺序变了

# 抽样:不放回,抽 3 个
picks = random.sample(range(10), 3)   # [8, 1, 5] 等,不重复

# 放回抽样,可重复,还带权重
rolls = random.choices(range(1, 7), k=4)   # 掷 4 次骰子,可重复
```

记忆:`shuffle` 就地洗;`sample` 不放回; `choices(k=n)` 放回带权重。需要随机子集就用 sample。

## 知识点 5:seed——让随机结果可复现

调试/测试时想让「随机」可复现,用 `random.seed(n)`:给定相同 seed,产生的随机序列完全一样。这对写可测试代码非常关键:

```python
import random
random.seed(42)
print(random.randint(1, 100))   # 每次 run(seed=42 后)都是一样的
```

科学实验、AI 里常用 seed 复现结果。注意:不同版本 Python 的随机序列可能不同,别指望跨版本一致。

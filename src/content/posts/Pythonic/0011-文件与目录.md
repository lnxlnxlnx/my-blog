# 文件与目录 os / shutil / json / csv

C 里读写文件是 fopen/fread/fwrite,操作目录得调系统 API,还没有方便的 JSON/CSV。Python 里:`pathlib/os` 操作路径与目录,`shutil` 处理复制/移动/删除,`json` 序列化,`csv` 读写表格。本课把日常文件生活补齐。

## 知识点 1:读写文本文件——with + pathlib

最省心的读写用 `pathlib` 的一行方法(内部就是 with):

```python
from pathlib import Path
p = Path("hello.txt")
p.write_text("你好,Python\n")      # 写文本
text = p.read_text()               # 读文本(默认 utf-8)

# 也可以 open 指定编码/模式
with open("hello.txt", "a", encoding="utf-8") as f:   # a=追加
    f.write("追加一行\n")
```

要指定编码用 `open(..., encoding="utf-8")`(强烈建议永远写 utf-8),读大文件逐行:

```python
with open("big.txt", encoding="utf-8") as f:
    for line in f:        # 逐行读,不一次全载入内存
        print(line.strip())
```

逐行用 `for line in f` 就够,别用 `readlines()` 读大文件(那会整列进内存)。

## 知识点 2:目录操作——os / pathlib

建目录、列目录、判断存在、拼接,Path 都有现成方法:

```python
from pathlib import Path
d = Path("data")
d.mkdir(exist_ok=True)           # 建目录(已有也不报错,像递归著名)
for child in d.iterdir():        # 列出目录里的东西
    print(child)
Path("x.csv").exists()           # 判断存在
Path("x.csv").is_file()          # 是文件吗
Path("x.csv").is_dir()           # 是目录吗
Path("x.csv").unlink()           # 删文件
Path("x.csv").rename("y.csv")    # 重命名/移动
```

要 `os` 的也有:`os.makedirs()`、`os.listdir()`;但 pathlib 一般更顺手。`mkdir(parents=True)` 会连父目录一起建。

## 知识点 3:复制/移动/删除——shutil

shutil 是「高级文件工具」,复制、移动、整目录删除/复制:

```python
import shutil
shutil.copy("a.csv", "b.csv")     # 复制文件
shutil.move("b.csv", "backup/b.csv")  # 移动
shutil.rmtree("tempdir")          # 递归删整个目录
shutil.copytree("src", "dst")     # 复制整个目录树
```

记忆:`shutil` 管「跨文件/目录」的动作(复制移动删除整棵),`os/pathlib` 管「单个路径/单文件」的动作。

## 知识点 4:JSON——存/读结构化数据

把 dict/列表存成 JSON 文件、再读回来,是配置和数据交换的标配:`json.dumps` 转字符串,`json.loads` 读回,`dump/load` 直接对文件:

```python
import json
data = {"name": "Ann", "scores": [92, 85, 78]}

# 转成 JSON 字符串
s = json.dumps(data, ensure_ascii=False, indent=2)
print(s)

# 写文件 / 读回
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
with open("data.json", encoding="utf-8") as f:
    loaded = json.load(f)             # 又是 dict/列表
print(loaded["name"])
```

要点:`dict → JSON`=dumps/dump,`JSON → dict`=loads/load。中文记得 `ensure_ascii=False` 才不乱码,`indent=2` 排版好看。

## 知识点 5:CSV——表格数据

处理表格用 `csv` 模块,自动处理逗号/引号/换行,别手写 split(","):

```python
import csv
# 写
with open("people.csv", "w", newline="", encoding="utf-8") as f:
    w = csv.writer(f)
    w.writerow(["name", "age"])         # 表头
    w.writerow(["Ann", 25])
# newline="" 很重要,避免 Windows 出现空行

# 读:一行一个 dict(以第一行为列名)
with open("people.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["name"], row["age"])
```

`csv.DictReader` 把第一行当列名、后面每行变成字典,最省事。写用 `csv.writer` + `writerow`。

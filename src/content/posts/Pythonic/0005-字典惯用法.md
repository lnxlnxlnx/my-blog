# 字典惯用法

这是 Pythonic 系列课程笔记的第 5 课，预计 20 分钟。C 程序员管「键值对」叫 struct 字段或查找表;Python 里 `dict` 是日常最常用的数据结构,而且有一整套「怎么取、怎么加、怎么数、缺了怎么办」的地道写法。本课把它讲透。

## 知识点 1:取不到键时用 .get,别自己 if 判

C 思维(先查有没有,再取):

```python
d = {"a": 1, "b": 2}
if "c" in d:
    v = d["c"]
else:
    v = -1
```

Pythonic——`dict.get(key, default)` 一行:

```python
d = {"a": 1, "b": 2}
v = d.get("c", -1)     # -1:取不到就返回默认值
v = d.get("c")         # None:不指定默认值则返回 None
```

直接 `d["c"]` 取不到会抛 KeyError;想「安全取,给个兜底」就用 `get`。

## 知识点 2:计数 / 分组,别手动看键在不在

C 思维(数每个元素出现几次,得先判断键存不存在):

```python
words = ["a", "b", "a", "c", "b", "a"]
counts = {}
for w in words:
    if w in counts:
        counts[w] += 1
    else:
        counts[w] = 1
```

Pythonic 更省——`collections.Counter` 专门干这个,还能一键 top、一键求和:

```python
from collections import Counter
words = ["a", "b", "a", "c", "b", "a"]
counts = Counter(words)          # Counter({'a':3,'b':2,'c':1})
counts["a"]                      # 3
counts.most_common(1)            # [('a', 3)]
```

不想引入 Counter,就用 `dict.setdefault` 或 `defaultdict` 省掉 if:

```python
d = {}
for w in words:
    d[w] = d.get(w, 0) + 1       # get 兜底,再 +1

from collections import defaultdict
d = defaultdict(int)             # 键不存在自动给 int() 即 0
for w in words:
    d[w] += 1
```

三个方案:Counter(计数首选) / dict.get(临时) / defaultdict(自动初始化)。

## 知识点 3:分组用 setdefault 或 defaultdict(list)

要把元素按某特征「分组进列表」,C 思维又得先查列表在不在:

```python
people = [("math", "Ann"), ("art", "Bob"), ("math", "Cara")]
groups = {}
for subj, name in people:
    if subj not in groups:
        groups[subj] = []
    groups[subj].append(name)
```

Pythonic——`defaultdict(list)` 或 `setdefault`:

```python
from collections import defaultdict
groups = defaultdict(list)
for subj, name in people:
    groups[subj].append(name)     # 键不存在自动建空列表
# groups == {'math':['Ann','Cara'], 'art':['Bob']}
```

一条 append 搞定,不再手写「先建列表再 append」的模板。

## 知识点 4:遍历字典——.items() 拿「键+值」

C 程序员想遍历键值对,常先拿 keys 再查值:

```python
d = {"a": 1, "b": 2}
for k in d.keys():
    print(k, d[k])
```

Pythonic——`for k, v in d.items()` 一次同时给:

```python
d = {"a": 1, "b": 2}
for k, v in d.items():
    print(k, v)          # a 1 / b 2
```

只要键:直接 `for k in d`(别写 `d.keys()`);只要值:`d.values()`。

## 知识点 5:enumerate 下标 + items() 值,还能进一步解包

把「下标 + 键 + 值」一起拿:`for i, (k, v) in enumerate(d.items())`。这是「`enumerate` 包 `zip` 包解包」组合拳的自然延伸——Python 处处鼓励「一次拿全,别再用下标够」。

## 测验

### 测验 1
取不到键想给兜底,用?
- A. d["c"]
- B. d.get("c", -1)(正确)
- C. d.pop("c")
- D. d.setdefault 一次

<details>
<summary>答案与解析</summary>

**答案：B**。get(key, default) 取不到就返回默认值,不抛 KeyError。
</details>

### 测验 2
统计每个元素出现次数,首选?
- A. 手写 if 判断
- B. collections.Counter(正确)
- C. set 去重
- D. sort + 遍历

<details>
<summary>答案与解析</summary>

**答案：B**。Counter 专为计数设计,还带 most_common 等便捷方法。
</details>

### 测验 3
遍历拿到键又拿值,用?
- A. for k in d
- B. d.items()(正确)
- C. d.keys()
- D. d.values()

<details>
<summary>答案与解析</summary>

**答案：B**。items() 一次给键和值;只有键用 for k in d,只有值用 values()。
</details>

### 测验 4
按分数分组进列表,最省代码?
- A. 先 if 建列表
- B. defaultdict(list)(正确)
- C. 普通 dict + append
- D. Counter

<details>
<summary>答案与解析</summary>

**答案：B**。defaultdict(list) 让键不存在时自动建空列表,直接 append。
</details>

# 真值与空判断

这是 Pythonic 系列课程笔记的第 3 课，预计 15 分钟。C 程序员最常踩的坑:`if (x)` 判断的是「x 是不是零」,可 Python 里它判断的是「x 是不是**真值**」。本课把「判空」「判 None」这两件事用 Python 的方式讲清楚——你会发现很多显式判断其实是多余的。

## 知识点 1:真值(truthiness)不是「非零」

C 里 `if (ptr)` 是「指针非零」。Python 里每个对象都「天生带真假」:`None、False、0、0.0、""、[]、{}、()、set()` 都是**假值**,其余都是真值。所以很多判断不用显式写:

```python
name = ""
if name:            # 空字符串是假 → 不进入
    print("有名字")
# 等价写法 if name != "" :

items = []
if items:           # 空列表是假 → 不进入
    print("有东西")
# 等价写法 if len(items) > 0 :
```

关键:`if []` 就是「if 非空」,`if not []` 就是「if 为空」。别写 `if len(xs) > 0`,直接 `if xs`。

## 知识点 2:判空别再 len(xs) > 0

C 思维(拿长度比大小):

```python
def has_items(xs):
    return len(xs) > 0

def is_empty(xs):
    return len(xs) == 0
```

Pythonic——直接利用真值:

```python
def has_items(xs):
    return bool(xs)      # 或直接 return xs

def is_empty(xs):
    return not xs
```

更顺的用法是在条件里直接用 `if xs:`,根本不用写函数。

## 知识点 3:判 None 必须用 is,不能 ==

这是 C 程序员最容易搞错的:`None` 的判必须用 `is None` / `is not None`,**不要**用 `==`。`==` 比较「值是否相等」,`is` 比较「是不是同一个对象」;None 是唯一的单例,判断单例身份用 is。

```python
def show(x):
    if x is None:
        print("没给")
    else:
        print("给了:", x)
```

同样地,`True` / `False` 判身份也用 `is`:`if flag is True`(更常见是直接 `if flag`)。

## 知识点 4:区分「空」和「None」

两者不是一回事:`[]` 是「有个空列表」,`None` 是「根本没有」。别混:

```python
a = []      # 元素个数 0
b = None    # 不存在

# 错:想判断 a 是不是空
# if a == None:         # 不行,a 是 [],不是 None

# 对:判空
# if not a:

# 对:判 None
# if b is None:
```

一句话:`None` 判「有没有」用 `is`;`空容器`判「有没有内容」用真值 `if x`。它们服务于两个不同的问题。

- D. 会报错

**答案：B**。空容器([]{}{}()"")都是假值,直接 if x 即可判断非空。

### 测验 2
判断 xs 非空,最 Pythonic?
- A. len(xs) > 0
- B. xs != []
- C. if xs(正确)
- D. xs is not []

<details>
<summary>答案与解析</summary>

**答案：C**。if xs 直接利用真值判断非空,不用比长度。
</details>

### 测验 3
判断 x 是不是 None,用?
- A. x == None
- B. x is None(正确)
- C. not x
- D. x != 0

<details>
<summary>答案与解析</summary>

**答案：B**。None 是单例,判断身份用 is None。注意 not x 会把空容器也判成 True。
</details>

### 测验 4
x = [] 时,not x 的结果?
- A. False
- B. True(正确)
- C. None
- D. 报错

<details>
<summary>答案与解析</summary>

**答案：B**。空列表是假值,not [] 是 True。这是判定空容器的正确姿势;判 None 则用 is None。
</details>

# Pythonic 课程总览

19 课 · 写给有 C/C++ 背景的你 · 把 C 思维翻成 Python 惯用法 · 惯用法 8 + 常用库 7 + 高级 4

心法一句：**这是口语，不是翻译**——别把 C 代码「逐行翻译」成 Python，而是用 Python 自己的语序重说一遍。别忘了你会读代码。

进阶分线：**DDD 与六边形架构（10 课）**——读得懂 GitHub 大型 DDD/六边形项目。

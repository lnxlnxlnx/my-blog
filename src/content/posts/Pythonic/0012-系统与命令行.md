# 系统与命令行 sys / os.environ / argparse

写命令行工具时,C 程序要用 argc/argv 手动解析参数。Python 更舒服:`sys` 拿命令行列参数、退出码、标准输出;`os.environ` 拿环境变量;`argparse` 自动解析复杂参数(还能生成 --help)。本课让你能写「真正的 Python 命令行程序」。

## 知识点 1:sys.argv——命令行列参数

运行 `python script.py a b c` 时,`sys.argv` 是 `["script.py", "a", "b", "c"]`:第 0 项是脚本名,从第 1 项起是你的参数(都是字符串):

```python
import sys
print(sys.argv)          # ['script.py', 'a', 'b', 'c']
# 取参数时要判长度,否则越界
if len(sys.argv) > 1:
    name = sys.argv[1]   # 简单场景手拿即可
```

要点:`sys.argv[0]` 是脚本名,真正参数从 1 开始;`sys.argv` 里都是字符串,数字参数要自己转 int/float。简单脚本手拿即可,复杂参数用 argparse。

## 知识点 2:sys.exit 退出码与标准错误

程序出错想非零退出(像 C 的 return;shell 和 CI 会看退出码),用 `sys.exit(码)`:

```python
import sys
def main():
    return 0     # 通常主函数 return 0
    # 出错:
    # sys.exit(1)   # 非零=失败
```

报错信息应该打到**标准错误**(stderr)而不是 stdout,用 `sys.stderr`;正常输出用 `sys.stdout`/print:

```python
import sys
print("正常结果", file=sys.stdout)   # 或直接 print
print("出错", file=sys.stderr)       # 走标准错误
```

区分:`stdout` 是「结果」,`stderr` 是「诊断/错误」。shell 里 `2>&1` 才能把 stderr 也重定向。

## 知识点 3:os.environ——环境变量

读环境变量用 `os.environ`(一个类字典),没设置时用 `.get` 给默认值:

```python
import os
h = os.environ.get("HOME", "/tmp")    # 取不到给默认
db = os.environ.get("DB_URL", "")     # 没设就是 ""
# 敏感配置(密码/密钥)优先放环境变量,别写死在代码里
```

安全习惯:密钥、路径、开关这类「因环境而异」的配置放环境变量,代码里只读。用 `os.environ.get(name, default)` 别直接 `os.environ[name]`(没有会 KeyError)。

## 知识点 4:argparse——自动解析参数 + 自带 --help

参数多时用 `argparse`,它负责解析、转类型、校验、生成帮助信息。三步:创建 → 声明参数 → parse:

```python
import argparse

p = argparse.ArgumentParser(description="计算器")
p.add_argument("a", type=int, help="第一个数")
p.add_argument("--op", choices=["+", "-", "*"], default="+",
               help="运算")
p.add_argument("-v", "--verbose", action="store_true",
               help="打印细节")
args = p.parse_args()

if args.op == "+":
    result = args.a + args.a
print(args.a, args.op, result)   # args.a / args.op 自动可用
```

运行 `python calc.py 5 --op - --verbose` 就能拿到 `args.a=5`。自动生成 `--help`:`python calc.py --help`。`action="store_true"` 是布尔开关,`choices` 限定可取值,`type=int` 自动转成 int。

## 知识点 5:推荐的结构——if __name__ == "__main__"

命令行入口常写成 `if __name__ == "__main__": main()`,这样脚本既能被 import(不执行),也能被直接运行:这是 Python 的程序入口习惯,像 C 的 `int main()`:

```python
def main():
    print("程序从这里开始")

if __name__ == "__main__":
    main()
```

`__name__` 在直接运行时是 `"__main__"`,被 import 时是模块名。套这个判断,写错 import 也不会误执行。

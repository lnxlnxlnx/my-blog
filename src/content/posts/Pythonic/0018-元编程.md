# 元编程:写代码的代码

**元编程** = 写「用来描述/生成/改造其他代码」的代码。Python 因为对象模型开放,很多地方能「动代码」:属性访问可以被接管(`__getattr__`)、属性读写能加逻辑(`__setattr__`)、类能被加工(装饰器/元类)、属性还能委托。你会频繁在框架(django、sqlalchemy)里见到这些。本课讲最常见的三件,并劝你别滥用。

## 知识点 1:属性访问拦截——__getattr__ / __setattr__

当「访问一个不存在的属性」时,`__getattr__` 会被调用,可以动态返回东西。`__setattr__` 在**任何**属性赋值时被调用(可用来记录写入、校验)。这是框架「魔法属性」的来源之一:

```python
class Config:
    def __init__(self, data):
        self._data = data          # 注意:这也会触发 __setattr__!
    def __getattr__(self, name):   # 只有属性不存在才来
        if name in self._data:
            return self._data[name]
        raise AttributeError(f"no {name}")
    def __setattr__(self, name, value):
        if name.startswith("_"):   # 内部带下划线直接存
            super().__setattr__(name, value)
        else:
            print(f"写配置 {name} = {value}")
            self._data[name] = value

c = Config({"host": "localhost"})
print(c.host)          # localhost:动态从 _data 取
```

关键区别:`__getattr__` 只在「找不到」时调用;`__getattribute__` 每次访问都调(更危险少用)。`__setattr__` 每次赋值都拦截。这类工具最常见的正确用法:`__getattr__` 给「懒加载/代理/兼容旧名」提供便利。

## 知识点 2:property vs 元编程——多数时候 property 就够

上一课(0006)学过 `@property` 给「单个属性」加逻辑。元编程的 `__getattr__` 是「接管所有未知属性」。**提醒**:能用 `@property` 或普通字段解决就别用 `__getattr__`——后者让 IDE 补全、类型检查、可读性都变差。元编程是「最后的手段」。

## 知识点 3:类装饰器——给类「加料」

装饰器不仅能装饰函数(0008),还能装饰**类**:收到类,返回「加工过的类」。这是比元类更轻量、更常用的「动类」方式:

```python
def add_repr(cls):
    cls.__repr__ = lambda self: f"<{cls.__name__} {self.__dict__}>"
    return cls

@add_repr
class User:
    def __init__(self, name): self.name = name

u = User("Ann")
print(u)   # <User {'name': 'Ann'}>:类装饰器帮我们加了 __repr__
```

也可以给类动态加属性/方法。对照 0007 的装饰器:`@add_repr` ≡ `User = add_repr(User)`。类装饰器是「不碰继承也能统一给一批类加能力」的最轻办法。

## 知识点 4:元类 metaclass——类的类(不常写,但要懂)

类是对象,它的「类」就是**元类**。默认元类是 `type`。自定义元类 = 在「类被创建时」打点/加工(比如自动注册、校验方法、注入行为)。你基本不会自己写,但要能认出它:

```python
class AutoRegister(type):          # 元类:继承 type
    registry = {}
    def __new__(mcs, name, bases, ns):
        cls = super().__new__(mcs, name, bases, ns)
        if name != "Base":         # 除基类外都注册
            AutoRegister.registry[name] = cls
        return cls

class Base(metaclass=AutoRegister):   # 指定元类
    pass

class Foo(Base): pass
class Bar(Base): pass
print(AutoRegister.registry)   # {'Foo':..., 'Bar':...}(自动收集子类)
```

用途:像「插件注册」「orm 表映射」「校验器自动登记」这种「类一创建就想登记」的需求用元类。**现实提示**:能不用元类就不用(类装饰器常常更简单);读代码时能「认出 __metaclass__/metaclass= 是类级魔法」就够了。

## 知识点 5:最实用的元编程一件——__getattr__ 做「快速代理」

想给一个对象包一层、把未知属性/方法「转发」给内部对象,`__getattr__` 是轻量代理的利器:

```python
class Proxy:
    def __init__(self, target): self.target = target
    def __getattr__(self, name):        # 属性不存在:转发给 target
        return getattr(self.target, name)

class Math:
    def square(self, x): return x * x

p = Proxy(Math())
p.square(5)          # 25:Proxy 自己没有 square,转发给了内部 Math
```

这就是「代理/门面」(你在架构课见过)的 Python 极简实现:`__getattr__` 把未知调用转发给被代理对象。

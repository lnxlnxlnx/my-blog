# 内置函数与函数当一等公民

这是 Pythonic 系列课程笔记的第 2 课，预计 20 分钟。上一课我们让循环「少了下标」。这一课的思路更进一步:很多循环**根本不用写**——Python 自带一堆内建函数,把「遍历 + 变形 + 过滤 + 汇总」一次说完。核心观念:**函数是值,可以当参数传来传去**。

## 知识点 1:把循环汇总交给内置函数

C 思维(手动建变量累加 / 找最大):

```python
nums = [3, 1, 4, 1, 5, 9, 2]
total = 0
for n in nums:
    total += n
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
count_gt3 = 0
for n in nums:
    if n > 3:
        count_gt3 += 1
```

Pythonic——`sum / max / min` 一个函数一次,`len` 数长度;「有几个满足条件」用 `sum(生成器)`(True 算 1):

```python
nums = [3, 1, 4, 1, 5, 9, 2]
total = sum(nums)
biggest = max(nums)
count_gt3 = sum(n > 3 for n in nums)   # True == 1
```

要点:凡是「对一整个序列做汇总」,先想内置函数,别手写循环。判断类统计用 `sum(cond for x in xs)` 是 Python 特有的一招。

## 知识点 2:any / all——「有没有」和「是不是都」

C 思维(写 bool 标志 + break):

```python
found = False
for x in [3, 1, 4]:
    if x % 2 == 0:
        found = True
        break
```

Pythonic:

```python
found = any(x % 2 == 0 for x in [3, 1, 4])   # 有没有偶数 → True
all_odd = all(x % 2 == 1 for x in [3, 1, 5])  # 是不是全是奇数 → True
```

`any`=一有满足就 True;`all`=全部满足才 True。它们都**短路**(early exit),不用自己 break。

## 知识点 3:sorted 不修改原列表

C 程序员总想着「就地排序」(像 `qsort` 或 `sort()`)。但 Python 的 `sorted()` **返回新列表**,原列表不动;还能加 key 排序:

```python
words = ["banana", "cherry", "apple"]
s = sorted(words)                      # ['apple', 'banana', 'cherry'],words 不变
by_len = sorted(words, key=len)        # ['apple', 'cherry', 'banana']:按长度排
by_last = sorted(words, key=lambda w: w[-1])  # 按最后一个字母排
```

注意区分:`sorted(xs)` 返回新表;而 list 自己的 `xs.sort()` 才就地排序。想不破坏原数据就用 sorted。

## 知识点 4:map / filter——其实推导式就够了

C 程序员(或学函数式语言的人)常想着用 `map(f, xs)` 和 `filter(pred, xs)`。

```python
nums = [1, 2, 3, 4]
squared = list(map(lambda x: x * x, nums))     # [1,4,9,16]
evens   = list(filter(lambda x: x % 2 == 0, nums))  # [2,4]
```

**但是——Python 社区普遍认为推导式更可读、更 Pythonic**,能一眼看出结构:

```python
squared = [x * x for x in nums]                 # 等价于 map
evens   = [x for x in nums if x % 2 == 0]       # 等价于 filter
```

判断:`map/filter` 只在「已经有一个现成函数名」(如 `map(str.strip, lines)`、`filter(None, xs)`)时比较顺;要写 lambda 的,一律用推导式。

## 知识点 5:函数当值——sorted 的 key 与 lambda

上一节见到的 `key=len` / `key=lambda...`,背后是「函数当参数」这回事。Python 里函数就是普通值,能存、能传:

```python
def by_last_letter(w):
    return w[-1]

words = ["banana", "cherry", "apple"]
s = sorted(words, key=by_last_letter)   # 把函数名传进去(不加括号!)
```

注意:`key=by_last_letter` 传的是**函数本身**(不调用),sorted 内部对每个元素调用它。lambda 只是「就地写的临时匿名函数」。想传现成函数就传名字,想现写就 lambda。

- B. sum(nums)(正确)

- D. len 求和

**答案：B**。对整列做汇总用内置函数 sum(nums),别再手写循环。

### 测验 2
「有没有满足条件」用哪个?
- A. all(...)
- B. any(...)(正确)
- C. sum(...)
- D. len(...)

<details>
<summary>答案与解析</summary>

**答案：B**。any = 一有就 True;all = 全满足才 True。
</details>

### 测验 3
sorted(xs) 之后 xs 会?
- A. 被就地排序
- B. 原样不变(正确)
- C. 被清空
- D. 变成元组

<details>
<summary>答案与解析</summary>

**答案：B**。sorted() 返回新列表,原列表不动;就地排序要用 xs.sort()。
</details>

### 测验 4
要 lambda 的 map/filter,更 Pythonic 的替代?

- D. zip 组合

<details>
<summary>答案与解析</summary>

**答案：B**。要写 lambda 的 map/filter 用推导式替代,更可读;除非已有现成函数名。
</details>

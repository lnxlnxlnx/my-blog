# 从下标循环到迭代与推导式

这是 Pythonic 系列课程笔记的第 1 课，预计 20 分钟。在 C/C++ 里你习惯了 `for (i=0; i<n; i++)`——因为 C 的数组就只认下标。但 Python 的 list / dict 是**容器**,不是「带下标的格子」,最强的取数方式是**直接迭代元素**,而不是拿下标去「够」它。这一课帮你把「需要下标」的执念卸掉一大半。

## 知识点 1:for 直接遍历元素,而不是下标

C 思维:

```python
fruits = ["apple", "banana", "cherry"]
for i in range(len(fruits)):
    print(fruits[i])          # 用下标去够
```

Pythonic:list 本身就可迭代,直接拿元素:

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)              # 直接是元素,不用下标
```

要点:除非你真的**需要下标**,否则永远写 `for x in seq`。大多数时候你其实不需要下标。

## 知识点 2:真需要下标时用 enumerate

当你要「元素 + 它在第几个」时,`enumerate` 一次给你两个,别手写计数器:

```python
fruits = ["apple", "banana", "cherry"]
for i, fruit in enumerate(fruits):
    print(i, fruit)            # 0 apple / 1 banana / 2 cherry
```

还想从 1 开始数:`enumerate(fruits, start=1)`。这就是 Python 典型的「禁止 `i+=1`」的地方——计数交给内建。

## 知识点 3:两个序列并行,用 zip 不用双下标

C 思维(两个数组按同一下标并行):

```python
names = ["Alice", "Bob", "Cara"]
ages  = [25, 30, 22]
for i in range(len(names)):
    print(names[i], ages[i])
```

Pythonic:用 `zip` 把两个容器「拉链」起来同时迭代:

```python
names = ["Alice", "Bob", "Cara"]
ages  = [25, 30, 22]
for name, age in zip(names, ages):
    print(name, age)           # Alice 25 / Bob 30 / Cara 22
```

想要下标 + 两边,《组合拳》:`for i, (name, age) in enumerate(zip(names, ages))`。

## 知识点 4:列表推导式——「筛选 + 变形」一行搞定

这是 C 程序员最震撼的一个:你要「把每个元素变个样,再挑出某些」,**列表推导式(list comprehension)**用方括号直接写出「结果长什么样」。

C 思维(先建空列表,再循环 append):

```python
evens = []
for x in range(10):
    if x % 2 == 0:
        evens.append(x * x)
print(evens)
```

Pythonic——一条推导式,先写「要什么」再写「从哪来、过滤条件」:

```python
evens = [x * x for x in range(10) if x % 2 == 0]
print(evens)                   # [0, 4, 16, 36, 64]
```

读法口诀:[**变形** for **变量** in **来源** if **条件**]。同样的骨架还能用在字典(`{k: v for ...}`)、集合(`{x for ...}`)。

## 知识点 5:生成器表达式——数据很大时别急着建列表

推导式会一次性建好整个 list;如果数据很大 / 只需要逐个消费,用**生成器表达式**(圆括号),它是惰性的,用到才算一个:

```python
total = sum(x * x for x in range(1_000_000))   # 不会先建一百万项的列表
print(total)
```

对 `sum / min / max / any / all` 这类函数,直接塞生成器表达式,省内存又简洁。

## 测验

### 测验 1
只想要每个元素,应该?
- A. for i in range(len(xs))
- B. for i, x in enumerate(xs)
- C. for x in xs(正确)
- D. zip 循环更合适

<details>
<summary>答案与解析</summary>

**答案：C**。只要元素本身就 `for x in xs`;下标没用就别要。enumerate 是「连点数一起要」时才用。
</details>

### 测验 2
要对两个列表按下标并行,Pythonic 写法?
- A. range(len(a)) 双下标
- B. zip(a, b)(正确)
- C. enumerate 嵌套两次
- D. 列表推导式就够了

<details>
<summary>答案与解析</summary>

**答案：B**。并行迭代用 zip(a, b),自动对齐逐个配对,不用管下标。
</details>

### 测验 3
[x*x for x in nums if x>2] 的顺序是?
- A. 条件→来源→变形
- B. 来源→变形→条件
- C. 变形→来源→条件(正确)
- D. 变形→条件→来源

<details>
<summary>答案与解析</summary>

**答案：C**。顺序:[变形 for 变量 in 来源 if 条件]。变形写最前,来源在中,条件在最后。
</details>

### 测验 4
数据百万条只求和,最省内存?
- A. 先建大列表再 sum
- B. sum(x*x for x in r)(正确)
- C. 列表推导式传给 sum
- D. for 循环手动累加

<details>
<summary>答案与解析</summary>

**答案：B**。生成器表达式是惰性求值,逐个算、不占内存;大数据的首选。
</details>

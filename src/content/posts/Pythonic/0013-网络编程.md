# 网络编程 requests / socket

C 里写网络十分痛苦(socket、bind、listen、accept、解析 HTTP 报文……)。Python 里分两层:95% 的日常用**`requests`**(发 HTTP 请求、调 API、抓网页,自动解析);只有做底层协议/自写服务器才碰 `socket`。本课主攻 requests,顺带讲清 socket 的定位。

## 知识点 1:requests——GET 请求与响应

`requests` 是第三方库(要先 `pip install requests`),发 GET 拿网页/JSON 就几行:

```python
import requests
resp = requests.get("https://api.github.com/users/octocat")
print(resp.status_code)     # 200
print(resp.headers)         # 响应头(dict)
print(resp.text)            # 原始文本
data = resp.json()          # 自动解析成 dict(若响应是 JSON)
print(data["login"])
```

要点:`resp.status_code` 是状态码(200 OK / 404 没找到 / 500 服务器错);`.json()` 直接把 JSON 体变 dict。`.text` 原始字符串;中文网页看 `resp.encoding`。

## 知识点 2:带参数、带请求头、POST

GET 带查询参数用 `params=`;带自定义头(如 User-Agent)用 `headers=`;发数据用 `POST + json=` / `data=`:

```python
import requests
# GET 带参数:GET /search?q=python&page=2
r = requests.get("https://httpbin.org/get",
                 params={"q": "python", "page": 2},
                 headers={"User-Agent": "my-app/1.0"})

# POST 发 JSON 数据
r2 = requests.post("https://httpbin.org/post",
                   json={"name": "Ann"})     # 自动转 JSON + 设 Content-Type
```

`params=` 会自动把 dict 编码成 `key=value&...` 拼到 URL;比手拼字符串安全(自动处理特殊字符)。POST 传 JSON 用 `json=`,表单用 `data=`。

## 知识点 3:检查响应、异常、超时

C 思维(不检查错误);Pythonic 应检查状态码、设超时防卡死:

```python
import requests
resp = requests.get("https://httpbin.org/status/404",
                    timeout=10)      # 超时 10 秒,不设会一直等
resp.raise_for_status()   # 状态码 4xx/5xx 会抛 HTTPError —— 推荐
# 不想抛异常就手动判断:
# if resp.status_code == 200: ...
```

两点:`timeout=` 一定要设,否则网络卡住程序会无限等;`raise_for_status()` 让失败立刻报错,别假装成功。对接 4xx/5xx 错误,HTTPStatus 语义看 [MDN 状态码表](https://developer.mozilla.org/zh-CN/docs/Web/HTTP/Status)。

## 知识点 4:响应 timeout 与 Session 复用

多次请求到同一站点,反复握手很浪费;`requests.Session()` 复用连接和 cookie:

```python
import requests
s = requests.Session()
s.get("https://httpbin.org/cookies/set/name/Ann")   # 设置 cookie
r = s.get("https://httpbin.org/cookies")            # 复用会话,带 cookie
print(r.json())
```

抓登录态、批量请求、保持 cookie 用 `Session`;一次性单发用顶层 `requests.get` 即可。

## 知识点 5:socket 是什么、何时用

`socket` 是底层 TCP/UDP 接口(C 的 socket 一样)。日常抓网页/调 API **用 requests 就够,不用碰 socket**;只有要「自定义二进制协议、自己写 TCP 服务器、UDP 通信」才用:

```python
import socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect(("example.com", 80))        # TCP 连上 80 端口
s.sendall(b"GET / HTTP/1.1\r\nHost: example.com\r\n\r\n")
data = s.recv(1024)
s.close()
```

判断:发 HTTP 用 requests;底层裸 TCP/UDP 才用 socket。多数 C 程序员担心的「网络编程」在 Python 里其实就是 requests。

## 测验

### 测验 1
发一个 GET 请求到网页,用?
- A. socket 手拼
- B. requests.get(url)(正确)
- C. http.open
- D. urlparse

<details>
<summary>答案与解析</summary>

**答案：B**。发 HTTP 用 requests.get,自动处理响应;不用碰底层 socket。
</details>

### 测验 2
把响应里的 JSON 变 dict,用?
- A. resp.text
- B. resp.json()(正确)
- C. resp.dict()
- D. json.loads(resp)

<details>
<summary>答案与解析</summary>

**答案：B**。响应若是 JSON,resp.json() 自动解析成 dict。
</details>

### 测验 3
GET 带查询参数?
- A. 拼到 URL 字符串
- B. requests.get(url, params=dict)(正确)
- C. data= 传参
- D. argparse 传参

<details>
<summary>答案与解析</summary>

**答案：B**。params=dict 自动编码成 ?key=value,比手拼安全。
</details>

### 测验 4
多次请求同一站点想复用连接/cookie,用?
- A. 每次 requests.get
- B. requests.Session()(正确)
- C. socket 长连
- D. threading

<details>
<summary>答案与解析</summary>

**答案：B**。Session 复用 TCP 连接和 cookie,适合相同站点的多次请求。
</details>

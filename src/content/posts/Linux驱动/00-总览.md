# Linux 驱动开发课程总览

从启动流程到驱动开发再到构建烧录的完整 Linux 驱动学习路线,面向有 C/嵌入式基础的学习者。14 课,四个阶段:**阶段 0** 看懂系统(0001-0002,零风险只读)、**阶段 1** 手写驱动(0003-0007,全部可逆)、**阶段 2** 设备树与子系统(0008-0010)、**阶段 3** 构建与烧录(0011-0014,最高风险区)。学完你就能从"会用板"到"能拆装系统、会写驱动、能排障"。

## 课程目录

|------|------|

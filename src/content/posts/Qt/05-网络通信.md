# 05 网络与远程通信

嵌入式 Qt 里的"通信"通常有四种：**MQTT 上云**、**TCP/套接字设备互联**、**Qt RemoteObjects 进程间通信**、**本地 Unix Socket**。本章全部结合 qt_dev 实例。

## 1. MQTT 智能控制（iot_control app）

iot_control 用 MQTT 协议远程控制开发板（手机发指令 → 板子执行 → 上报状态）。核心是 `MqttControl`（C++，用 paho.mqtt.c 库）。

**C++ 类暴露给 QML**（iot_control/mqttcontrol.h）：
```cpp
class MqttControl : public QObject {
    Q_OBJECT
    Q_PROPERTY(bool connected READ connected NOTIFY connectedChanged)
    Q_PROPERTY(QString topicPrefix READ topicPrefix WRITE setTopicPrefix NOTIFY topicPrefixChanged)
    Q_PROPERTY(QString logText READ logText NOTIFY logTextChanged)
public slots:
    void connectToBroker(const QString &host, int port);   // 连服务器
    void publish(const QString &topic, const QString &payload, bool retained); // 发消息
signals:
    void messageReceived(const QString &topic, const QString &payload);
    void connectedChanged(bool connected);
};
```

**QML**（iot_control 界面）：
```qml
import com.alientek.qmlcomponents 1.0
MqttControl {
    id: mqtt
    topicPrefix: "atk/led"
    onConnectedChanged: { statusText.text = mqtt.connected ? "已连接" : "未连接" }
    onMessageReceived: {
        // 收到手机指令, 控制硬件
        if (topic.endsWith("/cmd") && payload === "on") ledControl.setLedState(1)
    }
}
Button { text: "开灯"; onClicked: mqtt.publish(mqtt.topicPrefix + "/cmd", "on", false) }
```

> MQTT 适合"板子上云 + 手机远程控制"。paho 库需自行交叉编译进 rootfs。`publish` 发指令，`messageReceived` 收指令。

## 2. TCP 投屏（screenview app，QWidget 版）

screenview 是纯 Widgets 应用，用 TCP 接收 PC 推来的 MJPEG 视频流并显示。

```cpp
#include <QTcpServer>
#include <QTcpSocket>
#include <QImage>

// 主窗口里
m_server = new QTcpServer(this);
connect(m_server, &QTcpServer::newConnection, this, &MainWindow::onNewConnection);
m_server->listen(QHostAddress::Any, 9999);   // 监听 9999 端口

void MainWindow::onReadyRead() {
    QByteArray data = m_sock->readAll();
    m_jpegBuf.append(data);
    // 从流里切出完整 JPEG 帧
    int start = m_jpegBuf.indexOf("\xff\xd8");   // JPEG 起始标记
    int end   = m_jpegBuf.indexOf("\xff\xd9");   // JPEG 结束标记
    if (start >= 0 && end > start) {
        QByteArray jpg = m_jpegBuf.mid(start, end - start + 2);
        QImage img = QImage::fromData(jpg, "JPG");  // 解码
        m_img = img;
        update();                                 // 触发 paintEvent 绘制
    }
}
void MainWindow::paintEvent(QPaintEvent *) {
    QPainter p(this);
    p.drawImage(0, 0, m_img);                    // 全屏画视频帧
}
```

> API 要点：`QTcpServer::listen` 监听、`newConnection` 接客、`QTcpSocket::readyRead` 收数据、`QImage::fromData` 解码 MJPEG。**投屏 = TCP 收流 + QPainter 绘制**。

## 3. Qt RemoteObjects 进程间通信（systemui ↔ App）

systemui 桌面框架的通信机制，用 `.rep` 文件定义接口，Qt 自动生成两端代码。

### 定义接口（Repcs/systemuicommonapi.rep）
```
class SystemUICommonApi {
    SIGNAL(serverSendVariant(const QByteArray &ba))
    SLOT(void onServerVariant(const QByteArray &ba))
}
```

### 服务端（systemui）
```cpp
m_remoteObjectHost->setHostUrl(QUrl("local:interfaces"));  // 本地地址
m_remoteObjectHost->enableRemoting(this);                   // 对外暴露接口
// 收到 App 的消息:
void SystemUICommonApiServer::onServerVariant(const QByteArray &ba) {
    auto msg = deserialize(ba);
    if (msg["appState"] == "Active") {
        emit requestVisibilityChange(Command::Hide);  // 隐藏桌面
    }
}
```

### 客户端（每个 App 的 client）
```cpp
m_remoteObjectNode = new QRemoteObjectNode(this);
m_remoteObjectNode->connectToNode(QUrl("local:interfaces"));
m_replica = m_remoteObjectNode->acquire<SystemUICommonApiReplica>();  // 拿副本
connect(m_replica, &Replica::serverSendVariant, this, &Client::onServerVariant);
```

> API 要点：`QRemoteObjectNode::connectToNode("local:interfaces")` 连接本机服务、`acquire<Replica>()` 拿代理、`enableRemoting(this)` 暴露。消息统一打包成 `QByteArray`（QDataStream 序列化键值对）。

## 4. 本地 Unix Socket（我们的手柄方案）

手柄守护进程 `gamepadd`（纯 C）把 USB 手柄状态广播到 `/tmp/gamepad.sock`，Qt 的 `GamepadClient` 用 `QLocalSocket` 连上读取。

**C 守护进程端**（controller_dev/gamepadd.c）：
```c
int listen_fd = socket(AF_UNIX, SOCK_STREAM, 0);
bind(listen_fd, (struct sockaddr*)&addr, sizeof(addr));  // addr.sun_path="/tmp/gamepad.sock"
listen(listen_fd, 8);
// 每帧: accept 客户端, 向所有客户端 write 一行 "lx,ly,...,Up,Down,Left,Right"
```

**Qt 端**（mytest/gamepadclient.cpp）：
```cpp
#include <QLocalSocket>
m_socket = new QLocalSocket(this);
connect(m_socket, &QLocalSocket::readyRead, this, &GamepadClient::onReadyRead);
m_socket->connectToServer("/tmp/gamepad.sock");   // 连 Unix socket
connect(m_socket, &QLocalSocket::disconnected, this, [this]{ reconnect(); }); // 断线重连

void GamepadClient::onReadyRead() {
    m_buffer.append(m_socket->readAll());
    int idx;
    while ((idx = m_buffer.indexOf('\n')) >= 0) {   // 按行解析
        QByteArray line = m_buffer.left(idx).trimmed();
        m_buffer.remove(0, idx + 1);
        parseLine(line);   // 更新 20 个 Q_PROPERTY, emit changed()
    }
}
```

> API 要点：`QLocalSocket` = Unix domain socket 的 Qt 封装（比 TCP 快且本机安全）。**读一行 → split(',') → 更新属性** 是设备状态推送的标准套路。断开信号 `disconnected` 触发重连（游戏手柄热插拔）。

## 5. 串口通信（预留，参考 ref_code）

虽然 qt_dev 现有 App 没直接用 `QSerialPort`，但它是嵌入式必备，方法一样：
```pro
QT += serialport
```
```cpp
#include <QSerialPort>
QSerialPort sp;
sp.setPortName("/dev/ttymxc0");
sp.setBaudRate(115200);
sp.open(QIODevice::ReadWrite);
connect(&sp, &QSerialPort::readyRead, [&]{
    qDebug() << sp.readAll();   // 收数据
});
sp.write("AT\r\n");             // 发数据
```

## 6. 通信方式选择速查

| 场景 | 方案 | 优点 |
|------|------|------|
| 手机远程控制 | MQTT | 上云、跨网络、有 broker 中转 |
| PC↔板子传数据/投屏 | TCP socket | 简单、流式 |
| 板内多个 Qt 进程通信 | Qt RemoteObjects | 类型安全、自动生成 |
| 本机进程传状态 | Unix socket | 最快、无 TCP 开销 |
| 外设串口/RS485 | QSerialPort | 直接操作 UART |

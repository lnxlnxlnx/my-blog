# 04 硬件交互详解

嵌入式 Qt 和 PC Qt 最大的区别：**要直接操作硬件**。本章按硬件分类，全部结合 qt_dev 实例，给出 C++ 代码和对应 QML。

## 0. 硬件在 Linux 里的呈现

IMX6ULL 上的硬件大多以**文件**形式暴露，Qt 只需读写文件/打开设备：

| 硬件 | Linux 接口 | 操作方式 |
|------|-----------|---------|
| LED | `/sys/class/leds/sys-led/brightness` | 写 `0/1` |
| 蜂鸣器 | `/sys/class/leds/beep/brightness` | 写 `0/1` |
| GPIO 按键 | `/dev/input/eventX` | 读 input 事件 |
| 光感/陀螺仪 | `/dev/ap3216c`、`/dev/icm20608` | open + read |
| 摄像头 | V4L2（Qt Multimedia 封装） | `Camera` + `VideoOutput` |
| 音频 | ALSA（Qt Multimedia 封装） | `Audio` 等 |
| 触摸屏 | `/dev/input/event1` + tslib | 框架自动转鼠标事件 |
| LCD | `/dev/fb0` | 框架自动绘制 |

## 1. GPIO 输出 —— LED（led app）

`led/ledcontrol.cpp` 完整展示了"读写 sysfs + 文件监听"：

```cpp
#include <QFile>
LedControl::LedControl()
{
    this->addPath("/sys/class/leds/sys-led/brightness");  // 监听这个文件
    connect(this, SIGNAL(fileChanged(QString)), this, SLOT(onFileChanged(QString)));
    system("echo none > /sys/class/leds/sys-led/trigger"); // 关掉内核默认触发器
}

void LedControl::setLedState(int state)   // QML 调用: led.setLedState(1)
{
    QFile file("/sys/class/leds/sys-led/brightness");
    if (file.open(QIODevice::WriteOnly | QIODevice::Text)) {
        file.write(state > 0 ? "1" : "0");   // 写 sysfs 就是控制 GPIO
        file.close();
    }
}
```

**对应 QML**（led/LedLayout.qml）：
```qml
import com.alientek.qmlcomponents 1.0
LedControl { id: ledControl }
Image {
    source: ledControl.ledState ? "qrc:/icons/led_on.png" : "qrc:/icons/led_off.png"
}
MouseArea {
    anchors.fill: parent
    onClicked: ledControl.setLedState(ledControl.ledState ? 0 : 1)  // 切换
}
```

> API 要点：`QFile` 写 `/sys/class/...` 就是操作 GPIO；`QFileSystemWatcher` 可监听内核改动（如硬件状态变化）反向更新界面。

## 2. 按键/GPIO 输入（key app）

按键输入在 `/dev/input/eventX`。用 `read()` 读 `struct input_event`：

```cpp
#include <linux/input.h>
#include <fcntl.h>
#include <unistd.h>

int fd = open("/dev/input/event1", O_RDONLY | O_NONBLOCK);  // 触摸屏
struct input_event ev;
if (read(fd, &ev, sizeof(ev)) > 0) {
    if (ev.type == EV_KEY && ev.value == 1) {   // 按下
        qDebug() << "键码" << ev.code;
    }
}
```

> 更省事：screenview 用 `KeyInputEventThread`（QThread）后台循环读事件，通过信号把键值发给主线程，避免 UI 卡顿。

## 3. I2C 传感器（sensor app）

光感 AP3216C、陀螺仪 ICM20608 是 I2C 设备，内核驱动暴露为 `/dev/ap3216c`、`/dev/icm20608`。读取放子线程：

```cpp
void Ap3216cThread::run() {
    int fd = open("/dev/ap3216c", O_RDONLY);
    while (!isInterruptionRequested()) {
        QByteArray buf(6, 0);
        read(fd, buf.data(), 6);              // 读传感器原始数据
        setAlsData(QString("光照: %1").arg(...));   // 更新 Q_PROPERTY
        msleep(200);
    }
    close(fd);
}
```
QML 显示：
```qml
Ap3216cThread { id: als; onAlsDataChanged: lightText.text = als.alsData }
```
> 核心模式：**QThread + Q_PROPERTY(NOTIFY)**，子线程读硬件，界面自动刷新。

## 4. 摄像头（camera app）—— Qt Multimedia

摄像头用 Qt Multimedia 的 `Camera` + `VideoOutput`，Qt 内部用 V4L2 驱动。

**C++**（camera/camera.cpp）负责枚举设备、选择分辨率：
```cpp
#include <QCamera>
class Camera : public QObject {
    Q_OBJECT
    Q_PROPERTY(QStringList cameraList READ cameraList NOTIFY cameraListChanged)
public:
    QStringList cameraList() const;
    QStringList availableCameras() const {
        // QCameraInfo::availableCameras() 列出摄像头
    }
};
```

**QML**（camera/CameraLayout.qml）：
```qml
import QtMultimedia 5.0
Camera {
    id: camera
    deviceId: cameraDevice              // 切换设备
    // 摄像头图像直接出到 VideoOutput
}
VideoOutput {
    source: camera                       // 把相机画面画到这里
    anchors.fill: parent
}
Button {
    text: "拍照"
    onClicked: {
        var img = imageCapture.capture()  // 截图
    }
}
```

> API 要点：`Camera`（设备）、`VideoOutput`（显示）、`ImageCapture`（拍照）、`QCameraInfo::availableCameras()`（枚举）。

**mytest 的手写数字识别**更进阶：`DigitRecognizer` 用 C++ 从 `VideoOutput` 抓帧 → 神经网络推理 → 通过 `ImageProvider` 把识别图回传给 QML 显示：
```qml
Image { source: "image://digitpreview/frame" }   // 实时识别画面
Text { text: digitRecognizer.predictedLabel }     // 识别结果
```

## 5. 音频（music / audio app）

**播放音乐**用 Qt Multimedia：
```qml
import QtMultimedia 5.0
Audio {
    id: player
    source: "file:///home/root/music.mp3"
    volume: volumeSlider.value / 100
    onStatusChanged: if (status === Audio.EndOfMedia) next()
}
Slider { id: volumeSlider; from: 0; to: 100; value: 60 }
Button { text: player.playing ? "暂停" : "播放"; onClicked: player.playing ? player.pause() : player.play() }
```

**录音/音频分析**（audio app）：用 `AudioRecorder` + `QAudioInput` 采集，`QAudioProbe` 抓 PCM 帧画波形。

## 6. 触摸屏与虚拟键盘

### 触摸屏
底层由 tslib 驱动，Qt 启动时设：
```
QT_QPA_PLATFORM=linuxfb:tty=/dev/fb0
QT_QPA_FB_TSLIB=1
TSLIB_TSDEVICE=/dev/input/event1
```
QML 层**不用写任何触摸代码**，`MouseArea` 自动接收触摸。

### 屏幕虚拟键盘（notepad / settings / mytest）

```pro
QT += virtualkeyboard
```
```qml
import QtQuick.VirtualKeyboard 2.4
import QtQuick.VirtualKeyboard.Settings 1.2
InputPanel {
    id: inputPanel
    z: 99
    width: window.width
    // 有焦点时从底部弹起(动画)
    states: State {
        name: "visible"
        when: inputPanel.active
        PropertyChanges { target: inputPanel; y: window.height - inputPanel.height }
    }
}
Binding {   // 中英文
    target: VirtualKeyboardSettings
    property: "activeLocales"
    value: ["zh_CN", "en_US"]
}
```
输入框 `TextField` 获得焦点时键盘自动弹出。

## 7. 蜂鸣器（beep app）与简单 IO

beep 与 LED 完全同模式（sysfs）：
```cpp
QFile f("/sys/class/leds/beep/brightness");
f.open(QIODevice::WriteOnly); f.write("1");   // 响
```
QML 里按钮控制，可做"滴答"反馈。

## 8. 进程内启动外部命令

嵌入式常直接调系统命令（GPIO/网络/脚本）：
```cpp
system("echo 1 > /sys/class/gpio/gpioX/value");
system("wpa_cli -i wlan0 scan");
```
Qt 更推荐 `QProcess`：
```cpp
QProcess p;
p.start("sh", {"-c", "echo none > /sys/class/leds/sys-led/trigger"});
p.waitForFinished();
```
> 桌面墙纸、WiFi 等常这么干（settings 里操作 wpa_supplicant）。

## 9. 硬件交互总结（模式速查）

| 需求 | 用什么 | 关键 API |
|------|--------|---------|
| 控制 GPIO/LED | sysfs 写文件 | `QFile` 写 `/sys/class/...` |
| 读按键 | input 事件 | `open("/dev/input/eventX")` + `read` |
| 读 I2C 传感器 | 子线程 + 文件 | `QThread::run` + `open/read` |
| 摄像头 | Qt Multimedia | `Camera`+`VideoOutput`+`ImageCapture` |
| 音频播放/录音 | Qt Multimedia | `Audio`/`AudioRecorder`/`QAudioProbe` |
| 触摸屏 | tslib + 框架 | 无需写代码, `MouseArea` 直接用 |
| 屏幕键盘 | virtualkeyboard | `InputPanel` + 焦点 |
| 硬件状态变化 | 文件监听 | `QFileSystemWatcher` |
| 执行命令 | QProcess | `QProcess::start` |

# 06 图形效果与 3D、主题

Qt Quick 在"好看"这件事上有三层工具：**QtGraphicalEffects**（2D 特效）、**Qt Quick 3D / Qt 3D**（3D）、**主题系统**（Material、Fluid）。

## 1. QtGraphicalEffects —— 2D 特效

systemui、camera、mytest 都 import 了它，用来做**阴影、模糊、颜色调整**。

```qml
import QtGraphicalEffects 1.12

// 给图片加阴影
Item {
    Image { id: icon; source: "qrc:/xxx.png" }
    DropShadow {
        anchors.fill: icon
        source: icon
        radius: 8                    // 阴影半径
        samples: 16
        color: "#80000000"           // 半透明黑
        opacity: 0.8
    }
}
```
其他常用效果：
- `Blur`（高斯模糊，弹窗背景）
- `OpacityMask`（按通道裁剪）
- `Colorize`（上色）
- `BrightnessContrast`（亮度对比度，扫雷暗色处理）
- `FastBlur`（快但质量略低）

## 2. Qt Quick 3D —— 3D 仪表盘（dashboard app）

dashboard 用 Qt 3D 画汽车仪表盘（转速表/车速表/油量表），是 3D 场景嵌入 QML 的示例。

```pro
QT += 3dcore 3drender 3dinput 3dquick 3dquickextras
```

QML 顶层是一个 `Entity`（3D 场景根）：
```qml
import QtQuick 2.12
import Qt3D.Core 2.12
import Qt3D.Render 2.12
import Qt3D.Input 2.12
import QtQuick.Scene3D 2.0

Item {
    Scene3D {                       // 把 3D 场景嵌进 2D 界面
        anchors.fill: parent
        Entity {                    // 3D 场景根
            // 相机
            Camera {
                id: camera
                projectionType: CameraLens.PerspectiveProjection
                fieldOfView: 45
                aspectRatio: 16/9
                nearPlane: 0.1; farPlane: 100
                position: Qt.vector3d(0, 0, 20)
                upVector: Qt.vector3d(0, 1, 0)
            }
            // 渲染配置(场景表面/相机/窗口大小)
            RenderSettings { activeFrameGraph: ForwardRenderer { camera: camera } }
            // 输入(允许鼠标旋转视角)
            InputSettings {}
            // 你的 3D 模型/网格 + 材质 + 变换
            CuboidMesh { id: boxMesh }
            PhongMaterial { id: mat; diffuse: "#2196f3" }
            Transform { id: tr; rotation: fromAxisAndAngle(Qt.vector3d(0,1,0), 45) }
            MeshObject {
                mesh: boxMesh
                material: mat
                transform: tr
            }
        }
    }
    // 2D 覆盖层: 用 Slider/Text 控制 3D
    Slider { value: 45; onValueChanged: tr.rotation = ... }
}
```

> 概念：`Entity`(对象) = `Mesh`(几何) + `Material`(材质) + `Transform`(位置/旋转)，`Camera` 定视角，`RenderSettings` 管渲染，`Scene3D` 把 3D 嵌进 QML。
> 性能提示：A7 单核软渲染跑真 3D 会吃力，dashboard 用低面数模型+简单材质。

## 3. Material 主题（fluid_demo）

fluid_demo 用 Qt Quick Controls 2 的 Material 风格（Google 设计语言）：

```qml
import QtQuick.Controls 2.3
import QtQuick.Controls.Material 2.3

ApplicationWindow {
    Material.theme: Material.Dark        // 深色主题
    Material.accent: Material.Pink       // 强调色
    Button { text: "按钮" }               // 自动带 Material 样式
}
```
再配合 `Fluid.Controls`（开源组件库）里的 `AppBar`、`Card`、`NavigationBar` 等，快速搭出现代界面。

## 4. 自定义主题与统一风格

mytest 的美化示例——统一用"颜色常量 + 半透明卡片 + 圆角"：

```qml
// 卡片: 白底圆角 + 彩色边框
Rectangle {
    radius: 18
    color: "#ffffff"
    border.color: "#66ffd54f"
    border.width: 2
    // 悬浮/按下缩放反馈
    scale: mouse.pressed ? 0.96 : (mouse.containsMouse ? 1.03 : 1.0)
    Behavior on scale { NumberAnimation { duration: 90 } }
}
```

常用美化套路：
- **渐变背景**：`Rectangle { gradient: Gradient { GradientStop{...} } }`
- **半透明遮罩**：`color: "#cc000000"`（#AARRGGBB）
- **圆角 + 阴影**：`radius` + `DropShadow`
- **文字描边**：`style: Text.Outline; styleColor: "#00000088"`

## 5. 动画让界面"活"起来

- `NumberAnimation`：数字/位置渐变
- `SequentialAnimation` + `loops: Animation.Infinite`：循环动画（加载圈、尾焰）
- `Behavior on 属性`：属性一变就平滑过渡
- `PropertyAnimation` / `QPropertyAnimation`（C++ 里也能用，见 mypushbutton 的按钮弹跳）

mypushbutton 的"按钮点击弹一下"（C++ 动画）：
```cpp
QPropertyAnimation *animation = new QPropertyAnimation(this, "geometry");
animation->setDuration(200);
animation->setStartValue(QRect(x(), y(), width(), height()));
animation->setEndValue(QRect(x(), y() + 10, width(), height()));  // 下移 10
animation->setEasingCurve(QEasingCurve::OutBounce);
animation->start();
```

## 6. 性能注意事项（单核 A7）

- **动画/定时器别太多**：全局 16ms 定时器 2~3 个即可
- **大图尽量缩放绘制**：`paintEvent` 里 `painter.scale` 而非加载大图
- **Canvas 优先于大量 Rectangle**：游戏场景用 Canvas 单画布，别堆几百个元素
- **避免高分辨率模糊/阴影**：软渲染下 DropShadow 大半径很费

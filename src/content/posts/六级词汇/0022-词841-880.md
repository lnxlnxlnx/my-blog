## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| convict | vt. 宣判有罪 n. 已决犯,囚犯 | vict 胜(victory)→ 被“拿下” = 定罪;囚犯。 |
| contagious | adj. 接触性传染的;有感染力的 | tag 触碰 → 一接触就传染的 = 接触性传染。 |
| predator | n. 捕⻝者,捕⻝性动物;掠夺者 | 联想:predator 扑上前逮猎物 = 捕食者、掠夺者。 |
| surveillance | n. (对嫌疑人或犯罪场所的) 监视 | 谐音联想:surveillance ≈ “守(着)” → 摄像头监视。 |
| glare | vi. 瞪,怒视;发出强烈刺眼的光 n. 瞪,怒视;强烈刺眼的光 | 画面:气得 glare 怒视,灯光 glare 刺眼。 |
| buck | n. (一) 美元;雄鹿,公兔;小伙子 vt. 抵制,反抗 vi. (⻢) 弓背四蹄跳起 | 画面:buck 雄鹿;俚语一 buck 就是一块美元。 |
| lofty | adj. 高耸的;崇高的;高傲的 | 同源 lift 升高 → 高高在上的 = 高耸、高傲。 |
| gasoline | n. 汽油 | 谐音联想:gasoline ≈ “加(油)” → 汽油。 |
| sin | n. 罪,罪孽;过错,恶行 vi. 犯戒律,犯过失 | 谐音联想:sin ≈ “罪”,七宗罪 seven sins。 |
| handicap | n. 生理缺陷,残疾;障碍,阻碍 vt. 妨碍,阻碍 | 谐音联想:handicap ≈ “难搞” → 障碍、残疾。 |
| aim | n. 目的,目标;瞄准 vi. vt. 力求达到;瞄准 vt. 旨在;针对 | 画面:端起枪 aim 瞄准目标;人生 aim 目标。 |
| flutter | vi. vt. 拍打 (翅膀);(在空中) 飘动 vi. (心脏等) 怦怦乱跳,扑腾 n. 振动,飘动;小赌注;慌乱 | 拟声:小鸟翅膀 flutter 扑棱,心怦怦 flutter。 |
| weed | n. 杂草;水草;大麻 vt. vi. 除杂草 | 画面:花园里 weed 杂草丛生,要连根拔除。 |
| panel | n. 专⻔小组;镶板;仪表盘 n. (⻋身的) 金属板 vt. (用镶板、玻璃等) 镶嵌 | 谐音联想:panel ≈ “盘” → 一“盘”专家;仪表盘。 |
| extravagant | adj. 奢侈的,铺张浪费的;离谱的 | extra 超出 + vag 走(源自“游荡”)→ 超出去乱花 = 奢侈。 |
| rescue | vt. 营救,救援 n. 营救,营救活动 | 画面:消防队 rescue 营救被困者。 |
| worm | n. 蠕虫;寄生虫;蠕虫病毒;懦夫 vt. 蠕动,曲折行进;给...驱肠虫 | 画面:蚯蚓 worm 在土里蠕动,电脑病毒也叫 worm。 |
| milestone | n. 里程碑,重大事件 | mile 英里 + stone 石 → 路边里程碑 = 重大事件。 |
| rumor | n. 谣言,传闻 vt. 谣传 | 谐音联想:rumor ≈ “入耳” → 传入耳朵的话 = 谣言。 |
| beg | vi. vt. 恳求,哀求;乞讨,行乞 | 画面:乞丐伸手 beg 乞讨;苦苦哀求。 |
| beverage | n. 饮料 | 谐音联想:beverage ≈ “杯(中物)” → 杯中饮品 = 饮料。 |
| dismiss | vt. 不予考虑;解雇,开除;消除 vt. 解散,让 (某人) 离开;驳回 | miss 送,dis 送走 → 解雇、解散、驳回。 |
| snap | vt. vi. (使) 断裂;(使啪地) 移动;拍照 vi. 咬;突然失去自制力 n. 啪嗒声,咔嚓声;照片;摁扣 adj. 匆忙的,仓促的,迅速的 | 拟声:树枝 snap 咔嚓折断;咔嚓拍照 snap。 |
| dedicate | vt. 献身,致力于;将 (书等) 献给 | 语境:把一生 dedicate 献给事业;书扉页题献。 |
| clash | n. 冲突;差别,分歧;争执 vi. 打斗,冲突;抵触;(时间)冲突 vi. vt. 撞击出巨大的响声 | 拟声:刀剑 clash 铿锵相撞 = 冲突、撞响。 |
| dub | vt. 将...戏称为;为...配音 | 画面:给外国片 dub 配音;戏称某人叫 dub。 |
| scarce | adj. 缺乏的,不足的,稀少的 adv. 才,勉强 | 谐音联想:scarce ≈ “稀少” → 缺乏的、稀少的。 |
| dispatch | vt. 派遣;派送;迅速处理;处决 n. 派遣,调遣;急件,快信;电讯 | 画面:紧急 dispatch 派遣快递,火速送出急件。 |
| coincide | vi. 同时发生;(想法等) 相同;重叠 | co 共同 + 落下(同源 accident 意外)→ 撞在一起 = 同时发生。 |
| grind | vt. 磨碎,碾碎;绞碎;把...磨锋利 vi. vt. 摩擦 (发出刺耳声) n. 苦差事,令人疲惫的工作 | 画面:磨豆机 grind 磨咖啡;苦差事也叫 grind。 |
| revenge | n. 报复,报仇;雪耻 vt. 报复,报仇 | venge 报(同源 vengeance)→ 报复、雪耻。 |
| diabetes | n. 糖尿病 | 谐音联想:diabetes ≈ “多(尿)” → 糖尿病,词源即尿液多。 |
| superficial | adj. 肤浅的;表面的;表皮的 | surface 表面,super 在上面 → 只看到表面 = 肤浅的。 |
| preach | vi. vt. 讲道,布道;宣传,鼓吹 vi. 说教,唠叨 | 画面:牧师 preach 布道;长辈爱 preach 说教。 |
| horror | n. 震惊,恐惧;恐怖故事 (或电影等) | 谐音联想:horror ≈ “吓人” → 恐惧、恐怖片。 |
| rally | n. 公众集会;拉力赛;止跌回升 vi. vt. 召集,集合 vi. 复原,恢复健康;止跌回升 | 谐音“拉力”:拉力赛 rally;集合众力 rally 集会。 |
| obstacle | n. 阻碍;障碍物 | 同源 stand 站 → 站在路中间的 = 障碍物。 |
| broad | adj. 宽阔的;概括的;广泛的 | 画面:broad 宽阔的大路,马路又宽又广。 |
| intellect | n. 智力,领悟力;才智非凡的人 | lect 选(select)→ 在知识中精挑细选 = 智力。 |
| intensive | adj. 密集的,强化的;(农业) 集约的 | intense 强烈 → 高强度密集训练 = 强化的。 |

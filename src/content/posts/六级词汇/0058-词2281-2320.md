# 词 2281–2320

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| cunning | adj. 狡猾的,奸诈的;巧妙的 n. 狡猾,诡诈 | 与 canny（精明的）同源→过于精明就是狡猾奸诈。 |
| crouch | vi. 蹲伏,蜷缩 n. 蹲着的姿势 | 画面联想：猫 crouch 蹲伏身子，准备扑向猎物。 |
| howl | vi. 嗥叫,⻓嚎;大声叫喊;呼啸 vi. vt. 怒吼,怒声要求 n. 嗥叫,⻓嚎;喊叫声 | 拟声词：狼对月 howl 长嚎；风也呼啸。 |
| fragrant | adj. 芳香的,有香味的 | 谐音「芙蓉」：芙蓉花 fragrant 香气扑鼻。 |
| cleanse | vt. vi. 使清洁,清洗;清除 | clean（干净）+se→彻底洗净、清除。 |
| blade | n. 刀刃,刀片;叶片;冰刀 | 《银翼杀手》Blade Runner，blade=刀刃；也指叶片。 |
| dialect | n. 方言,地方话 | 词根 lect=说（同 lecture 演讲）→某地人说的话=方言。 |
| Christ | n. 基督,耶稣基督 int. 天哪 | Christmas=Christ 的节日；Christ=基督、耶稣。 |
| fortify | vt. 筑防御工事;鼓励;强化 | fort（堡垒）+ify（使）→建堡垒加固=筑防御工事、强化。 |
| salon | n. 美发厅,美容院;会客厅;沙⻰ | 音译「沙龙」：文艺沙龙；现在也指美发厅。 |
| oftentimes | adv. 常常,经常 | often（常常）+times（次）→常常、经常。 |
| beset | vt. 困扰,威胁 | be（使）+set（放置）→被团团围住=受困扰、威胁。 |
| jelly | n. 果冻;果酱;㬵状物 | 画面联想：果冻 jelly 颤颤悠悠、Q 弹可口。 |
| sauce | n. 调味汁,酱汁 | 画面联想：炸鸡蘸 sauce 酱汁，滋味十足。 |
| stab | vt. 刺,捅 vt. vi. (用手指或尖物) 戳 n. 刺,捅;突然一阵剧痛;企图 | 画面联想：刀 stab 刺、捅；也指突然一阵剧痛。 |
| cloak | n. 斗篷,披⻛;遮盖物,掩盖物 vt. 遮盖,掩盖 | 画面联想：披上斗篷 cloak 掩盖身份；动词=遮盖。 |
| interim | adj. 暂时的,过渡的;期中的 n. 期间 | interim report=期中报告→暂时的、过渡期的。 |
| pamphlet | n. 小册子,手册 | 谐音「派发」：街头派发的小册子 pamphlet。 |
| volt | n. 伏特,伏 (电压单位) | 以意大利科学家伏打（Volta）命名→电压单位伏特。 |
| synonym | n. 同义词 | syn（同）+onym（名，同 anonymous 匿名）→同义词。 |
| heroin | n. 海洛因 | 音译「海洛因」；别和 hero 混，沾上它毁一生。 |
| lid | n. 盖,盖子 | 画面联想：锅盖 lid 盖得严严实实。 |
| buffalo | n. 水牛,野牛 | 美国城市 Buffalo 因此地水牛多而得名→水牛、野牛。 |
| forehead | n. 前额,额头 | fore（前）+head（头）→头的前部=额头。 |
| loot | vt. vi. (尤指战争中) 抢劫,洗劫 n. 战利品,赃物 | 谐音「掳」：战乱中掳掠抢劫；抢来的=战利品。 |
| tick | vi. (钟表) 发出嘀嗒声 vt. 打钩,打对号 n. 嘀嗒声;对号;壁虱;一会儿 | 拟声词：钟表 tick 嘀嗒；打钩也叫 tick。 |
| lunar | adj. 月球的,月亮的,阴历的 | 罗马月亮女神 Luna→lunar 月亮的；农历 lunar calendar。 |
| treasury | n. 财政部;金库,宝库 | treasure（财宝）+y→存放财宝的地方=金库、财政部。 |
| abide | vi. 遵守,遵从;逗留,居住 vt. 忍受,忍耐 | abide by the rules=遵守规则；也指忍受、逗留。 |
| horsepower | n. ⻢力 (引擎的功率单位) | horse（马）+power（力）→一匹马的力量=马力。 |
| bridegroom | n. 新郎 | bride（新娘）+groom（新郎）→婚礼上的新郎。 |
| grill | n. 烤架;一盘烧烤;烧烤店 vt. vi. 烧烤,烤制 vt. 盘问,追问 | 画面联想：烤肉放 grill 烤架上；警察 grill 盘问。 |
| taboo | n. 禁忌,忌讳 adj. 禁忌的,忌讳的 | 音译「塔布」：源自波利尼西亚语的禁忌 taboo。 |
| firework | n. 烟花;烟花表演;愤怒的话语 | fire（火）+work（作品）→用火做的作品=烟花。 |
| murmur | vt. vi. 小声说,喃喃细语 vi. 发出低沉连续的声音;小声抱怨 n. 低语声;咕哝声;(心脏)杂音 | 拟声词：murmur 像嘴里念念有词的咕哝低语。 |
| cork | n. 软木塞;软木 vt. 用软木塞塞住 | 画面联想：红酒瓶的 cork 软木塞，拔出「啵」一声。 |
| corporal | n. 下士 adj. 肉体的,身体的 | 词根 corp=身体（同 corpse 尸体）→肉体的；军队下士。 |
| adversary | n. 对手,敌手 | 词根 vers=转（同 adverse 不利的）→转身对着你的=对手。 |
| bureaucrat | n. 官僚,官僚主义者 | bureau（办公桌）+crat（统治者）→坐办公室发号施令=官僚。 |
| grease | n. 动物油脂;润滑油;(皮肤) 油脂 vt. 在...上涂油 | 画面联想：煎肉滋滋冒油脂；机械要涂润滑油。 |

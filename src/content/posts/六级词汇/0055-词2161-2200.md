## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| lieutenant | n. 中尉,上尉;(美国) 警督;助理 | lieu 位置 + tenant 占据 → 代理上级之职 = 中尉 |
| perch | vi. 栖息;置于(顶上或边上) vi. vt. (使)坐在...边沿 n. 栖木;高位;河鲈 | 谐音"泊栖"：鸟儿 perch 栖息枝头 |
| corpse | n. 尸体,尸首 | 同源 corpus（躯体）→ corpse 尸体 |
| blush | vi. (因尴尬或害羞) 脸红;感到羞愧 n. 面部泛起的红晕;腮红 | 画面：害羞 blush 脸红到耳根 |
| skyline | n. 轮廓线,天际线 | sky 天 + line 线 → 天际线 |
| congregate | vi. 聚集,集合 | 词根 greg = 群（segregate 同源）→ congregate 聚集 |
| batch | n. 一批,一组;一批生产量 | 一炉烤 batch 一批面包 |
| avenge | vt. 报...之仇 | 同源 revenge（复仇）→ avenge 报仇 |
| turnout | n. 出席人数;投票人数,投票率 | turn out（出席）→ turnout 出席人数、投票率 |
| lass | n. 小姑娘,少女 | 对比 lad（小伙子）：lass 姑娘 |
| wax | n. 蜡,蜂蜡,石蜡;耳垢 vt. 给...打蜡;用蜡除毛 vi. 说话变得...起来;(月亮) 渐圆 | 蜡烛 wax 蜡；月亮 wax 渐圆 |
| persecute | vt. 迫害,残害,压迫;骚扰,打扰 | 词根 secute = 跟随（execute 同源）→ 一路追着迫害 |
| gang | n. 一帮 (罪犯,混混等);一伙朋友 | 画面：gang 一帮混混成群结伙 |
| indict | vt. 控告,起诉 | 词根 dict = 说（dictate 同源）→ 法庭上"说"出罪状 = 控告 |
| renown | n. 名誉,声望 | 同源 name（名字）→ renown 名声声望 |
| menace | n. 危险的事物 (人);威胁;捣蛋⻤ vt. 危及,威胁到 | 画面：menace 危险逼近的威胁 |
| chin | n. 下巴 | 谐音"亲"：亲亲下巴 chin |
| midwife | n. 助产士,接生员 | mid 中间 + wife 妇女 → 守在产妇旁 = 助产士 |
| shorthand | n. 速记法;简略的表达方式 | short 短 + hand 手 → 速记法 |
| gospel | n. 福音书;福音;绝对真理 | god 上帝 + spel 故事 → 福音书 |
| butcher | n. 屠夫,肉商;肉铺;刽子手 vt. 屠杀,杀戮;宰杀;糟蹋 | 画面：butcher 屠夫在肉铺切肉 |
| liner | n. 邮轮,客轮;衬里,内衬 | line（航线）同源 → liner 邮轮；衬里 |
| vein | n. 静脉;叶脉;矿层;⻛格,方式 | 谐音"纹"：静脉如蓝色纹路；叶脉 |
| bail | n. 保释,保释金 vi. (迅速地) 离开,撤 | 谐音"保"：交 bail 保释金"保"出嫌犯 |
| franchise | n. 特许经营权;特许企业;选举权 vt. 出售 (或授予) 特许权 | 麦当劳 franchise 加盟店特许经营 |
| crocodile | n. 鳄⻥;鳄⻥皮 | 谐音"克罗克戴尔"：鳄鱼大嘴尖牙 |
| darling | n. 亲爱的;好心的人;宠儿 adj. 可爱的,迷人的 | 谐音"达令"：对爱人喊"达令" darling |
| analogue | adj. (技术) 模拟的;指针式的 n. 类似物,相似物 | 对比 digital（数字）：指针表 = analogue 模拟 |
| watertight | adj. 不透水的,防水的;无懈可击的 | water + tight 严密 → 防水、滴水不漏 |
| stitch | n. (缝纫的) 针脚;缝合伤口的缝线 vt. 缝,缝补;缝合 (伤口) | 伤口缝了几 stitch 针脚 |
| jurisdiction | n. 司法权,管辖权;管辖区域 | juris 法律 + dict 说 → 依法裁决范围 = 司法权 |
| landlady | n. 女房东;(酒吧等的) 女店主 | land 房 + lady 女士 → 女房东 |
| cock | n. 公鸡 vt. 翘起,竖起;扳上 (枪的) 扳机 | 公鸡 cock"喔喔"打鸣；扳上 cock 扳机 |
| parrot | n. 鹦鹉 vt. 鹦鹉学舌般地复述 | 画面：parrot 鹦鹉学舌复述 |
| judiciary | n. 司法部,司法系统 | 词根 jud = 判（judge 法官同源）→ 司法系统 |
| sigh | vi. 叹气,叹息;(⻛) 悲鸣 vt. 叹息着说 n. 叹气,叹息 | 长叹一声 sigh，气从牙缝"嘶"出 |
| triangle | n. 三⻆形;三⻆铁;三⻆关系 | tri 三 + angle 角 → 三角形 |
| captive | adj. 被关押的;非自愿的 n. 俘虏,囚徒 | 词根 capt = 抓（capture 同源）→ 被抓住 = 俘虏 |
| quiver | vi. 颤抖,哆嗦 n. 颤抖,哆嗦;箭袋,箭筒 | 吓得 quiver 颤抖；箭袋里的箭也颤 |
| militia | n. ⺠兵组织,国⺠卫队 | 同源 military（军事）→ militia 民兵 |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| gadget | n. 小器具,小装置 | 手机、手环这些小装置 = gadget |
| domestic | adj. 国内的;家庭的;家养的 n. 佣人;家庭纠纷 | 词根 dom=家 → domestic 家庭的、国内的 |
| ideology | n. 思想体系,意识形态 | idea 观念 + ology 学 → 意识形态 |
| penguin | n. 企鹅 | 谐音"胖滚"——胖企鹅摇摇摆摆 |
| ignorant | adj. 无知的,愚昧的,不知情的 | 词根 nor 同 know → ig 不 + nor = 无知 |
| sympathy | n. 同情;支持,赞同;意气相投 | sym 共同 + pathy 感情 → 感同身受 = 同情 |
| credible | adj. 可信的,可靠的;可接受的 | 同根 credit(信用)→ credible 可信的 |
| consent | n. 许可,准许,同意 vi. 许可,准许,同意 | con 共同 + sent 感觉(sense)→ 同感 = 同意 |
| hamper | vt. 妨碍,阻碍 n. ⻝品盒;脏衣篓 | 脏衣篓 hamper 堵路妨碍通行 → 妨碍 |
| dense | adj. 密集的;浓的;笨的;密度大的 | dense fog 浓雾 → 浓密、密集 |
| lobby | n. ⻔廊,大厅;游说团体;游说 vt. vi. 游说 | 酒店大堂 lobby 是游说拉关系处 → 大堂、游说 |
| counsel | n. 建议,劝告;辩护律师 vt. 建议,劝告;提供专业咨询 | 与 council(委员会)形近——律师给忠告 |
| match | n. 火柴;比赛;相配的人或物 vt. vi. 般配,和...相配;相一致 vt. 配对;与...相匹敌 | 划一根 match 火柴，点燃 match 比赛 |
| complicate | vt. 使难以理解,使复杂化 | 同根 complex(复杂)→ complicate 使复杂化 |
| handicraft | n. 手工艺,手工艺品 | hand 手 + craft 工艺 → 手工艺 |
| stove | n. 炉子,火炉;厨灶,炉灶 | 冬天 stove 火炉烤火 → 炉子 |
| shrimp | n. 虾,小虾 | 小虾米 shrimp 一炸就蜷红 → 虾 |
| monopoly | n. 垄断;垄断企业;大富翁 (游戏) | mono 单一 + poly 卖 → 一家独卖 = 垄断 |
| remnant | n. 残余部分 | 同根 remain(剩余)→ remnant 残余 |
| pump | n. 泵,抽水机,打气筒 vt. vi. 用泵输送 vi. (液体) 涌出;快速来回移动 vt. 快速摇动;盘问 | 拟声"砰砰"——打气筒打气 = pump 泵 |
| fuel | n. 燃料;刺激因素 vt. 给...提供燃料;助⻓,加剧 vt. vi. 加油 | 谐音"费油"→ 汽车费油 = 燃料 |
| spectator | n. 观众 | 词根 spect=看(inspect)→ 看的人 = 观众 |
| wrist | n. 腕,手腕 | 手表 watch 戴在 wrist 手腕 |
| eligible | adj. 有资格的;适合作为结婚对象的 | 同根 elect(选举)→ 能被选上 = 有资格 |
| catastrophe | n. 重大灾难,横祸 | 地震海啸级大祸 = catastrophe 重大灾难 |
| AIDS | n. 艾滋病 | 谐音"爱滋"→ AIDS 艾滋病 |
| wildlife | n. 野生动物,野生物种 | wild 野 + life 生命 → 野生动物 |
| municipal | adj. 城市的,市政的 | 市政厅 municipal building → 市政的 |
| satellite | n. 人造卫星;卫星;卫星国 | 人造卫星 satellite 绕地球转 → 卫星 |
| settle | vt. vi. 解决,和解;定居;(使) 平静 vt. 确定,决定;把...放好 vi. 降落,停留 | 坐下(seat)安顿 → settle 定居、解决 |
| unprecedented | adj. 史无前例的,空前的 | un 无 + precedent 先例 → 史无前例 |
| evoke | vt. 引起,唤起 (回忆或感情等) | 词根 voke=喊 → e 出 + voke 喊 → 唤起回忆 |
| flame | n. 火焰;强烈的感情;橘红色 vi. 燃烧 vi. vt. (因强烈情绪而) 脸红 | 蜡烛 flame 火焰摇曳 → 火焰 |
| compatible | adj. 兼容的;可共存的;合得来的 | 同根 patient(忍耐)→ 能互相容忍 = 兼容 |
| wolf | n. 狼 vt. 狼吞虎咽地吃 | 狼嚎"呜——"→ wolf 狼;wolf down 狼吞虎咽 |
| breast | n. 乳房;胸部;胸脯肉 vt. 以胸部推...,挺胸顶着... | breastfeed 哺乳用乳房 → breast 胸、乳房 |
| harbor | n. 港口,港湾 vt. 窝藏,庇护;心怀;包含,藏有 | 港口是船只避风港 → harbor 港口、庇护 |
| mandate | n. 授权;授权令,命令;任期 vt. 强制执行;授权 | man 手 + date 给 → 交到手中的权力 = 授权 |
| herd | n. 兽群,牧群;一般⺠众 vi. vt. (把...) 赶到一起,聚到一起 vt. 放牧 | shepherd 牧羊人同根 → herd 兽群 |
| viable | adj. 可行的,可实施的;可存活的 | 同根 vital(生命)→ 能活下去 = 可行 |

| elapse | vi. (时间) 流逝 | lapse 滑过 → 时间流逝 |
| vegetation | n. 植被,植物,草木 | vegetable 蔬菜 → vegetation 植被 |

| congress | n. 代表大会;国会 | gress 走（progress 前进）→ 走到一起 → 国会 |
| exquisite | adj. 精美的;(感觉) 强烈的;敏锐的 | 精挑细选 → 精美的 |
| ignite | vt. vi. 点燃,(使) 燃烧 vt. 激起,引发 | ignite 点火 → 点燃 |
| grim | adj. 严肃的;令人沮丧的;阴森的 | 谐音'鬼' → 阴森可怕 → 严峻的 |
| footprint | n. 脚印,足迹 | foot 脚 + print 印 → 脚印 |
| fortune | n. 运气;时运;命运;巨款 | fortune 命运、巨款 → 运气、财富 |
| shallow | adj. 浅的;肤浅的;(呼吸) 微弱的 | 水 shallow 浅 → 浅的、肤浅 |
| nest | n. ⻦巢;巢穴;家;一套物件 vi. 筑巢,巢居 | 鸟 nest 筑巢 → 巢 |
| vary | vi. 不同,有差异;(根据情况) 变化 vt. 改变,使多样化 | various 多样 → vary 变化 |
| welfare | n. 幸福;社会福利;社会保障金 | well 好 + fare 过日子 → 福利 |
| tempt | vt. 引诱,怂恿 | 谐音'贪' → 引诱 |
| pace | n. (移动) 速度;步伐,节奏;一步 vi. vt. 来回踱步,走来走去 vt. 调整自己的工作节奏 | 踱步 pace → 步伐、速度 |
| seize | vt. 抓住;攻占,控制;逮捕;没收 | 谐音'撕' → 一把抓住 |

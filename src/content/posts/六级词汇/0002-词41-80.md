# 词 41–80

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 08月27日 Thursday · 词 41–80 · PDF 第 3–4 页 · 新词 40 · 复习 40 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| proficient | adj. 熟练的,精通的 | 词根 fic=做(efficient 高效)→ 做得又快又好 = 熟练精通 |
| construct | vt. 建造,修建;组成,构成;绘制 n. 构想,概念,观念 | con 一起 + struct 建造(structure 结构)→ 搭起结构 = 建造 |
| tract | n. 道,束;大片(土地);小册子 | 词根 tract=拉(attract 吸引)→ 拉出的一长条 = 大片土地 |
| disease | n. 疾病;弊病,恶习 | dis 不 + ease 轻松 → 身体不轻松 = 疾病 |
| therapy | n. 疗法,治疗;心理治疗 | psychotherapy 心理治疗里的 therapy = 疗法 |
| gas | n. 气体;煤气;汽油;毒气,瓦斯 vt. 使吸入毒气 | 音译"瓦斯/嘎斯"→ 气体、煤气、毒气 |
| heaven | n. 天堂,极乐之地;天空 | 与 heavy(沉重)相对——天堂轻盈飘在天上 |
| trigger | n. 扳机;触发器;起因,诱因 vt. 引起,触发 | 扣动扳机就触发 → trigger = 扳机、引发 |
| melody | n. 旋律,曲调,歌曲 | 谐音"麦乐迪"(KTV)→ 唱歌的旋律 |
| prince | n. 王子;(小国) 国君;大师,名家 | prince 与 princess(公主)成对记 → 王子 |
| hinge | n. 铰链,合⻚ vt. 给 (⻔、盖等) 装铰链 | 门开合时铰链"吱呀"响 → hinge = 铰链 |
| stumble | vi. 绊脚;踉跄;结巴;出现问题 n. 绊倒;差错 | st 石头 + tumble 摔倒 → 被石头绊倒踉跄 |
| bury | vt. 埋葬;埋藏;覆盖;掩藏 | burial(葬礼)同根 → bury = 埋葬 |
| tangible | adj. 实际的,真实的;有形的 | tang 触摸 + ible 可…的 → 摸得着 = 有形 |
| doll | n. 玩偶,玩具娃娃 | Barbie doll 芭比娃娃 → doll = 玩偶 |
| cherish | vt. 珍爱,珍惜;怀有 (希望等) | 把"亲爱的"之物好好珍藏 → cherish 珍爱 |
| preside | vi. 主持,负责 (会议等) | pre 前 + sid 坐(sit)→ 坐在前面主持 |
| prey | n. 猎物;受害者 vi. 捕⻝;坑骗 | 与 pray(祈祷)同音——猎物祈祷别被吃 |
| commence | vi. vt. 开始,着手 | 联想 come 来 → 事情来临 = 开始 |
| ray | n. 光线,射线;一丝,少量;鳐 | X-ray X射线 → ray = 光线 |
| thrive | vi. 兴旺,繁荣,欣欣向荣 | 联想 three(三)→ 一棵变三棵 = 草木兴旺 |
| miniature | adj. 很小的,微型的 n. 微型画,小画像;缩微模型 | mini(小)+ature → 迷你 = 微型 |
| hazard | n. 危险,隐患,危害 vt. 大胆提出或猜测;使...冒⻛险 | 谐音"害人的"→ 危险、隐患 |
| situate | vt. 使坐落于,使位于;将...置于 | sit 坐 → 建筑物"坐"在某处 = 使坐落 |
| affiliate | vt. vi. (使) 隶属于,(使) 紧密联系 n. 分支机构,附属组织,分公司 | fili=儿子(filial 子女)→ 认作儿子 = 隶属 |
| parliament | n. 议会,国会 | parle(法语"说话")→ 议员议政处 = 议会 |
| county | n. 郡,县 | count(伯爵)→ 伯爵领地 = 郡、县 |
| tolerate | vt. 容许;忍耐;对...有耐受性 | tolerant(宽容)同源 → tolerate 容忍 |
| mow | vt. vi. 割,刈 (草等) | mower 割草机 → mow = 割草 |
| atlas | n. 地图册,地图集 | 神话中肩扛天球的巨人 Atlas → 地图册 |
| motel | n. 汽⻋旅馆 | motor 汽车 + hotel 旅馆 → 汽车旅馆 |
| refute | vt. 反驳,否认...的正确性 | 同根 confute(驳斥)→ refute 反驳 |
| beforehand | adv. 事先,预先 | before 前 + hand 手 → 动手之前 = 事先 |
| cord | n. 粗线,细绳;电源线;灯芯绒裤 | power cord 电源线 → cord = 绳、线 |
| ruin | vt. 毁坏,毁掉;使破产 n. 毁坏,毁灭;破产;废墟;祸根 | 古罗马 ruins 废墟 → ruin 毁坏、废墟 |
| makeup | n. 化妆品;性格;组成;补考 | make up 化妆 → makeup 化妆品、构成 |
| dine | vi. 就餐,用餐 | dinner(正餐)同源 → dine = 用餐 |
| steep | adj. 陡的;急剧的;(价格等) 过高的 vt. 浸泡 (⻝物) | 陡坡像竖梯 → steep = 陡的、急剧的 |
| foresee | vt. 预⻅,预知,预料 | fore 前 + see 看 → 提前看到 = 预见 |
| orient | vt. 使朝向,针对;确定方位;使适应 n. 东方 (指东亚地区) | 词根 ori=升起(origin)→ 太阳升起处 = 东方 |

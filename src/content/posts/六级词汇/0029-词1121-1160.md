| yell | vi. vt. 大喊,吼叫 n. 大喊,吼叫 | 谐音"吆"→吆喝,大喊 |

| wander | vi. vt. 闲逛,游荡 vi. 偏离 (正道),走失;走神 n. 闲逛,游荡 | 同 wonder→闲逛时想东想西 |
| blur | n. 模糊不清的事物;模糊的记忆 vt. vi. (使) 视线模糊;使 (想法等) 模糊 | 联想失焦的照片→模糊 |
| refrain | vi. 克制,忍住,避免 n. 陈词滥调;副歌,叠句 | 同 restrain(抑制)→拉住自己,克制 |
| trademark | n. 商标;标志,特征 | trade(贸易)+mark(标记)→商标 |
| bay | n. 湾,海湾;隔间;月桂;栗色⻢ vi. 发出⻓嗥;强烈要求 adj. (尤指⻢) 棕红色的,栗色的 | 联想海湾→湾,海湾;bay leaves 月桂 |
| bathe | vi. vt. 洗澡,给...洗澡 vt. 清洗 (伤口等);使沐浴在光中 vi. (到海、河、湖等中) 游泳消遣 | bath(洗澡)+e→洗澡;沐浴 |
| dust | n. 尘埃;沙土,尘土;粉末 vi. vt. 擦去...的灰尘 vt. 把 (粉末) 撒于 | 联想灰蒙蒙→灰尘,尘土 |
| premature | adj. 过早的;早产的;仓促的 | pre(提前)+mature(成熟)→没熟就出来,早产 |
| prone | adj. 有...倾向的;俯卧的 | 联想俯卧撑→俯卧的;易受...的 |
| dart | n. ⻜镖;掷镖游戏;猛冲,⻜奔 vi. 猛冲,⻜奔 vi. vt. (朝某人猛然) 看,瞥 | 谐音"打他"→飞镖;猛冲 |
| contaminate | vt. 污染,弄脏;玷污,毒害 | 联想脏水污染水源→污染,弄脏 |
| secondhand | adj. 二手的;(信息) 间接得来的 adv. 作为二手货;间接地 | second(第二)+hand(手)→二手货 |
| prominent | adj. 杰出的,重要的;显眼的 | pro(前)+minent(突出)→突在前面,杰出 |
| turkey | n. 火鸡;火鸡肉;失败之作 | 联想土耳其 Turkey→火鸡 |
| baby boom | usage. 生育高峰 (期) | baby(婴儿)+boom(激增)→婴儿潮 |
| deed | n. 行为;契约 | 同 do(做)→做过的事,行为 |
| sparkle | vi. 闪闪发光,闪耀 n. 光亮,闪光;闪光点,亮点 | spark(火花)+le→闪闪发光 |
| thief | n. 小偷,窃贼 | 谐音"贼"→小偷,窃贼 |
| transistor | n. 晶体管 | 联想收音机里的晶体管→晶体管 |
| endeavor | vi. 努力,尽力 n. 努力,尝试 | 联想全力以赴→努力,尽力 |
| hawk | n. 鹰,隼;鹰派人士,主战派人士 vt. 叫卖,兜售 | 联想鹰在高空→鹰;鹰派好战 |
| compulsory | adj. 强制性的,义务的 | com+puls(推,同 pulse)+ory→被推着做,强制 |
| typewriter | n. 打字机 | type(打字)+writer(写)→打字机 |
| facet | n. 部分,方面;(宝石的) 小平面 | face(面)+t→宝石的一个面,方面 |
| rob | vt. 抢劫,掠夺 | 同 robber(强盗)→抢劫 |
| versatile | adj. (人) 多才多艺的;多功能的 | vers(转)+atile→什么都能转,多才多艺 |
| tunnel | n. 地道,隧道;(动物挖的) 洞穴 vi. vt. 挖隧道,挖地道 | 联想火车钻山洞→隧道 |
| subtract | vt. vi. 减,减去 | sub(下)+tract(拉,同 attract)→往下拉,减去 |
| execute | vt. 处死;执行;创作;使生效 | ex(出)+ecute→执行;处死 |
| infect | vt. 传染,使感染;(情绪等) 感染 | in(进)+fect(做,同 effect)→病菌进来起作用,感染 |
| fry | vt. vi. 油炸,油煎,油炒 vi. (被阳光) 灼伤,晒伤 n. 炸薯条;⻥苗 | 联想炸薯条 french fries→油炸 |

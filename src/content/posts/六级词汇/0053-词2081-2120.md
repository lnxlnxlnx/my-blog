## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| fascist | n. 法西斯分子;极右分子 adj. 法西斯主义的 | 源自拉丁语"束棒"（罗马权力标志）→ 法西斯 |
| countdown | n. 倒计时;大事临近的时期 | count 数 + down 下 → 倒计时 |
| indebted | adj. 感激的,蒙恩的;负债的 | debt（债）同源 → 负债的、欠人情 = 感激 |
| prop | vt. 支撑,撑住 n. 道具;支柱;支持者;螺旋桨 | 用棍 prop 撑住歪树；舞台道具 prop |
| mansion | n. 公馆,宅第;公寓,大厦 | 谐音"曼森"：明星的 mansion 豪宅 |
| petition | n. 请愿书;申诉书 vi. vt. 请愿;(向法庭) 申请;祈祷 | 词根 pet = 追求（appetite 同源）→ petition 请愿 |
| microphone | n. 话筒,⻨克⻛ | micro 小 + phone 声音 → 话筒 |
| choir | n. 唱诗班,合唱团;唱诗班的席位 | 教堂 choir 唱诗班齐声唱 |
| centigrade | adj. 摄氏度的 n. 摄氏温度 | centi 百 + grade 度 → 摄氏温度 |
| staircase | n. 楼梯 | stair（梯级）+ case → 楼梯 |
| inflict | vt. 使遭受,施加,造成 (伤害等) | 词根 flict = 打击（conflict 冲突同源）→ 施加伤害 |
| cupboard | n. 橱柜 | cup 杯 + board 板 → 放杯盘的橱柜 |
| fusion | n. 融合 (物);核聚变;合成音乐 | fuse（熔化）同源 → 融合、核聚变 |
| operative | adj. 可使用的,运作中的;手术的 n. 工作人员,工人;密探,特工 | operate（操作）同源 → 运作中的、手术的 |
| dusk | n. ⻩昏,傍晚 | 联想 dark（黑暗）：dusk 黄昏天渐暗 |
| isle | n. (常用于地名) 岛 | island 去掉 land → isle 小岛（地名常用） |
| interrogate | vt. 审讯,盘问 | 词根 rog = 问 → interrogate 审讯盘问 |
| reminiscent | adj. 使人回想起某事的;怀旧的 | 同源 memory（记忆）→ 令人回想起 |
| loaf | n. (面包的) 一条 vi. 游荡,闲逛 | 一条 loaf 面包；整天 loaf 游荡 |
| sarcasm | n. 讽刺,嘲讽,挖苦 | 画面：sarcasm 带刺的话，讽刺挖苦 |
| brunch | n. 早午餐 | breakfast + lunch 拼合 → 早午餐 |
| embassy | n. 大使馆,使馆官员 | ambassador（大使）在 embassy 大使馆办公 |
| transcript | n. 抄本,转录本;成绩报告单 | trans 转 + script 写 → 转录本、成绩单 |
| binoculars | n. 双筒望远镜 | bi 双 + ocular 眼 → 双筒望远镜 |
| apprentice | n. 学徒 vt. 使做学徒,使拜师于 vi. 当学徒 | 画面：apprentice 学徒跟着师傅打下手 |
| bait | n. ⻥饵;用作诱饵的人或物 vt. 给 (⻥钩或陷阱) 上诱饵;挑衅 | 谐音"备它"：钓鱼备好 bait 鱼饵诱鱼 |
| embargo | n. 贸易禁运 vt. 下令禁运;禁止发表 | bar（拦住）同源：embargo 把贸易拦住 = 禁运 |
| invert | vt. (使) 颠倒,逆转,倒置 | 词根 vert = 转（convert 同源）→ 颠倒、倒置 |
| skull | n. 颅⻣,头⻣;脑袋,头脑 | 画面：骷髅头 skull 头骨；脑袋 skull |
| toast | n. 烤面包片,吐司;干杯,祝酒 vt. 为...举杯敬酒 vt. vi. 烤 (尤指面包),把...烤得焦⻩ | 画面：toast 吐司烤焦黄；举杯 toast 祝酒 |
| porridge | n. 燕⻨粥,⻨片粥 | 早餐 porridge 燕麦粥热气腾腾 |
| bout | n. 一阵;(疾病的) 发作期;拳击赛 | 谐音"搏"：拳击赛一 bout 回合 = 一阵发作 |
| snob | n. 势利小人 | 谐音"势奴"：势利眼 snob 攀附权贵 |
| pudding | n. 布丁;甜点 | 谐音"布丁"：pudding 布丁甜点 |
| warrior | n. 勇士,武士 | war（战争）同源 → warrior 勇士 |
| hostage | n. 人质 | 画面：劫匪扣押 hostage 人质 |
| lipstick | n. 口红,唇膏 | lip 唇 + stick 棒 → 口红 |
| colon | n. 结肠;冒号 | 画面：冒号"："像结肠一段 → colon 冒号、结肠 |
| ale | n. ⻨芽啤酒 | 谐音"爱喝"：爱喝 ale 麦芽啤酒 |
| nude | adj. 裸体的;肉色的 n. 裸体画,裸体人像 | 画面：nude 裸体画；肉色 nude |

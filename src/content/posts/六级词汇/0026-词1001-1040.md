| leak | vi. vt. (使) 渗漏;泄露 (秘密等),走漏 vi. (气体或液体) 漏出 n. 漏洞,裂缝;泄露 | 联想水管漏水→渗漏;泄露秘密 |
| vague | adj. 模糊的;含糊的,笼统的 | 联想雾里看花→模糊,含糊 |

| twist | vt. vi. (使) 弯曲变形;扭动;缠绕 vi. 曲折,蜿蜒 vt. 使弯曲;转动,旋转;扭伤;曲解 n. 转动,旋转;转折;急转弯处 | twi(两,同 two)+st→拧两下,缠绕 |
| subsidy | n. 补贴,津贴 | sub(下)+sid(坐,同 sit)→在下面托着,补贴 |
| practitioner | n. 从业人员;实践者 | practice(实践)+er→从业人员,实践者 |
| relic | n. 遗物,遗迹,遗⻛;圣⻣,圣物 | 同 relinquish(放弃)词根"留"→留下的遗迹 |
| spill | vi. vt. (使) 溢出或洒出 vi. 蜂拥而出,涌出 n. 洒出 (量),泼出 (量);跌落 | 联想牛奶泼洒→洒出,溢出 |
| evaporate | vi. vt. (使) 蒸发,(使) 挥发 vi. 逐渐消失 | e(出)+vapor(蒸汽)→变成蒸汽跑掉,蒸发 |
| flock | n. (动物) 群;一大群(人) vi. 蜂拥,群集,涌向 | 联想羊群挤在一起吃草→群;蜂拥 |
| opaque | adj. 不透明的;(文字或演讲) 难懂的 | o(不)+paque→不透光,不透明 |
| degenerate | vi. 恶化,衰退,堕落 adj. 堕落的,腐化的 n. 堕落的人,腐化的人 | de(下)+generate(生成)→往下走,退化堕落 |
| glory | n. 荣誉,光荣;壮丽,辉煌 | 联想荣光闪耀→光荣,辉煌 |
| minister | n. 部⻓,大臣;牧师;公使 vi. 服侍,帮助 | mini(小)+ster→服务大众的人,大臣;牧师 |
| consensus | n. 一致看法,共识 | con+sens(感觉,同 sense)→同感,共识 |
| mortgage | n. 房屋抵押贷款,按揭 vt. 抵押 (房屋、土地) 借款 | 词根 mort=死(同 mortal),押到死→按揭 |
| robust | adj. 强健的;结实的;坚定的 | 联想"肉搏"→能肉搏的身体,强健 |
| chairman | n. (委员会) 主席;(会议) 主持人 | chair(椅子)+man→坐在主席椅上的人 |
| bachelor | n. 单身汉,未婚男子;学士 | 谐音"白吃了"→单身汉没人做饭;学士 |
| verse | n. 诗;诗节;(《圣经》等中的) 节 | 词根 vers=转(同 version)→转出来的诗行 |
| soil | n. 土壤,土地;国土,领土 vt. 弄脏,玷污 | 联想土地被弄脏→土壤;玷污 |
| expertise | n. 专⻓,专⻔技术 (知识) | expert(专家)+ise→专家知识,专长 |
| sorrow | n. 悲伤,伤心;令人悲伤的事 vi. 感到悲伤 | 联想流泪→悲伤,伤心 |
| résumé | n. 履历,简历;摘要 | 同 resume(继续)→继续经历的记录,简历 |
| discharge | vt. 准许离开,解雇;履行;开火 vi. vt. 排出,放出;放 (电) n. 排出 (物);获准离开;履行 | dis(出)+charge(负责)→解除责任,放人出院 |
| lately | adv. 最近,不久前 | late(晚)+ly→最近,近来 |
| ultra | adj. 极度...的,超级...的 pref. 外,超 | 联想"奥特曼"(ultra)→超级,极度 |
| gate | n. 大⻔;登机口;闸⻔ | 大门;机场登机口都叫 gate |
| revenue | n. (政府、企业) 收入,税收 | re(回)+venue(来)→收回来的钱,收入 |
| bracket | n. 括号;等级 (段);(墙上的) 托架 vt. 把...视为同类,把...相提并论 | 括号;括号把同类括在一起,相提并论 |
| biography | n. 人物传记,传记文学 | bio(生命)+graphy(写)→书写一生,传记 |
| insect | n. 昆虫,虫 | in+sect(切,同 section)→身体一节一节,昆虫 |
| tenure | n. 终身教职;任期;居住或使用权 | 词根 ten=拿(同 tenable)→拿住职位,终身教职 |

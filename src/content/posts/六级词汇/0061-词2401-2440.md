# 词 2401–2440

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 10月25日 Sunday · 词 2401–2440 · PDF 第 121–122 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| faction | n. 派别,派系;派系之争 | fact（做）+ion→一起做事的一伙人=派系；派系之争。 |
| vest | n. 背心;(特殊用途的) ⻢甲 vt. 授予,赋予 | 与 invest（授予）同源→vest 授予权利；也指背心。 |
| atop | prep. 在...之上,在...顶上 | a（在）+top（顶部）→在…顶上。 |
| dissident | n. 持不同政⻅者,异⻅分子 | dis（分开）+sid（坐，同 sit）→另坐一边=持不同政见者。 |
| corrode | vt. vi. (使) 腐蚀;削弱,损害,破坏 | 词根 rode=咬（同 rodent 啮齿动物）→金属被「咬」坏=腐蚀。 |
| electron | n. 电子 | electr（电）+on→带电粒子=电子。 |
| buckle | n. (皮带等的) 搭扣,锁扣 vi. vt. (使) 弯曲,压弯;用扣环扣住 vi. 双腿发软 | 画面联想：皮带 buckle 搭扣；腿发软 buckle 弯下去。 |
| cabin | n. 小木屋;(⻜机上的) 客舱;船舱 | 画面联想：林间小木屋 cabin；飞机客舱也叫 cabin。 |
| bishop | n. 主教;(国际象棋中的) 象 | 国际象棋里走斜线的「象」叫 bishop（主教）。 |
| equator | n. 赤道 | 与 equal（相等）同源→平分地球的线=赤道。 |
| gay | adj. 同性恋的;欢乐的 n. (男) 同性恋者 | gay 旧义「欢乐的」，今指同性恋的（多指男性）。 |
| groove | n. 凹槽,辙;(某种) 音乐节奏 | 画面联想：唱片上的 groove 凹槽刻着音乐；进入状态。 |
| soap | n. 肥皂;肥皂剧 vt. 用肥皂擦洗 | 肥皂剧 soap opera 得名于肥皂广告→soap=肥皂。 |
| trunk | n. 树干;后备箱;大箱子;象鼻 | 画面联想：大象的 trunk 象鼻；也指树干、后备箱。 |
| tournament | n. 锦标赛;(中世纪骑士的) 比武 | 与 tour（巡回）同源→队伍巡回比拼=锦标赛。 |
| adverb | n. 副词 | ad（添加）+verb（动词）→修饰动词的词=副词。 |
| tram | n. 有轨电⻋ | 画面联想：tram 有轨电车叮叮当沿轨道开过。 |
| batter | vt. vi. 殴打,连续猛击,撞击 n. 面糊;(棒球) 击球手 | 与 bat（击打）同源：batter 击球手；也指殴打、面糊。 |
| numb | adj. 失去知觉的;麻木的,迟钝的 vt. 使失去知觉;使麻木,使迟钝 | 谐音「木」：冻得 numb 麻木，失去知觉。 |
| peck | vi. vt. 啄 vt. 轻吻 n. 轻吻;啄 | 拟声词：小鸡 peck 啄米；也指轻轻一吻。 |
| multilateral | adj. 多国的,多边的,多方面的 | multi（多）+lateral（边）→多边的、多国的。 |
| dissent | n. 异议,不同意⻅ vi. 持异议,有不同意⻅ | dis（不同）+sent（感觉，同 sentiment）→感受不同=异议。 |
| dough | n. 生面团,湿面团;钱 | 画面联想：揉 dough 面团做面包；美俚 dough=钱。 |
| honeymoon | n. 蜜月;(初期的) 和谐期,蜜月期 vi. 度蜜月 | honey（蜜）+moon（月）→甜如蜜的新婚之月=蜜月。 |
| brandy | n. 白兰地酒;一杯白兰地 (酒) | 音译「白兰地」：葡萄酿的烈酒 brandy。 |
| syndicate | n. 辛迪加,商业财团,企业组织 vt. 出售给多家报刊发表 | 音译「辛迪加」：企业联合组织、商业财团。 |
| cylinder | n. 圆柱体,圆筒;汽缸 | 画面联想：发动机的 cylinder 汽缸是圆柱体。 |
| pea | n. 豌豆 | 画面联想：豌豆 pea 圆滚滚躺在豆荚里。 |
| melon | n. 瓜,甜瓜 | 画面联想：melon 甜瓜水汪汪，夏天抱半个挖着吃。 |
| parish | n. 教区;小行政区 | 画面联想：教堂管辖的 parish 教区，居民都来做礼拜。 |
| parachute | n. 降落伞 vi. 跳伞 vt. 伞投,空投 | chute（滑落）+para（防护）→防坠落的伞=降落伞。 |
| jog | vi. 慢跑 vt. 轻撞,轻碰 n. 慢跑 | 画面联想：清晨 jog 慢跑健身；轻撞一下也叫 jog。 |
| assorted | adj. 各种各样的,混杂的 | sort（分类）+ed→分成多种的=各种各样的。 |
| eclipse | n. 日⻝,月⻝;(权势等的) 丧失 vt. 遮住...的光;使黯然失色 | 画面联想：天狗食月=日食月食；强者令对手黯然失色。 |
| statute | n. 法令,法规 | 词根 stat=立（同 statue 雕像）→立下的规矩=法令。 |
| lime | n. 酸橙;石灰;酸橙树;酸橙绿 vt. (给土壤) 撒石灰 | 画面联想：lime 酸橙绿绿酸酸的；石灰也叫 lime。 |
| balcony | n. 阳台;(剧院的) 楼座,楼厅 | 画面联想：站 balcony 阳台看风景；剧院楼座也叫 balcony。 |
| jealous | adj. 嫉妒的;吃醋的;小心守护的 | 谐音「急了眼」：见别人好就嫉妒吃醋。 |
| prosecute | vt. vi. 起诉;担任控方律师;继续做 | 词根 secut=跟随（同 execute 执行）→追着告到底=起诉。 |
| damn | int. 该死,可恶 adj. 该死的,可恶的;完全的 vt. 该死,可恶;罚...入地狱;谴责 adv. 该死,可恶;非常 | Damn it! 该死！damn=该死、谴责。 |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| haste | n. 匆忙,仓促 | Haste makes waste 欲速则不达 → haste 仓促 |
| deputy | n. 副手,代理人;治安官助理 | deputy 音似'代'——代理副手 |
| metro | n. 地铁,地下铁路 adj. 大都市的 | 巴黎地铁叫 Métro → 地铁；大都市 metropolitan 同源 |
| wool | n. (羊等的) 毛;毛线;羊毛织物 | wool 羊毛：绵羊身上 wool 软绵绵 |
| vow | n. 誓言,誓约 vt. 起誓,立誓,发誓 | vow 誓言：婚礼上互许 vow |
| gland | n. 腺,腺体 | gland 音似'灌'，腺体分泌灌出液体 |
| refreshment | n. 茶点;⻝品和饮料;恢复精力 | refresh(提神)+ment → 茶点 refreshment 提神解乏 |
| parade | n. (庆祝) 游行;检阅,阅兵;一系列 vi. 游行;招摇过市 vt. 展览,展示 vi. vt. (使) 列队行进,接受检阅 | parade 音似'排'——列队游行的队伍；阅兵 |
| despise | vt. 鄙视,蔑视 | de(向下)+spise(看) → 往下看人=鄙视 |
| coherent | adj. 连贯的;言谈条理清楚的 | co(一起)+here(粘住，adhere 同源) → 粘在一起=连贯 |
| expressway | n. 高速公路 | express(快速)+way(路) → 快速路=高速公路 |
| waist | n. 腰,腰部;(衣服的) 腰部 | waist 谐音'围'，腰围 waist 一圈 |
| mist | n. 薄雾,雾霭,水汽;液体喷雾 vt. vi. (使) 结雾;被泪水模糊 vt. 向...喷雾 | mist 谐音'迷'——薄雾蒙蒙看不清 |
| henceforth | adv. 从今以后,从现在起 | hence(从此)+forth(向前) → 从今以后 |
| mercy | n. 仁慈,宽恕;幸运,恩惠 | mercy 仁慈：求 mercy 高抬贵手 |
| thermometer | n. 温度计 | thermo(热，thermos 保温瓶同源)+meter 测量 → 温度计 |
| van | n. 货⻋,面包⻋;(火⻋) 货⻋⻋厢 | van 货车：搬家面包车 van 一车拉走 |
| drum | n. 鼓;大桶;鼓状物 vi. 打鼓,击鼓 vt. vi. 不停地击打 | drum 拟声'咚'——敲鼓咚咚；大桶也叫 drum |
| humid | adj. 潮湿的,湿热的 | hum=湿(humidifier 加湿器同源) → 潮湿湿热 |
| lad | n. 小伙子,少年;哥们儿;⻢夫 | lad 小伙子：阳光少年 lad 哥们儿 |
| bin | n. 垃圾箱;箱子,储物箱 vt. 扔掉 | bin 垃圾桶：随手扔 bin；英国垃圾分类 bin |
| peddle | vt. 叫卖,兜售;宣传,传播 | ped=脚(pedestrian 行人同源) → 走街串巷叫卖 peddle |
| tack | n. 平头钉,图钉;方法;抢⻛调向 vt. 钉住;用粗线脚缝 vi. 抢⻛行驶,换抢,作之字形航行 | tack 图钉：海报用 tack 钉墙上；换方法、抢风改向 |
| dread | vt. 非常害怕,极为担心 n. 恐惧,令人惧怕的事物 | dread 音似'追'——被恐惧追着跑，非常害怕 |
| futile | adj. 徒劳的,无益的,无意义的 | futile 音似'废'——白费力气，徒劳无益 |
| hedge | n. 树篱;防止损失的手段 vi. 避免正面回答,拐弯抹⻆ vt. 用树篱围住;包围,限制 vi. vt. 防备,防范 (尤指金钱损失) | hedge 树篱围院；对冲基金 hedge fund 防损失 |
| rhetoric | n. 花言巧语,华而不实的言语;修辞 | rhetoric 修辞：政客的花言巧语华而不实 |
| biochemistry | n. 生物化学 | bio(生物)+chemistry(化学) → 生物化学 |
| manuscript | n. 手稿,原稿,底稿;手抄本 | manu(手，manual 同源)+script(写) → 手写稿 |
| showcase | n. 展示 (优点) 的场合;玻璃柜 vt. 展示...的优点 | show(展示)+case(柜子) → 玻璃柜；动词展示优点 |
| escort | vt. 护卫,护送 n. 护卫者;社交伴侣 | escort 护卫：保镖 escort 护送贵宾 |
| stipulate | vt. 规定,约定,明确要求 | stipulate 规定：合同条款 stipulate 明确要求 |
| jet lag | n. 时差反应 | jet(飞机)+lag(滞后) → 坐飞机后身体滞后=时差反应 |
| patriot | n. 爱国者 | patri=祖国(patriotic 爱国同源) → 爱国者 |
| vibrate | vi. vt. (使) 振动,(使) 颤动 | 手机 vibrate 震动模式嗡嗡响 → 振动 |
| lucrative | adj. 获利多的,赚钱的 | lucr=钱(拉丁词根) → lucrative 赚钱的 |
| feast | n. 盛宴;宗教节日;特别的享受 vi. 尽情享用 (美味佳肴) | feast 盛宴：满桌佳肴；圣诞 feast 大餐 |
| thrust | vt. vi. 猛推,挤;刺,戳 n. 猛推,刺,戳;驱动力;要点 | thrust 猛刺：剑尖 thrust 刺出；引擎推力 thrust |
| adjective | n. 形容词 | ad(添加)+ject(放) → 附加在名词上的词=形容词 |
| telecommunications | n. 电信,电讯 | tele(远)+communications(通信) → 远距离通信=电信 |

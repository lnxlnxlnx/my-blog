## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| mammal | n. 哺乳动物 | 谐音“妈妈(mama)”:喝妈妈奶长大的 = 哺乳动物。 |
| restrain | vt. 制止,阻止;克制,抑制 | strain 拉紧,re 往回 → 拉住 = 制止、克制。 |
| spin | vi. vt. (使) 快速旋转;(使) 急转身;纺 vt. 吐丝,作茧;有倾向性地陈述 n. 高速旋转;兜⻛;旋转 (球) | 画面:陀螺 spin 滴溜溜转;蜘蛛 spin 吐丝。 |
| blast | n. 爆炸,气浪;强劲的气流;响声 vi. vt. 炸毁,爆破;发出刺耳的高音 vt. 严厉批评;猛击;向...喷射 | 画面:工地 blast 爆破,气浪 blast 扑面。 |
| devastate | vt. 彻底破坏;使伤心欲绝 | vast 荒芜(vast 空旷)→ 夷为荒芜 = 彻底破坏。 |
| breathe | vi. vt. 呼吸 vt. 呼出;低声说 vi. 透气;(让酒) 通气飘香 | breath 名词呼吸 → breathe 动词呼吸、呼出。 |
| continent | n. 洲,大陆;欧洲大陆 | 画面:七大洲 continent 大陆,被海洋隔开的陆地。 |
| ferry | n. 渡船,渡轮 vt. vi. 渡运,运送,摆渡 | 画面:ferry 渡轮,把人和车渡到对岸。 |
| carve | vt. vi. 雕刻;把 (熟肉) 切成块 vt. 刻;成功获得;修 (路) | 画面:木匠 carve 雕刻花纹,切烤鸡也叫 carve。 |
| yoga | n. 瑜伽 | 谐音:yoga 就是“瑜伽”的音译。 |
| proceed | vi. 继续做,接着做;行进,前往 | 词根 ceed=走(同 exceed),pro 向前→向前走,继续做 |
| halfway | adv. 在...中间,在...中途;部分达成 adj. 在中间 (的),在中途 (的) | half(半)+way(路)→半路上,中途 |
| appoint | vt. 任命,指派;约定 (时间、地点) | ap+point(点)→点名指派;约定时间点 |
| nominate | vt. 提名;任命,指定 | 同 name,词根 nomen=名→报上名字,提名 |
| relieve | vt. 减轻,缓和;给...换班;解手 | 词根 lev=轻(同 lever 杠杆)→变轻,减轻 |
| up-to-date | adj. 新式的;掌握最新信息的 | up 到 to date(日期)→到最新日期,新式的 |
| mindset | n. 思维模式,心态 | mind(思维)+set(设定)→思维设定,心态 |
| comply | vi. 服从,遵守 | 同 complete,ply=折→折服照做,遵守 |
| dizzy | adj. 眩晕的;快得令人眩晕的;笨的 | 联想原地转圈→眩晕 |
| reside | vi. 居住,定居;存在于;属于 | re+side(坐,同 sit)→定居坐于某处 |
| commute | vi. 上下班往返,通勤 vt. 减刑 n. 每天上下班路程 | com+mut(换,同 mutual)→换乘往返,通勤 |
| aisle | n. 过道,走道 | 谐音"爱走"→过道就是让人走的路 |
| misfortune | n. 不幸,厄运;不幸的事故 | mis(坏)+fortune(运气)→坏运气,不幸 |
| altitude | n. 海拔高度;高处,高地 | 词根 alt=高(同 altimeter 高度计)→海拔 |
| subjective | adj. 主观的;主语的 | subject(主语)+ive→主语自己的看法,主观的 |
| beneath | prep. 在...之下;配不上 (某人) adv. 在下面,往下 | be+neath(下,同 below)→在...之下 |
| plate | n. 盘;一盘;金属牌;⻋牌;板块 vt. 电镀 | 盘子;地质板块像地球的"盘子" |
| endanger | vt. 危及,使处于险境 | en(使)+danger(危险)→使陷险境 |
| nursery | n. 托儿所;婴儿室;儿童室;苗圃 adj. 幼儿教育的 | nurse(照料)+ry→照看孩子的地方,托儿所;苗圃 |
| interact | vi. 互动,交流;相互作用 | inter(相互)+act(行动)→相互作用,互动 |
| recite | vt. vi. 朗诵,背诵 vt. (口头) 列举,逐一详述 | re(再)+cite(说)→再说一遍,背诵 |
| cluster | n. 群,组,串,簇,堆 vi. 群集,聚集 | 同 close(紧靠)→簇在一起,一串一簇 |
| amid | prep. 在...过程中;在...中 | a+mid(中间)→在...之中 |
| verge | n. 路边;边缘,边界 | 同 verse,词根 vers=转→转到边缘;on the verge 濒临 |
| trivial | adj. 琐碎的,微不足道的 | tri(三)+via(路)→三岔路口的琐事,微不足道 |
| sue | vt. vi. 控告,起诉 vi. (尤指在法庭上)提出请求 | 谐音"诉"→诉讼,起诉 |
| federation | n. 联盟,联合会;联邦制国家 | 同 federal(联邦的)→联盟,联邦 |
| longevity | n. ⻓寿,持久;寿命 | long(长)+ev(年代,同 era)→长寿 |
| reject | vt. 拒绝接受;不录用;抛弃;排斥 n. 次品,不合格者 | re(回)+ject(扔,同 inject)→扔回去,拒绝 |
| dock | n. 码头;港区;月台;被告席 vi. vt. (使船) 进港;(航天器) 对接 vt. 扣除 (工资等) | 联想船靠码头;扣工资也像船被扣在码头 |

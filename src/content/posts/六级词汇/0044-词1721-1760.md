## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| punch | vt. 用拳重击;打孔;按 (键) n. 重拳击打;感染力;打孔机 | punch 谐音'砰'——一拳砸下砰；打孔 punch |
| whisper | vi. vt. 耳语,小声说 vt. 私下说,秘密告诉 vi. (叶子、⻛等) 沙沙作响 n. 耳语 (声);轻柔的声音;传闻 | whisper 气音 wh 轻轻说=耳语；风沙沙作响也是 whisper |
| haze | n. 烟雾,霾;迷糊,懵懂 vt. 欺凌 (新生) | haze 谐音'灰'——天空灰蒙蒙的雾霾 |
| mercury | n. 汞,水银 | Mercury 神使跑得快，水银 mercury 流动也快 |
| whistle | n. 哨子;口哨声,汽笛声;汽笛 vt. vi. 吹口哨 vi. 吹哨子;鸣叫;嗖嗖地移动 | whistle 拟声：吹口哨'呜'的一声，哨子 |
| salmon | n. 鲑⻥,三文⻥;橙红色 | salmon 谐音'三文'，三文鱼；注意 l 不发音 |
| disintegrate | vi. 碎裂,分裂;崩溃,瓦解 | dis(反)+integrate(整合) → 整体散开=碎裂瓦解 |
| zoology | n. 动物学 | zoo(动物园)+logy(学) → 动物学 |
| clear-cut | adj. 明确的,易辨识的 | clear(清晰)+cut(切割) → 切得清清楚楚=明确 |
| couch | n. ⻓沙发;诊察台 vt. (以某种语言⻛格) 措辞 | couch 沙发：回家靠着 couch 窝着 |
| seduce | vt. 诱惑,勾引;引诱,诱使 | duce=引(introduce 引入同源) → 把人引走=诱惑 |
| niece | n. 侄女,外甥女 | niece 与 nephew(侄子)一对，niece 是侄女 |
| onion | n. 洋葱,洋葱头 | onion 洋葱：剥 onion 辣眼睛流泪 |
| germ | n. 病菌,细菌;起源,萌芽;胚胎 | germ 词根=芽：病菌繁殖如萌芽；也指起源萌芽 |
| alley | n. 小巷,胡同 | alley 小巷：窄窄的胡同 alley；保龄球球道也叫 alley |
| reciprocal | adj. 互惠的,相互的 | reciprocal 互惠：你帮我我帮你，有来有往 |
| tub | n. 盆,桶;(盛⻝物的) 小盒;浴缸 | tub 浴缸：跳进 tub 泡澡；冰激凌小盒也叫 tub |
| loophole | n. (法律上的) 漏洞,空子 | loop(环)+hole(洞) → 绕开法律的洞=漏洞 |
| denounce | vt. 谴责,指责;告发 | nounce=说(announce 宣布同源) → 当面说人坏=谴责 |
| empire | n. 帝国;企业集团 | emperor(皇帝)的国土 → empire 帝国 |
| corridor | n. 走廊,过道 | corridor 走廊：酒店长长的过道连着房间 |
| inaugurate | vt. 使正式就任;为...举行落成仪式 vt. 开创 | 古罗马就职前先占卜 augur → inaugurate 就职、开幕 |
| screw | n. 螺丝,螺丝钉;螺旋桨;狱警 vt. 用螺丝固定;旋紧,拧紧;诈骗 vi. 拧上去 | screw 音似'死抠'，螺丝刀拧紧螺丝 |
| whip | vt. 鞭打;突然地除去,抽出;搅打 vi. vt. (使朝某一方向) 猛然移动 n. 鞭子;纪律委员,党鞭 | whip 鞭子：甩 whip 啪地抽响；党鞭 whip 监督纪律 |
| lubricate | vt. 给...上润滑油,上油 | lubric 词根=滑 → 加润滑油让机件滑溜 |
| bulletin | n. 简明新闻,简讯;公告;简报 | bulletin 公告：新闻简讯 bulletin 滚动播报 |
| spade | n. 铲,锹;黑桃牌;黑桃 | spade 铲子；黑桃 ♠ 形状像铲子也叫 spade |
| trophy | n. 奖品,奖杯;纪念品,战利品 adj. 炫耀的,摆阔的,招摇的 | trophy 奖杯：冠军举起 trophy；战利品也是 trophy |
| peg | n. 短钉,挂钉,短桩;晾衣夹子 vt. 用夹子夹住,用销钉固定;看做 | peg 木钉：衣服挂 peg 上晾；晾衣夹 peg 夹住 |
| pray | vi. vt. 祈望,祈求;祈祷,祷告 adv. (用于提问或要求) 请问,请 | pray 祈祷：双手合十 pray 祈求平安 |
| wit | n. 机智⻛趣 (的人);头脑;明智 | wit 与 wise(聪明)同源 → 机智风趣 |
| abreast | adv. 并列地,并排地 | a+breast(胸) → 胸对胸并排走，并列 |
| glide | vi. 滑行,滑动;滑翔 n. 滑行,掠过,滑翔 | glide 滑翔：滑翔机 glide 无声掠过天空 |
| salvation | n. 救赎;救助途径 | salv=救(salvage 抢救同源) → 救赎 salvation |
| offset | vt. 抵消,弥补 | off(抵消)+set(放置) → 一增一减相互抵消 |
| tremble | vi. 颤抖,战栗;轻晃,震颤;恐惧 n. 颤抖,战栗 | trem=颤(tremor 震颤同源) → 吓得发抖 |
| cyberspace | n. 网络空间 | cyber(网络)+space(空间) → 网络空间 |
| divine | adj. 天赐的,神的;绝妙的,极棒的 vt. 猜测,揣度 vt. vi. (用探测棒) 探测 | div=神(deity 同源) → 神的 divine；天赐美味 divine |
| beast | n. 野兽;残暴的人;某种东西 | beauty and the beast《美女与野兽》→ 野兽 |
| shaft | n. 电梯井,竖井;杆,柄;一束 vt. 亏待,欺骗 | shaft 竖井：电梯井直上直下；一束光 shaft |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| drill | n. 钻机;练习;演习;军事训练 vt. vi. 钻 (孔);培训;进行军事训练 | drill 钻孔；军训 drill 操练 → 钻机、训练 |
| soccer | n. 足球运动 | soccer 足球（美式说法）→ 足球运动 |
| epidemic | n. 流行病;泛滥,猖獗 adj. 泛滥的,猖獗的 | dem 民众（democracy）→ 流行于民众 → 流行病 |
| gross | adj. 总的;严重的;令人恶心的 adv. 总共,全部 vt. (税前) 总收入为 n. (影片的) 总收入 | gross 总收入 = 总额 → 总的；恶心的 |
| tissue | n. 纸巾;(动植物的) 组织;薄纸 | tissue 纸巾擦鼻 → 纸巾；组织 |
| deposit | n. 存款;订金;押金;沉积物 vt. 存入银行;放下,放置;使沉积 | deposit 把钱放下 → 存款、押金 |
| tow | vt. 牵引,拖,拉 (⻋或船) n. (⻋或船的) 牵引,拖,拉 | 拖车 tow 拖走 → 牵引、拖 |
| autonomous | adj. 自治的;有自主能力的,自主的 | auto 自己 + nom 法则 → 自治的、自主的 |
| evacuate | vt. vi. (使) 撤离,疏散,转移 vt. 排泄 (粪便) | vac 空（vacuum 真空）→ 把人撤空 → 疏散 |
| vaccine | n. 疫苗 | vaccine 牛痘疫苗 → 疫苗 |
| shatter | vt. vi. (使) 破碎;使 (希望等) 破灭 vt. 使...极为惊愕难过 | 玻璃 shatter 碎一地 → 破碎、破灭 |
| suitcase | n. 行李箱,手提箱 | suit 套装 + case 箱 → 行李箱 |
| brake | n. 刹⻋,⻋闸;阻碍,阻碍物 vi. vt. 刹⻋ | brake 刹车 → 车闸 |
| discrepancy | n. 差异,不符合 | 账目 discrepancy 不符 → 差异 |
| coupon | n. 优惠券,赠券 | 谐音'酷胖' → 优惠券 |
| suburb | n. 城郊,郊区 | urb 城（urban）+ sub 下 → 城郊 |
| tender | adj. 温柔的;嫩的;一碰就疼的 vt. 提议,提出 n. 投标;煤水⻋;补给船 | 牛排 tender 嫩 → 嫩的、温柔的 |
| perpetual | adj. 不间断的,⻓久的;没完没了的 | per 一直 → 没完没了 → 永久的 |
| cart | n. 运货⻢⻋;手推⻋;专用小汽⻋ vt. 用⻢⻋运送;用手提;强行带走 | 购物车 cart → 手推车 |
| conservative | adj. 保守的;保守党的 n. 保守党党员;保守的人 | conserve 保存 → 守旧 → 保守的 |
| dash | vi. ⻜奔,猛冲 vt. vi. 猛摔,猛撞 n. ⻜奔,猛冲;少量;破折号 | 破折号 dash 像冲刺 → 猛冲 |
| stifle | vt. 抑止,阻止,压制 vt. vi. (使) 窒息,(使) 透不过气来 | stifle 压抑、窒息 → 压制 |
| straightforward | adj. 简单易懂的;坦率的,率直的 | straight 直 + forward 前 → 直来直去 → 坦率 |
| fleet | n. 舰队;捕⻥船队;⻋队 adj. 快速的,敏捷的 | fleet 舰队如飞 → 舰队、快速的 |
| kit | n. 成套工具;配套元件;全套装备 | 急救 kit 成套工具 → 成套工具、装备 |
| hop | vi. 跳跃;快速前往;换来换去 vt. 登上 (⻜机、汽⻋、火⻋等) n. 跳跃;短途旅行;啤酒花;舞会 | 兔子 hop 单脚跳 → 跳跃 |
| violate | vt. 违反,违背;侵犯,搅扰;亵渎 | violent 暴力 → violate 侵犯、违反 |
| well-off | adj. 富裕的,家境好的;有很多...的 | 日子过得好 → 富裕的 |
| stump | n. 树桩;残段,残肢 vt. 把...难住,把...难倒 vi. 迈着沉重的步子走 | 树桩 stump 绊人 → 难住；树桩 |
| credential | n. 资格,资历;资格证书 vt. 给...提供证书 | cred 信（credit 信用）→ 资格证书 |
| signify | vt. 表示,意味着;表达,表明 vi. 具有重要性,要紧 | sign 标记 → signify 表示、意味着 |
| contradict | vt. 反驳,否认;相矛盾 | contra 反 + dict 说 → 反着说 → 反驳 |
| clause | n. 从句;(法律文书的) 条款 | clause 从句、条款 → 从句 |
| heel | n. 脚后跟;鞋跟;女高跟鞋 vi. 倾斜,倾侧 | 高跟鞋 heel 跟 → 脚后跟、鞋跟 |
| conducive | adj. 有助于的,有益于的 | duc 引导（conduct）→ 引导向好 → 有助于的 |
| midst | n. 当中,中间 | mid 中 → 当中、中间 |
| imminent | adj. 即将发生的,逼近的 | minent 突出 → 悬在头顶 → 即将发生 |
| lord | n. (英国) 贵族;勋爵;阁下;上帝 | Lord 上帝 → 贵族、勋爵 |
| cellphone | n. 手机,移动电话 | cell 蜂窝 + phone 电话 → 手机 |
| maneuver | n. 策略;巧妙的移动;军事演习 vi. vt. (谨慎或熟练地) 移动;操纵 | 来自法语'用手操作' → 操纵、策略 |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| gorge | n. 峡,峡谷 vt. vi. 狼吞虎咽 vi. 灌满,塞满,浸满 | 峡谷 gorge 被流水灌满；狼吞虎咽=把胃也灌满 |
| detergent | n. 洗涤剂,去垢剂 | 词根 terg=擦，de 去掉 → 擦掉污垢的洗涤剂 |
| symposium | n. 专题讨论会,研讨会 | sym 一起+posis 喝 → 古希腊人边喝酒边讨论的研讨会 |
| poke | vt. vi. 捅,戳,杵;伸出,探出 n. 捅,戳,拨,挑 vt. 把...戳进,把...插入 | poke 音似'破壳'，一戳就破 |
| lenient | adj. 仁慈的,宽大的 | lenient 谐音'怜悯的'，心生怜悯自然宽大 |
| courtyard | n. 庭院,院子 | court(院子)+yard(院子) = 庭院 |
| chop | vt. 切碎,砍,劈;(大幅度地) 削减 n. 猪 (或羊等) 排;砍,劈;掌劈 | chop 音似'戳'，一刀砍下去；剁出来的猪排也叫 chop |
| irrespective | adj. 不顾的,不考虑的 | ir(不)+respect(考虑) → 不管不顾，不考虑的 |
| barge | n. 驳船 vi. vt. 乱撞,乱闯 | b 像鼓鼓的船肚，驳船 barge 肚子大能装货 |
| chopstick | n. 筷子 | chopstick = chop + stick(棍子)，两根小棍就是筷子 |
| verdict | n. 裁决,裁定;意⻅,决定 | ver(真实)+dict(说，dictionary 同源) → 说出真相的裁决 |
| repute | n. 名声,名誉 | repute 与 reputation 同源，被反复掂量的名声 |
| cardinal | adj. 基本的,最重要的 n. 红衣主教;基数 | cardo 词根=门轴，如门轴般关键=最重要的；红衣主教也穿红衣 |
| wedge | n. 楔子,楔形物 vt. 将...挤入;把...楔牢 | wedge 谐音'歪挤'，歪斜着挤进缝里的楔子 |
| spine | n. 脊椎;刺,棘;书脊;⻣气 | pin 像钉子串起一节节脊椎；书脊也叫 spine |
| idiom | n. 习语,成语 | 词根 idio=个人的，idiom 是某语言独有说法=习语 |
| uprising | n. 起义,暴动,造反 | up+rising，人民站起来 → 起义 |
| knot | n. 结;发髻;节疤;痉挛 vt. 把...打成结(或扎牢) vi. 缠结 vi. vt. (因害怕等而) 痉挛,使痉挛 | knot 的 k 不发音，绳子打成的结就是 knot |
| fist | n. 拳头 | fist 与 five(五)同源，五指握紧成拳头 |
| shrub | n. 灌木 | shrub 音似'树'——矮矮的灌木丛 |
| exposition | n. 清楚而详尽的解释;博览会 | ex(向外)+pose(摆放) → 摆出来给人看的博览会、详尽解释 |
| southwest | n. 西南方;西南部 adv. 向西南 adj. 西南部的;(⻛) 从西南来的 | south(南)+west(西) = 西南 |
| hitherto | adv. 迄今,到 (某时) 为止 | hither(到此，与 here 同源)+to → 直到现在，迄今 |
| mushroom | n. 蘑菇 vi. 迅速成⻓,大量涌现 | 雨后蘑菇 mushroom 一夜疯长，比喻大量涌现 |
| err | vi. 犯错,出差错 | err 与 error(错误)同源，err 是犯错 |
| packet | n. 小包,小盒;小件包裹 | pack(打包)+et(小后缀) → 小包 |
| arithmetic | n. 算术;算术运算 adj. 算术的 | 希腊词根 arithmos=数，arithmetic 就是算数的算术 |
| depreciate | vi. 贬值,跌价 vt. 贬低,轻视 | de(向下)+preci(价格，precious 珍贵同源) → 价格下降=贬值 |
| bronze | n. ⻘铜;⻘铜色;⻘铜制品;铜牌 adj. ⻘铜色的 | 奥运铜牌 bronze 是青铜做的；青铜器也是 bronze |
| decree | n. 法令,政令;判决,裁定 vt. vi. 判决,颁布 | decree 谐音'地规'，国家定的法规=法令 |
| scold | vt. vi. 训斥,责骂 | scold 谐音'死怪'——死命责怪，训斥 |
| cosmopolitan | adj. 世界性的;⻅多识广的 n. 四海为家的人 | cosmos(世界)+politan(城市，metropolis 同源) → 世界性的 |
| shred | vt. 切碎,撕碎 n. 碎片,细条;一丁点儿 | shred 音似'撕'——撕成碎片；碎纸机 shredder |
| ridge | n. 山脊;隆起 vt. 使隆起 | ridge 谐音'里脊'——背脊上的山脊 |
| shepherd | n. 牧羊人 vt. 带领,护送 | sheep(羊)+herd(牧群) → 牧羊人 |
| nephew | n. 侄子,外甥 | nephew 与 niece(侄女)同源成对，nephew 是侄子 |
| hospitable | adj. 好客的;环境适宜的 | hospitable 与 host(主人)同源，主人好客 |
| sinister | adj. 不祥的,有凶兆的,邪恶的 | sinister 拉丁语本义'左边'，古人占卜视左为凶 → 不祥的 |
| dilute | vt. 稀释,冲淡;削弱,降低 adj. 稀释了的,冲淡了的 | dilute 音似'滴流'——往浓汁里滴水流，稀释 |
| complexion | n. 面色,面容;性质,特性 | complexion 与 complex 同源，人的面色肤质复杂多变 |

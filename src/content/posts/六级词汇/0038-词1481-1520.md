## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| cushion | n. 坐垫,靠垫;起缓冲作用的事物 vt. 起缓冲作用;减轻...的影响 | 沙发上的 cushion 坐垫，软软缓冲 = 垫子 |
| scorn | n. 轻蔑,鄙视 vt. 轻蔑,鄙视 | 斜眼仰头 scorn 瞧不起 = 轻蔑、鄙视 |
| reunite | vt. vi. (使) 团聚;(使) 统一 | re 再 + unite 联合，再聚到一起 = 团聚 |
| tread | vi. vt. 踩,踏;行走 n. 脚步声;(轮胎的) 胎面;梯面 | tread on 踩到，脚下踩踏 = 踩；胎面 |
| appall | vt. 使大为震惊,使惊骇 | pale 苍白同源，吓得脸都白了 = 使惊骇 |
| appease | vt. 平息,安抚;绥靖 | peace 和平同源，让怒火平息 = 安抚、绥靖 |
| crane | n. 起重机,吊⻋;鹤 vi. vt. 伸⻓ (脖子) 看,探头看 | 长脖鹤 crane 伸长脖子，起重机像鹤 = 吊车、鹤 |
| confess | vi. vt. 供认,坦白;承认;忏悔 | con 全 + fess 说，把事全说出来 = 坦白、忏悔 |
| porcelain | n. 瓷,瓷器 | 源自意大利语"贝壳"，釉面如贝壳 = 瓷器 |
| intermediate | adj. 中级的;居中的,中间的 n. 中级水平者 | inter 之间 + medi 中，介于中间的 = 中级的 |
| pat | vt. 轻拍 n. 轻拍;(⻩油等的) 小块 adj. (回答等) 过于简单的 | 拟声 pat，轻轻拍两下 = 轻拍 |
| excerpt | n. 摘录,节选片段 vt. 摘录,节选 | ex 出 + cerpt 摘，从文中摘出 = 摘录、节选 |
| bibliography | n. 参考书目,文献目录 | biblio 书(Bible 同源)+graphy 写，论文"书单" = 参考书目 |
| tropic | n. 回归线;热带,热带地区 | 词源"太阳转向"之处，回归线；热带 |
| broker | n. 经纪人;股票 (或证券) 经纪人 vt. 协调,安排 | 股票经纪人 broker，撮合买卖抽佣金 = 经纪人 |
| query | n. 疑问,询问,查询 vt. 质疑,对...表示疑问;询问 | question 同源，提出疑问 = 询问、质疑 |
| courtesy | n. 谦恭有礼的举止,礼貌 adj. 可免费使用的 | court 宫廷礼仪变 courtesy = 礼貌、谦恭 |
| brood | vi. 沉思,忧伤 vi. vt. 孵 (蛋),抱窝 n. 一窝雏⻦;一家孩子 | breed 繁殖同源，母鸡抱窝孵蛋 = 孵；沉思 |
| canal | n. 运河,沟渠;⻝道,气管 | channel 水道同源，人工挖的河道 = 运河 |
| zip | n. 拉链,拉锁;速度,能量;零 vt. 拉上拉链 vi. vt. (使沿某方向) 快速移动 | 拟声 zip，拉链一声拉上 = 拉链；嗖地移动 |
| brigade | n. 旅;帮,伙 (侮辱性);队伍 | fire brigade 消防队，brigade = 队伍、旅 |
| incumbent | n. 在职者,现任者 adj. 在职的;有责任履行的 | in 在 + cumb 躺，正占着位子的人 = 现任者 |
| chill | n. 寒冷,寒意;着凉;害怕的感觉 vt. 使寒冷,使冰冷;使恐惧,恐吓 vi. vt. 冷却;冷静;放松 adj. 寒冷的,阴冷的 | 冷风 chill 起鸡皮疙瘩 = 寒冷；放松 chill |
| badminton | n. 羽毛球运动 | 源自英国 Badminton 庄园的球类 = 羽毛球 |
| blanket | n. 毯子,毛毯;厚层,覆盖层 vt. 覆盖,笼罩 adj. 总括的,全面的 | 床上的 blanket 毛毯，盖住全身 = 毯子、覆盖 |
| dye | vt. 给...染色 n. 染料 | 谐音 die(死)，染发剂 dye 给头发染色 |
| plumbing | n. (建筑物的) 管道系统;管道维修 | plumber 水管工同源，家里的管道系统 = plumbing |
| bloc | n. 集团,阵营 | block 块去 k，抱成一"块" = 集团、阵营 |
| condolence | n. 吊唁,慰唁,唁词,吊唁信 | con 共同 + dole 悲痛，与丧家同悲 = 吊唁 |
| hound | n. 猎犬 vt. 紧追,追踪,纠缠 | 猎犬 hound 死咬不放 = 猎犬；紧追纠缠 |
| agitate | vi. vt. 鼓动,煽动 vt. 激怒,使不安;搅动 ,摇动 | ag 动(act 同源)，把水搅浑 = 搅动、鼓动 |
| chef | n. 厨师,主厨 | chief 首领同源，厨房的"头儿" = 主厨 |
| botany | n. 植物学 | botanical garden 植物园同源，研究植物 = 植物学 |
| streak | n. 条纹;性格特征;一段时期 vt. 在...上留下条痕 vi. 疾驰,⻜跑 | 流星 streak 划过留光带 = 条纹；嗖地疾驰 |
| cannon | n. 大炮;自动机关炮 | 谐音"加农炮"，cannon = 大炮 |
| rattle | vt. vi. (使) 咯吱作响 vt. 使慌乱,使紧张 n. 嘎嘎声,咯吱声;拨浪鼓 | 拟声 rattle，摇拨浪鼓咔咔响 = 咯吱作响 |
| liquor | n. 酒精类饮料,尤指烈性酒 | liquid 液体同源，烈性酒液 = liquor |
| ripe | adj. (水果等) 成熟的;时机成熟的 | 苹果红透 ripe 可摘 = 成熟的 |
| overhaul | n. 检修,改造 vt. 彻底检修;赶上 (赛跑对手) | over 全部 + haul 拉，整车拆开修 = 彻底检修 |
| ribbon | n. 丝带;带状物;绶带,勋带 | 礼盒上的 ribbon 丝带，蝴蝶结 = 丝带、绶带 |

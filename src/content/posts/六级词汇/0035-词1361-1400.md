## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| ventilate | vt. 使...通⻛;公开表达,公开讨论 | vent 风(与 wind 同源)+ate，让风吹进来 = 通风 |
| tip | n. 建议,窍⻔;小费;尖端;密报 vi. vt. (使) 倾斜,侧倾;给小费 vt. 倾倒,倒出;轻触;预言...获胜 | 指尖 top 谐音 tip 尖端；服务好给 tip 小费、建议 |
| doom | n. 厄运,死亡,毁灭 vt. 使...注定遭受 (不幸等) | 游戏 Doom 末日，命中注定的毁灭 = 厄运 |
| passive | adj. 被动的,消极的;被动语态的 n. 被动语态,被动式 | pass 通过 + ive，事情"路过"不由你作主 = 被动的 |
| tutor | n. 家庭教师;助教,导师 vt. 教授,辅导 | tuition 学费同源，收学费教你的 = 家庭教师、导师 |
| headquarters | n. 总部,总公司,指挥部 | head 头 + quarters 驻地，头头们办公处 = 总部 |
| viewpoint | n. 观点,看法;视⻆,⻆度 | view 看 + point 点，看事情的角度 = 观点 |
| freeway | n. 高速公路 | free 自由 + way 路，可自由飞驰的路 = 高速公路 |
| betray | vt. 背叛,出卖;流露 (情感) | tray 交出(traitor 叛徒同源)，把机密交敌 = 背叛 |
| livestock | n. 牲畜,牲口 | live 活 + stock 存货，家里"活存货" = 牲畜 |
| destiny | n. 命运;神意,命运之神 | destination 目的地同源，命定要去之处 = 命运 |
| undergo | vt. 经历,经受,遭受 | under 下 + go 走，从下面走过 = 经历、遭受 |
| jungle | n. 热带丛林;弱肉强⻝的环境 | 谐音"荆棘"遍地，密不透风的热带丛林 |
| fraud | n. 诈骗 (罪);骗子,骗局 | 骗子造假合同骗钱，fraud = 诈骗 |
| rocket | n. 火箭;火箭弹;焰火;芝麻菜 vi. 快速增⻓,猛增;迅速移动 | 火箭冲天 rapid，股价 rocket 猛增 |
| ash | n. 灰,灰烬;废墟;⻣灰 | 火烧完剩下的灰 = ash，烟灰缸里的灰 |
| theft | n. 盗窃 (罪) | thief 小偷变 theft，小偷干的勾当 = 盗窃 |
| permeate | vt. vi. 渗透,弥漫;(感情等) 充斥 | per 穿过 + me 走，气味穿墙弥漫 = 渗透、弥漫 |
| invariably | adv. 总是, 不变地,始终如一地 | in 不 + vary 变化，永不变化 = 总是、始终如一 |
| suit | n. 西服,套装;诉讼,起诉 vt. 适合;相配,合身 | 西装合身才 suit 适合；lawsuit 打官司含 suit |
| circus | n. ⻢戏团;⻢戏表演;环形广场 | circle 圆环同源，圆场地里表演 = 马戏团 |
| democracy | n. ⺠主,⺠主制;⺠主国家 | demo 人民 + cracy 统治，人民当家做主 = 民主 |
| nonsense | n. 胡说;愚蠢的举动;无意义的话 | non 无 + sense 意义，毫无意义的话 = 胡说 |
| utilize | vt. 利用,使用 | use 用 + ize 动词化，把资源"用起来" = 利用 |
| metropolitan | adj. 大城市的,大都会的 | metro 母亲 + polis 城，城中之母 = 大都会的 |
| feeble | adj. 虚弱无力的;无效的,牵强的 | 谐音"废"，没力气 = 虚弱无力的 |
| enlighten | vt. 启发,开导,教化 | en 使 + light 光，心里亮堂了 = 启发、开导 |
| gratitude | n. 感激之情,感谢 | grateful 感激同源 grat，受人恩惠心存感激 = 感谢 |
| intelligible | adj. 可理解的,明白易懂的 | intelligent 聪明同源，聪明人能懂的 = 明白易懂的 |
| inertia | n. 惯性;缺乏活力,惰性 | 惯性定律 inertia，物体懒得动 = 惯性、惰性 |
| cream | n. 奶油;乳膏,乳霜;淡⻩色;精髓 adj. 淡⻩色的 vt. 把...搅成糊状;彻底打败 | ice cream 里的 cream 奶油；护肤 cream 乳霜 |
| gut | n. 直觉,本能;勇气;肠道;内脏 adj. 本能的,非理性的 vt. 取出...的内脏;损毁房屋内部 | gut 肠道，gut feeling 肚子里的感觉 = 直觉 |
| Catholic | adj. (罗⻢) 天主教的 n. 天主教教徒 | catholic 词源"普遍的"，普世教会 = 天主教 |
| spacecraft | n. 宇宙⻜船,航天器 | space 太空 + craft 飞行器(aircraft 同款) = 宇宙飞船 |
| tilt | vi. vt. (使) 倾斜;使倾向于,偏向 n. 倾斜,倾侧 | 比萨斜塔 tilt 斜着，倾斜、倾侧 |
| preoccupy | vt. 占据 (某人) 思想,迷住 | pre 先 + occupy 占据，心事抢先占满脑子 = 迷住 |
| differentiate | vi. vt. 区分,辨别 vt. 构成...间的差别 | different 不同 + iate，看出差别 = 区分、辨别 |
| helicopter | n. 直升机 | heliko 螺旋 + pter 翅膀，螺旋翼飞行器 = 直升机 |
| amidst | prep. 在...中间,在...当中 | amid 在...中的加强形式 = 在...当中 |
| partly | adv. 部分地,在某种程度上 | part 部分 + ly，只完成一部分 = 部分地 |

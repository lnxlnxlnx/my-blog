| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| cast | vt. 扔,抛;向...投以;投射;选⻆ vt. 投 (票);浇铸 vi. vt. 投 (钓线),抛 (钓钩) n. 全体演员;铸造品;石膏绷带 | 画面:cast 抛渔网、投眼光;全体演员阵容。 |
| greet | vt. 同...打招呼;回应;呈现在...前 | 画面:见面 greet 握手问好,热情回应。 |
| radar | n. 雷达 | 谐音:radar 就是“雷达”的音译,靠电波探测。 |
| assemble | vi. vt. (使) 集合,(使) 聚集 vt. 组装,装配 | 联想:as + sembl 同(same)→ 聚到一起 = 集合、组装。 |
| vent | n. 通⻛孔,排放口;开衩 vt. 发泄,宣泄 | 画面:给情绪开个 vent 排气孔 → 发泄;通风口。 |
| halt | vi. vt. (使) 停止 n. 停止,暂停 | 画面:士兵喊 halt 立定,队伍停止前进。 |
| knight | n. 骑士;爵士;(国际象棋) ⻢ vt. 封...为爵士 | 谐音联想:knight ≈ “night 骑士” → 夜行的骑士、爵士。 |
| estate | n. 庄园,地产;财产,遗产 n. 住宅区,工业区 | 语境:real estate 房地产;庄园 estate 是地产。 |
| pitch | n. 球场;音高;沥⻘;宣传论点 vt. 用力扔;搭 (帐篷);定音高 vi. vt. 投球;推销 vi. 颠簸,上下飘荡 | 画面:棒球投手 pitch 投球;球场、推销也叫 pitch。 |
| wrestle | vi. vt. 摔跤,扭打;试图解决,努力对付 | 画面:两人 wrestle 摔跤;与难题 wrestle 搏斗。 |
| unleash | vt. 释放,发泄 (感情等);放 (动物) | leash 牵绳,un 解开 → 解开牵绳 = 释放、发泄。 |
| contend | vt. 声称,主张 vi. 竞争,争夺;处理,对付 | tend 伸(extend)→ 伸手去争 = 竞争;主张。 |
| gram | n. 克 (重量单位) | 联想:1 千克 = 1000 gram 克,重量单位。 |
| physician | n. (内科) 医生 | phys 身体(physical)→ 治身体的人 = (内科)医生。 |
| spokesman | n. 发言人 | speak 说 + man → 代表发言的人 = 发言人。 |
| hierarchy | n. 等级制度;掌权集团;等级体系 | 词根 arch 统治(monarchy)→ 层层统治 = 等级制度。 |
| nuisance | n. 讨厌的人,麻烦的事;非法妨害 | 谐音联想:nuisance ≈ “恼(人)” → 讨厌的人、麻烦事。 |
| overtime | n. 加班;加班费;加时赛 | over 超出 + time 时间 → 超出工时 = 加班。 |
| ample | adj. 大量的,足够的;丰满的 | 谐音联想:ample ≈ “满(满的)” → 充足、大量。 |
| regulate | vt. vi. (以规章) 管理,约束 vt. 调整,调节 | regular 规则 → 按规则管理、调节。 |
| diffuse | vt. vi. 扩散,渗透;传播,散布 vt. 舒缓,减弱,平息 adj. 扩散的,分散的;冗⻓的 | fuse 流 → 向四面八方流 = 扩散、传播。 |
| academy | n. 学院;私立学校;学会,研究院 | 词源:柏拉图讲学的园林 → 学院、研究院。 |
| tin | n. 锡;罐头;金属⻝品盒;烤盘 | 画面:锡纸 tin foil;罐头 tin 是锡铁皮做的。 |
| exempt | adj. 被免除 (义务、付款) 的 vt. 豁免,免除 (义务、付款) | ex 出 + empt 拿 → 从义务中拿出来 = 免除、豁免。 |
| dazzle | vt. vi. (强光) 使目眩,使眼花 vt. 使倾倒,使惊叹 n. 令人赞叹的东西 (或品质) | 画面:强光 dazzle 晃得眼花;让人倾倒。 |
| wheat | n. 小⻨ | 画面:金灿灿的麦田 wheat,磨面粉的小麦。 |
| favor | n. 帮助,恩惠;赞同,支持;偏爱 vt. 更喜欢;偏爱;有利于 | 语境:do me a favor 帮个忙;偏爱叫 in favor of。 |
| dental | adj. 牙⻮的,牙科的 | 同源 dent 齿(dentist 牙医)→ 牙齿的、牙科的。 |
| fault | n. 过错,责任;缺点,弱点;故障 vt. 发现错误,找出缺点 | 谐音联想:fault ≈ “罚” → 有过错受罚 = 错误、缺点。 |
| greed | n. 贪婪,贪心,贪欲 | 谐音联想:greed ≈ “够(了还想要)” → 贪婪、贪心。 |
| decay | vi. vt. (使) 腐烂,朽烂 vi. (建筑等) 变破败;衰败,衰落 n. 腐烂,朽烂;衰败,衰落 | 谐音联想:decay ≈ “地(下)” → 烂在地里 = 腐烂、衰败。 |
| bestseller | n. 畅销书,畅销商品 | best 最 + seller 卖 → 卖得最好的书 = 畅销书。 |
| brochure | n. 小册子,宣传册,手册 | 画面:旅行社 brochure 宣传册,介绍景点的小册子。 |
| reign | n. 君主统治时期;任期,当政期 vi. 统治,当政;成为最佳;盛行 | 同音联想:reign 与 rein 缰绳同音 → 手握缰绳 = 统治。 |
| crave | vt. vi. 渴望,热望 vt. 恳求,请求 | 谐音联想:crave ≈ “渴” → 渴望、热望。 |
| hire | vt. 租用,租借;临时雇用 vt. vi. 聘用,录用 n. 租用,租借;新员工 | 画面:公司 hire 新人入职;租车也叫 hire。 |
| excess | n. 过多,过量;超过的部分 adj. 过多的,过量的 | cess 走(process 过程)→ 走过了头 = 过量、过多。 |
| compensate | vi. 弥补,补偿 vt. 给...赔偿 | pens 付(pension 养老金)→ 补偿付给 = 赔偿。 |
| setback | n. 挫折,阻碍 | set 放 + back 回 → 计划被挡回 = 挫折、阻碍。 |
| ditch | n. 沟,渠 vt. 丢弃,抛弃;逃学 vt. vi. (在海上) 迫降 | 画面:路边排水 ditch 沟渠;把旧计划 ditch 抛弃。 |

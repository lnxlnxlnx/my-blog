| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| tribute | n. 致敬;是...的充分体现;贡品 | 同根 contribute(贡献)→ tribute 致敬、贡品 |
| bath | n. 洗澡;浴缸;浴室 vt. 给...洗澡 | bathtub 浴缸 → bath 洗澡、浴缸 |
| uniform | n. 制服 adj. 始终如一的,一律的 | uni 一 + form 形式 → 统一款式 = 制服 |
| caution | n. 小心,谨慎;警告,告诫 vi. vt. 警告,告诫,提醒 | 警示牌"小心"caution → 小心、警告 |
| soak | vt. vi. 浸泡,湿透 vt. 使湿透,把...浸湿;宰客 n. 浸泡,湿透;泡澡 | 泡澡 soak 在水里 → 浸泡、湿透 |
| certify | vt. 证明,证实;授予专业合格证书 | 同根 certain(确定)→ certify 证明、认证 |
| trench | n. 沟渠;战壕;海沟 | 一战 trench warfare 战壕战 → 战壕 |
| spur | n. ⻢刺;鞭策,激励;山嘴 vt. 鞭策,激励;促进,加速 | 马刺 spur 踢马提速 → 激励、促进 |
| prison | n. 监狱;关押制度;难以脱身之处 | prisoner(囚犯)同根 → prison 监狱 |
| privilege | n. 特权;荣幸;权势 vt. 给予...特权,给予...优待 | 同根 private(私人)→ privilege 特权 |
| liberate | vt. 使自由,使解脱;解放 | 同根 liberty(自由)→ liberate 解放 |
| elastic | n. 弹性材料,松紧带 adj. 有弹性的;灵活的,能变通的 | 谐音"易拉伸"——橡皮筋易拉 → 弹性 |
| choke | vi. vt. (使) 窒息,噎住;使哽咽 vt. 掐死,勒死;阻塞,塞满 vi. (因紧张) 发挥失常 n. 窒息,哽噎声 | 被鱼刺卡喉咙 choke → 窒息、噎住 |
| conquer | vt. 占领,征服;克服 | 谐音"攻克"→ 征服、攻克 |
| electricity | n. 电,电力;紧张激动的情绪 | electric(电的)同根 → electricity 电 |
| epic | n. 史诗;史诗般的电影或书;壮举 adj. 史诗般的;漫⻓艰难的;壮丽的 | epic movie 史诗巨片 → 史诗、壮举 |
| benign | adj. 和善的;良性的;无害的;宜人的 | 与 malign(恶性)相对 → benign 良性 |
| bleed | vi. 流血,出血;(颜色) 渗开 vt. 给 (某人) 放血 | blood(血)同源 → bleed 流血 |
| orbit | n. (天体等的) 运行轨道;影响范围 vt. vi. 环绕...的轨道运行 | 卫星绕地球 orbit 轨道运行 → 轨道 |
| plight | n. 困境,难关 | 联想 light(光)→ 无光 = 困境 |
| dwell | vi. 居住 | 谐音"待窝"——待在窝里 = 居住 |
| sink | vi. 下沉;(人) 倒下;降低 vt. 使下沉;挖,掘;埋入;使受挫 n. 洗碗槽;洗脸池 adj. 贫⺠窟的 | 泰坦尼克号 sink 沉没 → 下沉、水槽 |
| cathedral | n. 大教堂,主教座堂 | 巴黎圣母院 cathedral 大教堂 → 大教堂 |
| chancellor | n. 总理;财政大臣;校⻓;大法官 | 德国总理称 chancellor → 总理、校长 |
| forecast | n. 预测,预报 vt. 预测,预报 | fore 前 + cast 投 → 提前播报 = 预报 |
| downward | adj. 下降的,向下的 adv. 向下 | down 下 + ward 向 → 向下、下降 |
| bureau | n. 局,司,处,署;办事处;衣橱 | FBI 的 B = Bureau 局 → 局、处 |
| impair | vt. 削弱,损伤 | 联想 repair(修理)反义 → 损害、削弱 |
| suffer | vi. vt. 遭受,蒙受,受苦 vi. 变差,变糟 | 词根 fer=带来 → 承受苦难 = 遭受 |
| vocation | n. 工作,职业;使命感,神召 | 词根 voc=喊(voice)→ 被召唤去做 = 职业 |
| divorce | n. 离婚;脱离,分离 vt. vi. 与 (某人) 离婚 vt. 使分离,使脱离 | 联想"分割(divide)家产"→ 离婚、分离 |
| flesh | n. 肉;(人体的) 皮肤;果肉;肉体 vt. 使具体,使充实 | flesh and blood 血肉之躯 → 肉 |
| beard | n. 胡须,络腮胡子,(动物的) 须 | bear(熊)多一个 d → 熊毛般胡子 |
| amplify | vt. 放大 (声音等) vi. vt. 详述,进一步阐述 | 同根 ample(充足)→ amplify 放大、详述 |
| riot | n. 暴乱,骚乱;丰富多彩 vi. (人群) 发生骚乱,闹事 | 联想"闹"——人群闹事 = 暴乱 |
| mold | n. 模具,铸模;(独特) 类型;霉菌 vt. (用模具) 浇铸;将...塑造成 vi. vt. (使) 紧贴于,(使) 与...吻合 | 面包发霉 mold;模具 mold 定型 |
| spear | n. 矛,标枪;嫩枝,幼芽 vt. 用尖物刺穿 | 古代士兵手持 spear 长矛 → 矛、刺穿 |
| embody | vt. 使具体化,体现;收录,包括 | em 使 + body 身体 → 使有形体 = 体现 |
| peach | n. 桃子;非常迷人的人 (或事物) adj. 桃红色的 | 水蜜桃 peach 粉嫩多汁 → 桃子 |
| fossil | n. 化石;老古董,老顽固 | 恐龙化石 fossil → 化石 |

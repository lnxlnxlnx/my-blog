## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| contemplate | vt. 打算,考虑,沉思;端详,凝视 | 联想:在 temple 神庙里凝望沉思 = 沉思、打算。 |
| detach | vt. vi. (使) 分开,脱离,拆卸 vt. 摆脱,离开;派遣 | attach 系上,de 去掉 → 解开、拆下 = 分离、派遣。 |
| whereby | adv. conj. 凭此,借以 | where + by → “凭它”,借此方法 = 凭此。 |
| garment | n. 衣服,服装 | 语境:garment 服装,一件件挂在衣橱里。 |
| mayor | n. 市⻓,镇⻓ | 同源 major 主要 → 一市之主 = 市长。 |
| convey | vt. 表达,传递,传达;运输,运送 | vey 路(vehicle 车辆)→ 载着上路 = 运送;意思送达 = 传达。 |
| warehouse | n. 仓库,货栈 | ware 货物 + house 房子 → 存放货物的房子 = 仓库。 |
| inquiry | n. 询问,打听;调查,探究 | 同源 question → 发问 = 询问;深入追问 = 调查。 |
| silicon | n. 硅 | 画面:Silicon Valley 硅谷,硅是芯片材料。 |
| underestimate | vt. 低估,轻视 n. 低估,轻视 | estimate 估计,under 往低了 → 低估、轻视。 |
| magnify | vt. 放大;使(问题等)加重;夸大 | magn 大(magnificent 壮丽)→ 使变大 = 放大、夸大。 |
| creature | n. 生物;(具有某种特征的) 人 | create 创造 → 被造出来的生命 = 生物。 |
| nitrogen | n. 氮,氮气 | 画面:空气里近八成是 nitrogen 氮气,惰性不活泼。 |
| exploit | vt. 剥削;利用;开采 n. 英勇的行为 | 语境:剥削工人、开采资源都叫 exploit,都是“榨取”。 |
| calcium | n. (化学元素) 钙 | 谐音联想:calcium ≈ “钙”,喝牛奶补 calcium 钙。 |
| baffle | vt. 使...困惑,把...难住 n. 隔板,折流板 | 谐音“白费”:想破脑袋也白费 = 把人难住。 |
| poster | n. 海报,大幅广告 | post 张贴 → 贴在墙上的大纸 = 海报。 |
| maritime | adj. 海的,海事的,海运的,船舶的 | 同源 marine 海的 → maritime 海事的、海运的。 |
| luggage | n. 行李 | 画面:机场传送带上 luggage 行李,托运的箱包。 |
| scream | vi. vt. 尖叫;高声喊 vi. 发出大而尖的声音 n. 尖叫,呼啸声;可笑的人 (或物) | 拟声:看到可怕的事 scream 尖叫,刺耳长声。 |
| chronicle | n. 编年史 vt. 按时间顺序记事 | chron 时间(chronic 长期)→ 按时间记录 = 编年史。 |
| automate | vt. 使...自动化 | auto 自己 → 机器自己动 = 自动化。 |
| flavor | n. 味道,⻛味;特色;调味品 vt. 给...调味 | 谐音联想:flavor ≈ “风(味)” → 菜的风味、调味品。 |
| obese | adj. 病态肥胖的,臃肿的 | 谐音联想:o-bese ≈ “胖死” → 病态肥胖的。 |
| transcend | vt. 超出,超越 | scend 爬(ascend 上升)+ trans 越过 → 超越。 |
| brand | n. 品牌;一种,一类;烙印 vt. 加污名于;(给牲畜)打烙印 | 画面:给牲畜打烙印 brand;牌子深入人心 = 品牌。 |
| irritate | vt. 使烦躁,激怒;刺激 (皮肤等) | 谐音联想:irritate ≈ “惹他” → 惹恼、激怒。 |
| romance | n. 浪漫,爱情 vt. 和 (某人) 谈情说爱 | 谐音:romance 即中文“浪漫”的来源,爱情浪漫。 |
| linger | vi. 继续存留;逗留,流连;奄奄一息 | 谐音联想:linger ≈ “赖着不走” → 逗留、徘徊。 |
| transplant | n. 移植;移植的器官 vt. 移植;移栽;使迁移 | trans 转移 + plant 种植 → 移栽;器官移植。 |
| lever | n. 操纵杆;杠杆,撬棒;施压手段 vt. 撬起,撬动 | lev 升起(elevate 抬高)→ 用来撬起东西的杆 = 杠杆。 |
| literal | adj. 字面上的;按照原文的;刻板的 | 同源 letter 字母 → 按字母逐字的 = 字面上的。 |
| outfit | n. 全套服装;团队 vt. 给...配置设备,供给服装 | out 出门 + fit 合身 → 出门穿的整套服装。 |
| leather | n. 皮革;皮衣,皮外套 | 画面:皮夹克 leather jacket,牛皮做的皮革。 |
| noteworthy | adj. 值得注意的,显著的 | note 注意 + worthy 值得 → 值得注意的。 |
| disclose | vt. 透露,披露;使显露 | close 关上,dis 打开 → 把秘密打开 = 透露、披露。 |
| costume | n. 演出服装;服装,装束;游泳衣 | 谐音联想:costume ≈ “cos(play)装” → 演出服装、戏服。 |
| vulnerable | adj. 脆弱的,易受伤害的 | 谐音联想:vulnerable ≈ “完能弱的” → 易受伤害、脆弱。 |
| correspond | vi. 相符,一致;类似,相当;通信 | respond 回应,cor 相互 → 互相对应 = 相符;通信。 |
| sphere | n. 球 (体),球形;范围,领域 | 同源 atmosphere 大气层(包地球的球面)→ sphere 球体、领域。 |

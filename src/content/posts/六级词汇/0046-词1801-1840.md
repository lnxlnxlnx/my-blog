## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| stern | adj. 严厉的,苛刻的;难对付的 n. 船尾 | stern 谐音'死盯'——老师死盯=严厉；船尾 stern |
| hay | n. 草料;少量的钱 | hay 干草：马吃的草料；make hay 趁天晴晒草 |
| malpractice | n. 玩忽职守,渎职 | mal(坏)+practice(执业) → 执业出错=渎职 |
| enclose | vt. 围住;随信附上 | en(使)+close(关) → 围住；随信附上 |
| stagnate | vi. 停滞不前,变萧条;不流动 | stagnate 谐音'死呆'——死水一潭停滞不前 |
| blink | vi. vt. 眨眼睛 vi. (灯光) 闪烁 n. 眨眼睛 | blink 眨眼：灯闪 blink；in the blink of an eye 一眨眼 |
| oath | n. 宣誓,誓言;咒骂,诅咒的话 | oath 誓言：证人宣誓 take an oath；也指咒骂 |
| tranquil | adj. 宁静的,安静的,平静的 | tranquil 与 quiet(安静)同源 → 宁静的湖面 |
| carrier | n. 运输公司;病原携带者;搬运人 n. 军输⻋,运输舰;通信公司 | carry(运载)+er(者) → 运输公司、病原携带者 carrier |
| arc | n. 弧,弧形;电弧 vi. 作弧形运动 | arc 弧：彩虹半圆 arc；闪电电弧 arc |
| avail | vi. vt. 有帮助,有用;利用 (机会等) n. 效用,帮助 | val=价值(valuable 同源) → avail 有用；of no avail 无用 |
| workout | n. 体育锻炼,体育训练 | work(练)+out(出来) → 练出一身汗=锻炼 |
| jewel | n. 宝石;珠宝,首饰;珍贵的东西 | jewel 谐音'珠'——珠宝首饰，宝石 |
| regiment | n. (军队) 团;一大群人或物 vt. 严格控制 | regiment 军队的团；也指严格控制，管得死死的 |
| uneasy | adj. 不安的,不自在的;不稳定的 | un(不)+easy(自在) → 不自在=不安 |
| procession | n. 队伍,行列,游行;一连串 | pro(向前)+cess(走) → 向前走的队伍=行列游行 |
| sting | vt. vi. 蜇,叮;(使) 感觉刺痛 vt. 激怒,使不安;敲诈,欺诈 n. 螫针,刺;刺伤,蜇伤;痛苦 | sting 音似'叮'——蜜蜂叮一下刺痛；也指敲诈 |
| complacent | adj. 自满的,自鸣得意的 | plac=取悦(please 同源) → 完全自我满足=自满 |
| ballot | n. 无记名投票;选票;投票总数 vi. 无记名投票 | ballot 源自意大利语'小球'，古时投小球表决=无记名投票 |
| drawer | n. 抽屉 | draw(拉)+er → 拉开的抽屉 |
| hose | n. 软管,㬵管;(旧时) 男式紧身裤 vt. 用软管洒水、清洗等 | hose 软管：花园浇水；house 少个 u 是 hose |
| agony | n. 极度痛苦,剧痛 | agony 剧痛：疼得在地上打滚，极度痛苦 |
| crackdown | n. 严厉的打击,镇压 | crack(打击)+down(下) → 严厉打击 crackdown |
| alloy | n. 合金 vt. 把...铸成合金 | alloy 合金：青铜就是铜和锡的合金 |
| spray | vt. vi. 喷,喷洒;向...扫射,往...上撒 n. 喷雾;喷雾器;浪花,⻜沫 | spray 喷雾：按压喷雾瓶喷洒；浪花 spray |
| withhold | vt. 拒绝给予,扣留,隐瞒 | with(向后)+hold(握住) → 握在手里不给=扣留 |
| disarm | vi. 裁军,裁减军备 vt. 使解除武装;使消气;拆弹 | dis(去掉)+arm(武器) → 缴械 disarm；裁军 |
| sturdy | adj. 牢固的,强壮的;坚定的 | sturdy 结实：小板凳 sturdy 稳当 |
| oversee | vt. 监督,监管 | over(上面)+see(看) → 在上头看着=监督 |
| bow | vi. 鞠躬;屈从于 vt. 低 (头),垂 (首) n. 鞠躬;船头;弓;蝴蝶结;琴弓 | bow 鞠躬弯腰；弓 bow 拉开；蝴蝶结 bow |
| weep | vi. vt. 哭泣,流泪 vi. (伤口) 流血,渗出液体 n. 哭泣,流泪 | weep 哭泣：无声 weep 泪流满面；伤口渗液也 weep |
| inward | adj. 内心的,内在的;向内的 adv. 向内地;向内心地 | in(内)+ward(方向，toward 同源) → 向内；内心的 |
| midday | n. 正午,中午时分 | mid(中间)+day(天) → 日当午=正午 |
| shipyard | n. 造船厂,修船厂 | ship(船)+yard(场地) → 造船厂 |
| yearn | vi. 渴望,渴求 | yearn 渴望：游子 yearn 家乡，望眼欲穿 |
| deport | vt. 把...驱逐出境 | de(出)+port(港口) → 赶出港口=驱逐出境 |
| barber | n. 男理发师;(男) 理发店 | barber 来自拉丁语'胡须'——给胡子理发的是 barber |
| gasp | vi. vt. 倒吸气;喘不过气,气喘吁吁 vi. 渴望 (酒或香烟) n. 倒吸气,倒抽气 | gasp 拟声：惊讶时倒吸一口气 |
| handbook | n. 手册,说明书 | hand(手)+book(书) → 随身手册 |
| clearance | n. 清除;间隙;审核批准;许可 | clear(清除/通过)+ance → 清除 clearance；海关放行许可 |

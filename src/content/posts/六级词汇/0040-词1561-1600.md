# 词 1561–1600

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 10月04日 Sunday · 词 1561–1600 · PDF 第 79–80 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| briefcase | n. 公文包 | brief 文件摘要 + case 箱子，装文件 = 公文包 |
| etiquette | n. 礼仪,礼节,行为准则,规矩 | 法语"标签"演变，言行贴的标签 = 礼仪 |
| underwear | n. 内衣,内裤 | under 里面 + wear 穿，贴身穿的 = 内衣 |
| crown | n. 王冠;王国;王权;冠军宝座;牙冠 vt. 为...加冕;给...加顶;使圆满 | 国王头上的 crown 王冠，加冕 = 王冠 |
| jaw | n. 颌;下巴;口部,嘴 vi. 喋喋不休 | 谐音"嚼"，吃饭靠 jaw 下巴咀嚼 = 颌、下巴 |
| forfeit | vt. 失去,被没收 n. 罚金,没收物 adj. 被罚的,被没收的 | for + feit 做(fact 同源)，违规被罚没 = 失去、罚金 |
| ail | vt. 困扰,干扰;使得病 | ailment 小病同源，身体出毛病 = 使生病、困扰 |
| foe | n. 敌人,仇敌 | friend 反义词 foe，敌人、仇敌 |
| handy | adj. 有用的,方便的;手边的;手巧的 | hand 手 + y，手边随手可用 = 方便的、手巧的 |
| canteen | n. ⻝堂,餐厅;水壶 | 部队的 canteen 食堂，也指行军水壶 |
| arch | n. 拱;拱⻔;足弓;拱形物 vt. vi. (使) 拱起,(使) 成拱形 adj. 调皮的,淘气的 pref. 最高等级的,主要的 | 凯旋门的大 arch 拱门，足弓、拱形 |
| uphold | vt. 支持,维护;维持 (原判) | up 上 + hold 持，向上托住 = 支持、维护 |
| diplomat | n. 外交官,外交家;圆滑的人 | diploma 文凭同源，持"国书"谈判的人 = 外交官 |
| slam | vi. vt. (使...) 砰地关上 vt. 用力一放,使劲一推;猛烈抨击 n. 猛关 (或推、摔、撞等) 的声音 | 拟声 slam，砰地摔门 = 砰地关上 |
| cult | n. 异教,邪教;狂热,崇拜 adj. 流行的,狂热崇拜的 | culture 文化同源，极端小圈子 = 邪教、崇拜 |
| doctrine | n. 信条,主义,教义 | doctor 博士同源 doc 教，教导的信条 = 教义、主义 |
| grocer | n. ⻝品杂货商;⻝物杂货店 | gross 整批同源，整批进货零卖 = 杂货商 |
| straw | n. ⻨秆,稻草;吸管 | last straw 最后一根稻草，straw = 稻草、吸管 |
| exponent | n. 倡导者,拥护者;大师;指数 | ex 出 + pon 放，站出来倡导 = 拥护者；指数 |
| swipe | vi. (手指在屏幕上) 滑动 vt. 偷窃;刷 (磁卡) vi. vt. 挥拳打,扬起巴掌打,挥起...打 n. 抡打,挥击;批评;滑动 | 手指 swipe 屏幕滑动；小偷 swipe 顺走东西 |
| distill | vt. 蒸馏;提炼 (信息) | dis 下 + still 滴，蒸馏滴出精华 = 蒸馏、提炼 |
| ape | n. 猿,类人猿 vt. 模仿 | ape 猿类会模仿人，模仿 = ape |
| tornado | n. ⻰卷⻛,旋⻛ | 西班牙语"旋转"，旋转的风柱 = 龙卷风 |
| deduct | vt. (从总量中) 扣除,减去 | duct 引(conduct 同源)，从总数里"引走" = 扣除 |
| tractor | n. 拖拉机 | tract 拉(attract 同源)+or，拉着犁跑 = 拖拉机 |
| aftermath | n. 后果,余波 | after 之后 + math 收割(古义)，灾后余波 = 后果 |
| cuisine | n. 烹饪 (法),⻛味;菜肴 | 法语"厨房"之意，French cuisine 法式烹饪 = 菜肴 |
| besiege | vt. 围困,包围;(烦恼等) 团团围住 | siege 围攻 + be，城池被围 = 围困、包围 |
| dogma | n. 教条,教义,教理 | dogmatic 教条主义同源，不容置疑 = 教条 |
| scramble | vi. 攀爬;争抢,争夺 vt. 仓促完成;扰乱;炒 (蛋) vt. vi. (使) 紧急起⻜ n. 争抢,争夺 | 手脚并用 scramble 爬坡；scrambled eggs 炒蛋 |
| berry | n. 浆果,莓 | 草莓 strawberry、蓝莓 blueberry 都是 berry 浆果 |
| lorry | n. 卡⻋,货⻋ | lorry 谐音'拉哩'——拉着货物跑的卡车 |
| dispense | vt. vi. 分配,发放;提供;配药;摒弃 | pense 与 spend(花费)同源，dis 分开 → 把东西分发出去 |
| hug | vt. vi. 拥抱,搂抱 vt. 抱紧;紧挨;(衣物) 贴 (身) n. 拥抱,搂抱 | hug 字母 u 像环抱的手臂，张开双臂拥抱 |
| ammunition | n. 弹药;把柄,论据,证据 | 辩论吵架时的'弹药'就是论据；军用弹药也叫 ammunition |
| wrench | vt. vi. 猛拉,猛扭,猛拧;使痛苦 vt. 扭伤 (脚踝、肩膀等) n. 扳手;猛扭;(离别的) 痛苦 | wrench 音似'抡起'——抡起扳手猛扭 |
| influenza | n. 流感 | influenza 与 influence(影响)同源，古人以为流感受星象影响 |
| fortnight | n. 两周,十四天 | fourteen nights 缩成 fortnight，十四夜=两周 |
| sword | n. 剑 | sword 拔剑出鞘'嗖'的一声——剑 |
| pact | n. 条约,协定,协议 | pact 与 compact(契约)同源，白纸黑字签的协议 |

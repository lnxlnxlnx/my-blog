## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| memorial | n. 纪念碑;(追忆逝者的) 纪念物 adj. (对逝者) 纪念的 | memory 记忆 → memorial 纪念碑 |
| clerk | n. 文员,文书;书记员;店员 vi. 当职员 (或文书、书记员) | clerk 文员、店员 → 职员 |
| senate | n. 参议院;大学评事会;元老院 | sen 老（senior 年长）→ 元老院、参议院 |
| bat | n. 蝙蝠;球棒,球拍 vi. vt. 用球棒击球 vt. 挥打 (空中的小东西) | 蝙蝠 bat 夜行；球棒 bat 打球 → 蝙蝠、球棒 |
| investigate | vi. vt. 调查,研究 | vestige 痕迹 → 追查 → 调查 |
| trillion | num. 一万亿;大量,无数 | tri 三 → 三次方 → 一万亿 |
| rust | n. 锈,铁锈 vt. vi. (使) 生锈 | 铁生锈 rust → 锈 |
| bully | n. 恃强凌弱者,恶霸 vt. 欺负,恐吓,胁迫 | 谐音'暴力' → 恃强凌弱的恶霸 |
| rein | n. 缰绳;控制,主宰;保护带 vt. 控制 | 缰绳 rein 勒马 → 控制 |
| delicacy | n. 佳肴;周到;脆弱;温柔;棘手 n. 精美 | delicious 美味 → delicacy 佳肴 |
| deviate | vi. 背离,偏离 | via 路 → 离开正路 → 偏离 |
| coalition | n. 联合政府;联合体,联盟;联合 | 联想 ally 同盟 → 联盟 |
| unite | vi. vt. (使) 团结,(使) 联合 | unit 一体 → unite 团结 |
| sunlight | n. 阳光 | sun 太阳 + light 光 → 阳光 |
| logistics | n. 后勤工作;物流 | logistics 后勤 → 物流 |
| ought to | usage. 应该,应当 | 谐音'哦特' → 应该、应当 |
| logo | n. 标志,标识 | logo 图标 → 标志 |
| repel | vt. 驱逐,赶走;使厌恶,使反感 vi. vt. (磁极等) 排斥,相斥 | pel 推（expel 驱逐）→ 推开 → 排斥 |
| tentative | adj. 暂定的,不确定的;犹豫不定的 | 联想 tempt 试探 → 试探性、暂定的 |
| dressing | n. 调料;打扮;敷料 | dress 穿衣 → 给沙拉'穿衣' → 调料 |
| cope | vi. (成功地) 应付,处理 | 谐音联想:cope 顶得住 → 遇到困难仍能 cope with 应付处理。 |
| contrary | adj. 相对立的,相反的 | 词根 contra 反对(contrast 对比)→ contrary 与…相反的。 |
| strand | n. 股,缕;部分;海滨,海岸 vt. 使滞留,使无法脱身;使搁浅 | 沙滩上一缕头发被浪冲上岸:strand 既指“缕”也指搁浅岸边。 |
| innovate | vi. vt. 革新,创新,改革 | nov 新(novel 新奇)→ 引入新东西 = 革新、创新。 |
| elect | vt. 选举,推选;选择 (做) adj. 已当选但未就任的 | 词根 lect 选(select 挑选)→ 把人选出来 = 选举。 |
| intervene | vi. 干涉,介入;干扰;介于...之间 vt. vi. 打断,插嘴 | inter 之间 + vene 来 → 插到中间来 = 干涉、插嘴。 |
| reassure | vt. 使安心,使消除疑虑 | assure 保证 + re 再 → 反复保证 = 使安心。 |
| empirical | adj. 以实验 (或经验) 为依据的 | empir 经验 → 凭经验(实验)得出的,以实验为依据。 |
| boom | n. 繁荣,激增;⻛靡的时期;轰鸣 vi. 轰鸣,轰响;繁荣,迅速发展 vt. vi. 以低沉有力的声音说话 | 拟声词:引擎 boom 轰鸣;经济轰鸣作响 = 繁荣。 |
| ponder | vi. vt. 沉思,考虑 | 联想:源自“称重”→ 心里掂量掂量 = 沉思。 |
| disrupt | vt. 使中断,扰乱 | rupt 断裂(rupture 破裂)→ 把秩序断开 = 扰乱。 |
| aluminum | n. 铝元素,铝 (金属) | 易拉罐、铝箔纸都由 aluminum 制成,轻金属。 |
| prerequisite | n. 先决条件,前提 adj. 作为先决条件的 | pre 先 + requisite 必需 → 事先必备的条件 = 前提。 |
| genre | n. (文学、艺术作品的) 类型,体裁 | 与 general 同源“属、种”→ 艺术作品的类型、体裁。 |
| enterprise | n. 企业;项目,规划;进取心 | enter 进入 + prise 抓 → 敢闯敢抓 = 进取心;企业。 |
| mar | vt. 破坏,损害 | 联想:mar 与 scar 押韵,一道痕毁一幅画 = 破坏损害。 |
| rip | vt. vi. 撕破,裂开 vt. 扯掉,扯下;(从网上) 撷取音频等 n. 撕开的大口子;离岸流 | 拟声词:布料 rip 一声撕破,裂开大口子。 |
| instruct | vt. 指示,吩咐;教授,传授 | struct 建造(structure)→ 把知识建进头脑 = 教授指示。 |
| submarine | n. 潜艇 adj. 海底的 | sub 下 + marine 海 → 海底航行的船 = 潜艇。 |
| poll | n. ⺠意调查;投票,投票站 vt. 做⺠意调查 vt. vi. 获得 (票数) | poll 原义“人头”,数人头统计 = 民意调查、投票。 |

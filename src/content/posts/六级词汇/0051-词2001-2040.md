## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| chapel | n. 小教堂,小礼拜堂 | 大学校园里的 chapel 小礼拜堂 |
| spaghetti | n. 意大利面 | 画面：spaghetti 意面一圈圈缠在叉上 |
| referee | n. 裁判员;介绍人;仲裁员 vi. vt. 担任裁判 | refer（提交裁决）+ ee → referee 裁判、仲裁员 |
| pedal | n. 踏板 vi. vt. 骑 (自行⻋);踩 (踏板) | 词根 ped = 脚（pedestrian 行人同源）→ 脚踩的踏板 |
| towel | n. 毛巾 vt. 用毛巾擦 | 画面：运动完拿 towel 毛巾擦汗 |
| outskirts | n. 市郊,郊区 | out 外 + skirts 裙边 → 城市裙边外围 = 市郊 |
| tact | n. 得体,老练 | 词根 tact = 触（tactile 触觉）：说话懂分寸 = 得体老练 |
| holy | adj. 与上帝有关的,神圣的;虔诚的 | Holy Bible 圣经 → holy 神圣的 |
| lottery | n. 乐透,彩票抽奖;碰运气的事 | 谐音"乐透"：彩票 lottery 中奖乐透了 |
| auditorium | n. 礼堂,会堂,音乐厅;观众席 | audio（听）同源 → 听演讲的场所 = 礼堂 |
| toil | vi. 苦干,辛勤劳作;跋涉 n. 苦工,劳累的工作 | 联想 to + oil：苦干流汗如油 → toil 辛勤劳作 |
| foam | n. 泡沫橡㬵;泡沫;泡沫剂 vi. (液体) 起泡沫 | 谐音"浮沫"：啤酒上浮一层 foam 泡沫 |
| mortal | adj. 终有一死的;致命的;极度的 n. 人,凡人,普通人 | 词根 mort = 死（mortuary 太平间同源）→ 终有一死、致命的 |
| allot | vt. 分配,摊派 (时间,钱等) | lot（份额）同源 → allot 分配摊派 |
| compass | n. 指南针,罗盘;圆规;范围 | 词根 pass 走：指南针指引方向；圆规画范围 |
| perplex | vt. 使困惑,使茫然 | 词根 plex = 编织（complex 复杂同源）→ 被缠住 = 困惑 |
| specimen | n. 标本,样本;具有...特性的人 | 词根 spec = 看（inspect 检查同源）→ 供检验的样品 = 标本 |
| hurdle | n. 障碍,难关;跳栏;跨栏赛跑 vt. vi. (奔跑中) 跳跃,跨越 | 跨栏选手越过一道 hurdle 栏 → 障碍、难关 |
| coward | n. 胆小⻤,懦夫 | 联想：coward 懦夫见危险像 cow（牛）受惊逃跑 |
| sodium | n. 钠 | 食盐 NaCl 里的钠 sodium |
| clarity | n. (表达) 清楚;(思路,图像) 清晰 | clear（清楚）同源 → clarity 清晰 |
| outing | n. 远足,短途旅行 | out（外出）同源 → outing 远足出游 |
| blueprint | n. 蓝图;行动方案;(基因的) 模型 | blue 蓝 + print 印 → 蓝图（晒图是蓝色） |
| solicit | vt. vi. 索求,征求,筹集;(卖淫者) 拉客 | 联想 excite（唤起）：solicit 主动唤起请求、拉客 |
| diameter | n. 直径;放大倍数 | dia 穿过 + meter 测 → 穿过圆心的线 = 直径 |
| strangle | vt. 扼死,勒死;限制,扼杀 | 谐音"死缠"：被绳子死缠住 = 扼死、扼杀 |
| rotate | vi. vt. (使) 旋转;轮流做;轮换 (位置) | 词根 rot = 轮（rotor 转子同源）→ 旋转、轮换 |
| frown | vi. vt. 皱眉 n. 皱眉 | 画面：frown 皱眉，眉间挤出"川"字 |
| ambulance | n. 救护⻋ | 谐音"俺不能死"：救护车呼啸而来 |
| underdeveloped | adj. 欠发达的;发育不全的 | under 不足 + developed → 欠发达 |
| pearl | n. 珍珠;珠状物 | 画面：蚌壳里圆润的 pearl 珍珠 |
| knob | n. 旋钮;球形把手;疙瘩;小块 | 谐音"脑拨"：手指"拨" knob 旋钮调音量 |
| olive | n. 橄榄;橄榄树;橄榄绿 adj. 橄榄绿的;(皮肤) 浅褐色的 | olive oil 橄榄油；和平鸽叼 olive 橄榄枝 |
| proverb | n. 谚语 | pro 前 + verb 话 → 前人传下的话 = 谚语 |
| caption | n. 说明文字,字幕 vt. 给 (图片等) 配说明文字 | 词根 capt = 抓（capture 同源）→ 抓住画面要点的话 = 字幕 |
| fringe | n. 刘海;(地区等的) 边缘;流苏 adj. 边缘的,非主流的 vt. 形成...的边缘 | 画面：fringe 刘海垂在额头边缘；流苏在衣边 |
| revolt | n. 反叛,造反 vi. 反叛,造反 vt. 使惊骇,令人厌恶 | re 反 + volt 转（revolve 旋转）→ 倒转乾坤 = 反叛 |
| monotony | n. 单调乏味,千篇一律 | mono 单一 + tone 音调 → 一个调子到底 = 单调 |
| swift | adj. 快的,迅速的;快速移动的 n. 雨燕 | 歌手 Taylor Swift：swift 迅速敏捷 |
| atom | n. 原子;一点儿,极少 | a 不 + tom 切 → 不可再分割 = 原子 |

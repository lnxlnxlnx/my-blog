## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| intricate | adj. 错综复杂的 | 联想 trick 诡计 → 诡计交织 = 错综复杂 |
| pant | vi. vt. 气喘吁吁,喘息 | 拟声 pant 气喘吁吁 → 喘息 |
| commission | n. 委员会;佣金;手续费;正式委托 vt. 正式委托;任命...为军官 | mission 使命 → 共担使命的委员会;佣金 |
| sausage | n. 香肠,腊肠 | 联想: 肉塞进肠衣 = 香肠 |
| relentless | adj. 不停的,持续的;无情的 | relent 心软 + less 无 → 不心软 = 无情 |
| sacrifice | n. 牺牲,献出;献祭,祭品 vt. 牺牲,献出 vt. vi. 献祭 | 献祭 sacrifice 给神 → 牺牲、献祭 |
| folk | n. 人们;各位;家属;⺠间音乐 adj. ⺠间的,⺠俗的;流传⺠间的 | folk music 民谣 → 民间的、人们 |
| tale | n. 故事,传说 | fairy tale 童话 → 故事、传说 |
| trim | vt. 修剪;削减;装饰,点缀 n. 修剪;(衣服等的) 饰物 adj. (人) 苗条的,修⻓的;整⻬的 | 理发店 trim 修剪 → 修剪 |
| well-being | n. 幸福,健康,成功 | well 好 + being 状态 → 幸福健康 |
| nickname | n. 绰号,外号 vt. 给...取绰号 | nick 刻 + name 名 → 刻上的别名 = 绰号 |
| optic | adj. 眼的,视力的,视觉的 | optic nerve 视神经 → 视觉的 |
| casualty | n. 伤亡人员;受害者;急诊室 | 战争 casualty 伤亡人员 → 伤亡 |
| cornerstone | n. 基石 | corner 角 + stone 石 → 基石 |
| reckon | vt. vi. 想,认为 vt. 看作,看待;估算,估计 | I reckon 我估计 → 认为、估算 |
| bruise | n. ⻘肿,瘀伤 vt. vi. (使) 出现伤痕,擦伤 vt. 打击,挫伤 (信心) | 撞出 bruise 瘀青 → 瘀伤 |
| deteriorate | vi. 恶化,变坏,衰退 | 联想: 一天天变坏 = 恶化 |
| superb | adj. 极好的,卓越的 | super 超级 → superb 极好 |
| alarm | n. 警报器;警报;闹钟;惊恐 vt. 使惊恐,使忧虑;给...装警报器 | alarm clock 闹钟 → 警报、惊恐 |
| crack | vi. vt. (使) 破裂,裂开;砸开,破开 vt. 重击,猛击;找到解决方法 n. 裂缝;缝隙;爆裂声;尝试 adj. 训练有素的,一流的 | 拟声"咔嚓"裂开 → 裂缝 |
| anchor | n. 锚;主持人;顶梁柱 vi. vt. 抛锚,使停泊;主持 (节目) vt. 使固定;使扎根 | 船抛 anchor 锚 → 锚;主持人 |
| intrinsic | adj. 本质的,内在的,固有的 | intro 向内 → intrinsic 内在的 |
| edible | adj. 可⻝用的,能吃的 n. ⻝品 | 词根 ed=吃(eat)→ 可食用的 |
| league | n. 联赛;联盟,同盟;级别;里格 | 英超 Premier League → 联赛、联盟 |
| rent | vt. vi. 租用,租借 vt. 出租 n. 租金,租用费 | 房东每月收 rent 租金 → 租金、租用 |
| incorporate | vt. 把...并入,包含;使组成公司 | 同根 corporation(公司)→ 并入 |
| threshold | n. ⻔槛;起始点,临界点 | thresh 踩 + hold 持 → 脚下横木 = 门槛 |
| fabricate | vt. 捏造,编造;制造,生产 | fabric 织物 → 像织布般编造 = 捏造 |
| debate | n. 辩论,讨论,争论 vt. vi. 辩论,讨论,争论;考虑,盘算 | 谐音"怼吧"→ 互怼辩论 |
| dive | vi. 跳水;潜水;俯冲;暴跌 n. 跳水;潜水;俯冲 | 跳水 dive 入水 → 跳水、俯冲 |
| discourse | n. 话语,语篇;演讲,论述;对话 vi. 讲述,论述 | course 跑 → 话语如水流跑出去 → 话语、论述 |
| haunt | vt. (⻤魂) 出没于;萦绕;⻓期困扰 n. 常去的地方 | 谐音'晃' → 鬼魂常晃的地方 → 萦绕、常去之处 |
| administer | vt. 管理,治理;给予 (药等) vt. vi. 执行,实施 | minister 大臣管国事 → administer 管理、执行 |
| delight | n. 高兴,愉快;令人高兴的事 (人) vt. 使高兴,使愉快 | de + light 光 → 心里一亮 → 高兴、愉快 |
| skyscraper | n. 摩天大楼 | sky 天 + scrape 刮 → 楼高得刮到天 → 摩天大楼 |
| hypothesis | n. 假说,假设 | hypo 下 + thesis 论题 → 未证实的论题 → 假说 |
| segregate | vt. 实行 (种族等) 隔离;(使) 分离 | greg 群（congregate 聚集）+ se 分开 → 隔离 |
| drought | n. 干旱,旱灾 | 与 dry 干燥同源 → 久不下雨 → 干旱 |
| expel | vt. 开除;驱逐出境;排出 | ex 出 + pel 推（repel 击退）→ 推出去 → 开除、驱逐 |
| civic | adj. 市政的,城市的;市⺠的 | 与 city 城市同源 → 市政的、市民的 |

| forbid | vt. 禁止,不准;妨碍,阻碍 | forbid 禁止 → 不准 |
| dioxide | n. 二氧化物 | di 二 + oxide 氧化物 → 二氧化物 |
| smartphone | n. 智能手机 | smart 智能 + phone 手机 → 智能手机 |
| harvest | n. 收获,收割;收成,收获量 vi. vt. 收获,收割 vt. 采集,搜集 | 秋天 harvest 收割庄稼 → 收获 |
| circulate | vi. vt. 循环,流通;流传,散布 vt. 传递,传阅 vi. (在聚会上) 往来应酬 | circle 圆 → 转圈传递 → 循环、流通 |

| deter | vt. vi. 威慑,制止,阻止 | terr 怕（terrible 可怕）→ 吓住 → 威慑 |
| inject | vt. 给...注射;给...添加;给...注入 | ject 投（project 投射）→ 打入体内 → 注射 |
| standpoint | n. 立场,观点,⻆度,立足点 | stand 站 + point 点 → 立足点、立场 |
| doze | vi. 打瞌睡,打盹儿,小睡 n. 小睡 | 谐音'豆子' → 点头如豆 → 打瞌睡 |
| penny | n. 便士;分 | penny 便士、一分钱 → 便士 |
| emulate | vt. (因仰慕而) 效仿,尽力赶超 | 联想 rival 竞争 → 效仿、尽力赶超 |
| disorder | n. 失调,紊乱,疾病;混乱;动乱 | order 秩序 + dis 不 → 紊乱、疾病 |
| freight | n. 货物,货运;运费 vt. (用⻜机等) 运送,托运 | 联想 weight 重量 → 货物重 → 货运 |
| kidney | n. 肾脏;腰子 | 肾脏 kidney 形如豆 → 肾脏 |
| endow | vt. 向 (院校、医院等) 捐款;赋予 | 联想 dowry 嫁妆 → endow 捐赠、赋予 |
| infant | n. 婴儿;幼儿学校的学生 adj. 供婴幼儿用的;初期的,初创的 | 联想 infantry 步兵 → infant 婴儿 |
| redundant | adj. 多余的,累赘的;被裁员的 | 被裁员 redundant → 多余的、累赘的 |
| humane | adj. 人道的,仁慈的 | human 人 → humane 人道的、仁慈的 |
| teen | n. ⻘少年;⻘少年时期 adj. ⻘少年的 | thirteen 十三岁起 → teen 青少年 |
| rat | n. 老鼠,耗子;卑鄙小人 | 老鼠 rat 过街人人喊打 → 老鼠 |
| fling | vt. 扔,掷;猛动 (身体) n. 一时的放纵;短暂的⻛流韵事 | 谐音'飞扔' → 用力扔、掷 |
| acclaim | vt. 赞扬,公开称赞 n. 赞扬,公开称赞 | claim 喊 → 齐声喊好 → 赞扬 |
| bypass | n. 旁道,外环路;(心脏) 搭桥手术 vt. 绕过,绕...走;(做某事时) 避开 | by 旁 + pass 过 → 从旁绕过 → 旁道 |
| wire | n. 金属丝;电线;铁丝网;电报 vt. 为...接电线;安窃听器;发电报 | wire 电线 → 金属丝、电报 |
| found | vt. 创立;兴建;基于 | foundation 基础 → found 创立 |
| accent | n. 腔调,口音;重音;变音符号 vt. 突出,强调 | accent 重音落在哪 → 口音 |
| compute | vt. 计算 | computer 计算机 → compute 计算 |
| acre | n. 英亩 | 音近'艾克' → 英亩 |
| marine | adj. 海洋的,海产的;海运的 n. 海军陆战队士兵 | marine 海军陆战队 → 海洋的 |
| heritage | n. (国家或社会) 遗产,传统 | inherit 继承 → heritage 遗产 |
| ounce | n. 盎司;很少量,一点点 | 音译'盎司' → 盎司 |
| texture | n. 质感;口感;(作品的) 韵味 | text 编织（textile 织物）→ 质感 |
| apology | n. 道歉,认错 | apologize 道歉 → apology 道歉 |
| mainstream | adj. 主流的 n. 主流,主流群体 vt. 使进入主流 | main 主 + stream 流 → 主流 |
| fragile | adj. 易碎的;脆弱的;精致的;虚弱的 | fragment 碎片 → fragile 易碎的 |
| odor | n. (常指难闻的) 气味 | 谐音'呕' → 难闻的气味 |
| mobilize | vt. vi. 动员,鼓动 vt. 调动,调用 | mobile 移动 → 使动起来 → 动员 |
| comedy | n. 喜剧,喜剧片;滑稽之处 | 喜剧 comedy 逗人笑 → 喜剧 |
| wage | n. 工资,工钱 vt. 发动,进行 (运动或战争) | wage 工资；wage war 发动战争 |

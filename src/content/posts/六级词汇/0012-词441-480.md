| slump | vi. 暴跌;猛地坐下 n. 暴跌;萧条期 | 股市 slump 暴跌 → 暴跌、萧条 |

| kidnap | vt. 劫持,绑架 | kid 小孩 + nap 抓 → 绑架 |

| indigenous | adj. 当地的,本土的 | gen 生 → 土生土长 → 本土的 |

| surpass | vt. 超过,胜过 | sur 超 + pass 过 → 超过、胜过 |
| spectacle | n. 眼镜;壮观的景象;奇特的现象 | spect 看（inspect 检查）→ 眼镜、壮观景象 |
| steel | n. 钢;钢铁工业;兵器 vt. 下决心应付 | steel 钢；steel oneself 下决心 → 钢 |
| summit | n. 山顶,顶峰;峰会,首脑会议 | summit 山顶 → 顶峰、峰会 |
| contempt | n. 鄙视,蔑视;藐视法庭 | 联想 tempt 诱惑 → 对诱惑不屑一顾 → 鄙视、蔑视 |
| demand | n. 要求;需求 vt. 要求;需要 | demand 强硬的要 → 要求、需求 |
| embarrass | vt. 使尴尬,使难堪 | 来自 bar 栏杆 → 被拦住出丑 → 使尴尬 |

| prosper | vi. 兴旺,发达 | sper 希望（despair 绝望反义）→ 有希望 → 兴旺 |

| premium | n. 保险费;额外费用 adj. 优质的,高端的 | premium 保费是额外费用 → 保险费、优质的 |

| savage | adj. 凶恶的;猛烈抨击的;野蛮的 n. 野蛮人;残暴的人 vt. 凶猛地攻击;激烈抨击 | savage 野蛮凶残 → 凶恶、野蛮 |

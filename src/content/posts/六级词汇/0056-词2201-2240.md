# 词 2201–2240

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| pint | n. 品脱;一品脱啤酒 | 谐音"品脱"：一品脱啤酒 |
| aloft | adv. 在高处,在空中 | loft（高处）同源 → aloft 在高处、在空中 |
| hereby | adv. (正式场合用语) 特此,兹,谨 | here + by（凭此）→ hereby 特此 |
| slogan | n. 口号,标语 | 画面：游行队伍喊 slogan 口号 |
| pistol | n. 手枪 | 画面：牛仔腰间别 pistol 手枪 |
| brass | n. ⻩铜;铜管乐器;要员 | 画面：brass 黄铜色铜管乐器闪亮 |
| portfolio | n. 文件夹;作品集;投资组合 | port 携带 + folio 纸 → 随身纸夹 = 作品集 |
| electoral | adj. 选举的,与选举有关的 | elect（选举）同源 → electoral 选举的 |
| brow | n. 额头;眉毛;山脊,坡顶 | 画面：紧锁 brow 眉头 |
| buffet | n. 自助餐;(火⻋上的) 餐⻋ vt. (⻛、雨等) 连续猛击,打击 | 谐音"补肥"：自助餐 buffet 吃到撑 |
| hysterical | adj. 歇斯底里的;极其可笑的 | 歇斯底里就是它的音译，hysterical 情绪失控、夸张得极其可笑。 |
| proximate | adj. (原因) 直接的;最接近的 | 与 approximate（大约的）同源，proximate=最接近的、最直接的原因。 |
| secular | adj. 世俗的,非宗教的;⻓期性的 | 谐音「世俗客」：俗世中人=世俗的、非宗教的。 |
| atrocity | n. (尤指战争中的) 残暴行为 | 词根联想：atro- 本义「黑」→黑暗的暴行=atrocity 残暴行为。 |
| cashier | n. 出纳员,收银员 vt. 开除,革除 (军职) | cash（现金）+ier（人）→管现金的人=收银员出纳员。 |
| obscene | adj. 下流的;骇人听闻的,不道德的 | ob（反）+scene（场景）→不该出现的场景=下流的。 |
| allude | vi. 间接提到,暗指,影射 | 词根 lude=玩（illusion 幻象同源），不直说、绕着「玩」→暗指。 |
| mister | n. 先生 | Mr. 的完整形式就是 mister，尊称先生。 |
| astray | adv. 误入歧途地;丢失地 | a（在）+stray（走失）→走丢了=误入歧途、丢失。 |
| bleach | vt. 漂白,使脱色,使变淡 n. 漂白剂 | 画面联想：漂白剂一倒，污渍瞬间被 bleach 漂白。 |
| fireman | n. 消防队员 | fire（火）+man（人）→冲进火里救人的人=消防队员。 |
| backyard | n. 后院 | back（后）+yard（院子）→房子后面的院子=后院。 |
| monarchy | n. 君主制;君主国;王室 | mono（单一）+archy（统治，同 anarchy 无政府）→一人统治=君主制。 |
| majesty | n. 雄伟壮观,庄严;(尊称) 陛下 | 与 major（大）同源→宏伟庄严；尊称陛下 His Majesty。 |
| almighty | adj. 全能的;极大的,十分严重的 n. 上帝,神 | all（全部）+mighty（强大的）→全能的；也指上帝。 |
| inmate | n. 囚犯,精神病院病人 | in（同住）+mate（伙伴）→同住一屋的人=囚犯、住院病人。 |
| coil | vi. vt. (使) 缠绕,盘绕 n. (绳子等绕成的) 卷;电路线圈 | 画面联想：蛇盘绕成一圈圈=coil；电器的线圈。 |
| steward | n. 乘务员;统筹人;管家,管理者 | 词根 ward=看守（同 warden）→照看乘客与家业的人=乘务员、管家。 |
| barn | n. 谷仓,畜棚 | 谐音「搬」：丰收了把粮食搬进 barn 谷仓。 |
| cabbage | n. 卷心菜,洋白菜 | 画面联想：卷心菜圆滚滚，叶子一层层包着=包菜。 |
| thorn | n. (植物茎上的) 刺;荆棘 | 画面联想：玫瑰枝上的刺扎手=thorn；荆棘。 |
| mop | n. 拖把;乱蓬蓬的头发 vt. 用拖把擦;用布擦掉 | 谐音「抹」：用拖把「抹」地=拖把。 |
| referendum | n. 全⺠投票,全⺠公投 | refer（提交）+endum→提交给全体人民表决=全民公投。 |
| malice | n. 恶意,害人之心 | 词根 mal=坏（malicious 恶意的）→害人的坏心思=恶意。 |
| convoy | n. 护卫⻋队,护航舰队 vt. 为...护航,护送 | 与 voyage（航程）同源，con+voy 结伴同路→护卫队护送。 |
| oar | n. 船桨,桨 | 谐音「摇」：船夫摇着 oar 桨划水。 |
| pastry | n. 油酥面团;油酥点心 | paste（面糊）+ry→用面团烤出的酥皮点心。 |
| witch | n. 女巫,巫婆;丑老太婆 | 画面联想：骑扫帚的女巫 witch 熬着毒药汤。 |
| disco | n. 迪斯科舞厅或舞会;迪斯科舞曲 | 音译「迪斯科」：disco 舞厅里灯光闪烁跳迪斯科。 |
| fable | n. 寓言;谎言,无稽之谈 | 伊索寓言就是 Aesop's Fables，fable=寓言；编的瞎话。 |

# 词 2241–2280

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 10月21日 Wednesday · 词 2241–2280 · PDF 第 113–114 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| comma | n. 逗号 | 画面联想：逗号像小蝌蚪；音近「逗」。 |
| sportswoman | n. 女运动员 | sports（运动）+woman（女人）→女运动员。 |
| limelight | n. 公众注意的中心 | 早期舞台用石灰灯（lime light）照明，站灯下=公众焦点。 |
| clamp | vt. vi. 紧紧抓住,被抓住,被夹紧 vt. 夹紧,固定;用夹锁锁住 n. 夹具,夹子 | 谐音「可夹」：大夹子 clamp 夹紧固定住。 |
| goat | n. 山羊 | 画面联想：长胡子山羊 goat 咩咩叫、爱顶人。 |
| goose | n. 鹅;鹅肉;傻瓜 vt. 推动,促进 | goosebumps=鸡皮疙瘩（直译「鹅皮疙瘩」）；鹅=goose。 |
| envelop | vt. 包住,裹住,盖住 | 与 envelope（信封）同源，信封把信包住→envelop=包住裹住。 |
| standby | n. 后备人员,备用物品 adj. (机票、⻔票等) 最后时刻出售的 | stand（站）+by（旁边）→站在旁边待命=后备人员、备用。 |
| quart | n. 夸脱 (英美容量或液量单位) | 音译「夸脱」；与 quarter（四分之一）同源，一夸脱=一加仑的四分之一。 |
| apron | n. 围裙;停机坪 | 画面联想：厨师系着围裙做饭；机场停机坪也叫 apron。 |
| frost | n. 霜冻,严寒天气;霜 vt. vi. (使) 结霜 | 诗人 Robert Frost 之名含 frost，frost=霜、霜冻严寒。 |
| tanker | n. 油轮,油罐⻋ | tank（罐子）+er→载着大油罐的船=油轮、油罐车。 |
| rouse | vt. 唤醒,叫醒;使...活跃;激发 | 与 arouse（唤起）同源→唤醒、激发。 |
| censor | vt. 审查,删改 (书、电影等) n. (书、电影等的) 审查员 | 古罗马审查官 censor 管道德审查→审查删改书刊电影。 |
| intercourse | n. 性交;交流,交往,交际 | inter（相互）+course（行走）→相互往来=交流；引申性交。 |
| bucket | n. 桶;铲斗;大量 | 画面联想：打水用 bucket 水桶；kick the bucket=翘辫子。 |
| perfume | n. 香水;芳香,香味 vt. 使香气弥漫;抹香水 | 词根 fume=烟气味，per 弥漫→香水让香气四溢。 |
| ass | n. 屁股;蠢货;驴 | 画面联想：蠢得像头驴（ass）；俚语也指屁股。 |
| clergy | n. 神职人员 | 与 clerk（文书）同源，原指教会抄写员→clergy 神职人员。 |
| Buddhism | n. 佛教 | Buddha（佛陀）+ism（主义）→佛陀的教义=佛教。 |
| unilateral | adj. 单方面的,单边的 | uni（单一）+lateral（边）→单边、单方面的。 |
| mock | vt. vi. 嘲笑,(通过模仿) 取笑 vt. 不尊重,轻慢 adj. 假装的;模拟的 n. (英国) 模拟考试 | mock exam=模拟考；模仿别人取笑=嘲笑、轻慢。 |
| flank | n. 胁腹;侧翼;侧面 vt. 两侧有... | 牛侧腹肉叫 flank steak；军队两翼=flank 侧翼。 |
| barometer | n. 气压计;(显示形势变化的) 指标 | 词根 baro=气压、meter=测量→气压计；也指形势指标。 |
| obstruct | vt. 堵塞,遮挡;阻挠,妨碍 | ob（挡）+struct（建造，同 construct）→挡住建造=堵塞阻挠。 |
| magistrate | n. 地方执法官 | 与 master（主人）同源→掌权执法的人=地方执法官。 |
| panorama | n. 全景,全景图;全貌,概述 | pan（全部）+orama（看）→一眼看全=全景。 |
| riddle | n. 谜,谜语;谜团,费解的事 vt. 使...满是窟窿 | 蝙蝠侠反派「谜语人」就叫 Riddler，riddle=谜语。 |
| conceit | n. 自负;幻想,奇想;巧妙的言辞 | 与 conceive（构想）同源，总自以为了不起=自负。 |
| surname | n. 姓 | sur（在…之上）+name（名）→排在名前的姓氏。 |
| mistress | n. 情妇;女教师;女主人 | master（主人）的女性形式→女主人；也指情妇。 |
| bluff | vt. vi. 虚张声势,唬人,吓唬 n. 虚张声势,唬人;峭壁,陡岸 | 打牌 bluff 虚张声势唬人；也指峭壁陡岸。 |
| pilgrim | n. 朝圣者;清教徒前辈移⺠ | 乘五月花号赴美的清教徒叫 Pilgrims→朝圣者。 |
| annex | vt. 兼并,并吞 (领土等) n. 附属建筑;附件,附录 | 词根 nex=绑（同 connect）→绑到自己名下=兼并领土。 |
| artillery | n. 火炮,大炮;炮兵部队 | 画面联想：战场上 artillery 大炮齐鸣、炮火连天。 |
| wink | vi. 眨一只眼,使眼色;闪烁,明灭 n. 眨一只眼,眨眼示意,眼色 | 画面联想：wink 眨一只眼、使眼色；灯光一闪一闪。 |
| discord | n. 不和,纷争,不协调;不协和音 | dis（不）+cord（心，同 cordial 热诚）→心不齐=不和纷争。 |
| concurrent | adj. 并存的,同时发生的 | con（共同）+current（流动）→一起流动=同时发生的。 |
| ratify | vt. 批准,正式签署 | 与 rate（评估）同源→评估认可后正式批准。 |
| jockey | n. 赛⻢骑师 vi. 用计谋获取 (利益、好处等) | 画面联想：骑师 jockey 骑在赛马上；动词=使计谋抢占。 |

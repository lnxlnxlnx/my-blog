# 词 1401–1440

> 📅 09月30日 Wednesday · 词 1401–1440 · PDF 第 71–72 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| outbreak | n. (暴力活动、疾病等的) 爆发 | out 出 + break 破，疾病"破壳而出" = 爆发 |
| editorial | n. (报纸的) 社论 adj. 编辑的,主编的,编者的 | editor 编辑 + ial，主编执笔的文章 = 社论 |
| headline | n. (报纸的) 大字标题;重要新闻 vt. 以...为标题,以...为主要故事 vt. vi. (演出等中的) 主演,主唱 | head 头 + line 行，报纸最顶头的大字 = 标题 |
| pot | n. 锅;罐;壶;凑集的资金;大麻 vt. 把...栽入盆中;击 (球) 入袋 | pots and pans 锅碗瓢盆，pot = 锅、罐 |
| rot | vi. vt. (使) 腐烂 n. 腐烂,腐烂物;衰败;废话 | 放久的西红柿 rot 烂掉 = 腐烂 |
| roar | vi. 吼叫,轰鸣;放声大笑 vi. vt. 咆哮,大声喊叫 n. 咆哮,吼叫;呼啸声,隆隆声 | 狮子张嘴 roar 咆哮 = 吼叫、轰鸣 |
| undoubtedly | adv. 毫无疑问地,确实地 | un 不 + doubt 怀疑，连怀疑都不用 = 毫无疑问 |
| constrain | vt. 限制,约束;强迫,迫使 | strain 拉紧 + con，把自由拉紧 = 约束、强迫 |
| spy | n. 间谍,密探 vi. 从事间谍活动,搜集情报 vt. 突然看⻅,发现 | spy 悄悄刺探情报 = 间谍；spy 一眼发现 |
| drain | vt. vi. 排空,(使) 放干;(使) 流走 vt. 喝光;使 (精力、钱) 耗尽 n. 下水道;排水孔;消耗,耗竭 | 与 dry 干同源，把水弄干 = 排干；下水道 |
| breach | n. 违背,破坏;(关系) 中断;缺口 vt. 违反,破坏;在...上打开缺口 | break 破同源，城墙破口 = breach；违约 |
| mill | n. 磨坊;工厂;磨粉机 vt. 碾碎,磨成粉 | windmill 风车磨坊，mill = 磨坊、磨粉 |
| treaty | n. 条约,协定 | treat 处理 + y，国与国"谈"出的文件 = 条约 |
| customs | n. 海关;(进口) 关税 | custom 习俗的复数，进出口"惯例"关卡 = 海关 |
| terminate | vt. vi. (使) 结束,(使) 终止 vi. 到达终点 | term 界限 + inate，画上句号到界限 = 终止 |
| nickel | n. 镍;(美国和加拿大) 五分硬币 | 美国五分硬币 nickel 是镍做的 = 镍、五分币 |
| cafeteria | n. 自助餐厅,⻝堂 | cafe 咖啡馆 + teria，自己端盘子的餐厅 = 自助餐厅 |
| compassion | n. 同情,怜悯 | com 共同 + passion 感情，感同身受 = 同情 |
| agriculture | n. 农业,农学 | agri 田地 + culture 耕作，种田的学问 = 农业 |
| resign | vi. vt. 辞职 vt. 使顺从 | re 回 + sign 签名，递辞呈签字 = 辞职 |
| culminate | vi. 以...告终,达到...的顶点 | 词根 culmin 顶端(column 柱同源)，爬到顶点 = 以...告终 |
| reputation | n. 名誉,名声 | re 反复 + put 想(compute 同源)，众人反复评价 = 名声 |
| exile | n. 流放,流亡;被流放者 vt. 流放,放逐 | ex 出 + ile，被赶出国门 = 流放、流亡 |
| discriminate | vi. 歧视,区别对待 vi. vt. 区分,辨别 | 把人分三六九等对待 = 歧视；分出差别 = 区分 |
| unify | vt. vi. 使统一,使成一体 | uni 一(unit 同源)+fy 使，使成一体 = 统一 |
| goodness | n. 善良,美德;(⻝物中的) 营养 int. (表示惊讶) 天哪 | good 好 + ness，好品质 = 善良；Oh my goodness 天哪 |
| air- | n. 空调系统 | air 空气，air conditioning 空调的缩写 = 空调系统 |
| regarding | prep. 关于,至于 | regard 看待 + ing，就...而言 = 关于 |
| ascribe | vt. 将...归因于;认为是...的特点 | scribe 写(describe 同源)，把功劳"记在"名下 = 归因于 |
| suspicion | n. 怀疑,嫌疑,猜疑;猜想,预感 | spic 看(suspect 同源)，斜眼打量 = 怀疑、嫌疑 |
| testify | vi. vt. (出庭) 作证;证实,证明 | test 证据 + ify 说，法庭上拿证据说话 = 作证 |
| obscure | adj. 鲜为人知的;难以理解的 vt. 掩盖,使模糊,使隐晦 | ob 遮盖 + scure，被遮住看不清 = 模糊、鲜为人知 |
| chunk | n. 厚块;大量,大部分;语块 | 砍下的一大 chunk 肉块 = 厚块、大量 |
| junction | n. 汇合点,交叉路口 | junct 连接(joint 同源)，道路相连处 = 交叉路口 |
| dirt | n. 灰尘,污物;(泥) 土;丑闻 | dirty 脏的名词形式，脏东西 = 灰尘、泥土 |
| constituent | n. 成分;选⺠ adj. 构成的,组成的 | constitute 构成同源，构成部分 = 成分；投票选民 |
| belt | n. 腰带,皮带;传送带;地带 vt. 抽打,狠打 | seatbelt 安全带，belt = 腰带；工业 belt 地带 |
| gallery | n. 展览馆,画廊;走廊,⻓廊 | 美术馆 gallery 墙上挂满画 = 展览馆、长廊 |
| overhead | adv. 在头顶上,在空中 adj. 在头顶上,在空中的;经营开支的 n. 经营开支 | over 上 + head 头，头顶上；公司开支压头顶 |
| reserve | vt. 预订,预约;预留;保留 (权利) n. 储备 (量);自然保护区;内向 | serve 留，先"留"起来 = 预订、储备 |

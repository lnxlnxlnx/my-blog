| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| mankind | n. 人类 | man 人 + kind 种类 → 人类 |
| qualify | vt. 使合格,使具备资格 vi. 取得资格 (或学历),合格 vi. vt. (使) 有资格,(使) 有权;配得上 | quality 质量 → qualify 使达标 → 合格、有资格 |
| oval | adj. 椭圆形的 n. 椭圆形,椭圆形物体 | 字母 o 就是椭圆 → oval 椭圆形的 |
| flee | vi. vt. 逃离,逃避 | 联想 fleet 飞快 → flee 飞快逃离 |
| levy | n. 征收额,(尤指) 税款 vt. 征收,征 (税) | lev 举起（elevate 升高）→ 征收税 |
| warfare | n. 战争;冲突 | war 战争 + fare → 战争、冲突 |
| shelf | n. 架子;暗礁,大陆架 | 书架 shelf 放书 → 架子 |
| palm | n. 手掌,手心;棕榈树 vt. 把...藏在手中 (尤指玩戏法) | 手掌 palm；棕榈叶如掌 palm → 手掌、棕榈 |
| crisp | adj. 脆的,酥脆的;挺括的;凉爽的 n. 炸薯片;水果酥 vi. vt. (使) 变脆 | 薯片咬一口 crisp 脆响 → 脆的、酥脆 |
| erode | vt. vi. (使) 侵蚀,(使) ⻛化;逐步削弱 | rod 咬（rodent 啮齿类）→ 一点点咬掉 → 侵蚀 |
| forth | adv. (从某时) 往前,(从某处) 向外 | and so forth 等等 → forth 向前、向外 |
| recipe | n. ⻝谱,烹饪法;原因,秘诀 | 食谱 recipe 是烹饪秘诀 → 食谱、秘诀 |
| expire | vi. (协议等) 到期,失效;死亡 | spire 呼吸（respire 呼吸）→ 气尽 → 到期、死亡 |
| swallow | vt. vi. 吞下,咽下 vi. (由于紧张等) 做吞咽动作 vt. 吞没,淹没;信以为真;掩饰 n. 燕子;咽,一口 | 燕子 swallow 吞虫子 → 吞下；燕子 |
| tangle | vt. vi. (使) 缠结在一起,(使) 乱成一团 n. 缠结的一团;混乱,纷乱 | 耳机线 tangle 缠成团 → 缠结、混乱 |
| combat | n. 战斗,搏斗 vt. 与...作斗争,打击,战斗 | bat 打（battle 战斗）→ 战斗、搏斗 |
| inhibit | vt. 抑制,阻碍;使拘束 | hibit 拿（exhibit 展出）→ 拿住不放 → 抑制 |
| famine | n. 饥荒 | fam 饿（famish 挨饿）→ 大范围挨饿 → 饥荒 |
| accessory | n. 配件,附属品;配饰;帮凶 | 配饰 accessory 附加于主体 → 配件、帮凶 |
| vacuum | n. 真空;空虚,空白;真空吸尘器 vt. vi. 用真空吸尘器打扫 | 谐音'挖空' → 真空、空虚 |
| dial | vt. vi. 拨号 n. 表盘,刻度盘,仪表盘 | 老电话 dial 转盘拨号 → 拨号、表盘 |
| ache | vi. 疼痛;渴望 n. 疼痛 | headache 头痛 → ache 疼痛 |
| proportion | n. 部分,份额;比例;匀称;规模 | portion 部分 → 各部分之比 → 比例 |
| bounce | vi. vt. (使) 弹起,弹跳;拒付 (支票) vi. (在...上) 跳动,蹦;颠簸行进 vt. 把小孩放在膝上颠着玩;解雇 n. 弹跳,跳动;弹性;活力;蓬松 | 球 bounce 弹起 → 弹跳、活力 |
| resent | vt. 怨恨,憎恶 | sent 感觉（sense）→ 反感 → 怨恨 |
| nail | n. 钉,钉子;指甲,趾甲 vt. 钉牢;抓住并证明有罪;揭发 | 钉子 nail 钉住；指甲 nail → 钉子、指甲 |
| cure | vt. 治愈,治好;解决;矫正 n. 药物,疗法;治疗;对策,措施 | 医生 cure 治好病 → 治愈、疗法 |
| sanctuary | n. 禁猎区;避难;庇护所;圣殿 | sanct 神圣（saint 圣徒）→ 圣殿、庇护所 |
| garage | n. ⻋库;汽⻋修理厂 vt. 把...送入⻋库 (或修⻋厂) | car 车 → 放车的地方 → 车库、修车厂 |
| consolidate | vt. vi. (使) 加强,(使) 巩固;(使) 合并 | solid 坚固 → 使更坚固 → 巩固、合并 |
| tire | n. 轮胎 vi. vt. (使) 疲劳,疲倦 | 轮胎 tire 磨久人 tire 疲劳 → 轮胎、疲劳 |
| aggregate | n. 总数,集合体;⻣料 adj. 总数的,合计的 vt. 总计达到,使聚集 | greg 群（segregate 隔离）→ 聚成群 → 总数 |
| advertise | vi. vt. 为...做广告;(在报纸等上) 征聘 vt. 宣扬,宣传 | vert 转 → 让目光转过来 → 做广告 |
| stun | vt. 使震惊;使昏迷;使印象深刻 | 一棒 stun 打昏 → 使震惊、使昏迷 |
| cocaine | n. 可卡因,古柯碱 | 谐音'可卡因' → 可卡因 |
| impulse | n. 冲动;脉冲;推动力 | pulse 脉搏 → impulse 冲动、脉冲 |
| statistic | n. 统计数字 (或资料);统计学 | state 国家统计 → statistic 统计数字 |
| friction | n. 摩擦,摩擦力;矛盾,不和 | 摩擦 friction 生热生矛盾 → 摩擦、不和 |
| certificate | n. 证明,证书;结业证书 | cert 确定（certain）→ 凭证 → 证书 |
| defeat | vt. 击败,战胜;挫败,使落空 n. 战败,失利;击败,战胜 | feat 做 → 使做不成 → 击败、挫败 |

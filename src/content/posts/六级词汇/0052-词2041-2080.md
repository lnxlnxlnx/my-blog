## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| layout | n. 布局,设计 | lay 摆放 + out → 布局设计 |
| mute | adj. 沉默的,无声的;哑的 n. 弱音器;哑巴 vt. 消音,减音;减弱,缓解 | 会议软件 mute 静音键 → 沉默、消音 |
| anguish | n. 极度痛苦 | 联想"哀"音：anguish 哀痛到极点 = 极度痛苦 |
| downstairs | adv. 往楼下,在楼下 adj. 在楼下的,在底楼的 n. 底楼,楼下 | down + stairs → 往楼下 |
| plaza | n. 广场,集市;购物中心 | shopping plaza 购物广场 |
| tug | vi. vt. 拉,拖,拽 n. 拖船;猛拽;一股强烈的感情 | 拔河 tug-of-war 两边猛拽 tug |
| morale | n. 士气,精神面貌 | 打了胜仗士气 morale 高涨 |
| princess | n. 公主;王妃;被宠坏的大小姐 | prince（王子）+ ess（女性）→ 公主 |
| thrift | n. 节约,节俭;海石竹 | 谐音"省福"：节俭省钱就是福 |
| corps | n. 特种部队;一组人;军,兵团 | 发音同 core（核心）：特种部队是军中核心 |
| conspire | vi. 密谋,图谋;导致,造成 | con 共同 + spire 呼吸（spirit 同源）→ 同呼吸密谋 |
| vulgar | adj. 粗俗的,俗气的;下流的 | 谐音"俗"：vulgar 粗俗、俗气不入流 |
| relish | vt. 享受,从...获得乐趣 n. 享受;调味酱,佐料 | 蘸着 relish 酱享受美食 → 享受、乐趣 |
| plumber | n. 水暖工,水管工 | 谐音"泼了么"：水管漏水泼一地，快叫 plumber |
| sunset | n. 日落 (时分),傍晚;晚霞 adj. 定期废止的 | sun + set（落下）→ 日落 |
| foremost | adj. 最重要的,最好的 adv. 最重要地,首要地 | fore 前 + most 最 → 最前面的 = 最重要 |
| clay | n. 黏土,陶土 | 画面：clay 黏土湿湿黏黏，捏陶罐 |
| soothe | vt. 安慰,使平静;减轻 (疼痛等) | 谐音"舒适"：轻轻安抚，让人舒服平静 |
| comb | n. 梳子 vt. 梳,梳理 vt. vi. 仔细搜索,搜寻 | 画面：comb 梳子梳头；翻箱倒柜地 comb 搜索 |
| foretell | vt. 预言 | fore 预先 + tell 说 → 预言 |
| saddle | n. ⻢鞍;⻋座;脊肉 vt. vi. 给...配鞍;使肩负重担 | 画面：saddle 马鞍架在马背上；背上重担 |
| beckon | vi. vt. (招手或点头) 示意;引诱 vi. 可能发生 | 谐音"呗肯"：招手 beckon 示意"过来呗" |
| veil | n. 面纱,面罩;掩饰,借口 vt. 戴面纱,戴面罩;掩饰 | 画面：新娘 veil 面纱遮脸 → 掩饰 |
| shit | int. (表示恼怒) 该死 n. 粪便;拉屎;胡扯;讨厌的人 vi. vt. 拉屎 | 谐音"屎"：本义粪便；俚语表恼怒的粗口 |
| scrub | vt. vi. 擦洗,刷洗 vt. 取消 (原有安排) n. 擦洗,刷洗;灌木丛;手术衣 | 画面：用力 scrub 刷洗地板；取消原计划 |
| overthrow | vt. 推翻,打倒,将...赶下台 n. (尤指用武力的) 推翻,打倒 | over 翻 + throw 扔 → 推翻 |
| exterior | n. 外部,外观;外表,外貌 adj. 外面的,外部的 | exter 外（对比 interior 内）→ 外部 |
| folklore | n. ⺠间传说,⺠俗 | folk 民间 + lore 知识 → 民间传说 |
| sportsman | n. 运动员;戶外运动爱好者 | sports + man → 运动员 |
| merchandise | n. 商品,货品 vt. 推销,(运用广告等进行) 销售 | merchant（商人）同源 → 商人的货 = 商品 |
| wrinkle | n. 皱纹;皱褶 vt. vi. (使) ⻓皱纹;(使) 起皱,起褶 | 谐音"纹扣"：脸上 wrinkle 皱纹、衣服皱褶 |
| rag | n. 抹布,破布;破旧衣服;小报 vt. 嘲笑,捉弄 | 画面：rag 破布抹布；穿得破破烂烂 rags |
| renaissance | n. 文艺复兴 (时期);重新流行 | re 再 + naiss 生（nascent 同源）→ 文化重生 = 文艺复兴 |
| gum | n. 口香糖;牙龈,牙床;树㬵,树脂 | 嚼 gum 口香糖"嘎吱"响；牙龈 gum |
| debut | n. 首次登台,初次亮相 vi. 首次登台,初次亮相 vt. 首次推出 | 源自法语"初次"：debut 首次登台 |
| pale | adj. (肤色) 苍白的;浅的;黯淡的 vi. 变得苍白;黯然失色 | 画面：吓得脸色 pale 苍白 |
| waterproof | adj. 防水的,不透水的 | water + proof（防…的）→ 防水 |
| sacred | adj. 上帝的,神圣的;受尊重的 | 词根 sacr = 神圣（sacrifice 献祭同源）→ 神圣的 |
| negligent | adj. 疏忽的,粗心大意的 | 同源 neglect（忽略）→ negligent 疏忽大意 |
| blonde | adj. (头发) 金色的;(人) 有金发的 n. 金发女郎 | blond 加 e 变女性 → blonde 金发女郎 |

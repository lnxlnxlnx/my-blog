## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| hive | n. 蜂房;蜂群;繁忙的地方;荨麻疹 | 画面联想：蜜蜂 hive 蜂巢嗡嗡响；繁忙之地也叫 hive。 |
| topple | vi. vt. (使) 不稳而倒下,(使) 摇摇欲坠 vt. 推翻 (当权者) | top（顶）+ple→从顶上翻下来=topple 倒塌、推翻。 |
| yacht | n. 游艇,大型帆船 | 音译联想：yacht 游艇，富豪开着出海兜风。 |
| webcast | n. 网络直播 | web（网络）+cast（播出）→网络直播。 |
| stout | adj. (人) 肥壮的;结实的;坚决的 n. (烈性) 黑啤酒 | 画面联想：stout 又矮又壮的人；烈性黑啤也叫 stout。 |
| clown | n. 小丑;傻瓜 vi. 装傻,做蠢事 | 画面联想：红鼻子小丑 clown 逗人发笑。 |
| beetle | n. 甲虫 vi. 快速移动 | 甲壳虫乐队 Beatles 的名字就来自 beetle 甲虫。 |
| armor | n. 盔甲;装甲;装甲⻋辆 | 与 arm（武器）同源→护身的盔甲、装甲。 |
| shave | vi. vt. 刮胡子,刮脸 vt. (少量地) 削减,调低,降低 n. 刮胡子,刮脸 | 画面联想：早晨 shave 刮胡子；价钱也 shave 削减。 |
| immigrate | vi. (从外国) 移居,作为移⺠定居 | im（进入）+migrate（迁徙）→迁入别国定居=移居。 |
| camel | n. 骆驼;驼毛,驼绒 | 画面联想：沙漠之舟 camel 骆驼驮着货物赶路。 |
| partisan | adj. 偏袒的,盲目拥护的 n. 坚定的支持者;游击队员 | party（党派）→只站党派一边=偏袒的；游击队 partisan。 |
| illicit | adj. 非法的,违禁的 | il（不）+licit（许可，同 license）→未经许可=非法的。 |
| homosexual | n. 同性恋者 adj. 同性恋性向的 | homo（相同）+sexual（性）→同性恋的。 |
| meadow | n. 草地,牧场 | 画面联想：牛羊在 meadow 草地上悠闲吃草。 |
| kneel | vi. 跪下,跪着 | knee（膝盖）+l→膝盖着地=跪下。 |
| overhear | vt. 偶然听到,无意中听到 | over（越过）+hear（听）→隔墙无意中听到。 |
| appraise | vt. 估量,估价;做出评价;打量 | 与 praise（称赞）同源→评估价值、做出评价。 |
| plaintiff | n. 原告,起诉人 | plaint（诉苦）+iff→向法庭诉苦的人=原告。 |
| angel | n. 天使;善良或美丽的人;大好人 | 音译「安琪儿」：angel 天使。 |
| bowel | n. 肠;深处,内部 | 谐音「饱了」：吃饱了肠子蠕动着消化。 |
| outlaw | vt. 使...不合法,全面禁止 n. 不法之徒,被剥夺法律权益者 | out（外）+law（法律）→法律之外的人=不法之徒；动词=宣布非法。 |
| tribune | n. (古罗⻢) 护⺠官;论坛 | 古罗马护民官 tribune 保护平民；tribunal 法庭同源。 |
| stewardess | n. 女乘务员 | steward（乘务员）+ess（女性后缀）→女乘务员。 |
| wharf | n. 码头 | 画面联想：货船停靠 wharf 码头卸货。 |
| ox | n. 阉牛,(泛指) 牛 | Oxford（牛津）里就有 ox，ox=公牛、牛。 |
| merry | adj. 欢乐的,愉快的 | Merry Christmas=圣诞快乐，merry=欢乐的。 |
| ruthless | adj. 无情的,残酷的 | ruth（怜悯）+less（无）→毫无怜悯=无情残酷。 |
| comrade | n. 同志;朋友,战友 | 词根 com=同室（同 camera）→同住一室=同志战友。 |
| lame | adj. 瘸的;无说服力的;差劲的 vt. 使 (人或动物) 跛,使残废 | 画面联想：lame 一瘸一拐；借口 lame 站不住脚。 |
| consulate | n. 使馆,领事馆 | consul（领事）+ate→领事办公处=领事馆。 |
| beak | n. ⻦嘴,喙;鹰钩鼻 | 画面联想：小鸟 beak 尖尖的喙啄食。 |
| militant | adj. 好战的,激进的 n. 好战分子,激进分子 | 与 military（军事）同源→好战、激进的分子。 |
| mug | n. ⻢克杯,大杯;人脸 vt. (公然) 行凶抢劫 | 音译「马克杯」：mug 大杯子；动词=当街抢劫。 |
| hibernate | vi. 冬眠 | 词根 hibern=冬季→动物过冬睡大觉=冬眠。 |
| lotion | n. 洁肤液,护肤液,润肤乳 | 画面联想：洗完脸涂 lotion 润肤乳保湿。 |
| vapor | n. 蒸气,水汽 | 与 evaporate（蒸发）同源→水汽、蒸气。 |
| banknote | n. 纸币,钞票 | bank（银行）+note（票据）→银行发行的票据=纸币。 |
| zigzag | n. 锯⻮形线条,之字形 adj. 之字形的,锯⻮形的,曲折的 vi. 曲折前进 | 拟形词：zig-zag 之字形曲折前进。 |
| boxing | n. 拳击 (运动) | box（拳头）+ing→用拳头对打=拳击运动。 |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| alleviate | vt. 减轻,缓解 (痛苦等) | 词根 lev=轻(同 lever)→变轻,减轻痛苦 |
| confront | vt. 直面,正视;使面对;对峙;对质 | con(一起)+front(前)→面对面,正视 |
| kindergarten | n. 幼儿园 | 德语 kinder(儿童)+garten(园)→幼儿园 |
| escalate | vi. vt. (使) 不断恶化;(使) 扩大,增加 | 同 scale(阶梯)→上台阶,升级 |
| radical | adj. 根本的,彻底的;激进的 n. 激进分子;游离基 | 词根 radic=根(同 radish)→根本;激进 |
| flatter | vt. 奉承,讨好;使...显得更好 | 联想"服了他"→奉承得服服帖帖 |
| perish | vi. 死亡;湮灭,毁灭 vi. vt. (使橡㬵等) 老化 | 谐音"怕你死"→死亡,毁灭 |
| solo | n. 独唱,独奏,独舞;单人活动 adj. 独自的,单独的;独唱的,独奏的 adv. 独自地,单独地;独唱地,独奏地 vi. 独唱,独奏;单独进行 | 同 sole(唯一)→一个人独奏 |
| cumulative | adj. 累加的,积累的 | 同 accumulate(积累)→累加的 |
| incidence | n. 发生 (率) | 同 accident 词根 cad=落→发生,发生率 |
| lane | n. 小路;小巷;⻋道;航线;跑道 | 联想一条条车道→车道;航线 |
| petroleum | n. 石油 | petro(石)+oleum(油)→石油 |
| maid | n. 女仆,侍女;少女 | 谐音"美的"→年轻少女;女仆 |
| manifest | vt. 显现,表明 adj. 明显的 n. 载货单,旅客名单 | mani(手)+fest(击)→用手打出来,显现 |
| presume | vi. vt. 推测,猜测 vt. (尤指法庭上) 推定,假定;假设 vi. 妄行,越权行事 | pre(提前)+sume(拿,同 assume)→预先拿定,推测 |
| hectic | adj. 忙碌的,繁忙的 | 联想忙到天黑→忙碌,繁忙 |
| intimidate | vt. 恐吓,威胁 | in+timid(胆小)+ate→使胆小,恐吓 |
| hemisphere | n. (地球的) 半球;(脑的) 半球 | hemi(半)+sphere(球)→半球 |
| amateur | n. 业余爱好者,外行 adj. 非职业的,业余的 | 谐音"爱摸着"→业余爱好者摸着练 |
| dissertation | n. (尤指) 学位论文 | 同 assert 词根 sert=说→长篇论述,学位论文 |
| multitude | n. 众多,大量;⺠众;人群 | multi(多)+tude→众多,大量 |
| sponsor | n. 赞助商,资助者;倡议者;保人 vt. 赞助,资助;举办;倡议 (法案) | 同 respond(回应)→出钱回应,赞助 |
| throat | n. 咽喉,喉咙 | 谐音"喉咙"→喉咙 |
| pension | n. 养老金,退休金;膳宿公寓 vt. 给...发养老金,使...退休 | 联想退休领养老金→养老金 |
| toe | n. 脚趾;足尖部;有...脚趾的 | 联想脚趾头→脚趾 |
| pathetic | adj. 可怜的,可悲的;差劲的 | 谐音"怕他死"→可怜可悲 |
| deduce | vt. 推断,推理,演绎 | de(下)+duce(引,同 produce)→引出来,推断 |
| yoghurt | n. 酸奶 | 谐音"优格"→酸奶 |
| rid | vt. 使摆脱,使消除,使丢弃 adj. 摆脱了的,丢弃了的 | 谐音"离的"→使摆脱,使离开 |
| bearing | n. 影响,关系;举止;方向;轴承 | bear(承受)+ing→轴承承受重量;举止 |
| bleak | adj. 没有希望的;阴冷的;荒凉的 | 联想荒原→荒凉,没有希望 |
| clinic | n. 诊所;⻔诊时间;研习班 | 联想小诊所→诊所 |
| cable | n. 缆绳,钢索;电缆;有线电视 vt. vi. (给...) 发电报 | 谐音"凯博"→电缆,缆绳 |
| amend | vt. 修订 (法律、文件等) | a+mend(修补)→修补法律,修订 |
| bore | vt. 使厌烦 vi. vt. 钻 (孔),挖 (洞) vi. 盯着看 n. 无趣的人;无聊的事;孔,口径 | 谐音"饱了"→听饱了,厌烦 |
| hostile | adj. 敌意的;反对的;(条件) 不利的 | 联想"吼死他"→充满敌意 |
| imprison | vt. 监禁,禁锢 | im(入)+prison(监狱)→关进监狱 |
| wary | adj. 小心的,提防的 | 谐音"畏"→畏而提防,小心 |
| voyage | n. 航行,航海,航天 vi. 航行,航海 | 联想航海远行→航行,航海 |
| carton | n. (装牛奶等的) 硬纸盒 | 谐音"卡通"→卡通图案的纸盒 |

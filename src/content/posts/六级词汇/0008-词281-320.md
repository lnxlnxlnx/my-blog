## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| linguistic | adj. 语言 (学) 的 | 词根 lingu=语言(language)→ 语言的 |
| momentum | n. 势头,冲劲;冲力;动量 | 滚雪球 momentum 势头 → 势头、动量 |
| trumpet | n. 喇叭,小号;喇叭形的东西 vt. 吹嘘,宣扬 vi. (大象) 吼叫 | 吹 trumpet 小号"嘟嘟"→ 喇叭 |
| shuttle | n. 航天⻜机;穿梭航班 (班⻋);梭 vi. 穿梭往返 vt. 短程往返运送 | space shuttle 航天飞机 → 穿梭 |
| neglect | vt. 疏忽,忽略;未做 (某事) n. 疏忽,(被) 忽略 | 词根 lect=选 → 没选到 = 忽略 |
| compartment | n. ⻋厢,舱;分隔间,隔层 | part 部分 → 分成一格一格 = 隔间 |
| advent | n. 到来,出现;降临节 | 词根 vent=来 → 来临 = 到来 |
| jack | n. 千斤顶;J 牌;插座 vt. vi. 偷,窃取 | 换轮胎用 jack 千斤顶 → 千斤顶 |
| brisk | adj. 轻快的;麻利的;凉爽的;兴隆的 | 联想: 步伐轻快如飞 = 轻快 |
| extinguish | vt. 熄灭,扑灭;毁灭,使破灭 | 灭火器 extinguish 火焰 → 熄灭 |
| integrity | n. 正直,诚实;完整,完全 | 同根 integer(完整)→ 完整、正直 |
| comprise | vt. 包括,由...组成;构成,组成 | 词根 pris=抓 → 全部抓在一起 = 包含 |
| debris | n. 残骸,碎片;残屑,垃圾 | 地震后遍地 debris 碎片 → 残骸 |
| ascertain | vt. 弄清,查明 | certain(确定)→ ascertain 查明、弄清 |
| carriage | n. ⻢⻋;火⻋⻋厢;运费;仪态 | car 车 → 马拉的车 = 马车 |
| leisure | n. 闲暇,空闲 | 谐音"累了"→ 累了享受闲暇 |
| intermittent | adj. 间歇的,断断续续的 | inter 之间 + mitt 送 → 中间停顿 = 间歇 |
| disturb | vt. 打扰,干扰;使烦恼;弄乱 | 词根 turb=搅(turbine)→ 搅乱 = 打扰 |
| elevate | vt. 提拔,提升;举起;提高;鼓舞 | 词根 lev=升(lever)→ elevate 提升 |
| thrill | n. 兴奋感,激动;一阵强烈的感觉 vt. 使非常兴奋 | 过山车 thrill 刺激 → 兴奋、激动 |
| verb | n. 动词 | noun 名词、verb 动词 → 动词 |
| huddle | vi. 挤在一起;缩成一团 n. 拥挤的一群,杂乱的一堆 | 企鹅挤成一团 huddle 取暖 → 挤在一起 |
| ornament | n. 装饰品;首饰,饰物;点缀 vt. 装饰,点缀 | 圣诞树 ornament 挂饰 → 装饰品 |
| elicit | vt. 引出,诱出,套出 | e 出 + 套出 → elicit 引出、诱出 |
| slack | adj. 松弛的;萧条的;懈怠的 n. (绳索的) 松弛部分 vi. 懈怠,偷懒 | 绳子 slack 松弛下垂 → 松弛、懈怠 |
| particle | n. 微粒;粒子;小品词 | part 部分 + icle 小 → 微粒 |
| habitat | n. 栖息地,生⻓地 | 联想 habit(习惯)→ 动物习惯待的地方 = 栖息地 |
| gauge | n. 测量仪器;宽度;口径;标准 vt. 判断 (尤指感受);测量;估算 | 油表 fuel gauge 测油量 → 仪表、测量 |
| summon | vt. 召唤;传唤出庭;召开;请求 | 七龙珠 summon 神龙 → 召唤 |
| converse | vi. (与...) 交谈 n. 相反的事物,相反的言论 adj. 相反的,逆的 | 词根 verse=转 → 来回对话 = 交谈 |
| banquet | n. 宴会,宴席 | 婚礼 banquet 婚宴 → 宴会 |
| patrol | vt. vi. 巡逻,巡查 vt. (尤指威胁性地) 逛荡,闲逛 n. 巡逻,巡查;巡逻队,巡逻⻋队 | patrol car 警车巡逻 → 巡逻 |
| infringe | vt. vi. 违反 (法律),侵犯 (权利) | in 入 + fringe 边缘 → 越界 = 侵犯 |
| volcano | n. 火山 | 庞贝城被 volcano 火山掩埋 → 火山 |
| sweat | n. 汗;出汗,流汗;累活儿;运动服 vi. vt. 出汗,流汗;焖 vi. 艰苦努力;担心,忧虑,不安 | 运动后大汗淋漓 = sweat 汗 |
| legacy | n. 遗产,遗赠;遗留问题 adj. (计算机系统等) 已停止更新的 | 留下 legacy 遗产给后人 → 遗产 |
| molecule | n. 分子 | 水分子 molecule(H₂O)→ 分子 |
| royal | adj. 皇家的,王室的;盛大的 n. 王室成员,皇族 | royal family 王室 → 皇家的 |
| syndrome | n. 综合征,综合症状;典型表现 | syn 共同 + drome 跑 → 一同出现的症状 |
| thesis | n. 论文,学位论文;命题,论点 | 毕业论文 thesis → 论文、论点 |

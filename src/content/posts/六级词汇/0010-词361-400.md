## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| behalf | n. 代表 (某人);为了...的利益 | on behalf of 代表某人 → behalf 代表 |
| scrutiny | n. 彻底审查,仔细检查 | 联想 scruple 顾虑 → 细查每一处 → 仔细审查 |
| tense | adj. 紧张的;令人紧张的;绷紧的 vt. vi. (使肌肉) 绷紧 n. (动词的) 时态 | 考试 tense 紧张；语法 tense 时态 → 紧张、时态 |
| safeguard | vt. vi. 保护,保障,捍卫 n. 安全设施,保护措施 | safe 安全 + guard 守卫 → 保护、保障 |
| nominal | adj. 名义上的;象征性的,很少的 | nomin 名字（name 同源）→ 只挂个名 → 名义上的 |
| valve | n. 阀⻔,气⻔;瓣膜;(乐器) 阀键 | 谐音'阀' → 水管阀门、心瓣膜 |
| pine | n. 松树;松木 vi. (因死亡、离别而) 悲伤 | 松树 pine 常青；为离别而 pine 憔悴 → 松树、悲伤 |
| chore | n. 家务活;令人厌烦的工作 | 谐音'吵' → 家务活干得人想吵 → 家务、苦差 |
| notion | n. 观念,理念,看法 | note 记下 → 心中的想法 → 观念、看法 |
| interior | n. 内部;内地,内陆;内政 adj. 内部的 | inter 内（internal 同源）→ 内部、内地 |
| album | n. 专辑,唱片;相册,集邮簿 | albus 白（albino 白化）→ 空白册子 → 相册、专辑 |
| labor | n. 劳动;劳动力;分娩;英国工党 vi. 努力做 (困难的事);干苦力活 | labor 劳动；分娩是'辛苦劳动'；英国工党叫 Labor |
| irrigate | vt. 灌溉;冲洗 (伤口) | 联想 irrig 浇水 → 灌溉田地 |
| stale | adj. 不新鲜的;没有新意的;厌倦的 vi. vt. (使) 变得不新鲜 | 陈面包 stale 放久了 → 不新鲜、无新意 |
| oak | n. 橡树,栎树;橡木,栎木 | 橡木 oak 做酒桶 → 橡树、橡木 |
| stripe | n. 条纹,线条;军阶条;种类 | 老虎身上的 stripe 条纹 → 条纹、军阶条 |
| augment | vt. 增大,增加,加强 | 词根 aug 增大 → 增大、增加、加强 |
| conserve | vt. 节约,节省;保护,保存 n. 果酱,蜜饯 | con + serve 保存 → 节省、保护；蜜饯也是'存' |
| curriculum | n. 课程 | cur 跑（course 课程）→ 要'跑'完的课程 |
| rear | n. 后部 adj. 后面的,后部的 vt. 抚养,养育;饲养 vi. (尤指⻢) 用后腿直立;巍然耸立 | 车 rear 后部；rear 把孩子养大 → 后部、抚养 |
| deprive | vt. 剥夺,使不能享有 | de 去掉 + private 私人 → 夺走 → 剥夺 |
| guilt | n. 内疚,悔恨;犯罪,罪行 | 犯罪 guilt 后内疚 → 罪行、内疚 |
| bacteria | n. 细菌 | 显微镜下像小杆菌 bacteria → 细菌 |
| euro | n. 欧元 | Europe 欧洲 → euro 欧元 |
| pharmacy | n. 药房,药店;药剂学,配药学 | pharma 药学词根 → 药房、药剂学 |
| melt | vi. vt. (使) 融化,熔化;使心软 | 冰激凌 melt 化掉 → 融化、使心软 |
| fox | n. 狐狸;狐皮;狡猾的人;美人 vt. 难住,使迷惑 | 狐狸 fox 狡猾 → 狡猾的人 |
| meantime | adv. 在此期间,与此同时 n. (在此) 期间,其间 | mean 中间 + time 时间 → 其间、与此同时 |
| whale | n. 鲸 vi. 捕鲸 vi. vt. 大力击打 | 鲸 whale 喷水柱 → 鲸 |
| defend | vt. vi. 防御,保卫;防守;为被告辩护 vt. 为...辩护;卫冕 | fend 挡（fence 篱笆）→ 挡在门外 → 防御、保卫 |
| census | n. 官方统计,人口普查 | 联想 censor 审查 → census 官方普查 |
| garbage | n. 垃圾;垃圾箱;废话 | garbage in, garbage out 垃圾进垃圾出 → 垃圾 |
| apartment | n. 公寓;套房 | part 部分 → 公寓是楼房的一部分 |
| dignity | n. 尊严,尊敬;自尊;庄重,体面 | dign 尊严（dignify 使尊荣）→ 尊严、体面 |
| coral | n. 珊瑚;珊瑚虫 adj. 珊瑚色的,粉红色的 | 海底珊瑚 coral 像树 → 珊瑚 |
| collaborate | vi. 合作,协作;勾结,叛国 | col 共同 + labor 劳动 → 一起干活 → 合作 |
| pastime | n. 消遣,娱乐 | pass 度过 + time 时间 → 消磨时光 → 消遣 |
| criterion | n. 标准,准则 | criteria 是复数 → criterion 标准、准则 |
| recur | vi. 再次发生,再次出现 | re 再 + cur 跑（occur 发生）→ 再次发生 |
| surplus | n. 过剩,过剩量;盈余,顺差 adj. 过剩的,剩余的 | sur 超 + plus 加 → 多出来的 → 过剩、盈余 |

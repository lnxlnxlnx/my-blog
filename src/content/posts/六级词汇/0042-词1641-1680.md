# 词 1641–1680

> 📅 10月06日 Tuesday · 词 1641–1680 · PDF 第 83–84 页 · 新词 40 · 复习 400 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| malignant | adj. (肿瘤) 恶性的;恶意的,恶毒的 | mal=坏 → 恶性肿瘤 malignant；对比 benign 良性 |
| temporal | adj. 时间的;世俗的;太阳穴的 | tempor=时间(temporary 临时同源) → temporal 时间的、世俗的 |
| repertoire | n. 全部节目,曲目;全部技能 | repertoire 谐音'任凭他'，任凭演员表演的全部曲目 |
| unanimous | adj. 一致通过的;意⻅一致的 | uni(一)+anim(心) → 一条心，全体一致通过 |
| rigid | adj. 严格的,死板的;固执的;僵硬的 | rigid 僵硬：木头人一板一眼，死板又固执 |
| legislate | vi. 立法,制定法律 | leg=法律(legal 合法同源) → legislate 制定法律，立法 |
| judicial | adj. 审判的,司法的,法庭的 | jud 词根=判断(judge 法官同源) → judicial 司法的 |
| emigrate | vi. 移居国外,移⺠ | e(出)+migrate(迁移) → 迁出去=移居国外；对比 immigrate 迁入 |
| mint | n. 薄荷;薄荷糖;造币厂 vt. 铸造 (硬币) | mint 薄荷糖清新；造币厂 mint 铸新币，都有'新'感 |
| synthesis | n. 综合,综合体;合成;电子合成 | syn(一起)+thesis(放置) → 合成在一起，综合 |
| fracture | n. 裂缝,裂痕,(尤指) ⻣折 vi. vt. (使) 断裂;(使)(组织等) 分裂 | fract=碎(fraction 碎片同源) → fracture 断裂骨折 |
| peel | vt. 剥皮,去皮 vi. vt. (表层) 脱落,剥去 (表层) vi. 脱皮,蜕皮 n. 果皮,外皮 | peel 谐音'皮'，剥掉果皮 peel |
| turmoil | n. 混乱,动荡 | turmoil 动荡：天下大乱，转个不停不得安宁 |
| pending | prep. 直到,在等待...期间 adj. 待定的,待决的;即将发生的 | pend 悬挂(pendulum 钟摆同源) → 事情悬着=pending 待定 |
| foil | n. 箔;箔纸;陪衬者;花剑 vt. 挫败,阻止 | foil 锡箔纸：巧克力包 foil；阴谋被 foil 挫败 |
| eyebrow | n. 眉毛 | eye(眼)+brow(眉骨) → 眉毛 |
| retrospect | n. 回顾,回想 | retro(向后)+spect(看) → 回头看，回顾 |
| coarse | adj. 粗糙的;大颗粒的;粗鲁的 | coarse 音似'糙'，粗糙的、粗鲁的 |
| downgrade | vt. 使降职,使降级;贬低,低估 n. 退步,下滑,下降 | down(向下)+grade(等级) → 降级 |
| cub | n. 幼兽;幼年童子军 | cub 幼兽：狮子老虎的崽 cub，圆滚滚的小不点 |
| counterfeit | adj. (钱币等) 伪造的,仿冒的 n. 仿品,赝品 vi. vt. 仿造,伪造 | counter(对着)+feit(做，同 fact) → 对着真钞造假 |
| affix | vt. 粘上,贴上,附上,使固定 n. 词缀 | fix(固定)加 af 朝向 → 粘上固定；词缀也 affix 附在词上 |
| caravan | n. 旅行拖⻋;大篷⻋;旅行队 | car(车)+avan → 旅行拖车大篷车 caravan |
| emancipate | vt. 解放,使不受束缚 | e(出)+man(手)+cip(拿) → 从手里放出，解放 |
| spice | n. (调味用) 香料;趣味,情趣 vt. 在...中加香料;给...增添趣味 | Spice Girls 辣妹组合 → spice 香料；给生活加 spice 趣味 |
| venue | n. (举办) 地点,场所 | ven(来，convenient 同源) → 大家来的地方=举办场所 venue |
| script | n. 剧本,讲稿;笔迹;答卷;脚本 vt. 为电影等写剧本;事先准备 | script 词根=写(describe 同源) → 写好的剧本、手稿 |
| tickle | vt. vi. 呵痒,胳肢;(使) 发痒 vt. 使高兴,使满足 n. 呵痒,胳肢;痒,痒感 | tickle 胳肢：tick 轻轻挠，痒得笑出声 |
| runway | n. (⻜机场的) 跑道;T台 | run(跑)+way(路) → 飞机跑的路=跑道 |
| locomotive | n. 机⻋,火⻋头 adj. 移动的,运动的 | loco(地方)+mot(移动) → 拉着地方跑的火车头 |
| idiot | n. 白痴,笨蛋 | idio(个人的) → 只想着自己的蠢人=白痴 |
| onset | n. 开始,开端 (尤指坏事) | on(上)+set(放置) → 事情开场=开端，常指坏事 |
| confederation | n. 联盟,联合体 | feder=盟约(federal 联邦同源) → confederation 联盟 |
| bribe | vt. 贿赂,收买 n. 贿赂,贿赂品 | 偷偷塞红包 bribe 贿赂官员 |
| bolt | n. 螺栓;(⻔窗) 插销;一道 (闪电) vt. vi. 闩上 (⻔、窗) vt. 用螺栓固定;狼吞虎咽 vi. (⻢等) 脱缰;(人) 跑开 | bolt 一道闪电劈下；门窗插销 bolt 闩上 |
| marble | n. 大理石;弹珠;弹子游戏 | marble 大理石；圆滚滚的弹珠也叫 marble |
| noun | n. 名词 | noun 与 name(名字)音近——名词是事物的名字 |
| sleeve | n. 袖子 | sleeve 袖子：have a card up your sleeve 袖中藏牌留一手 |
| inland | adv. 向 (或在) 内陆,向 (或在) 内地 adj. 内地的,内陆的 | in(内部)+land(陆地) → 内陆 |
| centimeter | n. 厘米 | centi(百，century 同源)+meter 米 → 百分之一米=厘米 |

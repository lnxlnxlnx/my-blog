## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| uncover | vt. 揭露,发现;揭开...的盖子 | un + cover 盖子 → 揭开盖子 = 揭露真相。 |
| elbow | n. 肘;(衣服的) 肘部 vt. 用肘推 | 记忆法:elbow 里有 bow(弓),手臂弯成弓形处就是肘。 |
| hijack | vt. 劫持 (⻜机、⻋辆等);控制,操纵 n. (⻜机、⻋辆等的) 劫持事件 | 经典联想:歹徒喊 “Hi, Jack!” 趁机劫持飞机。 |
| temper | n. 脾气;怒气;心情 vt. 使缓和;使 (金属) 回火 | 与 temperature 同源“适度”→ 调适缓和;lose temper 发脾气。 |
| justice | n. 公平,正义;法官;司法制度 | just 公正 + ice → 公平正义;法庭上主持的就是法官。 |
| loan | n. 贷款;暂借 vt. 借出 | 语境:向银行贷款 loan 买房,贷款要还本付息。 |
| timber | n. 树林;木材,木料;大梁 | 画面:森林伐倒的 timber 原木,盖房的大梁木材。 |
| crow | n. 乌鸦 vi. 啼叫,打鸣;(婴儿) 欢叫 vi. vt. 自鸣得意 | 拟声词:乌鸦 crow 啼叫,公鸡打鸣也叫 crow。 |
| inferior | adj. 较差的,较次的;级别低的 n. 下级,下属 | 反义 superior 优越 → inferior 较差的、级别低的下级。 |
| gesture | n. 手势,姿势;姿态,表示 vi. vt. 打手势,用手势表示 | 语境:说话时打手势 gesture,姿态表示友好。 |
| Thanksgiving | n. 感恩节 | thanks 感谢 + giving 给予 → 感谢上天给予 = 感恩节。 |
| cotton | n. 棉花;棉布;棉线;药棉 | 画面:棉花糖 cotton candy,软绵绵的棉花。 |
| discourage | vt. 打消...的念头,阻止;使灰心 | courage 勇气,dis 去掉 → 卸掉勇气 = 使灰心、劝阻。 |
| threat | n. 威胁;坏事发生的可能 | 语境:收到 threat 威胁信,扬言坏事会发生。 |
| portray | vt. 将...表现成;描绘,描写;扮演 | 同源 portrait 肖像画 → portray 描绘、刻画、扮演。 |
| statue | n. 雕像,雕塑 | 联想:status 地位,statue 立在广场的雕像,都源自“站立”。 |
| pesticide | n. 杀虫剂,农药 | pest 害虫 + cide 杀(suicide 自杀)→ 杀害虫的药 = 农药。 |
| inhabit | vt. 居住于,栖居在 | in 内 + habit 习惯 → 住习惯了 = 居住(habitat 栖息地)。 |
| disposition | n. 性情;倾向;布置,安排;处置 | position 位置,dis 分开摆放 → 布置;天生摆好的性情。 |
| tailor | n. 裁缝 vt. 定做 | 语境:裁缝 tailor 量体裁衣,为你定做衣服。 |
| dormitory | n. 宿舍,宿舍楼 | dorm 睡(dormant 休眠)→ 睡觉的地方 = 宿舍。 |
| shelter | n. 住处;庇护;避难处,收容所 vt. 保护,掩蔽 vi. 躲避 | 画面:暴风雨中 shelter 是避雨避难处,保护你。 |
| stare | vi. 盯着看,凝视 n. 盯着看,凝视 | 谐音联想:stare 像“死盯”,死死地盯着看。 |
| affluent | adj. 富裕的,富足的 | flu 流(fluid)→ 财富向里流 = 富裕的。 |
| imitate | vt. (为逗乐) 模仿;仿效,模拟 | 同源 image 形象 → 照样子做出 = 模仿、仿效。 |
| illiterate | adj. 文盲的;外行的 n. 文盲 | literate 识字(literature 文学),il 否定 → 不识字 = 文盲。 |
| frontier | n. 国界,边界;(知识的) 前沿 | front 前面 → 最前线 = 边疆;(知识)前沿。 |
| broke | adj. 身无分文的,破产的 | 联想:账本被 break 破了 → 身无分文 = broke 破产。 |
| inform | vt. 通知,告知;了解;影响 | 同源 information 信息 → 把信息告诉人 = 通知。 |
| wed | vi. vt. (与...) 结婚 | 同源 wedding 婚礼 → wed = 结婚。 |
| eyesight | n. 视力 | eye 眼 + sight 看 → 眼睛看东西的能力 = 视力。 |
| feasible | adj. 可行的,行得通的 | 同源 fact 做 → 做得成的 = 可行、行得通。 |
| acquaint | vt. 使熟悉,使了解 | 同源 acquaintance 熟人 → 使熟悉、使了解。 |
| indignant | adj. 愤慨的,愤怒的 | dignity 尊严,in 否定 → 伤了尊严 = 愤慨的。 |
| havoc | n. 灾害,祸患,浩劫 | 语境:wreak havoc 造成浩劫,天灾人祸横行 = 大破坏。 |
| collar | n. 衣领,领子;(动物的) 项圈 vt. 抓住,逮住 | 画面:抓猫抓 collar 项圈;抓人衣领 collar 就是逮住。 |
| primitive | adj. 原始的;落后的;原始本能的 n. 原始派艺术家 | prim 第一(primary)→ 最早的阶段 = 原始的、落后的。 |
| underlie | vt. 构成...的基础,作为...的原因 | under 下 + lie 躺 → 躺在下面支撑 = 构成基础。 |
| joy | n. 喜悦;令人高兴的事 (或人) | 画面:《头脑特工队》的主角 Joy 就是快乐本尊 = 喜悦。 |
| optimism | n. 乐观,乐观主义 | optim 最好(optimum 最优)→ 总往最好处想 = 乐观。 |

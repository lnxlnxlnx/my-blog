| chest | n. 胸部,胸膛;大箱子 | chest 胸膛 → 胸部、箱子 |

| latitude | n. 纬度;纬度地区;余地,自由 | lateral 横向 → latitude 纬度、余地 |

| fool | n. 傻瓜,笨蛋;小丑,弄臣 vt. 欺骗,愚弄 vi. 说蠢话,干傻事 adj. 傻的,愚蠢的 | 愚人节 April Fool → 傻瓜 |
| antibiotic | n. 抗生素 adj. 抗生素的 | anti 抗 + bio 生命 → 抗生素 |
| bewilder | vt. 使困惑,使糊涂 | 联想 wild 野 → 被搞晕 → 使困惑 |
| diploma | n. 毕业文凭,学位证书;文凭课程 | diplomat 外交官 → diploma 文凭 |
| revive | vt. vi. (使) 苏醒,(使) 复活 vt. 使...复兴;重新上演 | viv 活（vivid 生动）→ 再活过来 → 复苏 |
| equivalent | adj. 等同的,等值的,相当的 n. 等价物,等效物,对应词 | equi 等（equal）+ val 值 → 等价的 |
| sprawl | vi. 摊开四肢躺着;无序扩张 n. 杂乱扩张的地区;无序扩张 | 瘫在沙发上 sprawl → 摊开四肢 |
| retort | vt. 反驳,回嘴 n. 回应,反驳;曲颈瓶,蒸馏器 | tort 扭（torture 折磨）→ 顶回去 → 反驳 |
| conceive | vt. vi. 想象,想出,构想;怀孕 | ceive 拿（receive 收到）→ 心里想出 → 构想、怀孕 |
| boil | vi. vt. (使) 沸腾,烧开;烹煮 vi. 怒火中烧 n. 沸腾,沸点;疖,⻩水疮 | 水烧开 boil → 沸腾 |
| dismay | n. 沮丧,忧虑 vt. 使担心,使失望 | dismay 使气馁 → 沮丧、忧虑 |
| equity | n. 公平;资产净值;股票 | equi 相等 → 公平；净资产 |
| exaggerate | vi. vt. 夸张,夸大 | agger 堆 → 堆过头 → 夸张 |
| panic | n. 恐慌,惊慌失措;恐慌局面 vi. vt. (使) 惊慌失措 | 谐音'怕你' → 恐慌、惊慌 |
| inn | n. 小旅馆,小客栈,小酒馆 | inn 小旅馆 → 客栈 |
| mingle | vt. vi. (使) 混合,(使) 相混 vi. (社交场合) 应酬,交际 | 联想 mix 混合 → 混合、应酬 |
| deploy | vt. 部署,调度;有效运用,利用 | ploy 折叠（employ 雇佣）→ 展开部署 |
| exert | vt. 施加,运用,行使;努力,竭力 | sert 放（insert 插入）→ 使出 → 施加 |
| urine | n. 尿,小便 | 联想 urea 尿素 → urine 尿 |
| spouse | n. 配偶 | 联想 espouse 嫁娶 → spouse 配偶 |
| sensation | n. 知觉,感觉能力;直觉;轰动 | sense 感觉 → sensation 轰动 |
| youngster | n. 儿童,年轻人,幼小动物 | young 年轻 + ster → 年轻人 |
| barren | adj. 贫瘠的,荒芜的;不孕不育的 | barren 不毛之地 → 贫瘠、不孕 |
| trolley | n. 购物手推⻋;小推⻋;有轨电⻋ | 超市 trolley 推车 → 手推车 |
| trash | n. 垃圾,废物;劣质品;窝囊废 vt. 损坏,毁坏;抨击;把...抛弃 | trash 扔进垃圾桶 → 垃圾 |
| Bible | n. 圣经 | Bible 圣经 → 圣经 |
| artery | n. 动脉;主干路,干线 | artery 动脉 → 动脉、主干道 |
| drift | vi. 漂流,漂;缓缓移动 vt. 使漂流,使漂浮 n. 雪堆;水流,气流;主旨;偏航 | drift 漂流 → 漂流 |
| legitimate | adj. 合法的;正当的;婚生的 vt. 使合法化,使合理化 | leg 法律（legal 合法）→ 合法的 |
| potent | adj. 有强效的,烈性的 | potential 潜力 → potent 强效的 |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| stroll | vi. 散步,溜达,闲逛 n. 散步,溜达,闲逛 | stroll 漫步：夕阳下闲逛溜达 |
| pierce | vt. vi. 刺入;(光、声等) 穿透;突破 | pierce 刺穿：打耳洞 pierce 耳垂；声音穿透 |
| claw | n. 爪;螯,钳 vi. vt. 抓,挠 | claw 爪子：猫伸出 claw 挠人；螯钳 claw |
| slot | n. 狭槽,投币口;时段,位置 vt. vi. 投放,(被) 塞进 | slot 狭槽：投币口塞硬币；黄金时段 time slot |
| grin | vi. vt. 露⻮而笑,咧嘴大笑 n. 露⻮的笑,咧嘴的笑 | grin 咧嘴笑：傻乎乎 grin 露牙乐 |
| wield | vt. 行使,支配 (权力等);拿起 | wield 行使：wield power 掌权；挥剑 wield sword |
| lavish | adj. 奢侈的,大量的;慷慨的 vt. 过分给予 | lavish 奢华：lavish 盛宴铺张；慷慨挥霍 |
| hypocrisy | n. 伪善,虚伪 | hypocrisy 希腊词源'面具下演戏'——当面一套背后一套=伪善 |
| mule | n. 骡子;越境贩毒者;拖鞋 | mule 骡子：驴和马生的 mule 能驮货 |
| mat | n. 小地毯;厚软垫;衬垫;团,簇 | mat 垫子：门口蹭鞋 mat；瑜伽垫 yoga mat |
| canoe | n. 独木舟 vi. 划独木舟,乘独木舟 | canoe 独木舟：一根木头挖成的小船 |
| herb | n. 香草,药草 | herb 香草：herb 泡茶；注意 h 不发音 |
| wagon | n. 四轮运货⻢⻋;(火⻋)货⻋⻋厢 | wagon 马车：西部拓荒 wagon 车队；火车车厢 wagon |
| contingent | adj. 依情况而定的 n. 代表团;分遣队 | contingent 依情况而定：看条件 contingency 而定；代表团 |
| cradle | n. 摇篮;发源地;(电话的) 听筒架 vt. 轻抱,轻托 | cradle 摇篮：宝宝躺 cradle 摇；文明发源地 cradle |
| akin | adj. 近似的,类似的 | a+kin(亲属) → 像亲戚般相似 akin |
| vinegar | n. 醋 | vinegar 法语词源=变酸的酒 → 醋 |
| basin | n. 洗脸池;盆;流域;盆地;内港 | basin 盆：洗脸池 basin；四川盆地也是 basin |
| rack | n. 支架,架子;肋排 vt. 使...痛苦不堪,使受折磨 | rack 架子：行李 rack；rack one's brains 绞尽脑汁 |
| assimilate | vt. 吸收,接受,学习 vi. vt. (使) 同化,融入 | simil=相同(similar 同源) → 变得相同=同化吸收 |
| maternal | adj. 母亲的,母亲般的;母系的 | 词根 mater = 母：maternal 母亲般的；对比 paternal 父亲的 |
| aerial | adj. 从⻜机上的;空中的 n. (电视等的) 天线 | 词根 aer = 空气（aeroplane 飞机同源）：空中的；天线竖在空中 |
| cohesion | n. 团结,凝聚 (力) | co 共同 + hes 粘住（adhere 同源）→ 粘在一起 = 凝聚力 |
| hockey | n. (草地) 曲棍球;冰球 | 谐音"吼嘿"：冰球场上喊口号挥杆击球 = 曲棍球、冰球 |
| propaganda | n. 宣传,鼓吹 | 联想 expand（展开）：propaganda 把观点铺开传播 = 宣传 |
| bench | n. ⻓椅;法官席;替补席;工作台 vt. 把 (运动员) 从比赛中撤下 | 长椅：法官坐 bench 判案，替补坐 bench 冷板凳被撤下 |
| flirt | vi. 调情;玩儿似地对待 n. 喜欢调情的人 | 谐音"抚撩他"：撩拨对方 = 调情 |
| fax | n. 传真机,传真系统;传真件 vt. 用传真机发送 | fax 是 facsimile（摹本）的缩写：传真就是把文件复制过去 |
| cavity | n. 洞,腔,龋洞 | 词根 cav = 洞（cave 洞穴同源）→ 腔、洞；牙上的洞 = 龋洞 |
| ridicule | n. 嘲笑,奚落,戏弄 vt. 嘲笑,奚落,戏弄 | 同源 ridiculous（可笑的）→ ridicule 嘲笑、奚落 |
| allure | n. 诱惑力,吸引力 vt. 诱惑,引诱 | lure（诱惑）同源 → allure 吸引力、诱惑 |
| ambassador | n. 大使 | 大使馆 embassy 里住着 ambassador 大使，是国家的门面 |
| hurl | vt. 猛投;大声说出或喊出 vi. 呕吐 | 谐音"呼"：猛投时物品呼呼作响，怒气 hurl 出去 |
| monster | n. 怪物;庞然大物;恶棍;小坏蛋 adj. 巨大的,庞大的 | 联想怪物史莱克 Shrek：monster 怪物、庞然大物 |
| sew | vi. vt. 缝制,缝合,缝补 | 谐音"梭"：织布梭子穿线来回 = 缝 |
| singular | adj. 单数的;非凡的;奇特的 n. 单数形式 | single（单一）同源 → singular 单数的；独一无二 = 非凡的 |
| pessimism | n. 悲观,悲观主义 | 对比 optimism（乐观）：pessimism 凡事往最坏处想 = 悲观 |
| override | vt. (以权力) 否决,推翻;凌驾 | over 在上 + ride 骑 → 骑在别人头上 = 凌驾、否决 |
| tariff | n. 关税 | 谐音"他日付"：进口过关要交关税，账他日再付 |
| assortment | n. 各种各样 | sort（种类）同源 → 各种 sort 凑一起 = 各种各样 |

| leaflet | n. 传单,小册子 vi. vt. 散发传单 (或小册子) | leaf(叶)+let(小)→一张小纸片,传单 |
| heading | n. 标题,题目;类目,主题 | head(头)+ing→文章的头部,标题 |
| toll | n. 伤亡人数;严重后果;通行费 vi. vt. 敲 (钟),鸣 (钟) | 收费站 toll gate→通行费;伤亡人数 |
| harm | n. 伤害,损害 vt. 伤害,损害 | 谐音"害人"→伤害 |

| transient | adj. 短暂的;流动的,临时的 n. 暂住者,流浪者 | trans(穿过)+ient→穿过去的,短暂的 |
| compel | vt. 强迫,逼迫 | com+pel(推,同 propel)→一起推,强迫 |
| appliance | n. (家用) 电器,装置 | 同 apply(应用)→家用电器,装置 |
| dawn | n. 黎明,拂晓;开端,起始阶段 vi. 破晓,天亮;开始;变得明朗 | 联想拂晓→黎明;dawn on 恍然大悟 |
| Confucian | adj. 孔子的,儒家的 | Confucius(孔子)→儒家的 |
| avert | vt. 防止,避免;转移目光,背过脸 | a(离)+vert(转,同 divert)→转开目光,避免 |
| onto | prep. 到...上,向...上;(⻔或窗等) 朝 | on(上)+to(向)→到...上 |
| funeral | n. 葬礼,丧礼 | 联想葬礼黑纱→葬礼,丧礼 |
| solidarity | n. 团结一致,相互支持 | solid(坚固)+arity→团结得像一块铁板 |
| outrage | n. 愤怒,愤慨;暴行 vt. 使震怒,激怒 | out(出)+rage(愤怒)→怒火爆发,暴行 |
| institute | n. 机构,协会,研究院,学院 vt. 建立 (体系等),制定 (规章等) | in+stitute(站,同 constitute)→立起来,建立 |
| hammer | n. 锤子;(拍卖用) 木槌;击铁 vi. vt. (用锤子) 敲,捶打;反复敲打 vt. 猛踢,猛击;轻易打败 | 谐音"哈默"→锤子 |
| northeast | n. 东北,东北方 adj. 东北部的 adv. 向东北 | north(北)+east(东)→东北 |
| dam | n. 水坝,堤坝;母兽,母⻢ vt. 在 (河) 上筑坝;阻止,抑制 | 谐音"挡"→水坝挡住水流 |
| induce | vt. 引诱,劝说;引起,导致;催产 | in(入)+duce(引,同 produce)→引进,引诱 |
| feminine | adj. 女性的,女性化的;阴性的 | 同 female(女性)→女性的 |
| extinct | adj. 已灭绝的,消失的;(火山) 死的 | 同 extinguish(熄灭)→火灭了,灭绝 |
| annoy | vt. 使生气,使烦恼,烦扰 | 谐音"闹"→吵闹使人烦 |
| burst | vi. vt. (使) 爆裂,胀开 vi. 猛冲;爆满,涨满;突然爆发 n. 迸发,爆发;爆裂,裂口 | 谐音"爆"→爆裂,爆发 |
| ordeal | n. 苦难的经历,折磨,煎熬 | 谐音"熬得"→熬得过去的磨难,煎熬 |
| ink | n. 墨水,油墨,墨汁 vt. 给...上油墨;签订 (合同等) | 联想钢笔水→墨水 |
| tap | n. 水⻰头;轻敲,轻拍;电话窃听 vt. vi. 轻敲,轻拍;轻叩;利用,发掘 vt. (在电话上) 安装窃听器;委任 | 谐音"嗒"→轻拍声;水龙头 |
| ladder | n. 梯子;(晋升) 阶梯;(裤袜) 抽丝 | 联想晋升阶梯→梯子,阶梯 |
| jar | n. 玻璃罐;缸,坛子;撞击 vt. vi. (使) 撞击;(使) 不快,(使) 吃惊 vi. (与...) 不和谐,不相配 | 联想果酱罐→玻璃罐,坛子 |
| assess | vt. 评估;估算 | 同 assessor(估价员)→评估 |
| cue | n. 暗示,提示,信号;球杆 vt. 给 (某人) 提示或暗示 | 谐音"Q"→给个提示;台球杆 |
| breakthrough | n. 突破,重大进展 adj. 突破性的,取得重大成功的 | break(破)+through(穿过)→突破 |
| conference | n. 会议 | con(一起)+fer(带,同 transfer)→大家带意见开会 |
| deceive | vt. vi. 欺骗,蒙骗,误导 | de(反)+ceive(拿,同 receive)→反着拿,欺骗 |
| grand | adj. 壮丽的;宏伟的;极好的 n. 一千英镑 (或美元);三⻆钢琴 | 联想宏伟建筑→壮丽,宏伟 |
| agenda | n. 议事日程;待办事项;隐秘意图 | 同 agent(行动)→要做的事,议程 |
| laser | n. 激光;激光器 | 谐音"镭射"→激光 |

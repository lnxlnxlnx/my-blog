# 词 81–120

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 08月28日 Friday · 词 81–120 · PDF 第 5–6 页 · 新词 40 · 复习 40 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| shrewd | adj. 精明的,敏锐的 | 谐音"睿"——睿智敏锐 = 精明 |
| segment | n. 部分;(节目等的) 节,段;瓣 vt. 分割,划分 | 同根 section(部分)→ segment = 一段、部分 |
| concentrate | vi. vt. 全神贯注;(使) 集中 n. 浓缩液,浓缩物 | con 一起 + centr 中心(center)→ 聚向中心 = 集中 |
| tax | n. 税,税款 vt. 对...征税;给...施压 | taxi 少个 i → 打车费里含着税 |
| protein | n. 蛋白质 | 肉、蛋、豆富含 protein = 蛋白质 |
| thermal | adj. 热的,热量的;保暖的;温热的 n. 保暖内衣裤;上升的热气流 | 同根 thermometer(温度计)→ thermal 热的 |
| magnitude | n. 巨大,重要性;星等;震级 | 同根 magnify(放大)→ magnitude 巨大、震级 |
| dispose | vi. 丢掉;处理 vt. 布置,安排;使倾向于 | dis 分开 + pose 放 → 放掉 = 处理、丢掉 |
| tuck | vt. vi. 把 (布等的边缘) 塞进 vt. 用...裹严;把...塞进 n. 减肥手术 | 把衬衫下摆塞进裤子 = tuck 塞 |
| identity | n. 身份,本体;特性,个性;相同 | 同根 identical(完全相同)→ identity 身份 |
| cliche | n. 陈词滥调,陈腐的套语 | 法语 cliché(印刷铅版)→ 反复印的套话 = 陈词滥调 |
| patent | n. 专利权 adj. 专利的;明显的 vt. 得到...的专利权 | 发明申请 patent 专利，别人不能用 |
| gossip | n. 流言蜚语;闲聊;爱说闲话的人 vi. 闲聊,说⻓道短 | go sip 去喝咖啡闲聊 → gossip 流言蜚语 |
| forge | vt. 缔造,建立;伪造;锻造,制作 vi. 稳步前进 n. 铁匠铺;锻造炉,锻造⻋间 | 铁匠铺打铁 = forge 锻造;也指伪造 |
| concrete | adj. 确实的,具体的;混凝土制的 n. 混凝土 | 混凝土浇筑成实物 → concrete 混凝土、具体 |
| entertain | vt. vi. 使快乐,使有兴趣,娱乐;款待 vt. 怀有...想法 (或感受) | enter 进 + tain 保持 → 迎宾款待、使人快乐 |
| loom | vi. 隐约显现,赫然出现;逼近,迫近 n. 织布机 | 织布机上图案逐渐显现 → loom 织布机、隐约显现 |
| stain | vt. vi. 弄脏 vt. 给...染色;玷污,败坏 (名声) n. 污点,污渍;染色剂,着色剂 | paint 上色、stain 弄脏 → 污渍 |
| liberty | n. 自由;(某种) 合法权利;失礼 | 自由女神像 Statue of Liberty → liberty 自由 |
| accord | n. 协议,条约;一致,符合 vt. 给予,赠予 vi. (与...) 一致,符合 | cord 心(core)→ 心心相印 = 一致、协议 |
| refine | vt. 提炼,精炼;改善,改良 | re 再 + fine 好 → 反复弄好 = 精炼、改良 |
| interpret | vt. 解释,说明;把...理解为 vi. vt. 口译 | interpreter 同传译员 → interpret 口译、解释 |
| biotechnology | n. 生物技术,生物科技 | bio 生物 + technology 技术 → 生物技术 |
| entail | vt. 牵涉,涉及,需要 | 联想: 做一件事牵出一串后果 → 牵涉、需要 |
| bush | n. 灌木;丛林地带;浓密的毛发 | 谚语 beat around the bush 拐弯抹角 → 灌木丛 |
| crime | n. 犯罪活动,罪行;罪过 | criminal(罪犯)同根 → crime 罪行 |
| glitter | vi. 闪亮,闪耀;(眼睛) 闪现 n. 灿烂的光辉;吸引力;小发光物 | glitter 里藏 litter(散落)→ 散落小片闪耀 |
| versus | prep. 以...为对手;与...相比 | 缩写 vs → versus = 对阵、与…相比 |
| hip | n. 髋,臀部;野蔷薇果 adj. 新潮的,赶时髦的 | hip-hop 嘻哈舞扭胯 → hip 髋部 |
| bald | adj. 秃顶的;磨平的;直截了当的 | bald 像 ball(球)→ 头秃得像球 |
| celebrity | n. 名人,明星;名声,名气 | celebrate 庆祝同根 → 被庆祝的 = 名人 |
| prestige | n. 威信,声望 adj. 令人敬仰的,受尊重的;名贵的 | 名牌店里的 prestige 名贵感 → 声望 |
| moan | vi. vt. 呻吟;抱怨 vi. 呼啸,发出萧萧声 n. 呻吟声;抱怨;呼啸声 | 拟声"闷"——闷声呻吟、抱怨 |
| ham | n. 火腿;蹩脚演员 | ham and eggs 火腿煎蛋 → ham 火腿 |
| spite | n. 怨恨,恶意 vt. 故意伤害,激怒 | in spite of(尽管)→ spite 怨恨、恶意 |
| naive | adj. 幼稚的;天真的,率直的 | 像吃奶的娃娃一样天真 → naive 幼稚 |
| splash | vi. 泼洒,哗啦地溅;溅着水花行走 vt. 把 (水、泥等) 泼在...上 n. 溅泼声;引人注目的效果 | 拟声——水哗啦溅起 = 泼溅 |
| haven | n. 安全的地方,保护区 | haven 像 heaven(天堂)少个 e → 安全之地 |
| willpower | n. 意志力,毅力 | will 意志 + power 力量 → 意志力 |
| tenant | n. 房客,租戶 vt. 租用 | 与 landlord(房东)相对 → tenant 房客 |

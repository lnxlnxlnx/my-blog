# 词 1281–1320

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 09月27日 Sunday · 词 1281–1320 · PDF 第 65–66 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| tempo | n. (乐曲的) 节奏;(发展的) 速度 | tempo 与 temporary(临时的)同源"时间"，音乐里控制时间快慢 = 节奏、速度 |
| exclude | vt. 将...排斥在外;不包括;排除 | ex 出 + clude 关(include 包含反义)，关在门外 = 排除 |
| cabinet | n. 储藏柜,陈列柜;内阁 | cabinet = cabin 小屋 + et 小，小屋放东西 = 储藏柜；大臣小屋议事 = 内阁 |
| overstate | vt. 夸大,夸张,言过其实 | over 过度 + state 陈述，陈述过头 = 夸大 |
| ancestor | n. 祖先;(动物) 原种;原型 | an 前 + cest 走(cede 同源) + or 人，走在前面的人 = 祖先 |
| memorandum | n. 备忘录;协议备忘录;意向书 | memo 便条的全称，记要点的纸条 = 备忘录 |
| livelihood | n. 营生,生计 | live 活 + hood 状态，"活下去"所靠的东西 = 生计 |
| overnight | adv. 在夜间;突然,一夜之间 adj. 夜间的;突然的,一夜之间的 | over 经过 + night 夜，过一夜就发生 = 一夜之间 |
| considerate | adj. 体贴的,考虑周到的 | consider 考虑 + ate，处处为别人考虑 = 体贴的 |
| stall | n. 货摊,摊位;牲畜棚;小隔间 vi. vt. (使) 熄火,抛锚;暂缓,搁置 vi. 故意拖延 (以赢得时间) vt. 拖住 (以赢得时间做某事) | 集市货摊叫 stall；引擎一"停摆"就是 stall 熄火 |
| cynical | adj. 愤世嫉俗的;无所顾忌的 | 源自古希腊犬儒学派 Cynic，犬儒者愤世嫉俗 |
| amongst | prep. 在...中;在一群人或物之中 | among 的变体形式，在...之中 |
| lease | n. 租约,租契 vt. 租借,租用,出租 | 与 let 同源"让"，把房子"让"给别人用 = 出租、租约 |
| justify | vt. 证明...有理;为...辩解 | just 公正 + ify 使，使显得公正 = 为...辩解 |
| namely | adv. 即,也就是 | name 名字 + ly，点名道姓说 = 即、也就是 |
| owe | vt. 欠 (钱);欠 (人情);把...归功于 | IOU(I owe you)我欠你，owe = 欠钱、欠人情 |
| nationwide | adj. 全国性的,全国范围的 adv. 在全国范围内 | nation 国家 + wide 遍及，遍及全国 = 全国性的 |
| surgery | n. 外科手术;手术室;应诊时间 | surgeon 外科医生的手术就叫 surgery |
| warranty | n. 保修单 | warrant 保证 + y，商家"保证"修好的凭证 = 保修单 |
| unveil | vt. 公布,推出;为...揭幕 | un 去掉 + veil 面纱，揭开面纱亮相 = 揭幕、公布 |
| formulate | vt. 规划,策划,构想;确切表达 | formula 公式 + ate，把想法整理成公式 = 构想、表述 |
| oral | adj. 口头的;口腔的,口的 n. 口试 | 词源"嘴"，用嘴说的 = 口头的；口试 |
| dividend | n. 红利,股息;被除数 | divide 分 + end，利润"分"给股东 = 红利、股息 |
| lounge | n. 休息室;躺椅,沙发 vi. 懒洋洋地坐,躺,消磨时间 | 在 lounge 休息室"躺平"懒洋洋，消磨时间 |
| clothe | vt. 给...穿衣;为...提供衣服 | cloth 布 + e，用布裹身 = 给...穿衣 |
| oxide | n. 氧化物 | oxygen 氧气取 ox + ide 化合物后缀 = 氧化物 |
| tumble | vi. vt. (使) 跌倒,滚落 vi. 倒塌;暴跌;仓促移动;翻跟头 n. 跌倒,暴跌;混乱的一堆 | stumble 绊倒去 s = tumble，滚落跌倒；股价 tumble 暴跌 |
| depress | vt. 使沮丧;降低 (价格等);按下 | de 向下 + press 压，心情被往下压 = 使沮丧；按下 |
| jeans | n. 牛仔裤 | 源自意大利热那亚 Genoa 的布料，现指牛仔裤 |
| statesman | n. 政治家 | state 国家 + man 人，为国家服务的人 = 政治家 |
| mate | n. 朋友,伙伴;老兄;同伴;伴侣 vi. (动物) 交配 | classmate 同学、teammate 队友，mate = 伙伴、伴侣 |
| prototype | n. 原型,雏形;典型 | proto 原始 + type 型号，最初的型号 = 原型 |
| glacier | n. 冰川,冰河 | glacial 冰河期同源，glac 冰，大冰河 = 冰川 |
| authorize | vt. 批准,授权,许可 | author 作者 + ize，给你"作者"资格 = 授权、批准 |
| incur | vt. 招致,引起,蒙受 | in 进 + cur 跑(current 同源)，跑进麻烦里 = 招致 |
| hollow | adj. 空心的;虚假的;凹陷的 n. 凹陷处,坑洼处;洞,孔 vt. 挖空,挖出 (孔、洞) | 与 hole 洞同源，树洞空空 = 空心的、挖空 |
| conceal | vt. 掩盖,隐藏 | 联想 seal 封住，把东西封藏起来 = 掩盖、隐藏 |
| mall | n. 购物中心,商场 | 联想"摩尔城"购物中心，mall = 商场 |
| suppress | vt. 镇压;压抑;封锁,隐瞒;抑制 | sup 向下 + press 压，用力压下去 = 镇压、压抑 |
| stubborn | adj. 固执的,顽固的;难以对付的 | 联想 stone 石头般硬，怎么劝也不回头 = 固执的 |

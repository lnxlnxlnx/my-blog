# 词 2121–2160

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 10月18日 Sunday · 词 2121–2160 · PDF 第 107–108 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| afloat | adj. 经济上周转得开的;漂浮的 | float（漂浮）同源 → afloat 漂浮；经济不沉底 = 周转得开 |
| congratulate | vt. 祝贺;为自己感到高兴或自豪 | 词根 grat = 高兴（grateful 同源）→ 祝贺 |
| rim | n. (圆形物体的) 边缘;轮圈 vt. 形成...的边沿 | 画面：车轮 rim 轮圈，杯口 rim 边沿 |
| beware | vi. vt. 当心,注意,提防 | be + ware（当心）→ beware 提防 |
| overt | adj. 公开的,明显的 | 对比 covert（秘密的）→ overt 公开的 |
| casino | n. 赌场 | 谐音"卡西诺"：赌场 casino 一掷千金 |
| retaliate | vi. 报复,反击 | re 回 + tali 同等 → 以牙还牙 = 报复 |
| coup | n. 政变;惊人的成功之举 | 谐音"酷"：发动 coup 政变夺权，干得漂亮 |
| Easter | n. 复活节 | Easter egg 复活节彩蛋 → Easter 复活节 |
| zeal | n. 热情,激情,热忱 | 谐音"灼热"：zeal 热情灼热 |
| bouquet | n. 花束;(酒的) 芳香 | 画面：新娘捧 bouquet 花束，散发芳香 |
| paperback | n. 平装书 | paper 纸 + back 背 → 平装书 |
| Marxism | n. ⻢克思主义 | Marx（马克思）+ ism → 马克思主义 |
| petrochemical | n. 石 (油) 化 (学) 产品 | petro 石油 + chemical 化学 → 石油化工产品 |
| cellar | n. 地窖,地下室,地下贮藏室 | cell（小室）同源 → cellar 地窖、地下室 |
| paw | n. 爪子;手 vi. vt. 用爪子抓 (或扒) vt. 猥亵地摸,动手动脚 | 谐音"刨"：狗用 paw 爪子刨土 |
| curfew | n. 宵禁,宵禁令,宵禁时间 | 画面：curfew 宵禁一到，街上空无一人 |
| socialism | n. 社会主义 | social 社会 + ism → 社会主义 |
| desolate | adj. 荒无人烟的;孤独凄凉的 vt. 使感到凄凉 | 词根 sol = 单独（sole 同源）→ 荒凉孤独 |
| barracks | n. 兵营,营房;一片简陋的大房子 | 画面：士兵住在 barracks 兵营 |
| deadlock | n. 僵持,僵局;插销锁 | dead 死 + lock 锁 → 死锁 = 僵局 |
| delude | vt. 欺骗,哄骗 | 词根 lude = 玩（ludicrous 同源）→ 把人玩进圈套 = 欺骗 |
| confide | vt. 吐露 (隐私) | 词根 fide = 信任（confidence 同源）→ 信任地吐露隐私 |
| superintendent | n. 负责人;警⻓;(大楼的) 看管人 | super 上 + intend 照管 → 总管负责人 |
| gravitation | n. 地心引力,重力 | 同源 gravity（重力）→ 地心引力 |
| observatory | n. 天文台,气象台 | observe（观察）+ 场所后缀 → 天文台 |
| weary | adj. 疲劳的,厌倦的;使人疲劳的 vt. 使疲劳,使疲倦 vi. 变得不耐烦,感到厌倦 | 谐音"萎了"：weary 疲惫精神萎靡 |
| burglar | n. 破⻔盗窃者,窃贼 | 画面：burglar 破门而入的窃贼 |
| takeoff | n. (⻜机) 起⻜;起跳;滑稽模仿 | take off（起飞）→ takeoff 起飞；滑稽模仿 |
| composite | adj. 合成的,复合的 n. 合成物,混合物;罪犯画像 | com 共同 + pos 放 → 放一起 = 合成物 |
| negate | vt. 取消,使无效;否定,否认 | 词根 neg = 否定（negative 同源）→ 否定、使无效 |
| comet | n. 彗星 | 画面：comet 彗星拖着长尾划过夜空 |
| paddy | n. 稻田,水田 | 谐音"耙地"：paddy 稻田要耙地插秧 |
| linen | n. 亚麻布;亚麻制品 | 谐音"列宁"：列宁时代穿 linen 亚麻布 |
| Jeep | n. 吉普⻋,越野⻋ | 谐音"吉普"：Jeep 越野车 |
| parasite | n. 寄生虫,寄生动植物 | para 旁 + site 食 → 寄生在旁吃白食 = 寄生虫 |
| stammer | vi. vt. 口吃,结结巴巴地说 n. 口吃,结巴 | 画面：stammer 口吃，话在嘴边打结 |
| brag | vi. vt. 吹嘘,夸耀,自吹自擂 | 画面：brag 吹牛自夸，牛皮吹上天 |
| waive | vt. 宣布放弃 (权利等) | 联想 wave（挥手）：waive 挥手放弃权利 |
| giggle | vt. vi. 咯咯笑,傻笑 n. 咯咯笑,傻笑;趣事 | 拟声词：giggle 咯咯傻笑 |

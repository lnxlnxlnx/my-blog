# 词 801–840

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 09月15日 Tuesday · 词 801–840 · PDF 第 41–42 页 · 新词 40 · 复习 400 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| grope | vi. vt. 摸索,寻找 vt. 猥亵,摸 n. 抚摸,猥亵 | 画面:黑灯瞎火 grope 摸索着找开关。 |
| burden | n. 负担,重担 vt. 使担负,使烦恼;使负重 | 谐音“背担”:背上的担子 = 负担、重担。 |
| evade | vt. 躲避 (追捕);逃避,规避;回避 vt. 难倒,使困惑 | vade 走(invade 入侵)→ 溜之大吉 = 逃避、躲避。 |
| opt | vi. vt. 选择,作出抉择 | 同源 option 选项 → opt = 选择(opt for)。 |
| motorway | n. 高速公路 | motor 汽车 + way 道路 → 汽车快速路 = 高速公路。 |
| realm | n. 领域,范围;王国 | 谐音联想:realm ≈ “王领” → 王国;引申领域。 |
| quota | n. 限额,配额;定额,指标 | 谐音联想:quota ≈ “扣他” → 限额扣着用 = 配额。 |
| overlap | vt. vi. (与...) 重叠;(时间等) 有重叠 n. 重叠部分 | over 上 + lap 搭 → 你搭在我上 = 重叠、重复。 |
| stigma | n. 耻辱,羞耻 | 词源:原指“烙在奴隶身上的印记” → 耻辱、污名。 |
| nerve | n. 神经;紧张,焦虑;勇气;厚颜 | 画面:紧张时神经 nerve 紧绷;拿出勇气叫 have nerve。 |
| priest | n. 牧师,神父;神职人员 | 画面:教堂里 priest 牧师,主持礼拜的神职人员。 |
| elite | n. 精英,上层人士 adj. 精英的,精锐的 | 同源 elect 选 → 被选出的人 = 精英。 |
| flaw | n. 瑕疵,缺点;错误;性格缺陷 | 谐音联想:flaw ≈ “破” → 美玉上的破绽 = 瑕疵、缺点。 |
| dairy | n. 乳制品;牛奶场;乳品公司 adj. 乳品的;生产乳品的 | 画面:dairy 乳品,牛奶场里奶牛产奶。 |
| cargo | n. (轮船、⻜机所装载的) 货物 | 联想:car 车 + go 走 → 车拉着走的 = 货物。 |
| commodity | n. 商品,货物;有用的东西 | 语境:commodity 商品,粮食石油等大宗货物。 |
| hoist | vt. 吊起,升起,提起 n. 吊⻋,起重机 | 画面:码头起重机 hoist 吊起集装箱。 |
| scrap | n. 碎片;一丁点;剩饭;废品 vt. 废弃,取消,抛弃 vi. 打架 | 谐音联想:scrap ≈ “撕(烂)” → 碎片;废铁 = 废品。 |
| poultry | n. 家禽;禽肉 | 画面:农场里鸡鸭成群,poultry 家禽与禽肉。 |
| incentive | n. 激励,动机,刺激 | 谐音联想:incentive ≈ “引” → 引着人干活 = 激励。 |
| organ | n. 器官;管⻛琴;机构,机关 | 画面:心肝脾肺是 organ 器官;教堂管风琴也叫 organ。 |
| precede | vt. vi. 先于...(发生或存在) vt. 走在...之前 | cede 走(proceed 前进),pre 先 → 走在前面 = 先于。 |
| app | n. 应用软件 | 画面:手机里的 app 应用,application 的缩写。 |
| acupuncture | n. 针灸,针刺疗法 | acu 尖(acute)+puncture 刺 → 用针刺穴 = 针灸。 |
| lawsuit | n. 诉讼,官司 | law 法律 + suit 起诉 → 对簿公堂 = 诉讼。 |
| fog | n. 雾,雾气;迷惑,迷惘 vi. vt. (使) 起雾 vt. 使迷惘,使迷惑 | 画面:伦敦 fog 大雾,白茫茫看不清。 |
| accordingly | adv. 相应地,照着;因此,所以 | according 按照 → 照着做 = 相应地;因此。 |
| coordinate | vt. 使...协调 vi. vt. (使衣服等) 搭配 n. 坐标,坐标值 adj. (在句中) 并列的 | co 共同 + ord 次序(order)→ 一起排好序 = 协调。 |
| pyramid | n. 金字塔;棱锥体 | 画面:埃及金字塔 pyramid,三角锥形。 |
| hardship | n. 艰难,困苦 | hard 难 + ship 状态 → 艰难困苦。 |
| dolphin | n. 海豚 | 画面:海豚 dolphin 跃出水面,聪明的海洋动物。 |
| fiscal | adj. 国库的,财政的 | 谐音联想:fiscal ≈ “费(用)” → 国库的、财政的。 |
| assault | n. 攻击,袭击;攻坚;抨击 vt. 袭击,殴打;使...感到难受 | 谐音联想:assault ≈ “殴(打)” → 袭击、殴打。 |
| blouse | n. (女式) 短上衣,衬衫 | 谐音联想:blouse ≈ “白(衬衫)” → 女士短上衣。 |
| butterfly | n. 蝴蝶,蝶;蝶泳 | butter 黄油 + fly 飞 → 传说偷吃黄油的飞虫 = 蝴蝶。 |
| suck | vt. 吮,吸;抽 (空气等);把...卷入 vi. vt. 含在嘴里吮 vi. 糟糕透顶,很差 | 画面:用吸管 suck 吸饮料;糟糕透顶也叫 suck。 |
| confer | vt. 授予,赋予 vi. 商议,协商 | fer 带(offer 提供),con 一起 → 授予;聚在一起商议。 |
| discern | vt. 觉察出,了解;(依稀) 分辨出 | cern 分辨(拉丁语“筛分”)→ 从混杂中分开 = 觉察、分辨。 |
| laundry | n. (要洗或洗好的) 衣物;洗衣房 | 画面:周末 laundry 洗衣房,一筐脏衣物。 |
| thirst | n. 口渴;渴求 vi. 渴求 | 谐音联想:thirst ≈ “渴死” → 口渴;thirst for 渴望。 |

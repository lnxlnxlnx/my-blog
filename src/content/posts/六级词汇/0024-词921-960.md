# 词 921–960

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| bust | vt. 打碎;突击搜捕 n. 半身像;胸部;萧条期;搜捕 adj. 破碎的,毁坏的;破产的 | 谐音联想:bust ≈ “爆” → 破碎、破产、突击搜捕。 |
| monument | n. 纪念碑,纪念馆;名胜;典范 | mon 提醒(monitor)→ 立在原地提醒后人 = 纪念碑。 |
| satire | n. 讽刺,讽刺作品 | 谐音联想:satire ≈ “酸(讽)” → 讽刺、挖苦的作品。 |
| retreat | vi. 撤退;后退;退缩;逃避,躲避 n. 撤退;逃避,躲避;僻静处;静修 | 联想:treat 与 tract(拉)同源 → 往回拉 = 撤退、后退。 |
| bacon | n. 培根,熏猪肉 | 谐音:bacon 就是“培根”的音译,熏猪肉。 |
| soda | n. 苏打水;汽水;苏打,纯碱 | 谐音:soda 即“苏打”音译 → 苏打水、汽水。 |
| deck | n. 甲板;(⻋、船的) 层;一副 (牌) n. 木质平台;(录音机) 走带装置 vt. 装饰,装点 | 画面:轮船 deck 甲板;一副扑克 a deck of cards。 |
| ward | n. 病房;选区;受监护人 vt. 避开 (危险、疾病等) | 画面:住院进 ward 病房;ward off 挡开危险。 |
| nonetheless | adv. 尽管如此 | none 不 + the less 少 → 一点也不少 → 尽管如此仍然。 |
| temple | n. 庙宇,寺院;太阳穴 | 画面:香火 temple 庙宇;太阳穴也叫 temple。 |
| fountain | n. 喷泉,喷水池;喷射;源泉 | 画面:广场中央 fountain 喷泉,水柱喷涌。 |
| bias | n. 偏⻅,偏袒;偏好 vt. 使有偏⻅,使偏心 | 谐音联想:bias ≈ “拜(一边)” → 偏心、偏见。 |
| outlet | n. 出口,发泄途径;经销店;折扣店 n. 媒体公司;插座;排放口 | out 出 + let 让 → 让东西出去的口 = 出口、插座。 |
| fence | n. 栅栏,篱笆,围栏;销赃犯 vt. (用栅栏、篱笆) 围住,隔开 vi. 参加击剑运动;搪塞,回避 | 画面:院外 fence 栅栏;击剑运动也叫 fence。 |
| quantify | vt. 量化,用数量来表示 | quantity 数量 → 用数量来表示 = 量化。 |
| ski | n. 滑雪板,滑水板 adj. 滑雪的,滑水的 vi. 滑雪,滑水 | 画面:雪地上 ski 滑雪,踩着滑雪板飞驰。 |
| scholar | n. 学者;奖学金获得者 | 同源 school 学校 → 治学的人 = 学者。 |
| outdated | adj. 过时的,陈旧的,老式的 | out 出 + date 时代 → 被时代淘汰 = 过时的。 |
| drawback | n. 缺点,不利条件 | draw 拉 + back 回 → 拖后腿的地方 = 缺点。 |
| analogy | n. 类比,相似处 | 谐音联想:analogy ≈ “按(同样)理” → 类比、相似。 |
| athlete | n. 运动员;擅⻓运动的人 | 谐音联想:athlete ≈ “爱(动)” → 爱运动的人 = 运动员。 |
| resemble | vt. 看起来像,与...相似 | sembl 同(same 同源)→ 长得一样 = 相似、像。 |
| dubious | adj. 怀疑的;可疑的;不光彩的 | 谐音联想:dubious ≈ “怀疑” → 半信半疑、可疑。 |
| pretext | n. 借口,托辞 | text 编(编织),pre 预先 → 预先编好的话 = 借口。 |
| cholesterol | n. 胆固醇 | 谐音联想:cholesterol ≈ “胆固醇”音译 → 血脂胆固醇。 |
| dictate | vt. vi. 口述;命令,规定;支配,决定 n. 命令,规定 | dict 说(predict 预言)→ 口述;命令、规定。 |
| metabolism | n. 新陈代谢 | meta 变 + 抛(ball)→ 物质转化 = 新陈代谢。 |
| draw | vt. vi. 画,描绘;拔出,抽出 vt. 拖动;拉帘;吸引;得出;支取 vi. 移动,行进 n. 抽奖,抽签;平局,和局 | 画面:draw 画画、拉帘、抽签,全是“拽”出来的动作。 |
| hardy | adj. 能吃苦耐劳的;(植物) 耐寒的 | 同源 hard 硬 → 硬朗耐折腾 = 耐寒、吃苦耐劳。 |
| commend | vt. 赞扬;推荐;把...托付给 | 谐音联想:commend ≈ “夸(人)” → 赞扬、推荐。 |
| saturate | vt. 浸透,渗透;使饱和,使充斥 | 谐音联想:saturate ≈ “洒(透)” → 浸透、使饱和。 |
| stake | n. 股份;重大利益;赌注;桩 vt. 以...打赌,拿...冒险 | 画面:下注 stake 赌注;有 stake 就有利害;木桩。 |
| staff | n. 全体职员;(学校) 行政人员 vt. 任职于,为...配备职员 | 画面:公司全体 staff 职员;一根拐杖也叫 staff。 |
| Celsius | adj. 摄氏的 n. 摄氏度 | 谐音:Celsius 即“摄氏”的音译,温度单位。 |
| cloth | n. 布,布料;牧师 | 画面:一块 cloth 布,裁裁剪剪做衣服。 |
| jargon | n. 行话,行业术语 | 谐音联想:jargon ≈ “行(话)” → 行业术语、黑话。 |
| storey | n. 楼层 | 谐音联想:storey ≈ “层” → 楼层(英式拼法)。 |
| merchant | n. 商人,批发商 adj. 海上货运的,商船的 | 谐音“摸钱”:商人 merchant 天天摸钱做生意。 |
| crawl | vi. 爬,爬行;缓慢行进;巴结 n. 缓慢的速度;自由泳 | 画面:婴儿手脚并用 crawl 爬行,车流缓慢 crawl。 |
| compliment | n. 称赞,赞美的话;致意,致敬 vt. 称赞,赞美 | 对比记忆:compliment 是夸人的话,complement 是互补。 |

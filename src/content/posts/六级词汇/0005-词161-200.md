# 词 161–200

六级大纲词汇 · 每日一课 · 先学新词，再自测，后复习

> 📅 08月30日 Sunday · 词 161–200 · PDF 第 9–10 页 · 新词 40 · 复习 80 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| blunder | n. 愚蠢的错误,失误 vi. 犯愚蠢的错误,失误 | 联想 blind 盲目 → 盲目行事犯大错 |
| soul | n. 灵魂;精神,精髓;某种人 | soul 音乐(灵魂乐)→ 灵魂、精神 |
| blunt | adj. 钝的,不锋利的;直言不讳的 vt. 使 (感觉等) 减弱;使变钝 | 刀刃钝 = blunt;说话直言不讳 |
| lodge | n. 乡间小屋;⻔房;传达室;穴 vi. (付款) 寄宿,租住 vt. 为...提供住宿;正式提出 (声明) vi. vt. (被) 固定,卡住 | 谐音"落脚"→ 找地方落脚 = 寄宿、小屋 |
| cereal | n. ⻨片;谷类植物;谷物 | 早餐 cereal 麦片泡牛奶 → 谷物 |
| algebra | n. 代数学 | 谐音"爱解吧"——代数就是解方程 |
| concede | vt. 承认...属实;(勉强地) 让与 vi. vt. 承认 (竞赛、选举等的失败) | 词根 cede=走(proceed)→ 退让 = 承认、让步 |
| smog | n. 雾霾,烟雾 | smoke 烟 + fog 雾 → 雾霾 |
| paralyse | vt. 使瘫痪;使不能正常运作 | 谐音"趴了"——瘫痪趴下 |
| bulb | n. 灯泡,电灯泡;球茎,鳞茎 | 灯泡 bulb 圆圆像球茎 → 灯泡、球茎 |
| devil | n. 魔⻤,恶魔;淘气⻤;家伙 | devil = evil(邪恶)加个 d → 魔鬼 |
| incident | n. 事件;(两国间的) 冲突 | 同根 accident(事故)→ incident 事件 |
| virtue | n. 美德;优点,⻓处 | by virtue of(凭借)→ virtue 美德、优点 |
| jeopardize | vt. 使处于危险境地,危及,危害 | 联想: 把…逼入绝境 = 危及、危害 |
| emit | vt. 发出,散发 (热、光等);发 (声) | 词根 mit=送(mission)→ e 出 + mit 送 = 发出 |
| needle | n. 针;编织针;针头;指针;松针 vt. (用话) 刺激,激怒 | 大海捞针 a needle in a haystack → 针 |
| lamp | n. 灯;发热灯,射线照射器 | 台灯 desk lamp → lamp = 灯 |
| cheat | vt. 欺骗,蒙骗 vi. 作弊,舞弊;对 (配偶) 不忠 n. 骗子,作弊者;欺骗行为 | 谐音"欺他"→ 欺骗、作弊 |
| omit | vt. 省略,遗漏;未 (做) | 词根 mit=送 → 漏送出去 = 省略、遗漏 |
| pest | n. 害虫,有害动物;讨厌⻤ | 谐音"拍死它"——见害虫就拍死 |
| compete | vi. 竞争,对抗;参加比赛 | 词根 pete=追求 → 一起追求 = 竞争 |
| esteem | n. 尊重,敬重 vt. 尊重,敬重 | self-esteem 自尊 → esteem 尊重、敬重 |
| attitude | n. 态度,看法;我行我素的作⻛ | 谚语 Attitude is everything → 态度 |
| tyre | n. 轮胎,⻋胎 | tyre = tire 轮胎;spare tyre 备胎 |
| junk | n. 废品,垃圾;垃圾⻝品;舢板 vt. 丢弃,抛弃,废弃 | junk food 垃圾食品 → junk 废品、垃圾 |
| temperament | n. 气质,性情 | temper(脾气)同根 → temperament 气质 |
| orthodox | adj. 正统的;东正教的;正统教派的 | ortho 正 + dox 意见 → 正统的 |
| possess | vt. 拥有;具有,具备;支配 | 拥有 possess;也指被"鬼附身"支配 |
| landmark | n. 地标,标志性建筑;里程碑 | land 地 + mark 标记 → 地标、里程碑 |
| spider | n. 蜘蛛 | 联想"丝"——吐丝结网的蜘蛛 |
| audit | n. 审计;审查,检查 vt. 审计;旁听 (大学的课) | 词根 aud=听 → 听账目汇报 = 审计 |
| immune | adj. 免疫的;不受影响的;被豁免的 | 打疫苗后 immune 免疫 → 免疫的 |
| feat | n. 壮举,技艺,功绩 | defeat(击败)去掉 de → feat 壮举 |
| indulge | vt. vi. (使自己) 沉迷 (于) vt. 满足 (欲望等);纵容,迁就 | 联想"瘾"——上瘾沉迷 = indulge |
| madam | n. 夫人,女士 | 服务员称呼女士 Madam → 夫人、女士 |
| rigor | n. 严密,严谨;严峻,严酷 | rigorous(严格的)同根 → rigor 严谨 |
| ration | n. 定量,配给量;口粮,给养 vt. 定量供应,配给 | 战时 ration 定量配给口粮 → 配给 |
| hack | vi. vt. 劈,砍;非法侵入 (计算机) vi. 骑⻢ n. 雇佣文人;杂务人员;出租⻋ | hacker 黑客 → hack 入侵;也指劈砍 |
| complement | vt. 补充,补足,使完美 n. 补充物,补足物;足额;补语 | 同根 complete(完整)→ complement 补足 |
| aviation | n. 航空,航空工业 | 词根 avi=鸟(aviary)→ 像鸟飞 = 航空 |

# 词 721–760

> 📅 09月13日 Sunday · 词 721–760 · PDF 第 37–38 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| impress | vt. vi. 使印象深刻,使钦佩 vt. 使...谨记 | press 压,im 压进心里 → 印象深刻、使钦佩。 |
| pan | n. 平底锅;烤盘 vt. 严厉批评;淘 (金) vi. vt. 追拍,摇摄 | 谐音“盘”:平底锅 pan 像个大铁盘。 |
| paradise | n. 天堂,乐土;伊甸园 | 词源:波斯语“围墙花园”→ 墙内花园 = 天堂乐园。 |
| intuition | n. 直觉 | tuit 看(拉丁语“看”)→ 不经推理一眼看穿 = 直觉。 |
| radiate | vt. vi. 散发,流露;发出 (光、辐射等) vi. 呈辐射状发散 (或伸展) | radi 光(radio)→ 像光一样向外发散 = 辐射、流露。 |
| fraction | n. 少量,一点儿;(数学上的) 分数 | fract 断(fracture 骨折)→ 断开的一小块 = 分数、少量。 |
| fluid | n. 液体,流体 adj. 流畅优美的;不稳定的;流动的 | flu 流(flow)→ 能流动的物体 = 液体、流体。 |
| clutch | vt. vi. 抓紧;突然抓住 n. 离合器;一群,一窝;势力范围 | 画面:惊慌时 clutch 紧紧抓住;开车踩的离合也叫 clutch。 |
| vice | n. 恶习;(⻩赌毒等) 罪行;老虎钳 pref. 副的,次的 | 语境:抽烟是 vice 恶习;vice president 副总统,“副的”。 |
| aristocrat | n. 贵族 (成员) | 词根 aristo 最优 + crat 统治 → 最优者统治 = 贵族。 |
| currency | n. 通货,货币;通用,流传 | cur 跑(occur)→ 在市场上跑来跑去的 = 货币。 |
| disagree | vi. 不同意,有分歧;不一致 | agree 同意,dis 否定 → 不同意、有分歧。 |
| refund | n. 退款,归还金额 vt. 退 (款) | fund 资金,re 回 → 把钱退回 = 退款。 |
| reckless | adj. 鲁莽的,不顾后果的 | reck 在意(reckon 计算)→ 不算后果的 = 鲁莽的。 |
| slash | vt. 砍,劈;大量削减 n. 砍,劈;⻓条切口;斜杠 | 画面:一刀 slash 劈开;键盘斜杠键也叫 slash。 |
| stamp | n. 邮票;印章,印记 vt. vi. 跺 (脚),重踩;迈着重步走 vt. 在...上盖 (字样或图案等) | 画面:寄信贴 stamp 邮票;发怒跺脚也叫 stamp。 |
| quantity | n. 数量,数目;大量,大批 | 对比记忆:quality 质量、quantity 数量,一 q 之差。 |
| fiber | n. 纤维;纤维织物 | 语境:粗粮富含膳食纤维 fiber,一丝丝像线。 |
| pronoun | n. 代词,代名词 | pro 代替 + noun 名词 → 代替名词的词 = 代词。 |
| smash | vt. vi. 打碎,粉碎;(使) 猛撞;撞开 vt. 捣毁,打败 n. 破碎 (声);扣球;走红的歌曲等 | 拟声词:玻璃 smash 一声粉碎;扣球、走红也叫 smash。 |
| nourish | vt. 给...提供营养;培养,助⻓ | 同源 nutrition 营养 → 给营养 = 滋养、培养。 |
| worship | n. (对神的) 敬奉;崇拜;阁下 vt. 崇拜,景仰 vt. vi. 敬奉 (神) | worth 价值 + ship → 觉得值得,心生崇拜 = 敬奉。 |
| glamor | n. 魅力,吸引力 | 同源 grammar(原义“魔法”)→ 让人着迷的魔力 = 魅力。 |
| mentor | n. 导师,指导者 vt. 指导,辅导 | 出自《奥德赛》智者 Mentor → 指导者、导师。 |
| gray | adj. 灰色的;头发花白的;昏暗的 n. 灰色,灰白色 vi. (头发) 变花白 | 画面:阴天 gray 天空灰蒙蒙,头发 gray 花白。 |
| church | n. 教堂;礼拜仪式;基督教教派 | 画面:周日信徒去 church 做礼拜,尖顶教堂。 |
| grasp | vt. 抓紧;理解;急忙抓住 (机会) n. 紧抓,控制;理解 (力) | 画面:把知识像握拳 grasp 一样抓住 = 掌握、理解。 |
| fare | n. ⻋费,票价;乘客;饭菜 vi. 进展,进行 | 谐音“费”:乘车要付 fare 车费;进展如何叫 fare。 |
| snack | n. 零⻝,小吃 vi. 吃小吃,吃点心 | 画面:下午茶 snack 零食小吃,垫垫肚子。 |
| ballet | n. 芭蕾舞;芭蕾舞剧;芭蕾舞团 | 谐音:ballet 就是中文“芭蕾”的音译。 |
| dismantle | vt. 拆卸,拆除;(逐渐) 废除 | mantle 罩子,dis 去掉罩子 → 拆卸、拆除。 |
| stance | n. 态度,立场;(体育运动的) 站姿 | 同源 stand 站立 → 站姿;站哪边 = 立场。 |
| fold | vt. vi. 折叠,对折;包,裹 vi. 倒闭,停演 n. 褶,褶层;褶痕;羊圈 suff. 由...部分组成的;倍 | 画面:把纸 fold 对折;店铺经营不善 fold 倒闭。 |
| merge | vi. vt. (使) 合并 vi. 渐渐消失于...,逐渐融入... | 谐音“没”:两水相 merge 汇合,渐渐“没”在一起 = 合并。 |
| specialty | n. 专业,专⻓;特产,特色菜 | special 特别的 → 特别擅长的领域 = 专业;特产。 |
| predominant | adj. 占主导地位的,最主要的 | dominate 支配,pre 在前 → 支配在前的 = 占主导。 |
| dynasty | n. 王朝,朝代;(商业等的) 家族 | 谐音联想:dynasty 唐朝盛世,一个王朝统治若干代。 |
| tactic | n. 策略,手段;战术,兵法 | 谐音联想:tactic 用兵策略、手段,战术打法。 |
| shot | n. 射击;投篮;尝试;镜头;注射 n. 射手;炮弹;照片;少量烈酒 adj. 杂色的;耗尽的,破旧的 | 画面:shoot 开枪、投篮 → 名词 shot 一枪、一投、一张照片。 |
| transit | n. 运输;交通系统;过境,中转 vt. vi. 经过,穿过 (某一地区) | trans 穿过 + it 走(exit)→ 从这头穿到那头 = 过境运输。 |

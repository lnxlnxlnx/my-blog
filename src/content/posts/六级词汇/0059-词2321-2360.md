## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| squad | n. 警察小队;特别行动组;运动队 | squad car=警车→一组小队、特别行动组。 |
| naughty | adj. 顽皮的,淘气的;(书等) 下流的 | 谐音「闹」：爱闹腾的孩子=顽皮淘气。 |
| martyr | n. 烈士;乞怜者;受折磨的人 vt. 使殉难,折磨 | 画面联想：为信仰赴死的 martyr 烈士；被折磨的人。 |
| fasten | vt. vi. 扣紧,系牢;(使) 盖好;抓牢 vt. 使牢固,使固定 | fast（紧的）+en（使）→系紧扣牢。 |
| superstition | n. 迷信,迷信观念 | super（超）+st（站）→超出理性的说法=迷信。 |
| drip | vi. (液体) 滴下 vi. vt. 滴 (水),滴下 (液体);充满 n. 滴落,滴水声;滴液;点滴瓶 | 拟声词：水龙头 drip 滴答滴答滴水。 |
| vogue | n. 流行,时尚,⻛尚 | 时尚杂志《Vogue》→vogue=流行时尚；in vogue 正流行。 |
| horn | n. (动物的) ⻆;(乐器) 号;喇叭 | 谐音「号」：吹 horn 号角；牛羊的角也叫 horn。 |
| antonym | n. 反义词 | anti（反）+onym（名，同 synonym 同义词）→反义词。 |
| lick | vt. 舔;轻松战胜,轻易对付 vt. vi. (火焰) 轻轻触及 (某物) n. 舔;一点儿 (涂料) | 画面联想：狗 lick 舔盘子；轻松战胜对手也叫 lick。 |
| sponge | n. 海绵;海绵动物;海绵蛋糕 vt. 用海绵擦拭 vi. 吃白⻝,揩油 | 画面联想：海绵 sponge 吸满水，一挤就干。 |
| thigh | n. 大腿;(⻝用禽类的) 腿 | 画面联想：thigh 大腿；鸡腿也叫 thigh。 |
| preposition | n. 介词,前置词 | pre（前）+position（位置）→放在名词前的词=介词。 |
| yawn | vi. 打哈欠;(开口、洞穴等) 豁开 n. 哈欠;乏味的事情,无趣的想法 | 拟声词：困了 yawn 打哈欠「哈——」。 |
| dew | n. 露,露水,露珠 | 画面联想：清晨草叶上的 dew 露珠，日出即干。 |
| crate | n. 板条箱,装货箱 vt. 把...装入货箱 | 画面联想：装水果的 crate 板条箱，钉得结结实实。 |
| garlic | n. 大蒜 | 画面联想：剥开 garlic 大蒜，辣得直咧嘴。 |
| peanut | n. 花生;少得可怜的钱 | pea（豌豆）+nut（坚果）→花生；工资少得可怜也叫 peanut。 |
| lash | vt. vi. 猛击,狠打;迅速摆动 vt. 鞭打,抽打;捆绑,绑紧 n. 睫毛;鞭打,抽打 | 画面联想：lash 长睫毛；也指鞭子抽打。 |
| lace | n. 蕾丝,花边;鞋带,系带 vi. vt. (把...) 用带子系牢 vt. 给...掺 (酒或药等);在...里夹杂 | 音译「蕾丝」：lace 蕾丝花边；鞋带也叫 lace。 |
| velvet | n. 天鹅绒,丝绒 | 画面联想：velvet 天鹅绒柔软光滑、泛着光泽。 |
| battalion | n. (军队的) 营;队伍 | 与 battle（战斗）同源→军队战斗编制=营。 |
| vendor | n. 小贩;销售商 | 自动售货机 vending machine 的 vendor=小贩、销售商。 |
| anew | adv. 重新,再一次 | a（在）+new（新）→重新、从头再来。 |
| bark | vi. (犬) 吠 vt. 怒气冲冲地说,咆哮 n. 犬吠声;树皮;很大的响声 | 拟声词：狗 bark 汪汪叫；树的皮也叫 bark。 |
| bead | n. 珠子;念珠;(液体的) 小珠 | 画面联想：串成串的 bead 珠子；泪珠也成小珠。 |
| eggplant | n. 茄,茄子 | egg（蛋）+plant（植物）→结蛋形果实的植物=茄子。 |
| lesbian | n. 女同性恋者 | 源自希腊 Lesbos 岛（女诗人萨福故乡）→女同性恋者。 |
| rifle | n. 来复枪,步枪 vi. vt. 快速翻找,搜寻 | 音译「来复枪」：rifle 步枪；动词=快速翻找。 |
| coexist | vi. 同时存在,共存 | co（共同）+exist（存在）→共同存在=共存。 |
| artifact | n. 人工制品,手工艺品 | arti（技艺）+fact（做）→用技艺做出的物件=手工艺品。 |
| nil | n. 无,零 | 足球比分 nil=零；nil 就是无、零。 |
| impromptu | adj. 即兴的,无准备的,即席的 adv. 即兴地,无准备地 | im（不）+prompt（准备好的）→没准备的即兴发挥。 |
| clench | vt. vi. 握紧 (拳头),咬紧 (牙关) vt. 紧握,紧咬 | 画面联想：生气时 clench 握紧拳头、咬紧牙关。 |
| cosmos | n. 宇宙 | 希腊语 cosmos=秩序、宇宙；宇宙万物秩序井然。 |
| bilateral | adj. 双边的,双方的;两边对称的 | bi（二）+lateral（边）→双边、双方的。 |
| brace | n. 支架;牙箍;背带 vt. 防备,做准备;顶住,抵住 | 与 embrace（拥抱）同源→双臂撑住=支架；brace 做好准备。 |
| tray | n. 托盘,浅盘 | 画面联想：服务员端着 tray 托盘上菜。 |
| drunken | adj. 醉酒的,酗酒的;醉酒引起的 | drunk（醉的）+en→醉醺醺的、酗酒的。 |
| retarded | adj. 弱智的,智力迟钝的 (冒犯性) | 词根 retard（延迟）→发育迟缓；此词冒犯，慎用。 |

# 词 1321–1360

> 📅 09月28日 Monday · 词 1321–1360 · PDF 第 67–68 页 · 新词 40 · 复习 160 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| clearing | n. (树林中的) 小块空地 | clear 清除 + ing，树被清光的一块地 = 林中空地 |
| ingenious | adj. 精巧的,巧妙的;善于创造的 | 与 genius 天才同源，有内在天才的 = 精巧、巧妙 |
| imperative | adj. 紧急的,至关重要的;祈使的 n. 重要紧急的事;祈使语气 | 与 emperor 皇帝同源，皇帝下令必须做 = 紧急的；祈使句 |
| layman | n. 外行,⻔外汉;非神职人员 | lay 外行的 + man 人，不懂专业的人 = 外行 |
| nightmare | n. 噩梦;令人恐怖的处境 | night 夜 + mare 古义"梦魇鬼"，夜里压身的鬼 = 噩梦 |
| hover | vi. 盘旋,悬停;徘徊,摇摆不定 | 直升机在头顶 hover 悬停，盘旋不走 = 盘旋、徘徊 |
| eloquent | adj. 雄辩的,有口才的;传神的 | loqu 说(dialogue 同源)+e 出，话从口出 = 雄辩的 |
| mount | vt. 安排,组织开展;登上;安置 vi. 逐步增加 vt. vi. 骑上,乘上 n. 山峰;坐骑;托架 | mountain 山去尾 = mount，登上山；数量 mount 上升 |
| notify | vt. 通知,告知 | note 记号同源 not 知道 + ify 使，使知道 = 通知 |
| displace | vt. 取代;迫使...离开家园;移走 | dis 离开 + place 位置，把别人挤离位置 = 取代、移走 |
| distort | vt. 使变形,使扭曲;歪曲,曲解 | tort 扭(torture 酷刑同源)+dis 坏，扭得变形 = 扭曲、歪曲 |
| constitution | n. 宪法,章程;体质;构成,成分 | stitute 建立(institute 同源)，立国之本 = 宪法；体质 |
| irrational | adj. 不合逻辑的,不合理的,荒谬的 | ir 不 + rational 理性的，不讲道理 = 不合理的 |
| companion | n. 同伴;成双的物品之一;陪护 | com 共同 + pan 面包，一起吃面包的人 = 同伴 |
| layoff | n. 解雇,裁员;歇工期,停工期 | lay 放 + off 离开，让人放下活走人 = 解雇、裁员 |
| supplement | n. 增补 (物),补充 (物);增刊 vt. 增补,补充 | ple 填满(complete 同源)，再往满里填 = 补充、增刊 |
| religion | n. 宗教信仰;宗教 | lig 绑(ligament 同源)，把人与神绑在一起 = 宗教 |
| lump | n. 块;方糖;肿块;傻大个 vt. 把...归并一起 (或合起来考虑) | 一坨 lump 面团，大块、肿块 |
| airplane | n. ⻜机 | air 空气 + plane 飞机，天上飞的就是 airplane |
| repay | vt. 偿还,偿付;报答,回报 | re 回 + pay 付，把钱付回去 = 偿还、报答 |
| adhere | vi. 黏附,附着;遵循 (规章等) | 谐音"黏的"，胶水黏住 = 黏附；遵循 |
| turbulent | adj. 动荡的,混乱的;湍急的 | turb 搅动(disturb 同源)，水面被搅乱 = 动荡的、湍急的 |
| enlarge | vt. vi. (使) 增大,扩大 vt. 放大 | en 使 + large 大，使变大 = 扩大、放大 |
| pour | vt. vi. 倾倒,倒出;下大雨 vi. (液体、烟等) 涌流;不断涌向 | 谐音"泼"，把水泼出去 = 倾倒；大雨如泼 |
| reproduce | vt. 复制,翻印;使再现,再制造 vi. vt. 繁殖,生殖 | re 再 + produce 生产，再"生产"一个 = 繁殖、复制 |
| stalk | n. 茎,秆,梗;柄状物 vt. vi. 跟踪;出没,作祟 vi. 高视阔步,怒气冲冲地走 | 茎是竖着的杆；坏人 stalk 跟踪你，像盯梢 |
| hygiene | n. 卫生,保健 | 源自希腊健康女神 Hygieia，讲卫生保健康 |
| cage | n. 笼子 vt. 把...关进笼子里 | 鸟在 cage 里出不来，把鸟关进笼 = 笼子 |
| sociology | n. 社会学 | socio 社会 + logy 学，研究社会的学科 = 社会学 |
| insulate | vt. 使隔热,使绝缘,使隔音 | insul 岛 + ate，让电流变"孤岛" = 绝缘、隔热 |
| detain | vt. 拘留,扣押;耽搁 | tain 握(contain 同源)，把人扣住不放 = 拘留、耽搁 |
| mechanic | n. 技工;力学;机械学;机制 | machine 机器变 mechan + ic 人，修机器的人 = 技工 |
| institution | n. 机构;收容机构;习俗,制度 | stitute 建立(institute 同源)，建立的组织 = 机构、制度 |
| limb | n. 肢,臂,腿;大树枝 | climb 爬去 c = limb，爬树靠手脚 = 肢、臂、腿 |
| carpenter | n. 木工,木匠 | 源自拉丁语"造马车的人"，古代车匠 = 木匠 |
| flourish | vi. 繁荣,兴旺;茁壮成⻓ vt. 挥舞,挥动 n. 夸张动作;华丽辞藻 | flour 花(flower 同源)+ish，像花盛开 = 繁荣、兴旺 |
| payroll | n. 工资单;工资总支出 | pay 付钱 + roll 名单，发工资的名单 = 工资单 |
| northwest | n. 西北方,西北地区 adj. 西北部的;(⻛) 从西北方吹来的 adv. 向西北地;在西北 | north 北 + west 西，西北方向 |
| impart | vt. 传达,传授;赋予...特定品质 | im 进 + part 分，把知识分给人 = 传授、赋予 |
| recreation | n. 休闲,娱乐;再现 | re 再 + create 创造，玩一下恢复精力 = 休闲、娱乐 |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| bud | n. 芽,苞,花蕾;老兄,伙计 vi. 发芽,⻓出花蕾 | buddy（哥们儿）开头 bud：花蕾、老兄 |
| deregulate | vt. 撤销政府对...的管制 | de 去掉 + regulate（管制）→ deregulate 撤销管制 |
| swamp | n. 沼泽 vt. 淹没;使应接不暇 | 谐音"似汪"：一片汪洋泥水 = 沼泽，淹没一切 |
| cram | vt. vi. 把...塞进,挤满 vi. (为应考)临时死记硬背 | 考前一夜 cram 死记硬背，把知识硬塞进脑袋 |
| marsh | n. 湿地,沼泽 | 与 swamp 同义：marsh 湿地沼泽，水草杂生 |
| devour | vt. 狼吞虎咽地吃;急切地读;吞噬 | 词根 vor = 吃（carnivore 食肉动物同源）→ 狼吞虎咽 |
| millimeter | n. 毫米 | milli 千分之一 + meter 米 → 毫米 |
| auxiliary | adj. 辅助的;备用的 n. 助动词 | 车上 aux 接口 = 辅助输入 → auxiliary 辅助的、备用的 |
| attic | n. 顶楼,阁楼 | 画面：斜屋顶下的 attic 阁楼，堆满旧物 |
| rehearse | vi. vt. (使) 排练,(使) 预演 vt. 默诵,默默练习;反复讲 | 联想 hear（听）：rehearse 排练时反复听台词预演 |
| crumble | vt. vi. (使) 粉碎,(使) 破裂 vi. 崩塌,破裂;衰落,崩溃 | 画面：曲奇一捏 crumble 成碎渣 → 粉碎、崩塌 |
| maiden | n. 少女,姑娘 adj. 初次的,首次的 | maiden voyage 首航：maiden 少女、首次的 |
| feather | n. 羽毛 | 谐音"飞"：羽毛 feather 轻得能飞起来 |
| adore | vt. 爱慕,疼爱 (某人);喜爱 (某物) | 谐音"爱到"：adore 爱慕到极点 |
| flare | vi. (短暂) 烧旺,燃烧;突发,加剧 vt. vi. 张大,张开 (鼻孔);发怒地说 n. 闪光信号灯;旺火;喇叭裤 (复) | 短语 flare up：火苗骤然烧旺 → 突发加剧；信号弹闪光 |
| rig | vt. 操纵;给...装帆;装配 n. 钻井设备;大卡⻋;帆装 | 比赛结果被 rig 暗箱操纵 → rig 操纵；钻井设备 |
| sulfur | n. 硫,硫磺 | 火山口黄黄的 sulfur 硫磺味 |
| napkin | n. 餐巾,餐巾纸 | nap 布 + kin 小 → 膝上小布 = 餐巾 |
| roast | vt. vi. 烘,烤 (肉等);焙,炒 (坚果) vt. (对某人) 非常生气,严厉批评 n. 烤肉;戶外烧烤野餐会 adj. 烤的,焙的 | 烤肉 roast 滋滋冒油；喜剧节目 roast 把人"烤"狠批 |
| pottery | n. 陶器;陶艺;制陶厂 | pot（罐子）同源 → pottery 陶器、陶艺 |
| cab | n. 出租⻋;(卡⻋、火⻋的) 驾驶室 | taxicab 出租车的前半 cab → 出租车、驾驶室 |
| cigar | n. 雪茄 | 谐音"雪茄"：cigar 粗烟卷雪茄 |
| crab | n. 螃蟹;螃蟹肉 | 谐音"跨步"：螃蟹 crab 横着跨步走 |
| poise | n. 镇定,沉着;体态,姿态 vi. vt. 使平衡,保持 (某种姿势) | 谐音"抱姿"：保持姿势平稳 = 镇定、体态 |
| cane | n. 茎;藤条;手杖,拐杖 vt. 用藤条鞭打 | 画面：老人拄 cane 手杖；藤条杖打人 |
| spit | vt. 吐,唾;怒斥 vi. 吐口水;劈啪作响;下小雨 n. 唾液,口水;烤肉扦 | 画面：生气 spit 吐口水；烤肉时油"滋"一声 |
| lily | n. 百合 | 女孩名 Lily（莉莉）：lily 百合花 |
| ashore | adv. 在岸上,向岸上 | shore（岸）同源 → ashore 向岸上 |
| irregular | adj. 不整⻬的;不规则的;不正常的 n. 非正规军军人 | ir 不 + regular（规则）→ 不规则的 |
| steak | n. 牛排;肉排;牛肉块;⻥排 | 画面：铁板上的 steak 牛排滋滋作响，切一刀七分熟 |
| ozone | n. 臭氧 | 臭氧层 ozone layer：ozone 保护地球的臭氧 |
| upstairs | adv. 往楼上,在楼上 adj. 楼上的 n. 二楼及以上各层 | up + stairs（楼梯）→ 往楼上 |
| dodge | vt. vi. 躲开,避开 vt. 逃避,回避 n. 花招,伎俩 | 谐音"躲急"：紧急躲闪 = 躲避；耍花招 |
| aide | n. 助手,助理 | aid（帮助）同源 → aide 助手 |
| oversight | n. 疏忽,忽略;监督,监管 | over 越过 + sight 看 → 看漏 = 疏忽；居高监督 |
| discreet | adj. (言行) 谨慎的;不显眼的 | 行事 discreet 谨慎低调，不声张不显眼 |
| deplore | vt. 公开谴责,强烈反对 | 词根 plor = 哭喊：deplore 痛斥强烈反对 |
| notwithstanding | prep. adv. conj. 尽管,虽然 | not + withstand（抵挡）→ 抵挡不了 = 尽管 |
| affirm | vt. 证实,确认;断言,申明 | af 加强 + firm（坚固）→ 断言、证实 |
| plateau | n. 高原;平稳时期,停滞时期 vi. 达到稳定时期 | plate（盘子）同源：高原像平底大盘子；到平台期停滞 |

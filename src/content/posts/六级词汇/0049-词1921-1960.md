# 词 1921–1960

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| anecdote | n. 轶事,趣闻 | 谐音"安妮逗他"：讲安妮的轶事逗乐大家 = 趣闻 |
| sanitation | n. 公共卫生,卫生设施 | 词根 san = 健康（sane 健全同源）→ 保健康的设施 = 公共卫生 |
| massage | n. 按摩 vt. 按摩;篡改 (事实) | 谐音"马杀鸡"（粤语）：按摩店做个 massage 放松 |
| fingerprint | n. 指纹 vt. 提取...的指纹 | finger 手指 + print 印 → 指纹 |
| golf | n. 高尔夫球 (运动) | 谐音"高尔夫"：golf 把球一杆打进洞里 |
| knit | vt. vi. 编织,针织;(使) 紧密结合 n. 编织的衣服,针织衫 | 画面：奶奶一针一针 knit 织毛衣，越织越紧 → 编织、紧密结合 |
| paradigm | n. 典范,范例,样式 | 源自希腊语"展示的样板"→ 典范、范例；库恩的科学范式 |
| dent | n. 凹痕,凹坑 vt. 使凹陷;损害,伤害 | 联想 dentist（牙医）的 dent 牙根：牙被磕出凹痕 → 凹陷 |
| castle | n. 城堡;(国际象棋中的) ⻋ | 画面：城堡 castle 高墙；国际象棋的"车"形似城堡 |
| cocktail | n. 鸡尾酒;冷盘;混合物 | cock 公鸡 + tail 尾巴 → 鸡尾酒（源自鸡尾羽毛装饰） |
| nap | n. 小睡,打盹;绒毛 vi. 小睡,打盹 | 画面：午后打个 nap 小盹，起来精神好 |
| bumper | n. 保险杠 adj. 丰收的,巨大的 | bump（碰撞）同源 → bumper 保险杠专挡碰撞；丰收 = 产量撞顶 |
| longitude | n. 经度 | long（长）：经线南北最长 → 经度；对比 latitude 纬度 |
| shove | vi. vt. 猛推,乱挤,推撞 vt. 乱放,随手扔 n. 猛推 | 画面：地铁早高峰被人 shove 猛推乱挤，东西随手 shove 扔 |
| curtail | vt. 限制,削减,缩短 | 词根 cur = 短（curt 简短同源）→ curtail 缩短、削减 |
| dessert | n. (饭后) 甜点 | 对比 desert（沙漠）：dessert 甜点多一个 s = 多来一份甜点 |
| cardboard | n. 硬纸板,卡纸板 adj. 不真实的,虚假的 | card 卡片 + board 板 → 硬纸板 |
| blond | adj. (头发) 金色的;(人) 有金发的 n. ⻓着金发的人 | 画面：blond 金发碧眼，好莱坞金发帅哥 |
| commonwealth | n. 英联邦;自治政体;联合体 | common 共同 + wealth 财富 → 共富联合体 = 英联邦 |
| repress | vt. 忍住,克制;(用武力等) 镇压 | re 回 + press 压 → 把情绪压回去 = 克制、镇压 |
| optimum | adj. 最佳的,最适宜的 n. 最佳条件,最佳水平 | 词根 optim = 最好（optimistic 乐观同源）→ optimum 最佳的 |
| colonel | n. 上校 | 发音像 kernel（玉米粒）：上校肩章一排星星像玉米粒 |
| fuse | n. 保险丝;引信,导火线 vi. vt. (使) 融合,熔接;(使) 熔化 | 保险丝过热"熔断"：fuse 熔化、熔接 = 融合 |
| calf | n. 小腿肚;牛犊;幼兽 | 画面：小牛犊 calf 甩着小腿肚 calf，一词两义 |
| lavatory | n. 厕所,洗手间 | 词根 lav = 洗（laundry 洗衣同源）→ 盥洗室 = 厕所 |
| stark | adj. 荒凉的;严酷的;明显的 adv. 一丝不挂,赤裸 | 搭配 stark naked 一丝不挂：荒凉赤裸的 stark |
| chant | vi. vt. 反复呼喊;吟唱,吟诵 n. 重复的话语;圣歌,赞美诗 | 谐音"唱"：chant 反复吟唱、喊口号 |
| parole | n. 假释,有条件的释放 vt. 准许...假释,使获假释 | 词根 par = 说（parliament 议会同源）：假释凭口头承诺 |
| conjunction | n. 结合,同时发生;连词 | con 共同 + junct 连接（junction 路口同源）→ 结合；连词 |
| brink | n. 边缘;边沿 | 短语 on the brink of：濒临崩溃的边缘 |
| intangible | adj. 难以描述的;(资产等) 无形的 n. 无形的东西 | in 不 + tang 触摸（contact 同源）→ 摸不着 = 无形的 |
| tease | vi. vt. 戏弄,取笑;挑逗 vt. 逗弄 (动物);倒梳 (头发) n. 戏弄,取笑;爱戏弄人的人 | 画面：揪人辫子 tease 逗弄取笑，惹人生气 |
| bandage | n. 绷带 vt. 用绷带包扎 | band（带子）同源 → bandage 绷带包扎 |
| booth | n. 小隔间;摊位;火⻋座,卡座 | 画面：电话亭 phone booth、投票 booth 都是小隔间 |
| airborne | adj. 在空中的;空气传播的;空降的 | air + borne（bear 的过去分词被携带）→ 空中的、空气传播 |
| throne | n. (君王的) 宝座;王位,王权 | 同音 thrown（被扔出）：国王被扔下 throne 王座 |
| missionary | n. 传教士 | mission（使命）同源 → 传教士带着传教使命远行 |
| cosmetic | n. 化妆品 adj. 表面的,装点⻔面的;整容的 | 化妆品只修门面 → cosmetic 表面的、装点门面的 |
| quake | vi. (因恐惧) 发抖,颤抖;剧烈震动 n. 地震 | earthquake 地震 = earth + quake → quake 震动、发抖 |
| gown | n. 女礼服;礼袍;罩衣 | 画面：毕业典礼学士 gown 礼袍；晚宴 gown 礼服 |

# 词 1441–1480

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| sightseeing | n. 游览,观光 | sight 景色 + see 看，到处看景 = 观光 |
| equip | vt. 装备,配备;使有能力 | equipment 设备的动词，配上设备 = 装备、配备 |
| govern | vt. vi. 统治,治理 vt. 支配,控制,影响 | government 政府的动词，治理国家 = 统治 |
| disappoint | vt. vi. (使) 失望 vt. 使...破灭 | dis 不 + appoint 期望，期待落空 = 失望 |
| enact | vt. 通过 (法案);演出;使发生 | en 使 + act 行动，让法律"动起来" = 通过法案 |
| counterpart | n. 职务相当的人,作用相当的事物 | counter 相对 + part 部分，职位相对的那人 = 对应人物 |
| sunrise | n. 日出 (时分) | sun 太阳 + rise 升起，太阳升起时 = 日出 |
| attorney | n. 律师;代理人 | turn 转同源，替你"转办"事务的人 = 律师、代理人 |
| economics | n. 经济学;经济状况 | economy 经济 + ics 学，研究经济的学科 = 经济学 |
| ice cream | n. 冰淇淋,雪糕 | ice 冰 + cream 奶油，冻起来的奶油 = 冰淇淋 |
| oppress | vt. 压迫,欺压;压抑,使烦恼 | op + press 压，压在人民头上 = 压迫、压抑 |
| procedure | n. 步骤,程序;手术,治疗 | pro 前 + ced 走 + ure，一步步走的规矩 = 程序 |
| attempt | vt. 尝试,试图 n. 尝试,试图;谋杀企图 | tempt 试(temptation 同源)，去试一试 = 尝试 |
| cottage | n. 乡间小屋,村舍 | cot 小屋 + tage，乡村小木屋 = 村舍 |
| breakdown | n. 故障;破裂;精神崩溃;明细 | break 破 + down 下，机器趴窝 = 故障、崩溃 |
| accustom | vt. 使习惯于,使适应 | custom 习惯 + ac，使其成为习惯 = 使适应 |
| gymnasium | n. 健身房,体育馆 | 源自希腊语"裸体"锻炼之地，现为体育馆 |
| innocent | adj. 无罪的;无辜受害的;纯真的 n. 无辜的人,天真的人 | in 不 + noc 伤害，没伤过人 = 无罪的、纯真 |
| suicide | n. 自杀;自杀性行为;自杀者 | sui 自己 + cide 杀(pesticide 同源)，杀自己 = 自杀 |
| submerge | vt. vi. (使) 浸没,淹没,没入水中 vt. 掩盖,遮掩 (想法、感情等) | sub 下 + merge 沉(emerge 反义)，沉入水下 = 浸没 |
| testimony | n. 证词,口供;证据,证明 | testify 作证同源，法庭上的证词 = testimony |
| envisage | vt. 设想,展望 | vis 看(vision 同源)，脑中"看见"未来 = 设想 |
| upward | adj. 向上的;上升的,升高的 adv. 向上;上升地;...以上 | up 上 + ward 朝向，朝上的 = 向上的 |
| equate | vt. 同等看待,使等同 | equal 相等同源，划等号 = 同等看待 |
| indifferent | adj. 不感兴趣的,冷淡的;一般的 | in 不 + different 不同，对啥都"无所谓" = 冷淡的 |
| misunderstand | vt. vi. 误解,误会 | mis 错 + understand 理解，理解错了 = 误解 |
| strait | n. 海峡,狭窄的水道;困境,窘迫 | strict 紧同源，狭窄水道 = 海峡；困境 |
| orphan | n. 孤儿 vt. 使...成为孤儿 | 希腊语"孤儿"，失去父母的孩子 = orphan |
| clap | vi. vt. 鼓掌;拍手 vt. (友好地) 轻拍某人;急速放置 n. 鼓掌,掌声;砰然巨响 | 拟声 clap，拍手的声音 = 鼓掌 |
| encyclopedia | n. 百科全书 | cyclo 圆(cycle 同源)+pedia 教育，一圈全收录 = 百科全书 |
| astronomy | n. 天文学 | astro 星(astronaut 同源)+nomy 学，研究星星 = 天文学 |
| juvenile | adj. 少年的;幼稚的;(动物) 幼小的 n. 少年;幼仔,雏⻦ | juvenile court 少年法庭，juvenile = 少年的 |
| chimney | n. 烟囱;(岩石间的)狭缝 | 圣诞老人钻的 chimney 烟囱，呼呼冒烟 |
| fury | n. 狂怒,暴怒;猛烈,爆烈 | furious 狂怒的同源名词，怒火冲天 = 狂怒 |
| mechanize | vt. 使机械化 | machine 机器变 mechan + ize，让机器干活 = 机械化 |
| stool | n. 凳子;粪便 | 矮脚凳 stool，坐的凳子；stool test 大便化验 |
| kettle | n. 烧水壶 | kettle 烧水壶，水开呜呜叫 |
| amass | vt. 积累,大量收集 | a + mass 大量，攒成一大堆 = 积累 |
| cucumber | n. ⻩瓜 | cool as a cucumber 从容冷静，cucumber = 黄瓜 |
| wholesale | adj. 批发的;大规模的 adv. 以批发方式;大规模地 n. 批发 | whole 整 + sale 卖，整批卖 = 批发；大规模 |

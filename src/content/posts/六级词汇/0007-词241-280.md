# 词 241–280

> 📅 09月01日 Tuesday · 词 241–280 · PDF 第 13–14 页 · 新词 40 · 复习 320 词 · ⏱ 约 50–60 分钟

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| graph | n. 图表,图解,曲线图 | 词根 graph=写画(photograph)→ 图表 |
| erect | adj. 竖起的,直立的 vt. 建造;使...竖起;创立 | 词根 rect=直(correct)→ 竖立、建造 |
| utter | adj. 完全的,彻底的 vt. 发出 (声音),说 | utter = 彻底的;也指说出口 utter a word |
| gamble | vi. vt. 赌博;冒险,以...为赌注 n. 冒险,赌博 | 谐音"敢博"——敢下注搏一把 = 赌博 |
| apt | adj. 有...倾向的;恰当的;聪明的 | adapt(适应)去掉 ad → apt 恰当、易于 |
| nut | n. 坚果;怪人,疯子;...迷;螺母 | 核桃、腰果都是 nut;螺母也叫 nut |
| cattle | n. 牛 | 牧场 cattle 牛群 → 牛 |
| plead | vi. vt. 恳求,央求;认罪,申辩;声援 vt. 陈述案情;以...为借口 | 同源 please(请)→ plead 恳求 |
| surrender | vi. vt. 投降 vt. (被迫) 放弃,交出 n. 投降;屈服,屈从;放弃,交出 | render 交出 → 举手交出武器 = 投降 |
| rash | adj. 轻率的,鲁莽的 n. 疹子,皮疹;大量,许多 | 皮肤起 rash 红疹;行事 rash 轻率 |
| intrude | vi. 闯入,侵入;打扰,干涉 | 词根 trude=推 → 硬推进来 = 闯入 |
| deplete | vt. 大量消耗,耗减 | 联想: 把资源用到空 = 耗尽 |
| poet | n. 诗人 | poetry(诗歌)同根 → poet 诗人 |
| slight | adj. 轻微的,微小的;纤细的 n. 轻视,冷落 vt. 轻视,冷落 | 轻如羽毛 = 轻微、微小 |
| snail | n. 蜗牛 | 蜗牛 snail 慢慢爬 → 蜗牛 |
| luminous | adj. 光亮的,发光的 | 同根 illuminate(照亮)→ luminous 发光 |
| brick | n. 砖,砖块;积木;可靠的朋友 | 红砖 brick 垒墙 → 砖 |
| downtown | adv. 在市中心,往市中心 adj. 在市中心的,往市中心的 n. 市中心,城镇中心 | down 下 + town 城 → 下城 = 市中心 |
| navy | n. 海军;藏⻘色 | 海军蓝 navy blue → navy 海军 |
| astronaut | n. 航天员,宇航员 | astro 星 + naut 航行 → 宇航员 |
| ore | n. 矿石,矿砂 | iron ore 铁矿石 → ore 矿石 |
| convene | vt. vi. 召集,召开,集合 | 词根 vene=来(venue)→ 聚到一起 = 召集 |
| fur | n. (动物的) 软毛;毛皮;毛皮衣服 | 谐音"肤"——毛皮如皮肤外衣 |
| fascinate | vt. vi. 使着迷,迷住 | fascinating(迷人的)同根 → 使着迷 |
| ascend | vi. vt. 上升,攀登 vi. 晋升 | 同根 descend(下降)→ ascend 上升、攀登 |
| medieval | adj. 中世纪的 | medi 中间 + eval 时代 → 中世纪 |
| supreme | adj. 至高无上的;(程度上) 最大的 | 美国最高法院 Supreme Court → 至高无上 |
| embark | vi. vt. 登船,登机 vi. 从事,着手,开始做 | em 上 + bark 船 → 上船出发 = 着手 |
| necessity | n. 必要;必需品;不可避免的情况 | necessary(必要)同根 → 必要、必需品 |
| dentist | n. 牙医;牙医诊所 | 同根 dental(牙齿)→ dentist 牙医 |
| cricket | n. 板球运动;蟋蟀 | 拟声 crick-crick 蟋蟀叫 → 蟋蟀、板球 |
| entity | n. 实体 | 谐音"一体"——独立一体 = 实体 |
| council | n. 地方议会;委员会 | 与 counsel(劝告)形近 → 委员会 |
| duplicate | vt. 复制,复印;重复,重做 adj. 完全一样的,副本的 n. 复制品,副本 | du 二(dual)→ 变两份 = 复制 |
| textbook | n. 教科书,课本,教材 adj. 典范的,范例的,规范的 | text 文本 + book 书 → 教科书 |
| deliver | vt. vi. 递送,传送;履行,兑现 vt. 发表 (讲话);交与;接生;分娩 | 外卖 delivery → deliver 递送、交付 |
| fuss | n. 紧张不安,大惊小怪 vi. (为小事) 烦恼;过分关心 | make a fuss 小题大做 → 大惊小怪 |
| resist | vt. vi. 按捺,克制;抵抗,抵制;抵御 vt. 经得起,抗 (伤害) | 词根 sist=站(stand)→ 站对面 = 抵抗 |
| retrieve | vt. 取回,找回;检索数据;挽回 | 联想"取回"——retrieve 找回、检索 |
| homogeneous | adj. 由同种族人组成的,同类组成的 | homo 同 + gene 种 → 同类组成 |

## 今日新词（带记忆钩子）

| 单词 | 释义 | 记忆钩子 |
|------|------|------|
| dove | n. 鸽子;(政治) 温和派人物,鸽派 | dove 鸽子：和平鸽 dove；政坛鸽派 dove 温和 |
| symmetry | n. 对称;相似,相等 | sym(相同)+metry(测量) → 两边量得一样=对称 |
| herald | vt. 是...的前兆;宣布 (好或重要) n. 预兆;信使,传令官 | herald 传令官先到报信 → 前兆；《先驱报》Herald |
| cape | n. 披肩,披⻛;海⻆,岬 | cape 披风：超人 cape；好望角 Cape 海角 |
| stair | n. 楼梯;一级楼梯 | stair 楼梯：一级一级往上 |
| overdue | adj. 过期未做的;早该做的 | over(过了)+due(到期) → 过期未还，早该做的 |
| rug | n. 小地毯;男用假发 | rug 小地毯：门口一块 rug 蹭蹭鞋 |
| petty | adj. 琐碎的,不重要的;小气的 | petty 琐碎：petty cash 零用钱——小钱小事；小气 |
| teller | n. 出纳员;自动提款机;讲述人 | teller 出纳员：柜台后数钱的人；ATM 取款机 teller |
| radioactive | adj. 放射性的,有辐射的 | radio(射线)+active(活跃) → 放射性的 |
| mutter | vt. vi. 嘀咕,嘟囔,小声抱怨 n. 嘀咕,嘟哝,低语 | mutter 拟声：嘴里 mumumu 咕哝=嘟囔抱怨 |
| wither | vt. vi. 枯萎,凋谢;萎缩 | wither 枯萎：花儿缺水 wither 蔫了凋谢 |
| regime | n. 政权,政体;组织方法;养生法 | regime 政权：当权者的统治；养生法 regime |
| arena | n. 竞技场,剧场;活动场地 | arena 拉丁语原义'沙地'——罗马竞技场铺沙 |
| sniff | vt. vi. 嗅,闻 vi. 抽鼻子 n. 吸气 (声),抽鼻子 (声) | sniff 拟声：抽鼻子嗅一嗅 |
| ace | n. 纸牌 A;佼佼者;发球得分 adj. 很棒的;技巧高超的 vt. 在...中表现出色 | 扑克王牌 ace A 最大 → 佼佼者；发球得分 ace |
| lap | n. (坐着时的) 大腿部;(跑道) 一圈 vi. (水) 轻拍,轻打 vt. 舔⻝;领先一圈 (或数圈) | lap 膝上：猫蜷在 lap 打盹；跑道上一圈 lap |
| terrain | n. 地形,地势,地带 | terr=地(territory 领土同源) → 地形 terrain |
| voucher | n. 代金券;凭单,收据 | vouch(担保)+er → 担保凭证 voucher 代金券 |
| heroine | n. 女英雄;女主⻆;女偶像 | hero(英雄)+ine(女性后缀) → 女英雄 |
| punctual | adj. 准时的,守时的 | punct=点(point 同源) → 卡着时间点=准时 |
| ensue | vi. 接着发生,随之产生 | en+sue(跟随，pursue 同源) → 随之而来=接着发生 |
| psychiatry | n. 精神病学,精神病治疗 | psych(心理)+iatry(治疗) → 精神病学 |
| aptitude | n. 天资,天赋 | apt(适合、有才能)+itude → 天赋 aptitude |
| durable | adj. 耐用的,持久的 | dur=持续(during 同源) → 能持久=耐用 |
| patron | n. 资助人,赞助人;顾客,常客 | patron 来自拉丁语'父亲'——像父亲般资助；也是常客 |
| whilst | conj. 当...的时候,然而,尽管 | whilst 就是 while 的古雅写法，当…时候、尽管 |
| terrace | n. 露台;梯田;排屋;阶梯看台 | terr=地(terrain 同源) → 依地而建的露台、梯田 |
| innumerable | adj. 多得数不清的 | in(不)+numer(数，number 同源) → 数不清的 |
| missile | n. 导弹,⻜弹;(作为武器) 投掷物 | miss=投掷发射 → 发射出去的导弹 |
| custody | n. 监护权;拘留,羁押 | custody 监护：法院判监护权；嫌疑人被拘留 |
| apparatus | n. 器械,仪器;机构,组织;器官 | apparatus 器械：实验室里仪器摆一排 |
| trauma | n. 精神创伤;外伤 | trauma 音似'撞'——事故撞出的精神创伤 |
| peasant | n. 农⺠,佃农 | peasant 农民：佃农在田里劳作 |
| thumb | n. 拇指;(手套的) 拇指部分 vi. vt. 翘起拇指请求搭乘;用拇指摸 | thumb 拇指：搭车竖拇指；注意 b 不发音 |
| ankle | n. 脚踝,脚脖子 | ankle 脚踝：崴了 ankle 走路疼 |
| boycott | vt. 抵制 n. 抵制行动 | 源自爱尔兰地主 Boycott，被佃户联合抵制 → 抵制 |
| sow | vt. vi. 播种,种;灌输,散布,煽动 n. 母猪 | sow 播种：春天撒种；母猪 sow 下崽 |
| antagonism | n. 对抗,敌对,敌意 | agon=斗争(agony 剧痛同源) → 对着干=敌对 |
| chorus | n. 副歌;合唱团;合唱曲;⻬声 vt. 合唱,⻬声说 | chorus 合唱：众人齐声；歌曲副歌也叫 chorus |

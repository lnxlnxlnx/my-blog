|------|------|------|
| rub | vt. vi. 擦,搓,揉;摩擦 vt. 涂,抹 n. 擦,搓,揉;问题,困难 | rubber 橡皮同源，用橡皮 rub 擦 = 摩擦、搓 |
| uranium | n. 铀 | 以天王星 Uranus 命名的元素 = 铀 |
| textile | n. 织物,纺织品;纺织业 | texture 织物质地同源，织出来的 = 纺织品 |
| gloom | n. 忧郁,沮丧;阴暗,昏暗 | 乌云压顶 gloom 昏暗，心情跟着忧郁 = 阴暗、忧郁 |
| clog | vt. vi. (使) 阻塞,堵塞 n. 木屐,木底鞋 | 下水道 clog 堵住；木屐 clog 走路咔哒 = 堵塞、木屐 |
| recede | vi. 渐渐远离;减弱;(发际线) 后移 | re 回 + cede 走(go)，水退回去 = 退去 |
| blackmail | n. 勒索,敲诈,讹诈 vt. 勒索,敲诈,讹诈 | black 黑 + mail 信，寄"黑信"勒索 = 敲诈 |
| humiliate | vt. (尤指公开) 羞辱,使丢脸 | 词源"泥土"，把人踩进泥里 = 羞辱、丢脸 |
| propagate | vt. 宣传,传播 vt. vi. (动植物) 繁殖,繁衍 | pag 页(page 同源)，像传单一样散开 = 传播、繁殖 |
| rehabilitate | vt. 协助康复;恢复名誉;修复 | re 再 + habil 能力(able)，恢复能力 = 康复、修复 |
| reshuffle | n. (机构) 人事调整,改组 vt. vi. (机构) 做人事调整,改组 | re 再 + shuffle 洗牌，人事重新"洗牌" = 改组 |
| scar | n. 伤疤;(精神) 创伤 vt. 在...上留下疤痕;留下精神创伤 | 伤口结的疤 scar，留痕 = 伤疤、创伤 |
| passerby | n. 路人,过路的人 | pass 过 + by 经过，路过的人 = 路人 |
| cheek | n. 脸颊;无礼的话 (或行为) vt. 对...粗鲁无礼地说 | 脸颊 cheek 鼓鼓的，cheek 也指厚脸皮无礼 |
| bystander | n. 旁观者,局外人 | by 旁 + stand 站，站在旁边看的人 = 旁观者 |
| denote | vt. (符号等) 代表;表示,意指 | note 标记 + de，符号带着标记 = 代表、表示 |
| meticulous | adj. 小心谨慎的 | 词源"害怕出错"，一丝不苟 = 小心谨慎 |
| groan | vi. vt. 呻吟,哼哼 vi. (因重压而) 嘎吱作响;抱怨 n. 呻吟声,哼哼声,嘎吱声 | 拟声 groan，病人疼得哼哼 = 呻吟 |
| wretched | adj. 恶劣的;可怜的;难受的 | wretch 可怜人 + ed，落魄可怜 = 可怜的 |
| preface | n. (书的) 序言,前言,绪论 vt. 以...为开端,以...作为开场白 | pre 前 + face 面，书最前面的页 = 序言 |
| furnace | n. 熔炉;暖气炉,锅炉 | 炼钢炉 furnace 火红，高温熔炉 = 熔炉、锅炉 |
| connotation | n. 含义,隐含意义 | con 附带 + note 标记，词义外带的含义 = 隐含意义 |
| detriment | n. 伤害,损害 | 词根"磨损"，慢慢磨坏 = 伤害、损害 |
| broom | n. 扫帚,扫把 | 灰姑娘用 broom 扫帚扫地 = 扫帚 |
| dissolve | vi. vt. (使) 溶解;消除,(使) 消散 vt. 解除,终止,解散 vi. 禁不住 (笑起来或哭起来等) | dis 散 + solve 解，糖入水散开 = 溶解、解散 |
| canvas | n. 帆布;画布,油画 | 帆布鞋 canvas 同款布，画家作画 = 画布、帆布 |
| metaphor | n. 比喻,暗喻 | meta 变 + phor 带，把意思"带"过去 = 比喻、暗喻 |
| slap | vt. (用手掌) 打,掴;啪地放下 vi. 啪地击打 (或撞上) n. (用手掌) 打,掴;拍打声 adv. 猛然,径直;恰好,正好 | 拟声 slap，啪一耳光 = 掴、拍打 |
| crunch | n. 嘎吱声;困境;关键时刻;卷腹 vt. vi. 嘎吱嘎吱地咀嚼 | 拟声 crunch，咬薯片咔嚓 = 嘎吱响；关键时刻 |
| slaughter | vt. 屠杀,杀戮;(体育比赛) 使惨败 n. (对动物的) 屠宰;(对人的) 屠杀 | 谐音"杀戮"，屠宰场里 = 屠杀、屠宰 |
| flour | n. 面粉 vt. 给...裹上面粉,在...上撒以面粉 | 与 flower 花同音，磨碎麦子 = 面粉 |
| capsule | n. 㬵囊;航天舱;小容器 | 吃药的小 capsule 胶囊；太空舱同词 |
| ivory | n. 象牙;象牙色;钢琴键 | 象牙 ivory 白，钢琴键原是象牙 = 象牙、象牙色 |
| defer | vt. 推迟,延缓 vi. 遵从,听从 | fer 带(transfer 同源)，把事情往后带 = 推迟 |
| dole | n. 失业救济金 vt. 发放,分发 | 失业者排队领 dole 救济金 = 救济金、发放 |
| sprinkle | vt. 洒,撒;使零星分布,点缀 n. 少量,一点;小雨 | 洒水器 sprinkle 洒水 = 洒、撒；点缀 |
| kin | n. (统称) 家属,亲戚 | kith and kin 亲朋好友，kin = 亲属、家属 |
| pirate | n. 海盗;盗版者;非法广播者 vt. 盗版,侵犯版权 | 海盗船上的 pirate，也指盗版者 = 海盗、盗版 |
| streamline | vt. 精简;使...成流线型 | stream 流 + line 线，水滴流线型 = 精简、流线型 |
| veto | vt. (正式) 否决;不同意 n. 否决权 | 拉丁语"我禁止"，一票否决 = veto |

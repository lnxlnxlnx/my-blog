# 一、私有制基础上商品经济的基本矛盾
## 1. 矛盾内容：私人劳动和社会劳动的矛盾
在以生产资料私有制为基础的简单商品经济中：
1. **私人劳动**：生产资料归私人所有，生产什么、生产多少由生产者私人决定，劳动具有私人性质；
2. **社会劳动**：商品生产面向社会分工，产品供给社会，劳动本质是社会总劳动的一部分，具有社会属性。

## 2. 矛盾如何产生
生产者劳动直接表现为私人劳动，只有商品交换成功，产品卖出去，私人劳动才能转化为社会劳动；若商品滞销，私人劳动不被社会承认，矛盾就暴露出来。

## 3. 这一矛盾是商品经济一切矛盾的根源
1. 决定商品二因素（使用价值与价值）的矛盾：卖不出，使用价值无法让渡，价值无法实现；
2. 决定劳动二重性（具体劳动、抽象劳动）的矛盾；
3. 决定商品生产者命运：商品顺利交换则获利，失败则亏损、破产；
4. 发展到资本主义商品经济，这一矛盾发展为**生产社会化与生产资料资本主义私人占有之间的基本矛盾**。

# 二、劳动价值论及其深化发展
## （一）经典劳动价值论核心内容
1. **商品二因素**
商品是使用价值和价值的统一体。使用价值是有用性，自然属性；价值是凝结在商品中无差别的一般人类劳动，社会属性，是交换价值的基础。
2. **劳动二重性（理论枢纽）**
- 具体劳动：生产使用价值；
- 抽象劳动：形成商品价值；
同一劳动过程两个方面，不是两种劳动。
3. **价值量决定**
商品价值量由**社会必要劳动时间**决定，与劳动生产率成反比。
4. **价值规律**
内容：商品价值由社会必要劳动时间决定，交换以价值量为基础等价交换；
表现：价格围绕价值自发波动。

## （二）劳动价值论的深化发展（马克思对古典政治经济学的完善与拓展）
1. 区分劳动与劳动力，为剩余价值理论奠基
古典经济学家分不清劳动和劳动力，马克思指出：工人出卖的是**劳动力**而非劳动，劳动没有价值，劳动力有价值。
2. 拓展价值创造主体：认识到总体工人
现代化生产中，脑力劳动、管理劳动、技术劳动都属于创造价值的劳动，不只是体力劳动。
3. 解释价值形式发展，揭示货币起源
简单价值形式→扩大价值形式→一般价值形式→货币，说明货币本质是固定充当一般等价物的商品。
4. 区分价值创造与价值分配
价值唯一源泉是活劳动；但土地、资本等生产要素参与分配，分配制度不改变劳动创造价值的根本原理。
5. 阐明私人劳动与社会劳动矛盾，打通商品经济到资本主义经济的逻辑链条。

# 三、资本有机构成
## 1. 三个相关概念
1. **资本价值构成**：不变资本c（生产资料）和可变资本v（工资）在价值上的比例 c:v；
2. **资本技术构成**：生产资料数量和劳动力数量的实物比例，由生产技术水平决定；
3. **资本有机构成**：由资本技术构成决定，并反映技术构成变化的资本价值构成，公式：**c:v**。

## 2. 核心规律
资本主义生产会不断改进技术，每个劳动者推动更多生产资料，因此资本有机构成**不断提高**是必然趋势。

## 3. 带来两大结果
1. 利润率趋于下降；
2. 相对过剩人口（失业工人）产生，为资本积累理论铺垫。

# 四、剩余价值理论（马克思主义政治经济学核心）
## 1. 前提：劳动力商品特殊属性
劳动力商品的使用价值（劳动）能够创造出**大于自身价值**的价值，差额就是剩余价值。
劳动力价值由再生产劳动力所需生活资料价值决定。

## 2. 不变资本c与可变资本v
- c：厂房、机器、原料，只转移原有价值，不增殖；
- v：购买劳动力的资本，能发生价值增殖，是剩余价值唯一来源。

## 3. 剩余价值生产两种方式
1. **绝对剩余价值**：工作日延长，在必要劳动时间不变前提下延长剩余劳动时间；
2. **相对剩余价值**：工作日长度不变，提高劳动生产率，缩短必要劳动时间，相对延长剩余劳动时间。
超额剩余价值是个别企业率先提高生产率获得的额外剩余价值，全社会追逐超额剩余价值最终形成相对剩余价值。

## 4. 剩余价值率 m'
反映资本家剥削程度：
$m'=\frac{剩余价值m}{可变资本v}=\frac{剩余劳动时间}{必要劳动时间}$

## 5. 剩余价值分配
产业资本、商业资本、借贷资本、土地所有者，分别瓜分产业利润、商业利润、利息、地租，本质都是剩余价值的转化形式。

# 五、资本积累
## 1. 资本积累含义
资本家不把全部剩余价值用于个人消费，而是把一部分剩余价值转化为资本，购买追加生产资料和劳动力，扩大生产规模。
剩余价值是资本积累的唯一源泉。

## 2. 资本积累两大动因
1. 内在动力：追逐更多剩余价值；
2. 外在压力：市场竞争，不扩大生产就会被淘汰。

## 3. 资本积累带来的社会后果
1. **资本有机构成不断提高**
技术进步，c比重上升、v比重下降；
2. **相对过剩人口（产业后备军）**
资本对劳动力需求相对减少，大批工人失业；
3. **两极分化（资本主义积累一般规律）**
一极：资本家财富不断积累；
另一极：无产阶级贫困不断积累；
4. **资本主义基本矛盾激化**
生产社会化与生产资料私人占有矛盾越来越尖锐，最终导向资本主义制度历史暂时性。

## 4. 资本积累历史趋势
资本积累推动生产高度社会化，但生产资料集中少数资本家手中，矛盾不可调和，必然要求公有制取代私有制。

# 整体逻辑串联
1. 起点：劳动价值论，解释商品、价值、劳动，揭示私有制商品经济基本矛盾；
2. 过渡：劳动力成为商品，创立剩余价值论，揭露剥削本质；
3. 延伸：资本家把剩余价值再投资即资本积累；
4. 伴随资本积累，技术进步，引出资本有机构成及其一系列经济后果；
整套理论层层递进，完整揭示资本主义生产运行内在规律与内在矛盾。

# lwIP 课程总览

本系列课程讲解 **lwIP 网络协议栈（原理 + 三套编程接口 + 物联网上云）**：STM32F407 探索者 + LAN8720A，主线教材为正点原子《lwIP 开发指南 V1.7》（lwIP 2.1.3），原理与应用并重。

> **课程使命：**逐层看懂 ARP/IP/ICMP/TCP 协议原理与 lwIP 源码，熟练使用 RAW / NETCONN / Socket 三套接口，打通 MQTT 上云，组合成完整联网产品。

## 前置知识

- **已具备**：STM32F407 探索者裸机开发熟练（LVGL 产品界面、FATFS、letter-shell）；FreeRTOS 课程（原理深入型）与 LVGL 课程进行中，FreeRTOS 在另一个 git 分支工程
- **本次起点**：当前工程无任何 lwIP/以太网代码；无网络编程经验——网络概念（IP 地址、端口、协议分层）从零讲起
- **课程要求**：原理 + 编程 + 上云全都要；无 OS 与带 FreeRTOS 两套移植都学
- **实验环境**：仅网线直连电脑（无路由器），需手动配置静态 IP；抓包工具 Wireshark 贯穿全程验证
- **风险提示**：直连环境下没有 DHCP/网关，MQTT 上云实验暂时无法完成——课程中明确标注并给出"联网后补做"的路径

## 课程目录（15 课，五个阶段）

每课一个独立页面，含知识讲解 + 源码分析 + 自测 + 真机练习。实验环境：网线直连电脑（MQTT 上云需联网环境补做）。

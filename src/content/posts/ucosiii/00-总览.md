# UCOSIII 课程总览

µC/OS-III 与手写操作系统内核（MiniOS）——STM32F407 探索者 · 主线教材：正点原子《µC/OS-III 开发指南 V1.5》· 与 FreeRTOS 课程强衔接对比。**课程使命：**学透 µC/OS-III（位图就绪表内核），并亲手实现一个可运行的最小操作系统 MiniOS。

## 前置知识

本课程为 FreeRTOS 原理深入课程的续作，起点较高：

- **已具备**：STM32F407 探索者裸机开发熟练（F407 + LVGL + FATFS）；FreeRTOS 课程（原理深入型）进行中，已完成第 1 课，将掌握链表就绪表、PendSV 切换、调度器原理；另一个 git 分支有 µC/OS-III 工程；明确要求 UCOS 课程"讲解怎么实现一个操作系统"。
- **对课程的影响**：课程不再重复"什么是 RTOS/为什么用 RTOS"这类基础，直接进入 UCOS 机制与 FreeRTOS 的对照；第 7~12 课 MiniOS 系列每课产出一段可运行的内核代码，最终在 F407 上跑通；UCOS 应用部分（13~16 课）精选任务/信号量/互斥/队列/事件/内存管理。
- **风险提示**：同时维护三套课程（LVGL/FreeRTOS/UCOS），进度可能交叉；MiniOS 系列依赖 FreeRTOS 课程已讲过的 PendSV/调度点概念，若 FreeRTOS 未学完就开 UCOS 课，第 7~12 课会用到前置知识，需在课程里标注前置依赖。

## 课程地图（16 课，四个阶段）

每课一个独立页面，含知识讲解 + 源码分析 + 自测 + 真机练习（练习在 µC/OS-III 分支工程上进行）。

# 创建数组与基础

这是 NumPy 专题课程的第 1 课，预计 20 分钟，配套 numpy-100 的题 1~14、17，无需前置知识。

numpy 的核心对象是 **ndarray**（多维数组）：一个同类型元素的网格，比 Python list 快得多、且能整体运算。这一课先搞定**怎么创建数组**、看它的**形状/类型**，以及习题 1~14、17 会用到的全部 API。

## 知识点 1:导入与版本(题 1、2)

惯例是 `import numpy as np`，然后看版本与配置：

```python
import numpy as np
print(np.__version__)          # '2.4.4'
np.show_config()               # 打印编译/系统配置(题 2)
```

## 知识点 2:三种最基础的创建——array / arange / linspace

`np.array` 从现有列表造; `np.arange` 造整数序列(半开区间); `np.linspace` 造等距浮点(含两端):

```python
import numpy as np
np.array([1, 2, 3])                  # 一维:array([1,2,3])
np.array([[1, 2], [3, 4]])           # 二维:传入嵌套列表
np.arange(10)                        # array([0..9]) 题7 → np.arange(10,50)
np.arange(0, 10, 2)                  # 0,2,4,6,8 (start, stop, step)
np.linspace(0, 100, 5)               # 0,25,50,75,100 (含端点)
```

题 7 用 `np.arange(10, 50)`;题 9 要先 `np.arange(9)` 再 reshape(下一课讲reshape)。

## 知识点 3:预填数组——zeros/ones/eye/empty

要"全 0、全 1、单位阵"这类按需填充的数组,别用循环:

```python
np.zeros(10)                 # 10 个 0(题3:a size-10 null vector)
np.zeros((3, 4))             # 3x4 全 0(shape 用元组)
np.ones((2, 3))              # 2x3 全 1
np.eye(3)                    # 3x3 单位阵(题11)
np.empty((2, 2))             # 未初始化(垃圾值,别乱用)
```

题 3 是 `np.zeros(10)`;题 6 想在"第 5 个元素为 1":先 zeros 再 `Z[4] = 1`(索引下一课详细讲)。

## 知识点 4:形状与类型属性——shape/ndim/dtype/itemsize/size

一个数组的"体检"属性,题 4 的陷阱就在 size/itemsize:

```python
Z = np.zeros((10, 10))
Z.shape          # (10, 10) 各维长度
Z.ndim           # 2 维度数
Z.size           # 100 元素总数
Z.dtype          # dtype('float64') 每个元素类型
Z.itemsize       # 8 每个元素字节数(float64 = 8 字节)
```

题 4 问"内存多大":`Z.size * Z.itemsize`(元素数 × 每元素字节)。这 5 个属性是 numpy 的基础读法,务必都记住。

## 知识点 5:随机数组——np.random(题 12、13、14)

造随机数组(均匀分布)是 numpy 高频需求:

```python
rng = np.random.default_rng()          # 现代做法(推荐)
rng.random((3, 3, 3))                  # 题12:3x3x3 随机(0~1)
rng.random((10, 10))                   # 题13:10x10 随机
rng.random(30)                         # 题14:30 个随机
```

旧式写法 `np.random.random((3,3,3))` 仍可运行;新代码建议 `default_rng()`。随后取 min/max(题13)与 mean(题14):直接 `Z.min() / Z.max() / Z.mean()`(下一课讲聚合)。

## 测验

### 测验 1
创建 3 行 4 列全 0 数组?
- A. np.zeros(12)
- B. np.zeros((3,4))(正确)
- C. np.empty(3,4)
- D. np.zero(3,4)

<details>
<summary>答案与解析</summary>

**答案：B**。shape 用元组:np.zeros((3,4));np.zeros(12) 是一维 12 个。
</details>

### 测验 2
一数组 size=100、itemsize=8,占多少字节?
- A. 100
- B. 800(正确)
- C. 8
- D. 108

<details>
<summary>答案与解析</summary>

**答案：B**。size×itemsize = 100×8 = 800 字节。题4的核心。
</details>

### 测验 3
0~1 之间 5 个等距浮点?
- A. np.arange(0,1,5)
- B. np.linspace(0,1,5)(正确)
- C. np.random(5)
- D. np.array(0,1)

<details>
<summary>答案与解析</summary>

**答案：B**。linspace 含端点等距;arange 是等距整数步长,不是造 N 个点。
</details>

### 测验 4
Z.size 表示?
- A. 每维长度
- B. 元素总数(正确)
- C. 维度个数
- D. 字节数

<details>
<summary>答案与解析</summary>

**答案：B**。size=总元素数;每维长度是 shape;维度数是 ndim;字节数 itemsize。
</details>

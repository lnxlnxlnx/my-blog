# 高级题型总复习

这是 NumPy 专题课程的第 6 课，也是最后一课，预计 30 分钟，配套 numpy-100 的题 75~100，前置是第 5 课「结构化数组与进阶」。

最难的一批(★★☆~★★★,题75~100)其实都在重复同样几招:**滑窗 `sliding_window_view`**、**下一步转移 `stride/pad/roll`**、**卷积 `convolve`**、**距离/矩阵 `einsum/linalg`**、**group-by `bincount`**。把本课的大招记熟,75~100 就不难了。

## 知识点 1:滑窗 / 卷积——跳过 for(题 75、80、84、88)

凡是"相邻 N 个一起算"(均值、移动平均、块求积),都优先滑窗;凡是要"邻居线性叠加"用卷积:

```python
from numpy.lib.stride_tricks import sliding_window_view
x = np.arange(1, 11)
W = sliding_window_view(x, 3)        # 每行3个连续
avg = W.mean(axis=1)                 # 移动平均

# 卷积:做"邻居加权和"
import numpy as np
k = np.ones(3) / 3                    # 3点平均核
np.convolve(x, k, mode="valid")       # 和 sliding_window.mean 一致
# Game of Life(题88)就是二维卷积:neighbor 计数
```

题75 滑动窗口平均 → sliding_window+mean;题84 3×3 子块 → sliding_window_view(arr,(3,3))。

## 知识点 2:一维滑窗生成"错位数组"(题 70、76)

题76:由一维 Z 生成二维数组,第 i 行是 Z[i],Z[i+1],Z[i+2]——这就是 sliding_window_view(窗口3):

```python
Z = np.arange(1, 11)
N = 3
sliding_window_view(Z, N)            # shape (8,3)
# 每行 = Z[i],Z[i+1],Z[i+2]
```

题70 是"3 个连续的窗"收集,和它同招。记住:连续窗口 → sliding_window_view。

## 知识点 3:距离 / 矩阵——einsum 与广播(题 69、78、82、86)

题69:两个矩阵内积的对角线(避免整体矩乘):

```python
A = np.random.random((5, 8))
B = np.random.random((8, 5))
# 对角线用元素乘再按行和,避免 A@B 整体算
np.einsum("ij,ji->i", A, B)   # 每个 i:A[i]·B[:,i](不建整个内积阵)
# 或:np.sum(A * B.T, axis=1)
```

题82:矩阵秩 `np.linalg.matrix_rank`:`np.linalg.matrix_rank(M)`。题86:一堆矩阵×一堆向量——用 `np.matmul(A, v[...,None])` 或 einsum。距离/模长用 `np.linalg.norm` 或手写平方和。`einsum` 是"指定下标求和"的瑞士军刀(德国人是真懂的)。

## 知识点 4:group-by→均值(题 68、79、83)

"按标签分组求均值 / 最频值"这类,一律 bincount(带权重),别写循环:

```python
labels = np.array([0, 0, 1, 1, 2])     # bincount 是整数标签
values = np.array([1.0, 3.0, 10.0, 14.0, 99.0])
counts = np.bincount(labels)                    # [2,2,1] 每标签个数
sums   = np.bincount(labels, weights=values)    # 每标签和
means  = sums / counts                          # 每标签均值
# 题83:最频值 → bincount 的 argmax
```

题79 两个点集合之间的距离矩阵:广播 `P0[:,None] - P1[None,:]` 再 norm。题83 最频值 = `np.bincount(Z).argmax()`。

## 知识点 5:进/出流与重排(题 95、96、99、偶有 93)

题95:整数向量转二进制矩阵——用位运算+广播:

```python
Z = np.arange(1, 6)          # 1..5
n = 4
(Z[:, None] & (1 << np.arange(n)[::-1])) > 0    # 二进制的每一位展开
# 或:((Z[:,None] >> np.arange(n-1,-1,-1)) & 1).astype(int)
```

题96:二维数组去重行:`np.unique(Z, axis=0)`(unique 可指定按轴/行)。题99:选"行和能被 n 整除"的行:`Z[Z.sum(axis=1) % n == 0]`。核心再强调:**能整体/广播/唯一/位运算,就别写 for**。

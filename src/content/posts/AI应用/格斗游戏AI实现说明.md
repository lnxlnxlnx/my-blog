# 格斗游戏 AI 实现说明

> 位置：`qt_dev/mytest/FightGame.qml`（2 人格斗，Canvas 绘制，P1 手柄 + P2 AI）
> 结论先行：**不是强化学习，也不是决策树/状态机**，而是**纯手写的距离阈值 + 随机策略**。AI 每帧读对手位置，按距离分档决定"靠近 / 后退 / 出手 / 发呆"。

## 1. 总体结构

游戏主循环（`Timer` 16ms）每帧依次调用：

```
onTriggered()
  ├─ p1Input()      P1 读手柄(摇杆/A/B/X)
  ├─ p2AI()         本文主角:P2 决策
  ├─ updateFighter()  物理/状态更新(含攻击判定框生成)
  ├─ checkAttacks()   攻击矩形碰撞检测
  └─ canvas.requestPaint()  重绘
```

## 2. AI 决策逻辑

`p2AI()`（优化后，`FightGame.qml:74`）只有两段：

**第一段 —— 面向与距离判定**

```js
var dx = p1.x - p2.x
var dist = Math.abs(dx)
if (p2.state !== "idle" && p2.state !== "walk") return   // 出招/跳跃中不重新决策
p2.vx = 0
p2.facing = dx > 0 ? 1 : -1    // 始终面向对手
```

**第二段 —— 按距离三档决策**

| 距离区间 | 行为 |
|---------|------|
| `dist > 68` | 朝对手走（`vx = ±2.8`） |
| `dist < 38` | 后退拉开（`vx = ∓1.8`），避免贴身无攻击空间 |
| `38 ≤ dist ≤ 68` | 攻击冷却好了就 80% 概率出拳/踢，20% 犹豫 |

关键常量：

- `ATK_DIST = 68` —— 攻击判定框实际有效射程（见下节推导）
- `BACK_DIST = 38` —— 过近后退阈值
- `atkCd = 42` —— 攻击硬直帧（出招后 42 帧内不再出手）

## 3. 攻击距离怎么来的

AI 出拳的判定框（`updateFighter` 中生成）：

```js
x: f.x + (f.facing > 0 ? f.w - 12 : -reach),   // 右向: f.x + 28
w: reach                                        // reach = 44
```

面向右时，判定框覆盖 `[f.x+28, f.x+28+44] = [f.x+28, f.x+72]`。
对手身体在 `[p1.x, p1.x+40]`。命中条件是两者相交：

```
p2.x + 28 < p1.x + 40  →  p1.x > p2.x - 12
p2.x + 72 > p1.x       →  p1.x < p2.x + 72
```

即 **`dist < 72` 出手必中**。代码取 `ATK_DIST = 68` 留了 4px 余量，保证 AI 出手不会打空。

## 4. 攻击/命中细节

- **伤害**：AI 拳 6、脚 9（P1 是 12/16，玩家占优）
- **射程**：AI 44px（P1 62px，玩家更长）
- **攻击判定时机**：`atkDur` 在 4~12 帧之间生成判定框，出招中段生效
- **命中效果**：扣血 + `hitFlash` 闪白 + 击退（`vx = attacker.facing * 3`，位移 12px）
- **胜负**：血 ≤ 0 判定，弹结束遮罩（A 再来一局 / B 返回）

## 5. 本次优化改了什么

原版把 AI 做得"笨"靠的是**一堆随机多余动作**，已移除：

| 原问题 | 问题分析 | 处理 |
|--------|---------|------|
| 出手距离用 `dist < 85` | 实际判定框只到 72px，85 内出手必打空 | 改为精确的 `ATK_DIST = 68` |
| AI 30% 挥空（`miss`） | 距离对了也随机打不中，纯浪费 | 删除挥空逻辑 |
| `r < 0.1` 乱跳 | 跳起后不攻击、还脱离距离 | 删除 AI 跳跃 |
| 接近时 30% 概率后退/绕圈 | `dist > 140` 时后退越走越远，毫无意义 | 删除，靠近就是靠近 |
| 出手概率仅 45% | 大部分时间发呆 | 提高到 80% |
| 未显式面向对手 | 站定时可能朝反方向出招 | 决策前强制 `facing` 指向对手 |

优化后 AI 行为："远离→靠近、贴脸→拉开、射程内→果断出手"，不再有打空、乱跳、反向出招等冗余动作，同时保留 20% 犹豫和 42 帧硬直，不会无脑连击。

## 6. 为什么不叫"AI 算法"

这里的 `p2AI()` 严格说是**规则脚本**，不是算法：

- 没有搜索（不像五子棋的 alpha-beta）
- 没有学习（不是强化学习）
- 没有状态机抽象（就是几个 `if/else` 距离分支）
- 决策输入只有**一个变量**：距离 `dist`（+ 随机数 + 冷却计时）

它适合这个场景：格斗 AI 的对手只是让玩家有个能打的陪练，规则够用、零训练成本、单核实时跑无压力。

## 7. 如果想继续调

- **强度**：改 `ATK_DIST`（攻击范围）、`Math.random() < 0.8`（出手概率）、`atkCd = 42`（攻击间隔）
- **行为**：加状态机（压迫/防守/反击），或检测 P1 出招后闪避/格挡
- **公平性**：目前玩家伤害/射程都占优，改 `dmg` 和 `reach` 可平衡

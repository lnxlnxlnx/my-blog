# 裸机 ARM 汇编课程总览

主线：《I.MX6U 驱动开发指南 V1.81》第 6/7/8/9/10/15 章，为 Linux 驱动课补“亲手写寄存器”的地基。

课程背景要点：为支撑 Linux 驱动课的“亲手写寄存器”基线开设；工具链三连（gcc 汇编编译 → ld -Ttext 0X87800000 → objcopy）与烧录仅走 SD 卡（imxdownload，不动 eMMC）；`start.S` 三步曲（关看门狗、`ldr sp,=0X80200000`、`b/bl main`）；A 系列与 Linux 课术语打通（同一组寄存器地址），可先用 objdump 反汇编完成大部分练习。

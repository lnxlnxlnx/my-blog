# 基础功能:索引、选择、排序、统计

这一课是 pandas 最常用的"手":**怎么取数据(reindex/drop/loc/iloc)**、**算术对齐算术方法**、**排序与排名**、**描述性统计**。参考:[书 5.2/5.3](https://github.com/BrambleXu/pydata-notebook)、[hangsz 2/9/10](https://github.com/hangsz/pandas-tutorial)。

## 知识点 1:选择数据——loc(标签)vs iloc(位置)

pandas 有三种取法,关键是要分清**标签**和**位置**:

```python
import pandas as pd
df = pd.DataFrame({"a": range(5), "b": range(5, 10)},
                  index=["r0", "r1", "r2", "r3", "r4"])

df["a"]           # 列:取一列(按列名)
df[["a", "b"]]    # 列:取多列
df.loc["r0"]      # 行:按标签取
df.loc["r0":"r2", "a"]   # 标签切片(含两端)+ 列标签
df.iloc[0]        # 行:按位置取
df.iloc[0:2, 0]   # 位置切片(不含尾)+ 位置列
df.loc[df["a"] > 2]      # 布尔掩码
```

口诀:`df["col"]` 取列;`.loc` 用**标签**(含末端);`.iloc` 用**位置**(不含末端);布尔条件也行。`df.x` 属性式取列(数据少用,和现方法名冲突会踩坑)。

## 知识点 2:reindex 与 drop——改标签/删行

`reindex` 按新标签重排/补 NaN;`drop` 删行或列:

```python
obj = pd.Series([1, 2, 3], index=["a", "b", "c"])
obj.reindex(["b", "a", "c", "d"])      # 重排 + d→NaN
obj.reindex(["a", "b", "c", "d"], method="ffill")  # 向前填

df = df.drop(["r0", "r1"])            # 删行
df = df.drop("a", axis=1)             # 删列(axis=1)
df.drop(columns="b")                  # 更清晰的删列写法
```

`drop` 默认返回新对象(不原地改),除非 `inplace=True`;axis=0 是行、axis=1 是列。

## 知识点 3:算术与对齐——add/sub/... 和 fill_value

DataFrame/Series 运算按索引自动对齐,对不上的 NaN;用 `add(sub/mul/div)` 的 `fill_value=` 可指定补值:

```python
df1 = pd.DataFrame(np.ones((3, 2)), columns=list("ab"))
df2 = pd.DataFrame(np.ones((2, 2)), columns=list("bc"))
df1 + df2            # 对齐后:缺失的地方 NaN
df1.add(df2, fill_value=0)   # 缺失当 0 来加

# DataFrame 与 Series 运算(广播到每列/每行)
arr = df1["a"]
df1.sub(arr, axis=0)           # 每行减同一 Series(按行)
```

对齐是 pandas 的"默认行为";想要"缺失当 0"就用 `add(fill_value=0)`。

## 知识点 4:排序与排名——sort_values / sort_index / rank

```python
df.sort_values("b")               # 按列 b 升序
df.sort_values("b", ascending=False)  # 降序
df.sort_index()                   # 按行标签排
ser = pd.Series([3, 1, 2, 2])
ser.rank()                        # 排名:并列的平均名次
ser.rank(method="first")          # 并列按先来后到
```

`sort_values` 按列值排;`sort_index` 按索引排;`rank` 求名次(默认并列取均值,method 可改)。

## 知识点 5:描述性统计——sum/mean/describe/corr(书 5.3 + hangsz 10)

沿列(axis=0)或行(axis=1)聚合;describe 一次给全;corr/cov 看相关性:

```python
df = pd.DataFrame({"a": [1, 2, 3, 4], "b": [4, 3, 2, 1]})
df.sum()              # 每列和
df.mean()             # 每列均值
df.sum(axis=1)        # 每行和
df.describe()         # count/mean/std/min/25%/50%/75%/max
df.corr()             # 列与列相关系数矩阵
df.cov()              # 协方差

# 唯一值/计数(书5.3)
s = pd.Series([3, 3, 1, 2, 2, 2])
s.unique()            # 不重复值
s.value_counts()      # 每个值出现次数(默认降序)
s.isin([1, 2])        # 判断哪些在列表里
```

axis 含义和 numpy 一样(0=跨行/每列,1=跨列/每行)。value_counts/unique 是分类统计的入门,下一课会经常用。

### 测验 1
按"标签"取行,用什么?
- A. df.iloc
- B. df.loc(正确)
- C. df[0]
- D. df.rows

<details>
<summary>答案与解析</summary>

**答案：B**。loc 用标签(含末端);iloc 用位置(不含末端);df[col] 取列。
</details>

### 测验 2
删列用?
- A. df.drop("c")
- B. df.drop("c", axis=1)(正确)
- C. df["c"]=None
- D. del rows

<details>
<summary>答案与解析</summary>

**答案：B**。删列要 axis=1(或 drop(columns=...));axis=0 是删行。
</details>

### 测验 3
df1.add(df2, fill_value=0) 作用?
- A. 忽略 NaN
- B. 对不上的当0(正确)
- C. 报错
- D. 只加对角

<details>
<summary>答案与解析</summary>

**答案：B**。fill_value=0 让索引对不上的位置按 0 计算,不留 NaN。
</details>

### 测验 4
看数值列 count/mean/std 一次给全?
- A. .info()
- B. .describe()(正确)
- C. .head()
- D. .shape

<details>
<summary>答案与解析</summary>

**答案：B**。describe 一次性给 count/mean/std/分位数;info 是列类型+缺失。
</details>

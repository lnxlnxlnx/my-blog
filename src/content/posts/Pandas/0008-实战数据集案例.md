# 实战:书第14章三案例

把前面 7 课全部串起来。书 [第14章](https://github.com/BrambleXu/pydata-notebook) 给了三个真实案例:

- **14.1 USA.gov Bitly 数据**:URL 缩短日志 → 时区统计、逐小时热度
- **14.2 MovieLens 1M**:电影评分 → 评分分布、顶级电影(join + groupby)
- **14.3 美国婴儿姓名 1880–2010**:一年一文件 → 拼接、流行度排序、单字图

## 知识点 1:USA.gov——读 JSON、时区分布(14.1)

先读 JSON 成 DataFrame,再"计数"高频时区(`tz.value_counts`)与缺失处理(`fillna` / `isnull`):

```python
import pandas as pd, numpy as np
# 书里的 records 来自在线 JSON;这里模拟读取
df = pd.read_json("usa_gov.json", lines=True)
df["tz"].fillna("Missing")            # 缺时区给个占位
df["tz"][df["tz"].isnull()].count()   # 缺失数
df["tz"].value_counts().head(10)      # Top 时区
# 加一列"是哪一天"再按天计数 → 一天热度
df["date"] = pd.to_datetime(df["timestamp"]).dt.date
df.groupby("date").size()             # 每天多少条
```

这套"读 → 清洗缺失 → value_counts → 分组热度"是日志分析的通路。

## 知识点 2:MovieLens——join 拓表 + groupby 评级(14.2)

核心是两张表通过 merge 关联(survey 你 0005 学的 join),再按电影算平均分:

```python
# ratings: user, movie, rating; movies: movie, title
rating = pd.read_table("ratings.dat", sep="::", names=["user","movie","rating"], engine="python")
movie  = pd.read_table("movies.dat", sep="::", names=["movie","title","genre"])
data = pd.merge(rating, movie, on="movie")     # 把电影名接进来
data.head()

# 每部电影的平均分 & 评分次数 → 找出"又多人评又高分"的
mean_rating = data.groupby("title")["rating"].mean()
count_rating = data.groupby("title")["rating"].count()
top = pd.concat([mean_rating, count_rating], axis=1).sort_values("rating", ascending=False)
data.rating.value_counts().sort_index()       # 评分分布(直方图用)
```

merge 两张表 → groupby("title").mean/count → sort_values = 排行榜 标准套路。

## 知识点 3:婴儿姓名——多个文件 concat + 年代演化(14.3)

一年一个 txt,用循环统一读入再 concat 成长表,再按年/性别统计:

```python
import glob, os
pieces = []
for year in range(1880, 2011):
    frame = pd.read_csv(f"names/yob{year}.txt",
                        names=["name", "sex", "births"])
    frame["year"] = year              # 补一列年份
    pieces.append(frame)
names = pd.concat(pieces, ignore_index=True)
names.shape                          # (~2M 行)

# 每年出生总数按性别
total_births = (names.pivot_table(index="year", columns="sex",
                                  values="births", aggfunc="sum"))
# 名字流行度:按 (年,性别) 算排名 top1000 再计数
# 单字名:name 长度==1 的比例逐年
# 这就是"读N个文件→concat→groupby/pivot→画出演化"
```

多文件循环 concat + 补年份列 + pivot_table 按年×性别聚合 —— 这是时间演化分析的通用套路。

## 知识点 4:把分析画出来(matplotlib 一招)

分析结果配张图立刻变直观:

```python
import matplotlib.pyplot as plt
total_births.plot()                 # 绘多年曲线(用 y 轴图)
# 或按性别的两条线:total_births[["F","M"]].plot()
plt.title("births by year"); plt.show()
```

DataFrame.plot 一行画图(matplotlib 已装)。这三个案例"输出大多是时序/分布图",这一招够起步。(matplotlib 专题可另行深入。)

## 知识点 5:综合心法——分析一条龙

把三案例的共同套路提炼成一条龙:

```python
# 1 读取:read_csv/read_json/read_table(看分隔符/编码)
# 2 体检:shape/dtypes/isnull/head
# 3 清洗:fillna/replace/astype(to_datetime)
# 4 关联/重塑:merge 拓列 / concat 堆行 / set_index/pivot
# 5 聚合:groupby+agg / value_counts / pivot_table
# 6 展示:result.plot() / describe / to_csv
```

以后拿到任何数据,都按这 6 步走;前面 7 课就是给这 6 步加料的。你现在已经具备完整的数据分析工作流。

## 测验

### 测验 1
多张表按共同键拼字段用?
- A. concat(axis=0)
- B. merge / join(正确)
- C. stack
- D. cut

<details>
<summary>答案与解析</summary>

**答案：B**。merge/join 按共同键拼列(如 movie 的 title);concat(axis=0) 是堆行。
</details>

### 测验 2
一年一个文件拼成一张长表?
- A. merge 多表
- B. 循环+concat(axis=0)(正确)
- C. pivot_table
- D. fillna

<details>
<summary>答案与解析</summary>

**答案：B**。结构相同的文件用循环 concat 堆成一张表再统一分析。
</details>

### 测验 3
按年×性别 聚合成一张宽表用?
- A. merge
- B. pivot_table(正确)
- C. cut
- D. shift

<details>
<summary>答案与解析</summary>

**答案：B**。pivot_table(index=年, columns=性别, aggfunc=sum) 转宽表便于画图。
</details>

### 测验 4
排行榜:每部电影平均分排序用?
- A. fillna
- B. groupby+mean→sort_values(正确)
- C. qcut+n
- D. pd.crosstab

<details>
<summary>答案与解析</summary>

**答案：B**。groupby("title")["rating"].mean() 再 sort_values(升/降)就是排行榜。
</details>

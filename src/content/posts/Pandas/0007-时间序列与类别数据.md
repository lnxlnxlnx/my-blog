# 时间序列与类别数据

两个专题收尾:**时间序列**(datetime64 索引、重采样、滑动)与**类别数据**(category dtype,省内存、分类统计)。对应书 [第11、12章](https://github.com/BrambleXu/pydata-notebook) 与 [hangsz 12、13](https://github.com/hangsz/pandas-tutorial)。

## 知识点 1:把字符串变 datetime——pd.to_datetime(书 11.1)

读入日期常是字符串,先用 `pd.to_datetime` 转:

```python
import pandas as pd
s = pd.Series(["2024-01-01", "2024-02-01", None])
dt = pd.to_datetime(s)          # -> datetime64[ns];None 变 NaT
print(dt.dtype)                 # datetime64[ns]
print(pd.isnull(dt))            # NaT 也算缺失
# 指定格式(性能好),应从各种格式来:
pd.to_datetime(["2024/03/05"], format="%Y/%m/%d")
pd.to_datetime(["2024:06:01"], errors="coerce")   # 解析不了变 NaT 不报错
# epoch 秒 → 时间
pd.to_datetime([1700000000], unit="s")
```

转到 datetime64 后,才能用 [年/月] 切片、重采样等时间操作。`errors="coerce"` 让坏数据变 NaT 而不是崩。

## 知识点 2:datetime64 索引——切片、loc、取组件(hangsz 13)

把 datetime 设为索引后,切片像字符串;`.dt` 取组日期成分:

```python
idx = pd.to_datetime(["2024-01-01", "2024-01-02", "2024-02-01"])
ts = pd.Series([1, 2, 3], index=idx)
ts["2024-01"]            # 按"月份"切片(所有1月)
ts["2024-01-02":]        # 字符串切片

# 取日期成分:.dt 访问器
s2 = pd.Series(pd.to_datetime(["2024-01-01", "2024-06-15"]))
s2.dt.year; s2.dt.month; s2.dt.day        # 年/月/日
s2.dt.strftime("%Y-%m")                    # 格式化
```

`ts["2024-01"]` 这种按月切片非常优雅;取成分用 `.dt`(呼应 0004 里 .str/.cat 的约定)。

## 知识点 3:重采样与滑动——resample / rolling(高价值)

把高频数据汇总成低频(日→月)用 `resample`;滑动窗口用 `rolling`:

```python
idx = pd.date_range("2024-01-01", periods=365)
ts = pd.Series(range(365), index=idx)
ts.resample("ME").mean()        # 按月求均值(每月一个值)
ts.resample("W").sum()         # 按周求和
ts.resample("D").ffill()       # 重采样后前向填充
ts.rolling(7).mean()           # 7天滑动均值(前面有NaN)
ts.rolling(7).mean().sum()     # 组合
```

resample = 改变采样频率(降采样);rolling = 固定窗口滚动统计(滑动平均)。这是时序最常用的两个。日期范围 `pd.date_range(start, periods, freq)` 生成等距索引。

## 知识点 4:时间序列移动/差分——shift / diff(pct_change)

```python
ts = pd.Series([1, 2, 4, 8], index=range(4))
ts.shift(1)          # 数据后移一格(前面 NaN),比较"跟昨天差"
ts.diff()            # 一阶差分:今天-昨天
ts.pct_change()      # 变化率:(今-昨)/昨
```

shift/diff/pct_change 三个是"跟过去比"的工具,股票/时序分析天天用。

## 知识点 5:类别数据 category(hangsz 12 / 书 12.1)

重复值很多的列用 `category`,省内存还支持有序:

```python
s = pd.Series(["a", "b", "a", "c"] * 1000)
s2 = s.astype("category")        # 类别 dtype
print(s2.cat.categories)         # Index(['a','b','c'])
print(s2.cat.codes[:5])          # 每项对应编号
print(s2.memory_usage())         # 比 object 省内存

# 有序类别 + 分箱
ser = pd.Series([1, 2, 5, 9]).astype("category")
p = pd.qcut(pd.Series(range(20)), 4, labels=["Q1","Q2","Q3","Q4"])  # 等分
p.cat.remove_unused_categories()  # 去掉没用到的类别
pd.get_dummies(s2)               # 类别→one-hot(0/1列)
```

category = 只存"编号+类别表"省内存;支持排序、做 one-hot(`get_dummies`,书 7.2 也用过)。记忆:.cat 是它的访问器。

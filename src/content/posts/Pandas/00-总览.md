# Pandas 课程总览

Pandas 专题共 8 课,基于 [pydata-notebook](https://github.com/BrambleXu/pydata-notebook)(《利用Python进行数据分析》中文笔记)+ [pandas-tutorial](https://github.com/hangsz/pandas-tutorial) + 补齐缺章。

这本书笔记只到第 5/7/11/12/14 章,缺了最关键的**数据载入(6)、合并重塑(8)、分组聚合(10)** ——本课程已用官方+hangsz 补齐,并追加太多练习。心法:**读 → 体检 → 清洗 → 合并/重塑 → 分组 → 时间/类别 → 画图**。

# 数据载入与输出

[pydata-notebook](https://github.com/BrambleXu/pydata-notebook) 没有书第 6 章「数据载入/存储/文件格式」,但这是 pandas 日常第一动作。本课给你补齐:`read_csv/read_excel/read_json` 与对应写文件。[pandas IO 参考](https://pandas.pydata.org/docs/reference/io.html)。

## 知识点 1:读 CSV——最常用

`pd.read_csv(路径)` 一步把表格读成 DataFrame;常用参数控制分隔符/表头/缺失值:

```python
import pandas as pd
df = pd.read_csv("data.csv")               # 最简
df = pd.read_csv("data.csv", sep=";")      # 分隔符(默认逗号)
df = pd.read_csv("data.csv", encoding="utf-8")   # 指定编码(中文必用)
df = pd.read_csv("data.csv", nrows=100)    # 只读前100行
df = pd.read_csv("data.csv", na_values=["NA", "?"])   # 把哪些当缺失
df = pd.read_csv("data.csv", index_col=0)  # 第0列当行索引
# 打印列名/前几行快速验证
print(df.columns.tolist(), df.shape)
```

中文文件务必 `encoding="utf-8"`(有时要 "gbk");不确定先 `nrows=5` 试读。

## 知识点 2:读 Excel / JSON / 剪贴板

```python
df = pd.read_excel("data.xlsx", sheet_name="Sheet1")
df2 = pd.read_excel("data.xlsx", sheet_name=None)  # 读全部sheet(返回dict)
dfj = pd.read_json("data.json")
# 从剪贴板直接读(非常实用)
dfc = pd.read_clipboard()
```

Excel 要 `openpyxl` 库(`uv pip install openpyxl`);sheet_name=None 一次读全部工作表成 dict。

## 知识点 3:写文件——to_csv / to_excel / to_json

```python
df.to_csv("out.csv", index=False)      # 不写行索引(常用)
df.to_csv("out.csv", index=False, encoding="utf-8-sig")   # 中文给Excel不要乱码
df.to_excel("out.xlsx", sheet_name="结果", index=False)
df.to_json("out.json", orient="records", force_ascii=False)
```

三个坑:① `index=False` 别漏,否则多一行索引列;② 中文写 CSV 给 Excel 用 `utf-8-sig`;③ to_json 用 `force_ascii=False` 保留中文。

## 知识点 4:读入后的检查习惯

读入后立刻体检(呼应 0001/0002):

```python
print(df.shape)          # 行×列
print(df.columns.tolist())   # 列名
print(df.dtypes)         # 每列类型
print(df.isnull().sum()) # 每列缺失数量
print(df.head())         # 前几行
```

黏贴这三五行,秒懂新数据集。find 缺失、类型错读(本来是数字读出 object)是读数据时最高频问题。

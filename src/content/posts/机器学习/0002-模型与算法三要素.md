# 模型 vs 算法：三要素一次讲透

这是机器学习系列课程笔记的第 2 课，前置要求：课程 0001（机器学习全景与学习路线图），预计阅读 15 分钟。这一课用一个比喻 + 一组练习，让你彻底分清日常口语里总被混用的「模型」和「算法」这两个概念。

## 一句话区别

> **模型**是「候选函数的集合」——你在哪个圈子里选答案。
> **策略**是「判断好坏的标准」——怎么给候选函数打分。
> **算法**是「搜索的过程」——你具体怎么一步步找到最好的那个。

模型是**名词**（一个空间），算法是**动作**（一段过程）。一个是被选的对象，一个是寻找的动作。

---

## 生活比喻：选一家餐厅

- **模型** = 你考虑的所有餐厅的集合（候选空间）
- **策略** = 你的评分标准（味道、价格、环境各占多少分）
- **算法** = 你找餐厅的方式（一家家排队试吃？还是看点评 App 按分排序？）

注意：候选空间（有哪些餐厅）和你找它的方法（怎么逛）是两码事。同一个餐厅集合，你可以用「全城扫街」找，也可以用「点评排序」找——**空间没变，搜索方法变了**。

---

## 线性回归三要素（示范，已填好）

| 三要素 | 在线性回归里 |
| --- | --- |
| **模型** | 所有形如 f(x) = w·x + b 的线性函数（w、b 取任意值的全体） |
| **策略** | 使均方误差（训练集上的平均平方误差）最小 |
| **算法** | 求解析解（正规方程），或梯度下降迭代 |

---

## 你来拆：把每项分进正确的分类

### 练习 1 · 逻辑回归

- 假设函数族 $f(x) = \frac{1}{1+e^{-(wx+b)}}$ 的所有可能参数 → **模型**。所有候选函数都长这样，只是 w、b 不同——候选空间 = 模型。
- 对数损失（交叉熵）：衡量预测与真实标签的差距 → **策略**。它定义「怎么打分、算多差」——评分标准 = 策略。
- 梯度下降：沿梯度反方向一步步更新 w、b → **算法**。它描述「怎么一步步找到最好的参数」——搜索过程 = 算法。

### 练习 2 · 决策树

- 所有可能的树形结构（不同切分顺序组成的全体） → **模型**。候选空间 = 模型。你最终得到的是一棵树，而候选的是所有树。
- 信息增益 / 基尼系数：选「切完后最纯」的特征 → **策略**。它定义「怎么切更好」——评价标准 = 策略。
- ID3 / C4.5：从根到叶递归地生成树 → **算法**。它描述「怎么一步步把树建出来」——生成过程 = 算法。

### 练习 3 · 支持向量机

- 所有超平面 w·x + b = 0（及其决定的分隔方式） → **模型**。候选空间 = 模型：SVM 其实是在所有超平面里选一个。
- 间隔最大化：选「离两类样本都尽量远」的那个超平面 → **策略**。它定义「哪个超平面更好」——评价标准 = 策略。
- SMO（序列最小最优化）：把大问题拆成小步迭代求解 → **算法**。它描述「具体怎么解」——求解过程 = 算法。

## 为什么容易混：术语陷阱

日常说「逻辑回归模型」「SVM 算法」，这里的「模型/算法」是**整套路线的简称**（模型+策略+算法打包）。而李航三要素里的术语是**精确**的：模型只指假设空间。这两种用法都没错，但要看清语境。这也解释了为什么你会在资料里看到它俩被混着用。

最清晰的证据：**三要素可以自由组合**。

- 同一个模型 + 同一个策略，可以配不同算法：线性回归用「正规方程」或「梯度下降」都行。
- 同一个模型，换策略就是另一个问题：把均方误差换成绝对值误差，优化目标就变了。
- 同一个算法（梯度下降）能服务无数个模型。

如果「模型」和「算法」是同一个东西，就不可能这样自由组合。像乐高积木一样：**块是块，拼法是拼法**。

## 测验

### 测验 1
问题：三要素中，「在哪个函数集合里选」指的是？
选项：A. 策略 / B. 算法 / C. 模型（正确） / D. 数据

<details>
<summary>答案与解析</summary>
<p><strong>答案：C</strong>。模型 = 候选函数的集合（假设空间），解决「在哪些答案里选」。</p>
</details>

### 测验 2
问题：「梯度下降」在逻辑回归中属于？
选项：A. 模型 / B. 策略 / C. 算法（正确） / D. 数据

<details>
<summary>答案与解析</summary>
<p><strong>答案：C</strong>。梯度下降是「怎么找参数」的过程 = 算法。</p>
</details>

### 测验 3
问题：「经验风险最小化（选训练损失最小的函数）」属于？
选项：A. 模型 / B. 算法 / C. 策略（正确） / D. 数据

<details>
<summary>答案与解析</summary>
<p><strong>答案：C</strong>。策略 = 怎么判断好坏。风险最小化是评价标准，不是候选空间也不是搜索过程。</p>
</details>

### 测验 4
问题：同一个模型配上不同的损失函数，相当于改变了？
选项：A. 模型 / B. 算法 / C. 策略（正确） / D. 数据

<details>
<summary>答案与解析</summary>
<p><strong>答案：C</strong>。损失函数属于策略。候选空间没变，只是「怎么打分」变了——三要素可自由组合。</p>
</details>

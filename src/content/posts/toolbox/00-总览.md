# Toolbox 课程总览

**嵌入式工程师工具箱** —— 构建与调试 · 代码规范 · 多媒体文件格式 · CAN 总线 · 20 课

**课程使命：**补全 LVGL/FreeRTOS/lwIP 之外"工程师日常"的硬技能。教材来自 `参考文档/other/` 的 9 份文档（正点原子技术文档 / ISO JPEG 标准 / 瑞萨 CAN 教程 / GIF 英文文章），按主题重组。详见 MISSION.md 与 RESOURCES.md。

## 前置知识

本课程面向有一定 STM32 基础的读者：

- **进行中的框架课程**：LVGL（产品界面）、FreeRTOS（原理深入）、lwIP（全栈）三门课程进行中
- **STM32 基础**：STM32F407 裸机熟练，工程含 FATFS、DAC 波形、letter-shell
- **课程组织方式**：基于 `参考文档/other/` 下 9 份零散文档，按主题模块重组为 20 课，覆盖构建调试 / 代码规范 / 多媒体格式 / CAN 总线
- **风险提示**：文档来源风格差异大（正点原子中文技术文档 / ISO 标准英文原版 / 瑞萨官方教程 / 网络文章），课程统一为工程化中文表述，英文文档术语翻译需注意准确性

## 课程目录

每课一个独立页面，含知识讲解 + 源码/格式分析 + 自测 + 真机练习。

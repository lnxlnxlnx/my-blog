# FreeRTOS 课程总览

FreeRTOS 实时操作系统（原理 + 产品多任务化）——STM32F407 探索者 · 主线教材：正点原子《FreeRTOS 开发指南 V1.12》（FreeRTOS V10.4.6）· 原理深入型。**课程使命：**系统掌握 FreeRTOS 内核原理（调度、同步、通信、内存管理），并把 LVGL 产品界面多任务化。

## 前置知识

- **已具备**：STM32F407 探索者裸机开发熟练（当前工程含 LVGL 产品界面、FATFS、letter-shell）；LVGL 课程进行中；另一个 git 分支上有 FreeRTOS 工程；课程要求「原理深入型」，使命为产品多任务化 + 系统掌握 RTOS 原理。
- **对课程的影响**：起点跳过 C/STM32 基础；练习全部落在 FreeRTOS 分支工程（当前分支不动）；第 5/6/7 课（列表、启动流程、任务切换）按教材第 7/8/9 章逐行源码分析；第 17 课综合项目与 LVGL 课程第 12 课衔接（LVGL 跑在 FreeRTOS 上）。
- **风险提示**：裸机思维固化（顺序执行 + 中断）是最大门槛，RTOS 的「并发 / 阻塞 / 优先级抢占」是常见思维难点，课程练习特意设计对比实验（裸机 vs RTOS 同一场景）来跨越。

## 课程目录

课程共 17 课，按教材 20 章重组为五个阶段。每课一个独立页面，含知识讲解 + 源码分析 + 自测 + 真机练习（练习在 FreeRTOS 分支工程上进行）。

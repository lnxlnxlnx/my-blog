# 从 STM32 到 ESP32:开发模型

你已经会 STM32 + C。这一课只做一件事:**把你知道的 STM32 开发模型,翻译成 ESP32 的世界**。翻译通了,后面看 xiaozhi 的代码就顺了。

## 知识点 1:入口函数——main() 变成 app_main()

STM32 里你写 `main()`,然后自己管理 `while(1)` 和中断。ESP-IDF 里入口是 `app_main()`,它**由系统调用**,而且返回后程序并不会退出——FreeRTOS 调度器已经接管了一切。

```c
// STM32:你熟悉的写法
int main(void) {
    HAL_Init();
    while (1) {
        HAL_Delay(500);
    }
}
```

```c
// ESP-IDF:入口换了个名字,而且不用 while(1)
void app_main(void) {
    xTaskCreate(task_led, "led", 2048, NULL, 5, NULL);
    // app_main 返回后,任务继续跑
}
```

关键点:`app_main` 里几乎全是「**创建任务 + 订阅事件**」,不做长时间循环。这就是为什么 xiaozhi 的 `app_main` 看起来"什么都没干"——它把活都交给了任务。

## 知识点 2:工程组织——从"工程"到"组件"

STM32 工程里,文件按功能摊开;IDF 里一切按**组件(component)**组织。每个组件 = 一个目录,有自己的 `CMakeLists.txt`,可以被多个项目复用。

```text
my_project/
├── CMakeLists.txt          # 项目入口:PROJECT(my_project)
├── main/
│   ├── CMakeLists.txt      # 声明 main 组件
│   └── main.c              # app_main() 在这
├── sdkconfig               # menuconfig 产物(自动生成,不进 git)
└── components/             # 可选:自己拆的组件
```

看 xiaozhi 时你会发现它把 `boards/`、`audio/`、`protocols/` 都拆成了组件——这就是 IDF 的模块化。

## 知识点 3:配置——CubeMX 变 menuconfig

CubeMX 图形化配置引脚/时钟,生成代码;IDF 用 `menuconfig`(Kconfig)在终端里配,产物是纯文本 `sdkconfig`——**文本才能进 git、能 diff**。选开发板、开蓝牙、定分区表,全在这。

## 动手实践

用你仓库里现成的 `basic_routines/00_basic`(点灯例程):

```bash
cd ~/mcu_study/esp_study/basic_routines/00_basic
source ~/esp/esp-idf-v5.5-rc1/export.sh
idf.py set-target esp32s3
idf.py -p /dev/ttyUSB0 flash monitor
```

预期串口日志出现 `hello world` 和周期性打印。然后打开 `main/main.c`,**找出三个 API**:GPIO 初始化、延时、日志打印分别调用了什么函数?写下来,下一课逐个翻译成 STM32 术语。

## 测验

### 测验 1
ESP-IDF 的代码入口函数叫什么?
- A. app_main(正确)
- B. main
- C. setup

<details>
<summary>答案与解析</summary>

**答案：A**。app_main(),由系统调用;返回后 FreeRTOS 调度器继续跑。
</details>

### 测验 2
menuconfig 生成的配置文件是?
- A. sdkconfig(正确)
- B. config.h
- C. cube.ini

<details>
<summary>答案与解析</summary>

**答案：A**。sdkconfig,纯文本,可以进 git、可以 diff。
</details>

### 测验 3
看 xiaozhi 时,最该先认识的组件目录是?
- A. boards(正确)
- B. utils
- C. docs

<details>
<summary>答案与解析</summary>

**答案：A**。boards/,每块开发板一个目录,是"看懂板级抽象"的入口。
</details>

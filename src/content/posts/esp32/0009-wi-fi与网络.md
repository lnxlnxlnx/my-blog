# Wi-Fi 与网络

这是 ESP-IDF 课程系列笔记的第 9 课(预计 20 分钟)。STM32 接网是外挂模块 + 透传指令;ESP32 是**片上 Wi-Fi**,而且 API 是"事件驱动"的——连上、断开都有事件。这一课打通:**初始化 → 事件回调 → 配网 → TCP/HTTP**,这是 xiaozhi 一切网络功能的地基。

## 知识点 1:初始化三步

```c
esp_netif_init();                       // 1. TCP/IP 协议栈
esp_event_loop_create_default();        // 2. 事件循环
esp_wifi_init(&wifi_cfg);               // 3. Wi-Fi 驱动
```

## 知识点 2:事件驱动连接

```c
esp_event_handler_register(WIFI_EVENT, ESP_EVENT_ANY_ID, wifi_handler, NULL);
esp_event_handler_register(IP_EVENT, IP_EVENT_STA_GOT_IP, got_ip_handler, NULL);
// 连上+拿到 IP 后,才敢去连服务器——这就是 xiaozhi 的启动顺序
```

## 知识点 3:配网与 HTTP

xiaozhi 支持两种配网:热点配网(Hotspot,设备自己开 AP 让你填 WiFi)和 BluFi(BLE 配网)。配好密码存 NVS。网络层收发用 lwIP;HTTP 用 `esp_http_client`;WebSocket 有 `esp_websocket_client`——xiaozhi 的 `websocket_protocol.cc` 就是用它。

## 动手实践

打开 `xiaozhi-esp32-2.2.4/main/protocols/websocket_protocol.cc`,**搜 `esp_websocket_client` 和事件回调**,画出"连接→断线重连"的事件流。再在 `main/application.cc` 找 Wi-Fi 事件处理的注册位置。

## 测验

### 测验 1
拿到 IP 的事件是?
- A. IP_EVENT_STA_GOT_IP(正确)
- B. WIFI_EVENT
- C. SC_EVENT

<details>
<summary>答案与解析</summary>

**答案：A**。IP_EVENT_STA_GOT_IP,拿到 IP 才能连服务器。
</details>

### 测验 2
xiaozhi 默认配网方式是?
- A. 热点配网(正确)
- B. 串口配网
- C. SD卡配网

<details>
<summary>答案与解析</summary>

**答案：A**。Hotspot(设备开热点)为主,也可开 BluFi。
</details>

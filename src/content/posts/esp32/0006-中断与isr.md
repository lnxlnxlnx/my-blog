# 中断与 ISR

STM32 里你用 EXTI + NVIC,中断服务函数里"尽量少干活"。ESP32 的规则一样,但注册方式不同:**一切通过 driver 的 ISR 注册接口**,而且 ISR 里不能直接用 FreeRTOS API,要用 `...FromISR` 版本。

## 知识点 1:GPIO 中断注册

```c
// 配置时带上中断类型
gpio_config_t io = {
    .pin_bit_mask = 1ULL << GPIO_NUM_0,
    .mode = GPIO_MODE_INPUT,
    .pull_up_en = GPIO_PULLUP_ENABLE,
    .intr_type = GPIO_INTR_NEGEDGE,      // 下降沿
};
gpio_config(&io);
gpio_install_isr_service(0);            // 装 ISR 服务(一次)
gpio_isr_handler_add(GPIO_NUM_0, button_isr, NULL);
```

## 知识点 2:ISR 里只"通知",不"干活"

```c
static void button_isr(void *arg) {
    // 正确:往队列塞一个事件,让任务去处理
    BaseType_t woken = pdFALSE;
    xQueueSendFromISR(evt_queue, &evt, &woken);
    portYIELD_FROM_ISR(woken);
}
```

错误示范:在 ISR 里 `ESP_LOGI`、`printf`、长循环——都会拖垮系统。

## 知识点 3:和 STM32 的映射

| STM32 | ESP-IDF |
|-------|---------|
| EXTI_IRQHandler + HAL_GPIO_EXTI_Callback | gpio_isr_handler_add + 自写 ISR |
| NVIC 优先级分组 | esp_intr_alloc / driver 内部管理 |
| ISR 里置标志位 | xQueueSendFromISR / event group |

### 测验 1
ISR 里向任务传数据用什么?
- A. FromISR队列(正确)
- B. printf
- C. 长循环

<summary>答案与解析</summary>

**答案：A**。xQueueSendFromISR 等 FromISR 系列 API。
</details>

### 测验 2
GPIO 中断注册前的必调函数?

<details>
<summary>答案与解析</summary>

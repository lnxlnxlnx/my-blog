# NVS 与文件系统

这是 ESP-IDF 课程系列笔记的第 10 课(预计 15 分钟)。STM32 存配置靠 Flash 扇区 + 自建协议;ESP32 官方给了现成方案:**NVS(键值对)** 和 **SPIFFS(小文件系统)**。xiaozhi 的 WiFi 密码、OTA 地址、音量全在 NVS;语音资源在文件系统。

## 知识点 1:NVS(键值对存储)

```c
nvs_handle_t h;
nvs_open("storage", NVS_READWRITE, &h);
nvs_set_str(h, "ota_url", "http://192.168.3.20:8003/xiaozhi/ota/");
nvs_commit(h);                        // 别忘了提交
char url[128]; size_t len = sizeof(url);
nvs_get_str(h, "ota_url", url, &len);
```

所有 app 启动第一件事几乎都是 `nvs_flash_init()`(你已在 00_basic 见过)。xiaozhi 的 `settings.cc` 就是 NVS 的封装——`GetString/SetString`。

## 知识点 2:SPIFFS / LittleFS 文件系统

需要"文件"时(图片、音频、JSON),挂一个分区做文件系统:

```c
esp_vfs_spiffs_register(&conf);        // 挂载后就能 fopen() 了
FILE *f = fopen("/spiffs/hello.txt", "r");
```

xiaozhi 的 assets(唤醒词、提示音、表情图)用生成脚本打包成 `generated_assets.bin`,烧进专用分区。

## 动手实践

打开 `basic_routines/27_spiffs` 例程:找到挂载代码,往 `/spiffs` 写个文件再读出来。然后去 xiaozhi `main/settings.cc` 看 `ota_url` 是怎么读写、默认值从哪来(`CONFIG_OTA_URL`)。

## 测验

### 测验 1
NVS 写完后必须调用?
- A. nvs_commit(正确)
- B. nvs_flush
- C. nvs_sync

<details>
<summary>答案与解析</summary>

**答案：A**。nvs_commit,否则可能不落盘。
</details>

### 测验 2
xiaozhi 的 ota_url 存在哪?
- A. NVS(正确)
- B. SPIFFS
- C. RAM

<details>
<summary>答案与解析</summary>

**答案：A**。NVS(settings.cc 封装),所以配网页面能改。
</details>

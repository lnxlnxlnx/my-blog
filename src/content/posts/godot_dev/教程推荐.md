# Godot 引擎学习与资源汇总指南
本文档整合了 Godot 引擎入门所需的教程、创作必备的资源以及开源参考项目，为不同阶段的开发者提供清晰、可落地的学习与创作路径，助力高效掌握 Godot 游戏开发。


## 一、Godot 入门与进阶教程
### 1. 官方文档：基础权威参考
- **教程名称**：Godot Engine 4.5 简体中文文档  
- **链接**：[https://docs.godotengine.org/zh-cn/4.x/](https://docs.godotengine.org/zh-cn/4.x/)  
- **特点**：  
  - 社区翻译的官方文档，涵盖引擎核心功能、类参考、工具使用等基础内容，支持离线下载（HTML/EPUB 格式，每周一更新）。  
  - 适合作为入门初期的“字典”，搭配其他教程同步查阅，确保知识的准确性。

## 三、开源游戏参考项目
- **项目名称**：开源视频游戏与商业游戏开源重制版列表  
- **链接**：[https://github.com/bobeff/open-source-games](https://github.com/bobeff/open-source-games)  
- **内容亮点**：  
  - 按游戏类型分类（如动作、冒险、策略、Roguelike），包含经典游戏的开源重制版（如《超级马里奥64》《毁灭战士》《文明V》）。  
  - 部分项目基于 Godot 引擎开发（如 3D 多人FPS《Liblast》），可直接查看源码学习核心逻辑（如网络同步、物理碰撞）。  


## 四、Godot 官方资源库
- **资源库名称**：Godot Asset Library  
- **链接**：[https://godotengine.org/asset-library/asset](https://godotengine.org/asset-library/asset)  
- **功能价值**：  
  - 官方收录的引擎插件、模板、演示项目，支持按“版本”“类型”筛选（如 4.5 版本的 2D 工具、3D 插件）。  
  - 热门资源包括：  
    - **工具类**：GD-Sync（多人同步插件）、Subtitles Importer（字幕导入工具）、AI Assistant Hub（AI辅助开发工具）。  
    - **模板类**：Godot 3D 多人游戏模板、2D 卡牌游戏模板。  
    - **特效类**：3D Planet Generator（星球生成器）、Surface-Stable Fractal Dithering（分形抖动着色器）。

# AGENTS.md

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues, driven via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five canonical labels are used as-is: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout — a root `CONTEXT.md` plus `docs/adr/`. See `docs/agents/domain.md`.
